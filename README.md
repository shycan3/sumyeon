# 수면 — 심층 원정 프로토타입

《수면》은 네 명의 동료가 하나의 덱을 공유하는 원정형 카드 전술 게임 프로토타입입니다. 플레이어는 카드, 실행자, 대상을 선택해 전투에 개입하고, 적의 공개된 행동을 읽으며 원정의 경로와 보상을 결정합니다. 전투 자동 운영도 제공해 카드·실행자·대상 판단을 관전할 수 있습니다.

현재 플레이 버전은 `prototype/party-expedition.html`입니다. 이전 시스템과 실험은 `prototype/` 안에 보존되어 있으며, 최신 플레이 버전과 구분해서 보세요.

## 실행

Python 3가 설치되어 있다면 저장소 루트에서 다음 명령을 실행한 뒤 브라우저에서 `http://localhost:8765/prototype/party-expedition.html`을 여세요.

```powershell
python -m http.server 8765
```

게임은 정적 HTML/CSS/JavaScript로 동작하며 별도 패키지 설치가 필요하지 않습니다. 진행 저장은 현재 브라우저의 로컬 저장소에 기록됩니다.

## 현재 플레이 버전의 규칙

- 4인 파티, 6개 문양 중 편성, 공용 덱과 공용 손패
- 카드 계열 5종: 돌파·수호·교란·순환·정비
- 카드 → 실행자 → 대상 순서로 선택하며, 모든 동료가 모든 계열 카드를 실행할 수 있음
- 시작 에너지 4, 남은 에너지 이월 후 2 회복, 최대 5; 기본 손패 5장
- 동료별 지속 특성과 카드 실행 특성, 카드 연계 및 강화
- 적 행동·표적을 미리 공개하고, 지원·다중 표적·준비 공격·단계 전환을 갖춘 적과 보스
- 분기 원정 지도, 전투·강적·정박지·상점·사건·최심부, 카드 보상과 보상 건너뛰기
- 원정 유물과 전술 도구, 선택형 브레이크 규칙, 전투 자동 운영과 수동 개입

이 버전은 과거 20장 덱/다른 에너지 규칙의 시제품과 다릅니다. 이전 프로토타입 문서를 볼 때는 해당 문서의 작성 시점과 버전을 확인하세요.

## 진행 요약과 다음 작업

2026-10-10 기준, 핵심 전투·원정 흐름과 자동 원정 시뮬레이션, 로그·결과 분석, 1차 적 밸런스 조정이 구현·기록되어 있습니다. 실제 재미와 이해도는 자동 시뮬레이션 승률만으로 확정하지 않으며, 사용자의 플레이 관찰과 함께 판단합니다.

가장 최근 관찰에서 확인된 강점은 적 행동을 살피고 카드와 실행자를 골라 상황을 푸는 재미입니다. 남은 핵심 과제는 캐릭터 역할과 두 특성이 직관적으로 읽히는지, 카드 연계가 전술 선택으로 느껴지는지, 공격 외의 대응이 유효한 전투가 충분한지 검증하는 것입니다.

다음 우선순위는 전투·역할·카드·경로의 새 시스템을 무작정 추가하는 것이 아니라, 현재 규칙이 플레이어에게 명확한 선택을 제공하는지 확인하고 관찰 결과에 따라 소수의 변화를 적용하는 것입니다. 세부 근거는 [현재 개발 현황과 계획](docs/INDEX.md)에서 시작하세요.

## 검증

현재 심층 원정 규칙을 확인하는 주요 Node 검사 스크립트는 `prototype/party-expedition-*-check.cjs`입니다. 예를 들어 다음 검사를 실행할 수 있습니다.

```powershell
node prototype/party-expedition-rules-check.cjs
node prototype/party-expedition-integration-check.cjs
node prototype/party-expedition-onboarding-check.cjs
node prototype/party-expedition-auto-check.cjs
```

브라우저 자동화 검사는 Playwright/Chromium이 필요할 수 있으며, 개발 PC의 설치 경로를 가정하는 과거 검사가 포함되어 있습니다. 모든 옛 실험이 현재 플레이 버전과 호환되는 것은 아닙니다.

## 저장소 구성과 기록 범위

- `prototype/`: 현재 게임, 이전 실험 버전, 작성한 테스트 및 게임 에셋
- `docs/`: 설계, 플레이 관찰, 검증 결과, 의사결정의 기록
- `.gitignore`: 시뮬레이션 원시 로그, 테스트 결과 덤프, 로컬 진단 파일과 QA 스크린샷을 제외

검증의 요약과 해석은 문서에 보존하고, 재생성할 수 있는 대형 JSONL/CSV 원시 데이터와 화면 캡처는 저장소에 넣지 않습니다. 게임에서 사용하는 에셋은 `prototype/assets/`에 포함됩니다.
