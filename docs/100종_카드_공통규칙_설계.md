# 《수면》 100종 카드 설계와 구현 계약

2026-10-10 · 사용자 요청: 100종 역할·계열·연결 설계 → 공통 규칙 구현·검사 → 카드 구현 → 전체 보상·덱 다양성·자동 전투 검증.

## 기준

100종은 기본 카드 포함, 강화판과 기본 공격은 제외한다. 모든 카드는 4인 공용이며 소유자 조건을 두지 않는다. 계열은 돌파 25·수호 20·교란 20·순환 20·정비 15종. 혼합 효과도 주된 선택 목적에 따라 한 계열만 지정한다. 계열은 효과가 참조할 수 있는 실제 데이터이며 보존·소진·지속·X코스트·선택은 별도 규칙이다.

전체의 명시적 설계 원본은 `prototype/party-expedition-catalog.js`다. 기존 30종의 계열과 신규 70종 각각의 이름·비용·효과·역할·연결 관계를 기록한다. 이 파일의 존재는 실행 엔진 구현 완료를 뜻하지 않으며 공통 규칙 검사 이후 연결한다.

## 공통 규칙 계약

- 보존: 미사용 카드 사본은 라운드 종료 때 손패에 남는다. 다음 라운드 손패 공급의 일부를 차지하며 추가 손패가 아니다. 인양으로 이미 사용한 카드를 보관하는 규칙과 구분한다. 보존 여부 때문에 인양 할인 유효기간이 연장되지는 않는다.
- 지속: 카드 사용 시 효과를 이번 전투의 파티 효과로 설치하고 해당 사본은 소진 영역에 둔다. 설치 자체로 자신의 발동 조건을 만족시키지 않는다. 캐릭터가 쓰러져도 설치된 파티 효과는 유지한다. 전투를 새로 시작하면 초기화한다. 동일 효과 중첩은 공개된 최대 수치를 사용해 무한 누적을 피한다.
- X코스트: 사용 전 현재 에너지를 전부 지불하고 그 값으로 명시된 효과를 배수 적용한다. X=0은 사용 불가. 인계 할인은 X에 적용하지 않는다. 인쇄 비용 2 이상을 참조하는 도선사의 지속 효과는 X카드에 적용하지 않는다. 실제 지불과 앞선 지출 조건은 일반 유료 카드 규칙을 사용한다.
- 선택: 손패 카드 → 효과 선택 → 실행자 → 대상. 선택지는 각각 대상 종류와 효과를 갖는다. 선택하지 않은 카드는 실행하지 않는다. 미리보기·실행·자동 판단은 같은 선택 인덱스를 사용한다. 효과 선택은 자원·RNG·손패를 변경하지 않는다. 취소 가능.
- 연타: 노출·교대·브레이크 추가 피해는 기존 규칙처럼 첫 직접 타격 한 번에 적용한다. 각 타격은 실제 HP·보호를 순서대로 처리하며 적이 쓰러지면 멈춘다.
- 기존 보호·약화 활용: 조건은 카드 사용 전 상태로 평가한다. 카드가 뒤늦게 만들거나 실행 특성이 제공한 보호·약화로 같은 카드의 조건을 소급 만족시키지 않는다.
- 다음 라운드 준비: 에너지와 보호의 예약은 표시·저장한다. 생존 중인 실행자에게 다음 라운드 보호를 적용하고, 에너지는 기존 최대 5를 지킨다. 예약으로 최대 에너지 자체를 늘리지 않는다.
- 계열 회수: 버림더미에서 해당 계열의 가장 최근 실제 사본 한 장을 손패로 옮긴다. 임의 복제·강화·삭제는 하지 않는다. 없으면 회수 없이 나머지 효과를 실행한다.
- 지속 발동: 매 라운드 전원 보호·회복·에너지와 라운드 첫 순환/소진의 드로우를 명시한다. 전투 시작 라운드에는 아직 설치하지 않은 지속 효과가 없다. 카드 보호에 반격 부여는 카드의 보호 효과와 함께 적용하며 지속이 다시 자신을 발동시키지 않는다.

## 보상과 호환

새 콘텐츠 버전에서만 100종 전체 보상 풀을 사용한다. 기존 원정의 이미 제시된 보상·미래 RNG와 재도전 풀은 유지한다. 새 풀은 같은 희귀 카드 정답을 강제하지 않으며 공격/생존/도구의 선택 구조를 유지한다. 같은 사본 복수 획득은 허용하되 제시된 세 후보의 중복을 피한다. 이전 카드의 실제 수치는 우선 보존하고 신규 효과의 의미·설명·강화 차이를 일치시킨다.

## 검증 기준

1. 100개 고유 ID·이름·계열 매핑. 강화판은 종류 수에 미포함. 역할과 연결의 누락 없음.
2. 각 공통 규칙의 정상·경계·잘못된 입력·저장 복원·미리보기 비변경 검사.
3. 100종 일반/강화 전부 합법 실행, 모든 선택지·X값·보존·지속 검사. 카드 영역과 사본 수 불변.
4. 실제 자동 전투를 사용하는 반복 원정에서 경로·보상만 검사 정책이 선택. 카드 사용은 자동 전투 모듈의 선택 그대로 수행.
5. 전체 보상 접근 가능성, 최종 덱 차이, 카드 사용 분포, 승패·생존·전투 길이, 판단 시간과 최대 지연을 기록한다. 자동 승률은 사람의 재미 증거가 아니다.
6. 특정 카드가 대부분의 상황에서 다른 카드를 대체하거나 선택형의 한 갈래가 늘 지배하면 수정하고 관련 표본을 다시 검사한다. 단순 수치가 높은 카드만으로 확장하지 않는다.
7. 사용자 현재 원정은 직접 진행하지 않는다. 독립 QA에서 자동 전투로 진행하고 경로·보상만 선택한다.

현재 상태: 100종 설계·공통 규칙·신규70종 제품 연결·일반/강화·선택 UI·계열 표시·전체 보상·자동 판단 구현을 완료했다. 2,520건 전 카드 실행 및 저장 검사와 제품 자동 전투 120회 원정으로 보상·덱 다양성·성능을 확인하고 중복/압도 카드와 자원 순환을 수정했다. 브라우저 독립 QA 완주·지속 표시·좁은 화면·사용자 기존 저장 보존도 확인했다. 상세 증거와 한계는 [100종 구현·검증](100종_카드_구현_검증.md)을 따른다. 사람의 재미 관문은 기술 완료와 구분한다.
