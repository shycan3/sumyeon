# 《수면》 공용 카드 100종 구현·검증

2026-10-10. 사용자 목표 1~4의 구현 결과. 기술 검증과 자동 플레이 관찰은 사람의 재미·최종 밸런스 판정을 대신하지 않는다.

## 구현 범위

기존 30종과 신규 70종으로 공용 카드 100종을 연결했다. 기본 공격과 강화판은 별도 종류로 세지 않는다. 계열은 돌파 25·수호 20·교란 20·순환 20·정비 15종이며 캐릭터 사용 제한은 없다. 전부 역할과 연결 관계를 갖는다. [실제 100종 목록](공용_카드_100종_목록.md)은 게임 정의에서 생성한다.

- 보존: 미사용 실제 사본을 다음 손패에 남기며 정상 공급의 일부를 차지한다. 사용 후 인양 보관과 구분한다.
- 지속: 이번 전투에 효과를 설치하고 카드 사본은 소진한다. 설치 자체로 자기 조건을 발동하지 않는다. 동일 효과는 큰 값만 적용하며 새 전투에서 초기화한다.
- X: 현재 에너지를 전부 사용한다. 0은 사용 불가이고 인계 할인·인쇄 비용 2 이상 조건에는 해당하지 않는다.
- 선택형: 카드 → 효과 → 실행자 → 대상. 선택 전 실행을 거부하고 미리보기·실행·자동 전투가 같은 분기를 사용한다. 소진 여부도 선택한 효과를 따른다.

연타·사용 전 보호/약화 조건·다음 라운드 예약·계열별 실제 사본 회수도 구현했다. 지속과 예약은 전투 화면에 표시한다. 손패와 덱·보상에 계열을 표시하고, 덱 창의 ‘전체 카드 보기’에서 일반·강화·목적을 계열별로 조회할 수 있다. 균형 탐사는 브레이크 사용 시에만 적용되는 균형 감소를 설명한다.

신규 원정은 `cards100-1` 전체 풀을 사용한다. 전투 보상은 돌파, 수호, 교란/순환/정비에서 각 한 장씩 제시한다. 모든 카드가 제시될 수 있으며 후보 중복은 없다. 기존 원정과 같은 조건 재도전은 이전 풀·RNG를 유지한다. 기존 카드의 전투 수치를 변경하지 않았다.

## 자동 원정 결과와 성능

`prototype/party-expedition-100-check.cjs`는 제품의 `party-expedition-auto.js`로만 전투 행동을 결정한다. 검사 정책은 경로·보상·정비만 선택한다. 기본 10장 덱으로 시작하며 3편성 × 브레이크 2조건 × 보상 선호 5종 × 4시드로 120회를 실행했다. 편성별 시드를 달리해 12개의 원정 시드를 사용하며 같은 편성·브레이크·시드의 보상 정책은 비교 가능하다.

결과 파일: `prototype/party-expedition-100-results.json`.

- 116승·4패; 종료하지 않는 원정 없음.
- 카드 구성 기준 최종 덱 61가지. 총 95종 획득, 수집 카드 81종과 기본 공격 사용.
- 자동 판단 12,737회. p50 3.58ms·p95 10.38ms·p99 12.84ms·최대 18.83ms. 로컬 Node의 판단 함수 측정이며 화면 연출·전체 프레임 시간은 포함하지 않는다.
- 모든 100종은 보상 검사에서 실제 제시됐지만, 이 120회 정책 표본이 모든 카드를 획득·사용하지는 않았다.

## 중복·압도 카드 수정

선택 유연성과 보존이 기존 단일 목적 카드를 무조건 대체하지 않도록 조정했다. 두 갈래 진격의 집중/광역 피해, 갈림 방벽의 집중 보호, 구조 판단의 회복/보호, 침묵 사슬의 약화, 나선 관통의 연타 피해를 낮췄다. 간직한 해법은 보존 드로우의 비용을 높였다. 교차 베기는 약화된 적에 대한 연타 역할을 부여했다.

갈림길의 에너지 분기는 소진한다. 실제 사본 회수로 무한 자원 순환을 만들지 않도록 한 것이다. 구조 판단의 회복 분기도 소진해 기존 응급 처치의 역할을 보존한다. 일반/강화 모두 검사했다. 자동이 긴급 회복·에너지 분기·지속 설치를 실제 선택하고 실행하는 별도 상황 검사도 통과했다.

시드 범위를 확장하기 전 기준 결과와 수정 전 동일 표본 결과는 각각 baseline/prebalance 결과 파일에 보존했다. 덱 종류 33→61은 시드 확대의 영향이며 카드 수정 성과로 해석하지 않는다. 동일 표본 수정 전후는 모두 116승·61가지 덱이다.

## 브라우저 확인

저장과 분리된 QA에서 전투는 자동 기능에 맡기고 경로·보상·구매·강화만 선택해 파수꾼까지 8전투를 완료했다. 최종 덱 18장, 생존 동료 3명. 이 QA는 신규 규칙을 보려는 샘플 시작 덱을 사용했고, 정상 시작 덱의 원정 증거는 위 120회 검사다.

지속 QA에서 자동이 불침번과 반향 장막을 설치하고 이후 라운드에 보호·반격 효과가 화면에 표시됨을 확인했다. 선택형 두 분기와 안내를 확인했다. 390×844·320×740의 좁은 화면에서 문구·버튼이 겹치지 않고 문서 가로 넘침이 없었다. 손패는 의도적으로 가로 스크롤한다. 검사 후 뷰포트 설정을 해제했다.

사용자 탭을 새로고침해 1구역·1라운드, 에너지 4, 사냥꾼 HP26, 동료 HP30, 기존 다섯 손패와 카드 영역 수가 보존됨을 확인했다. 사용자 전투를 진행하거나 원정을 초기화하지 않았다. 새 도감의 100종과 콘솔 오류 없음도 확인했다.

## 남은 평가

기술 구현 목표 1~4는 완료했다. 자동의 높은 승률은 사람의 재미나 모든 편성의 동등한 가치를 증명하지 않는다. 자동이 드물게 고른 카드와 지속 빌드의 실전 선택 가치는 다음 사람 원정에서 관찰할 대상이다. P0~P6의 재미 관문은 별도이며 수치 결과만으로 통과 처리하지 않는다.
