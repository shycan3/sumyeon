# 1차 밸런스 패치 · 예고를 읽고 대응하는 기회

적용 규칙: `voyage-balance-1`. 기존 684원정·4,845전투의 기록을 검토하고 적 패턴과 보상 후보 두 곳을 변경했다. 목표는 예고를 보고 처치·약화·보호·다음 행동 준비를 고를 기회를 늘리는 것이다. 자동 승률을 특정 값으로 맞추는 패치가 아니다.

## 실제 변경

| 대상 | 기존 | 1차 패치 | 근거 |
|---|---|---|---|
| 정예 분열된 감시자 | 1턴 공격 → 2턴 약한 공격 → 3턴 광역 준비 → 4턴 광역 | 1턴 공격 → 2턴 광역 준비 → 3턴 광역 → 4턴 약한 공격 | coverage-450의 4구역 105전투 중 광역 공개 6·적용 3, 7구역 114전투 중 공개 24·적용 11. 핵심 패턴이 전투 종료 뒤에 몰림 |
| 브레이크 끔의 균형 탐사 | 보상·상점·사건 후보에 등장 | 해당 후보에서 제외 | 비용 1·피해 3·균형 감소 3 중 핵심 균형 감소가 꺼진 규칙에서는 작동하지 않음. 450회 표본의 제시 148회·채택 0회는 보조 관찰 |

감시자의 HP·단일 피해·광역 피해는 유지한다. 4턴 주기의 명목 피해 총량도 동일하다. 준비 뒤 다음 라운드에 실행한다는 공개 규칙과 대응 시간을 보존했다. 변경 범위는 **정예 조우**이며 해류의 심장에 동행하는 감시자는 기존 순서를 유지한다.

균형 탐사의 카드 효과와 강화는 바꾸지 않았다. 브레이크를 사용하면 계속 등장한다. 후보 필터 뒤에도 희귀도 추첨·희귀 확률 보정·보상 난수 소비량은 동일하다. 후보 목록이 달라져 같은 난수의 카드 종류와 이후 성장 선택은 달라질 수 있다.

캐릭터 능력·에너지 회복·기존 카드 수치·유물·회복 경제·두 보스 및 전투 오토 판단은 변경하지 않았다. 낮은 사용률만으로 지속·회수 카드를 약하다고 판정할 근거가 부족했다. 파수꾼의 높은 부담은 실제로 관찰됐지만 진입 덱과 자동 표적 선택의 영향을 분리할 필요가 있다.

## 같은 전투 상태의 패턴 대조

원본 로그에서 정예 감시자 진입 상태를 실제 Run 명령으로 복원했다. 동일한 전체 상태를 복제하고 밸런스 버전·정예 표식만 바꿨다. 카드·HP·적·유물·도구·에너지·난수·뽑기 순서는 같다. 원본 명령과 기존 자동 정책의 종료 재현도 확인했다.

4·7구역 각각 6건, 각 구역 균형·공세·신중 2건씩, 구역별 서로 다른 6편성을 선택했다. 원본 승패나 패치 결과로 사례를 선별하지 않았다. 후속 보상은 진행하지 않고 전투 종료에서 비교한다.

| 12건 대조 | 기존 | 패치 |
|---|---:|---:|
| 승리 / 패배 | 12 / 0 | 12 / 0 |
| 광역 준비를 본 전투 | 7 | 12 |
| 광역 공격 예고를 본 전투 | 2 | 8 |
| 실제 광역 적용이 확인된 전투 | 1 | 2 |
| 실제 HP 피해 합계 | 59 | 59 |
| 쓰러짐 | 0 | 0 |
| 카드 사용 합계 | 89 | 92 |
| 라운드 합계 | 38 | 41 |

예고를 보고 대응할 기회가 늘었다는 좁은 해석을 지지한다. 한 사례의 피해는 1→29로 증가했으므로 모든 편성의 부담이 같은 것은 아니다. 같은 정책도 바뀐 의도에 맞춰 후속 카드·실행자·대상을 다르게 선택한다. 사람의 재미나 대표 승률을 증명하지 않는다. 이 24전투는 별도 진단이며 원정 승률 표본에 합산하지 않는다.

## 전체 원정 비교와 새 시드 확인

일반 난이도·브레이크 끔·전체 15편성·세 정책·같은 상한에서 전후 각각 90회씩 실행했다. 새로운 시드에서도 전후 각각 90회씩 실행했다. 총 **360원정·2,490전투**, 중단·오류·HP 검산 불일치 0이다. 기존 684회 자료와 합산하지 않고 조건별 비교로 보존한다.

| 조건 | 기존 규칙 원정 승패 | 패치 원정 승패 | 양쪽 전투 수 |
|---|---:|---:|---:|
| 개발 비교: 시드 31~32 | 89승·1패 | 85승·5패 | 각각 630 |
| 새 시드: 51~52 | 89승·1패 | 89승·1패 | 각각 615 |

개발 비교에서 정예 감시자의 광역 예고를 본 전투는 5→25, 적용 전투는 4→9였다. 새 시드의 4구역은 광역 예고 0→13·적용 0→4, 7구역은 예고 4→17·적용 0→3이었다. 해당 정예전의 패배·쓰러짐은 모두 0이었다.

개발 비교의 신규 패배 4건은 모두 파수꾼전이고 진입 덱도 달라졌다. 새 시드에서는 신규 패배 증가가 반복되지 않았다. 보상 후보의 변화가 경로·덱 성장·후속 난수 소비에도 영향을 주므로 원정 전체의 차이를 감시자 패턴 하나의 효과로 단정하지 않는다. 새 시드도 두 시드뿐이며 다양한 편성이 시드의 다양성을 대신하지 않는다.

새 시드 52의 유일한 패배는 양쪽 모두 신중 정책의 항해사·도선사·측심사·인양사였다. 관측자는 HP 18을 끝까지 유지하고 공격은 파수꾼에게 집중됐다. 이전 시드 32와 같은 오토 표적 선택 양상이 반복됐으므로, 보스 수치와 자동 판단을 별도로 조사한다.

## 저장·재생·적용

- 새 원정과 새 연구실 배치는 `voyage-balance-1`을 기록한다. 페이지를 새로고침한 뒤 **새 원정**을 시작하면 적용된다.
- 진행 중인 저장은 덱·HP·지도·후보·공개된 적 행동을 그대로 보존한다. 버전이 없는 저장은 기존 규칙으로 이어진다.
- 과거 명령 로그의 재생은 누락된 버전을 `voyage-balance-0`으로 해석한다. CLI의 `--balance legacy` / `--balance current`로 전후 규칙을 비교할 수 있다.
- 분석은 같은 소스에서도 밸런스 버전이 다르면 조건을 분리한다. 진단용 상태 복제 자료는 전체 원정 집계에서 제외한다.
- 게임 도움말의 ‘1차 밸런스 패치’에 적용 범위를 적었다. 전투 화면에 상시 안내문은 추가하지 않았다.

## 기술 검사와 브라우저 확인

신규 패치 검사 10건은 정확한 패턴·주기 피해·보스와 기존 저장의 보존·준비 저장과 실행·보호/약화/처치 대응·모드별 후보·희귀도와 난수 소비·과거 실제 로그 재생을 확인했다. 기존 원정 검사 25건, 수집기 검사 16건(9원정·66전투), 분석 및 비교 자기 검사도 통과했다.

독립 QA에서 실제 Run API로 정상 시작 덱부터 4구역 정예까지 진행했다. HP·덱·적·난수는 임의 변경하지 않았다. 2턴 준비, 3턴 광역 예고와 억제 사용 후 아군별 받을 피해 10→6을 브라우저에서 확인했고 콘솔 오류·경고는 없었다. 실제 원정 저장에는 쓰지 않는다.

## 이후 판단

직접 플레이에서는 정예의 2턴 준비를 본 순간 집중 처치·약화·보호·자원 이월 사이에서 다른 선택을 고민하는지 확인한다. 반복 보호가 의무 절차가 되거나 특정 희귀 카드가 입장권이 되면 재검토한다. 보스의 초반 동시 광역과 동행 적의 지속 압박, 오토의 여러 행동에 걸친 처치 가치는 분리해서 다음 패치를 판단한다. P0~P6의 재미 관문은 직접 플레이 관찰로 유지한다.
