## 현재 상태

현재 플레이 버전은 4인 파티가 공용 덱을 사용하고, 카드마다 실행자와 대상을 고르는 심층 원정입니다. 돌파·수호·교란·순환·정비 계열, 공개 적 의도, 카드 연계, 분기 지도, 보상·정비, 원정 유물·전술 도구, 자동 전투와 수동 개입을 갖추고 있습니다.

2026-10-10의 사용자 플레이에서는 파수꾼까지의 원정이 재미있고 상황에 따라 카드와 실행자를 고르는 판단이 좋았다는 평가가 있었습니다. 아쉬운 점은 캐릭터별 역할과 특성이 직관적으로 기억되지 않고, 카드가 자연스럽게 이어지는 연계가 더 필요하다는 점입니다. 이후에는 자동 승률보다 캐릭터 역할의 이해도, 연계가 만드는 전술 선택, 공격 외의 대응이 실제로 쓰이는지를 우선 검토합니다.
