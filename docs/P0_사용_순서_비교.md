## 목적과 조건

D에서 상황별 카드·실행자 재선택의 재미를 보고받았다. 남은 P0 우선 관찰은 카드 순서의 의미와 조작 피로다. 이를 위한 고정 전황 E를 추가하며 기존 A/B/C/D를 보존한다.

- 메뉴: 비교 E · 사용 순서.
- 라운드2, 에너지2. 이월·회복2·상한5를 기본 비교 규칙으로 사용한다.
- 버팀·추격·돌봄 HP30, 재현 HP8. 첫 카드 효과 모두 준비.
- 사냥꾼 HP10, 예고는 재현에게 피해12. 이후 같은 표적이 생존하면 계속 겨냥한다.
- 시작 손패: 타격1·보호3·억제1. 공용 덱 구성은 자유 전투와 동일한 타격4·보호4·견제1·억제1이며 초기 배치만 고정한다.
- 기존 카드 비용·기본 수치·고유 효과·에너지 규칙·조작 방식은 변경하지 않는다.

E 내부에서 다시 시작하면 같은 손패·HP·예고·시드로 돌아간다. B나 D와 순서만 달라진 표본은 아니며, 자연스러운 드로우를 대표하는 표본도 아니다. 순서의 결과 차이를 분리해서 관찰하는 도구다.

## 플레이 관찰 진행

두 카드의 실행자와 대상을 정해 사용한 뒤, 다시 시작해서 같은 행동을 반대 순서로 비교한다. 첫 실행 전에는 특정 카드·실행자·대상의 조합을 정답으로 알려주지 않는다. 모든 조합에서 순서에 따른 차이가 생기는 것은 아니며 차이가 없는 조합도 정상이다. 순서 차이를 발견했다면 어떤 효과 때문인지 플레이어의 설명을 받는다.

비교 이후 한 번에 묻는다:

1. 사용 순서를 바꾸면 무엇이 달라졌고, 왜 그렇다고 생각하는가?
2. 카드·실행자·대상을 고르는 과정이 판단에 도움이 되었는가? 반복 클릭·취소·대상 선택에서 번거로운 점은 무엇인가?

흥미로운 판단과 클릭 수를 구분한다. 빠른 승리나 서로 다른 클릭만으로 관문을 통과시키지 않는다. 특정 조합 발견은 기존 추격 효과의 이해이며, 다른 모든 카드 순서의 재미까지 일반화하지 않는다. E에서 짧게 조작한 소감과 D에서 여러 턴 반복한 피로도는 구분한다.
