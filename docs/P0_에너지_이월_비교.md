# P0 에너지 이월 비교

2026-10-09 / 상태: 비교용 규칙 구현·기술 검사 완료, 직접 플레이 재관찰 대기

사용자가 매턴 에너지4·비용1 카드·손패5 구조에서 대부분의 카드를 사용할 수 있어 선택이 빈약하다고 지적했다. 자동 회복 자체가 문제라고 확정하지 않고, 자원을 남길 의미가 있는 비교안을 구현했다. 기존 자유 전투와 전문성·브레이크 규칙을 그대로 사용한다.

## 두 규칙

| 항목 | 매턴 4 · 기존 기준 | 이월 · 회복 2 · 새 시험안 |
|---|---|---|
| 전투 시작 | 에너지4 | 에너지4 |
| 다음 플레이어 라운드 | 잔량 폐기 후4 | 잔량+2, 최대5 |
| 손패 | 5장까지 공급 | 동일 |
| 미사용 손패 | 라운드 종료 시 버림 | 동일 |
| 고유 효과 | 라운드마다 초기화 | 동일 |

시험안에서4를 모두 쓰면 다음2, 두 번 지출해2를 남기면 다음4, 한 번 지출해3을 남기면 다음5다. 쉬는 라운드에도 적이 행동하며 보호가 만료하므로 저장은 공짜 시간이 아니다. 전투가 이미 끝났다면 추가 라운드 회복은 실행하지 않는다.

새 브라우저 표본의 기본값은 이월 방식이다. 상단 에너지 규칙 선택기로 ‘매턴4’를 선택할 수 있다. **규칙을 변경하면 같은 시드·시나리오의 초기 상태로 전투를 재시작한다.** 중간 에너지만 변환하지 않는다. 덱·의도·시드 생성은 규칙 선택 자체의 영향을 받지 않는다.

에너지 옆에 현재 잔량과 지금 종료할 경우 다음 라운드 에너지를 표시한다. 이는 카드의 전체 턴 종료 예측이 아니라 확정된 자원 회복값이다. 이후 카드를 더 쓰면 수치가 갱신된다.

## 정보 표시 수정

적의 표시를 ‘→ 버팀 · 피해8’처럼 대상과 피해로 구분했다. 위협받는 아군에 이번 적 구간의 공격 합계와 현재 보호 적용 후 HP 피해를 표시한다. 죽은 적은 제외하고, 약화를 반영하며, 광역 공격은 모든 생존 대상에게 포함한다. 이 수치는 현재 공개 공격과 현재 보호 기준이며, 다음 라운드 의도·전투 전체 결과를 예측하지 않는다. 적 수치·도발·타깃 규칙·카드 효과는 변경하지 않았다.

두 에너지 모드 모두 같은 정보 표시를 사용한다. 이전 표본과 새 표본을 비교할 때는 정보 표시도 달라졌음을 고려한다. 에너지의 효과는 새 UI 내 모드 간 비교로 분리한다.

## 저장과 검사

새 저장 키 `sumyeon-party-v3-energy-v1`에 에너지 모드와 잔량을 포함해 저장한다. 기존 `sumyeon-party-v3-single` 저장은 그대로 보존한다. 새 키에 이어할 상태가 없으면 이월 모드의 자유 전투를 시작한다.

기존 규칙29개와 에너지10개, 총39개 자동 검사 통과. 이월·상한·실제5에너지 소비·잔여 손패 폐기·보관·난수 통제·미리보기 불변성·중간 복원·기존 모드 초기화를 검사했다. 실행: `node prototype/party-v3-check.cjs`, `node prototype/party-v3-energy-check.cjs`.

브라우저에서는 타격1장 사용 후 에너지3→다음5, 아군 보호4로 예고 피해8→실제 HP 위험4 표시, 새로고침 후5에너지 복원, 기존 방식 선택 시 재시작 및 다음4를 확인했다. 교차 압박에서 에너지4를 모두 사용한 뒤 다음 라운드2로 회복하고 보관 사본을 포함한 손패5장이 공급되는 것도 확인했다. 390×844에서 보호 실행자·대상 선택과 페이지 가로 넘침 없음을 확인하고, 1280×720에서 최종 표시를 확인했다. 이 검사 중 콘솔 오류·경고는 없었다. 화면 기록은 `prototype/p0-energy-desktop.png`, `prototype/p0-energy-mobile.png`다.

## 재관찰 기준

- 에너지를 남기거나 다 쓰는 이유를 공개 위협과 연결할 수 있는가?
- 보호·약화·처치를 위한 현재 지출과 다음 라운드의 준비 사이에 선택이 생기는가?
- 저장한5로 여러 카드를 사용하는 순간이 준비의 보상인가, 단순히 쉬었다가 전부 쓰는 반복인가?
- 부족한 에너지 때문에 선택이 흥미로워지는가, 행동할 수 없어 답답해지는가?
- 공격 카드만 기다린다는 기존 소감이 달라지는가? 위협 표시 개선과 자원 변경의 효과를 분리해 묻는다.

사용자의 ‘지금 바꾼 게 훨 낫겠는데?’는 구현 전 제안에 대한 선호·시험 승인으로 기록한다. 변경된 게임을 직접 플레이한 재미 검증 결과로 기록하지 않는다. P0는 계속 수정 후 재관찰 상태이며 P1로 넘어가지 않는다.

후속 직접 플레이에서 사용자는 ‘전술적인 판단이 필요해졌어’, ‘진짜 이게 훨씬 나아’라고 보고했다. 이월 방식을 P0 기본 시험안으로 유지할 긍정적 근거다. 구체적 선택 사례와 실행자·순서·조작 피로 관찰은 남아 있으며 P0 전체 통과를 뜻하지 않는다. 이번 변경에는 위협 표시 개선도 포함되어 있다.
