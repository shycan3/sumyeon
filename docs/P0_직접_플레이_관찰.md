# P0 직접 플레이 관찰 기록 양식

상태: **미실시 / 미기입**. 기술 검사 결과를 사람의 답변으로 대체하지 않는다.

## 진행

자유 전투로 조작을 익힌 뒤 같은 손패의 교차 압박·두꺼운 표적을 플레이한다. 비교 순서도 기록한다. 첫 선택 전에 정답이나 고유 효과의 유리한 활용법을 알려주지 않는다. 규칙 질문에 답했다면 어떤 도움을 주었는지 남긴다. 전문성·브레이크 개편안은 이 표본에 섞지 않는다.

행동 후 중립적으로 묻는다: “누구에게 맡겼고 왜 그렇게 했나요?”, “다른 순서라면 무엇이 달라질까요?”, “조건이 바뀐 뒤 계획을 유지하거나 바꾼 이유는 무엇인가요?”, “고민과 조작 중 어느 부분이 편하거나 번거로웠나요?” 플레이 도중 계속 질문해 호흡을 방해하지 않는다.
