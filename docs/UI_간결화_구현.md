# UI 간결화 — clearui1

레퍼런스: [Slay the Spire](https://store.steampowered.com/app/646570/Slay_the_Spire/)와 [Monster Train](https://www.themonstertrain.com/). 보상 선택/지도 스크린샷의 상태 요약, 중심 선택, 필요할 때 상세 정보를 보는 배치를 참고했다. 이미지를 복제하거나 외부 아트를 가져오지 않았다. 원정 카드의 효과·특성은 기존 카드 그림과 함께 유지한다.

- 거점: 원정 시작/이어하기와 기초 편성을 중심에 배치. 캐릭터 카드·공개 도전·실험실은 접기 영역.
- 지도: 6방 진행 → 4인 HP 요약 → 다음 방 선택 → 편성/방침/태세 → 특성/기록. 실제 선택 혜택과 비용은 항상 표시. 적 구성·전체 대응 설명/예고는 펼쳐보기. 모바일 첫 교전 버튼은 390×844에서 스크롤 없이 접근 가능.
- 특성: 단계·종류 수·다음 기준은 3칸 요약, 상세 효과와 구성은 펼쳐보기. 모바일에서 상세 효과를 열면 한 열로 확장해 긴 설명을 읽는다.
- 보상: 후보 카드와 넘기기가 먼저, 덱 특성/다음 교전은 뒤에. 카드 그림·효과·명령시간·특성·제안 목적을 유지. 교체 전 예상 종류 수를 표시하며 실제 교체에서는 빠지는 카드까지 비교한다.
- 진화: 같은 일반 카드를 묶고 사본 수 표시. 버튼은 한 사본만 진화한다. 진화와 릴레이의 선택 비용은 유지한다.
- 결과: 기여도 표는 기본 접기, 주요 위협·전술 결과·동일 조건 연습 버튼은 유지.

전투 규칙·저장 스키마·밸런스 수치는 변경하지 않았다. 전투 수동 도구는 기존 동작을 유지하며 도전의 오토 한정도 유지한다. 전체 UI/대규모 아트 개편의 완료를 뜻하지 않는다.

검증: `clear-ui-browser-check.cjs`에서 PC 1280/모바일 390의 실제 원정 출발, 주 선택 버튼 접근, 상세 규칙/태세 접근, 3후보 보상과 실제 교체, 사본 한 장 진화, 저장 복원을 검사한다. `character-browser-check.cjs`로 수동/자동 전투·완주·초기화·저장 내보내기/가져오기·구 저장을 확인하며, 도전/기여도/릴레이 브라우저 회귀 검사도 수행한다. 화면 스크린샷을 확인하고 가로 넘침과 브라우저 오류를 검사한다.
