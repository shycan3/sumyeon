# UI 리뷰 후속 수정

2026-10-07 · `character.html?v=refineui2`.

[refineui1 리뷰](refineui1_업데이트_리뷰.md)에서 확인한 네 문제를 수정하고, 편성 중 특성 변화 요약을 추가했다.

## 적용

- **일반/진화 식별:** 편성 목록에 일반·진화 배지를 실제로 표시한다. 같은 카드의 사본 그룹과 상세의 실제 진화 수치는 유지한다. 선택 여부는 행의 테두리와 aria-pressed로 구분한다.
- **전투 조회창:** 현재 손패·실험 도구·전투 기록·전황 상세를 하나의 제어기로 관리한다. 한 번에 하나만 열며, 같은 닫기 버튼과 Escape를 사용한다. 닫으면 해당 summary로 초점을 돌려준다. select에서 Escape를 눌러도 닫힌다. 열린 창은 모달이 아닌 조회 패널이며 전투 관전을 계속한다. 화면 전체를 모달처럼 어둡게 만드는 그림자는 제거했다.
- **상세 읽기 위치:** 수량 변경과 편집 초기화에서는 선택 카드 article의 실제 스크롤을 보존한다. 다른 카드를 선택하거나 필터로 선택 카드가 바뀌면 상세를 위에서부터 보여준다. 목록과 상세는 각각 하나의 스크롤 영역을 사용한다.
- **결과 사건 구분:** 아군 기여 장면은 최대 3개, 아군 전투불능의 첫 발생 장면은 최대 2개로 나눴다. 적 처치와 아군 전투불능을 구분하고, 피해 분담 중 쓰러진 경우도 표시한다. 적의 공격을 아군 카드의 기여로 연결하지 않는다.
- **행동 출처:** 신규 recap에 선택 필드 origin을 기록한다. 기본 행동·카드·적 행동·불명 출처를 구분한다. 과거 기록에서 출처가 없으면 미기록으로 표시하며 기본 행동이라고 단정하지 않는다. 저장 버전 2와 기존 선택 cardKey 필드는 유지한다.
- **특성 변화:** 편성 확정 버튼 옆/위에 호위·추격·공명의 종류 수와 단계를 항상 표시한다. 편집을 시작한 덱과 현재 편집 덱을 비교하고 단계 변화는 `1→0단계`, 종류 변화는 `3→2종`으로 표시한다. 같은 카드의 중복·진화 사본은 새 종류로 세지 않는다.
- **짧은 화면:** 수량 버튼을 짧게 표현하고 카드 이름을 포함한 접근성 이름은 유지한다. 844×390 편성에서는 글로벌 메뉴를 접고 편성 취소 버튼을 유지하며, 특성과 확정 버튼을 한 줄에 배치한다. 카드 식별과 효과·수치를 나란히 보여 상세를 읽을 공간을 확보한다.

실험 도구를 닫거나 다른 조회창으로 전환할 때의 오토 복귀와 현재 정지 상태 유지도 보존했다. 변경한 메타데이터는 기록용이며 피해·회복·AI 판단·난수 계산은 바꾸지 않았다.
