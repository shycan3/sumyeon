# 전투 시스템 개발 로드맵 v2.0

갱신일: 2026-10-07. 현재 제작 대상은 `prototype/character.html`의 세린 원정이다. 기존 캐릭터 중심 계획은 [v1.0 기록](개발_로드맵_v1.0_기록.md)으로 보존한다. 파티 확장은 뒤로 미루고 현재 4인·20장 덱·6개 방 안에서 시스템을 완성한다.

## 현재 판단

기본 행동·태세·다층 AI·수동/오토·명령 보유·공통 효과·행동 중단·카드 수명·관전 연출·복기·저장은 이미 있다. [최신 위험 구역 원정 통합](위험_구역_원정_통합.md)으로 이동 카드 획득·편성·진화와 최종 낙하 보스까지 연결했다. 이 기반을 다시 만드는 단계는 아니다.

업데이트 1~3으로 적 전술 미리보기·직선 기믹 강적·집중 공격과 다수전·출정별 경로·다음 교전을 고려하는 보상 선택을 실제 원정에 연결했다. 업데이트 4와 두 오토 방침으로 새 패턴의 관전 가독성과 전체 흐름의 안정화를 검사했다. 경로와 카드의 최종 재미·난이도 균형은 별도 플레이 판단이 필요하다.

기본 덱 원정 8회와 오토 48쌍 비교는 진행 가능성·회귀 검사의 결과다. 모든 덱과 체력에서 난이도가 적절하거나 숙련자의 수동 개입이 더 낫다는 증거는 아니다.

## 업데이트 1: 적 전술 미리보기와 중간 기믹 강적 — 적용 완료

[구현 및 검사 기록](적_전술_미리보기_직선_강적.md).

기존 선택 강적 방에 직선 범위 공격을 쓰는 강적 한 종을 연결한다. 공통 직선 판정을 재사용하고, 예고가 끝난 뒤 실제 위치로 피해를 판정한다. 현재 구조에 맞게 활성 위험 구역은 한 번에 하나만 사용한다.

지도에서 적 수·핵심 전술·공격 예고 유형을 보여주고 같은 화면에서 덱과 태세를 준비한다. 별도 준비 화면을 매번 거치게 하지 않는다. 기존 최종 보스와 함께 구출·재배치의 활용 기회를 제공하되 차단·보호·회복으로도 대응할 수 있게 한다.

완료 기준:

- 이동 보상이 최종 보스 전에도 유효한 선택이 된다.
- 이동 카드가 없는 기본 덱에도 대응과 진행 가능성이 있다.
- 예고·실제 판정·이동 대기·공격 취소·빈틈·저장 재개가 일치한다.
- 기본 AI는 기존 역할 이동을 유지하며 무료 기믹 회피를 하지 않는다.

## 업데이트 2: 일반 전투별 카드 선택의 차이 — 적용 완료

[구현 기록](일반_전투_차별화_구현.md)과 [조건 비교 결과](전투_선택_조건_비교.md).

기존 두 일반 전투의 성격을 집중 공격과 다수전처럼 구별한다. 비교 체험에서 확인한 전술과 공통 엔진을 활용하며, 비슷한 적을 많이 추가하는 방식으로 규모를 늘리지 않는다.

집중 공격에서는 도발·엄호·단일 회복·빠른 처치, 다수전에서는 광역 공격·전체 회복의 사용 이유가 드러나게 한다. 강적과 보스에서는 명령 보유·차단·이동·빈틈 공격을 비교한다.

개발 전 기준선을 기록하고 변경 후 같은 조건으로 비교한다. 시작 HP 100%/70%/45%, 여러 시작 손패, 기초·추격·엄호·이동 보상 덱을 사용한다. 승패 외에 생존자·남은 HP·실제 피해·피격·차단·개입 횟수를 본다. 전투 중 동일 스냅샷에서 개입 유무도 비교한다.

완료 기준:

- 서로 다른 전투에서 유효한 카드와 개입 시점이 달라진다.
- 특정 보상 카드가 없다는 이유만으로 일반 진행이 막히지 않는다.
- 공개 정보만 사용하는 오토의 제한을 유지하고 고의 오판이나 숨은 보정을 넣지 않는다.
- 도구로 만든 개입 정책의 성적과 실제 사람의 판단 우위를 구분해 보고한다.

## 업데이트 3: 6개 방 안에서 원정 선택 연결 — 적용 완료

[구현 및 조건별 경로 비교](원정_갈림길_보상_연결_구현.md). 새 출정의 첫 교전은 두 전술 중 하나이며, 중간 교전은 선택한다. 강적 승리 시 카드 보상 외에 한 장 진화 또는 생존자 20% 회복을 선택한다. 32회 실제 원정과 48회 조건 비교, PC·모바일·저장 검사를 완료했다. 조건 비교는 강적 보상의 최종 균형을 보장하지 않는다.

검증된 전투 후보를 출정마다 배치해 같은 캐릭터로도 다른 준비를 하게 한다. 방 수와 보상 풀은 먼저 유지한다. 회복·진화·정비·선택 강적의 기회비용을 전투 압박과 보상에 연결한다.

지도에서 선택에 필요한 위협 정보를 제공하고, 보상을 받은 뒤 다음 교전의 성격을 고려해 덱을 교체하도록 한다. 보상 풀 4종을 무작정 무작위로 줄여 선택지를 빈약하게 만들지 않는다. 출정 시 정해진 전투·보상 상태를 저장하고 새로고침으로 재추첨하지 않는다.

완료 기준:

- 추격·엄호·이동 운영에 따라 서로 다른 경로와 편성 이유가 생긴다.
- 회복이 항상 최선이거나 강적이 항상 무의미한 선택이 되지 않는다.
- 원정 종료 초기화와 기존 진행 중 원정의 호환을 유지한다.

## 업데이트 4: 관전과 안정화 마감 — 적용 완료

[오토 방침과 관전 안정화 구현·검증](오토_방침_관전_안정화_구현.md). 공격·보호 중심의 카드/대상 평가와 비교 체험을 함께 추가했다. 384회 조건별 전투·24회 연속 원정·PC/모바일·실제 프레임/배속 검사를 완료했다. 지원가 단독 무한 교전은 공개된 180초 제한과 정확한 종료/저장 규칙으로 처리했다.

새 패턴까지 포함해 예고와 주요 연출이 겹칠 때의 가독성을 정리한다. 재배치 직후 카메라가 멀어진 동료를 놓치는지, 사용 불가능한 카드의 이유가 충분히 보이는지 확인한다. 캐릭터의 실제 보호·추격·사격·회복 장면을 유지하며 반복 연출의 혼잡을 줄인다.

저장·복기·반응형 기능을 새로 만드는 단계가 아니라, 달라진 원정 전체를 마감하는 단계다. 여러 원정 연속 실행, PC/모바일, 배속, 일시정지·모드 전환·예고 중 저장/복원과 화면·연출 조회의 판정 독립성을 검사한다.

완료 기준:

- 새 적을 포함한 전체 원정에서 진행 막힘·중복 명령·남은 예약·저장 불일치가 없다.
- 긴 관전에서 성능 저하와 표시 혼잡이 누적되지 않는다.
- 실제 플레이 가능한 짧은 원정과 검증 결과를 함께 제시한다.

## 범위와 판단

업데이트 1·2·3·4는 프로토타입 범위에서 적용했다. 다음 판단 대상은 자동 관전에서 덱·방침 선택을 반복하고 싶게 만드는 전투 난이도와 관전 재미다. 추가 구현 범위는 플레이 결과를 보고 정한다. 비교 조건 확대는 각 업데이트의 검증에 포함한다. 날짜보다 위 완료 기준을 통과한 결과로 다음 단계에 들어간다.

신규 캐릭터·파티 확장·다중 위험 구역·판매와 정식 아트는 후속 단계에 둔다. 중간 제작은 사용자 피드백 없이 진행할 수 있지만, 관전 재미·반복 피로·숙련자의 개입 가치는 완성된 플레이를 통해 확인한다. 현재 계획은 이 취향 판단을 자동 검사 결과로 대신하지 않는다.
