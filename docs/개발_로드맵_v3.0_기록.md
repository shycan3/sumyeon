## 목표와 현재 기반

매력적인 캐릭터가 자동으로 싸우고, 플레이어는 전투 사이에 덱·방침·경로를 선택한다. 덱을 바꾸면 실제 행동이 달라지고, 그 변화로 이전에 실패한 조건을 극복할 수 있어야 한다.

유지할 기준: 4인·정확히 20장·손패 5장·공유 명령 회복시간·모든 카드의 특성·캐릭터/기초 키트는 보유·원정 보상/개별 진화는 종료 시 초기화·유한 캐릭터 레벨. 파티 확대는 계속 후순위다.

이미 적용: 기본 행동/태세/다층 AI, 카드 오토와 공격·보호 방침, 효과·행동 중단 처리, 이동 카드, 직선/원형 위험 구역, 적 전술 미리보기, 6방 경로와 강적 혜택, 특성 3종과 특성 오토, 출발 덱 3종/자유 편성, 그림과 보상 교체 비교, 대기/폐기/되돌리기, 관전 연출·복기·저장.

기본 AI의 위험 구역 회피와 메인의 풀오토 화면 정리는 남아 있다. 메인 보스 단계 변화는 새 원정에 적용했다. 사용자 덱의 동일 조건 연습은 `insights1`에서 제공한다. 보상에 기초 키트 사본을 추가해 호위·추격 출발의 공명 활성화 경로를 열었다.

## 1. 결과 분석·동일 조건 연습과 풀오토 정리 — 진행 중

완료한 첫 작업: 실제 카드 기여도, 첫 전투불능/주요 피해 위협, 시작 조건과 출발/최종 덱 보존, 독립 연습과 기본 키트 실험, 이전 저장 미기록 처리. 단위 검사와 PC/모바일 흐름 검사 통과. 다음은 아래 풀오토 화면 정리 → 제한적 회피 → 공통 예측이며, 1단계 전체를 완료한 것은 아니다.

첫 작업 묶음은 **결과를 보고 덱을 수정해 같은 적에게 시험하는 흐름**이다. 보상 풀 개선 설계는 동시에 진행할 수 있지만 새 콘텐츠의 최종 균형은 이 도구를 사용한다.

개발 내용:

- 전투 시작 편성/진화·레벨·HP·태세·방침·적 설정·시드·규칙 버전을 보존. 출발/최종 덱과 교체 이력을 결과에서 연결.
- 카드별 사용 횟수·유효 피해·유효 회복·실제 보호 기여·특성 강화 장면. 기존 통계를 먼저 표시하고 없는 지표만 추가 계측.
- 첫 전투불능과 주요 피해 위협을 보여주되 단일 실패 원인을 단정하지 않음. 미사용은 카드 노출/사용 조건과 구분.
- 보상 없는 연습에서 원래 조건과 수정 덱/방침을 비교. 기본은 그 전투 시작 시 보유한 pool 내 수정; 모든 카드 시험은 별도 실험 옵션. 연습은 원정/경험치/발견 기록에 영향 없음.
- 메인을 관전 속도·정지·기술 정보 중심으로 정리. 수동 전환/확정/리롤/대기/전투 중 태세 조작은 검사 도구로 옮김. 전투 전 태세·방침 선택 유지.
- 도보 회피 가능 범위는 정상 이동속도·행동 잠금으로 제한하고, 다른 위협은 카드 대응으로 처리하는 기준을 명시. AI가 전부 피하거나 전부 맞는 구조를 목표로 하지 않음.
- 오토의 공개 정보 유효 효과 예측을 공통화. 보호막·과잉 피해·연속 타격·빈틈 추정과 선택 이유를 일치시킴.

완료 기준:

- 같은 설정의 연습 재실행이 재현되고, 원정 보상·레벨·저장 상태를 바꾸지 않는다. 덱 변경 뒤 난수 소비가 달라질 수 있다는 비교 한계를 표시한다.
- 세 출발 덱과 방침의 실제 카드 사용/장면 차이를 결과로 확인할 수 있다. 읽기·연출 조회로 실행 상태와 난수가 변하지 않는다.
- 이전 저장에 없는 지표는 미기록으로 처리하며 진행 중 원정은 기존 규칙 버전으로 이어진다.
- 손조작이 없으면 해결 방법 자체가 사라지는 기믹이 없다. 기본 이동 회피만으로 모든 대응 카드가 불필요해지지도 않는다.

참고 원리: [Balatro의 시드·통계](https://store.steampowered.com/app/2379780/Balatro/?l=english), [Into the Breach의 공개 공격 정보](https://store.steampowered.com/app/590380/Into_the_Breach/?l=english). 우리 기여도·연습 설계가 해당 게임과 동일하다는 뜻은 아니다.

## 2. 보상으로 완성·보완·전환할 수 있는 성장 구조 — 적용

적용: 기초 키트 11종 + 전용 기술 4종, 일반/정비/강적 3/4/3개의 고정 제안, 목적·특성 설명, 원정 한정 기초 사본, 기존 원정의 이전 규칙 유지. 300개 첫 제안과 96개 실제 원정, PC/모바일 검증 통과. 신규 스킬보다 기존 기술 재획득 대안을 먼저 선택했다. [도달 지도와 한계](보상_성장_경로_구현.md).

개발 내용:

- 출발 덱별 주 특성 심화/보조 특성/약점 대응의 도달 지도를 작성. 현재 불가능한 연결은 의도적으로 막힌 경로인지 수정할 경로인지 표시.
- 기존 3특성 안에서 연결 기능이 있는 보상을 소수씩 추가. 미편성 기초 카드의 원정 한정 사본 보상 대안과 비교해 비용이 적은 방법부터 사용. 새 캐릭터는 추가하지 않음.
- 보상 카드의 기술 기능·명령시간·단계 상승·기회비용을 함께 평가. 주 특성 2단계에 필요한 보상 수를 같게 강제하지 않지만 보상 한 장의 가치 차이를 검증.
- 충분한 보상 풀 이후에만 제한 후보를 도입. 소규모 첫 후보 수는 구현 시 비교 결정. 심화/즉시 대응/다른 운영의 기회가 경쟁하도록 구성.
- 전투·정비·강적의 보상 목적을 구분. 제안은 원정에 저장하고 새로고침으로 추첨하지 않음. 원정 한 번의 제한된 보상 재제안은 필요가 확인될 때 검토.

완료 기준:

- 각 추천 덱에 주 컨셉 심화와 적어도 하나의 다른 컨셉/대응 경로가 존재하며, 연결되지 않는 경로는 명확하게 설명된다. 모든 덱이 모든 최종 조합에 도달할 필요는 없다.
- 카드의 특성뿐 아니라 실제 전투 기능 때문에 선택할 이유가 있다. 미활성 특성이라는 이유만으로 항상 무가치하지 않다.
- 같은 출발 덱에서도 제안·적 요구에 따라 두 가지 이상의 최종 편성 경로를 관찰할 수 있다. 새 선택의 비용을 무료 전체 기초 카드 지급으로 없애지 않는다.
- 주 특성 완성 카드의 상시 확정 지급과 필수 대응 카드의 완전 운 의존을 모두 피한다. 보상 넘기기·대기·교체 비교·20장 검증·원정 초기화를 유지한다.

참고 원리: [Monster Train의 주/보조 컨셉과 경로 혜택](https://store.steampowered.com/app/1102190/Monster_Train/?l=english), [TFT 2022년 특성 보상 가치·제안 개선 회고](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/dragonlands-set-mechanics-overview/).

## 3. 서로 다른 덱을 요구하는 적·보스 — 적용

적용: 회복자 방벽·강공격 돌격대, 공개 대응 안내와 보상 연동, 시드별 중간 교전 선택, HP 50%의 원형→부상자 중심 직선 보스 전환, 기존 예고/빈틈 유지, 구 원정 보존. 288개 새 적 비교·48개 실제 원정과 보스 연습·PC/모바일 검사 통과. [결과와 한계](적_대응_보스_단계_구현.md).

개발 내용:

- 보호막 적, 후열 지원자, 긴 시전 적 등 기존 판정을 활용한 적 조합 2종부터 비교. 이름/HP만 바꾸는 확장을 하지 않음.
- 지도에서 해당 위협과 대응 계열을 미리 안내. 집중 공격·다수전과 다른 덱 장단점이 생기는지 확인.
- 메인 보스의 단계 전환을 실제로 연결. 단계마다 대응 요구를 변경하고 전환 조건을 공개. 이미 예고한 공격의 처리 규칙 유지.

완료 기준:

- 새 위협마다 최소 두 대응 계열이 유효하다. 특정 카드 한 장을 못 얻었다고 무조건 실패하지 않는다.
- 적 조건에 따라 카드/방침/경로 선택의 유효성이 달라지며, 공개 정보만으로 오토가 사용 가능한 대응을 실행한다.
- 실제 원정의 체력·보상 연속 상태와 상한 레벨에서도 덱 수정의 효과를 비교한다. 숫자만 늘려 난도를 맞추지 않는다.

## 4. 원정마다 싸움의 규칙이 달라지는 보상 — 첫 변형 적용

적용: 초반 진화 대신 추격 릴레이 선택, 처치/새 표식 기본 공격 마무리의 한 번 전달, 다른 캐릭터의 정상 카드 후속, 활성 추격 공격 명령 +1초, 전달 선·표식·알림·결과·저장·연습·초기화. 288개 비교와 24개 실제 원정, PC/모바일 검사 통과. 후속 카드 연결 빈도는 추가 검증 대상이며 공동 반격 등 다른 변형은 아직 없다. [비용과 실험 결과](원정_규칙_추격_릴레이_구현.md).

개발 내용:

- 공동 반격, 처치 후 표식 전달 등 연계 행동이 달라지는 변형을 한 가지씩 검증. 기존 카드나 특성 변형으로 가능한지 먼저 판단.
- 별도 원정 규칙이 필요한 경우 하나를 선택하는 작은 틀부터 시험. 유물·장비·증강을 동시에 추가하지 않음.
- 실제 연계가 카드·초상화·동작으로 드러나고 결과에 남도록 표시. 추가 효과의 명령·연쇄 비용을 명시.

완료 기준:

- 수치표 없이 관전 장면으로 선택 전후의 차이를 구분할 수 있다.
- 효과의 자기 재발동·무한 연쇄·무료 반복 행동·저장 복원 불일치가 없다.
- 카드 특성/오토 방침과 선택 비용이 연결되며 모든 덱에 최선인 자동 선택 보상이 아니다.

참고 원리: [Slay the Spire의 유물 상호작용](https://store.steampowered.com/app/646570/Slay_the_Spire/?l=english), [Balatro의 Joker 시너지](https://store.steampowered.com/app/2379780/Balatro/?l=english). 신규 별도 시스템 채택은 작은 변형 실험 이후에 결정한다.

## 5. 6방 안의 경로와 도전 목표 — 첫 틀 적용

적용: 현재 HP 기준 회복/포기 혜택 안내, 경로 기록, 완주 후 공개 도전 2종, 고정 시드·레벨 5·오토 한정, 별도 전원 생존/경로 목표, 종료 기록·최단 시간·최고 잔여 HP 저장, 원정 초기화. 24개 실제 원정에서 모두 완주했고 성장 경로 12개는 목표 달성했다. 이는 고난도 검증 완료가 아니며, 덱별 경로 선택 가치와 목표 난도는 후속 조정 대상이다. [구현과 검증](경로_공개_도전_구현.md).

개발 내용:

- 늘린 적/보상 목적을 기존 방에 연결. 회복·진화·보상·원정 규칙의 혜택을 공개하고 기회비용을 조정.
- 덱 선택이 경로 선택에 영향을 주도록 제한된 갈림길/이벤트부터 도입. 화폐·상점은 비용 구조에 실제 필요할 때 추가.
- 기본 원정 이후 공개 전술 조건·도전 단계를 제공. 적 조합·제한 조건·보상 운영으로 변화시키고 무한 영구 능력치 상승을 쓰지 않음.

완료 기준:

- 같은 6방에서도 덱에 따라 다른 경로를 선택할 이유가 있다. 회복 또는 강적이 항상 정답/무의미한 선택으로 수렴하지 않는다.
- 레벨 상한 이후에도 새 덱/운영을 시험할 목표가 있다. 종료된 원정 카드·진화는 계속 초기화한다.
- 조건·단계·성적은 저장되며 사용자에게 공개된다. 플레이 피로가 늘면 방 수를 확대하지 않고 선택 빈도부터 조정한다.

참고 원리: [Wildfrost의 해금·도전](https://store.steampowered.com/app/1811990/Wildfrost/?l=english), [Slay the Spire의 위험/안전 경로](https://store.steampowered.com/app/646570/Slay_the_Spire/?l=english).

## 검증과 종료 기준

자동 검사: 정확한 카드/기본 행동 판정, 실제 사용과 결과 지표, 같은 초기 조건 비교, 복사본/종류 계산, 공개 정보 독립성, 실제 6방 HP/보상 연속, 레벨 1/상한, 여러 시드·방침·편성, 저장 버전·PC/모바일·배속.

플레이 판단: 카드 획득 기대감, 덱을 바꿔 극복했다는 이해, 캐릭터 연계의 매력, 관전 반복 피로. 자동 검사 전승이나 과거 회귀 통과로 재미를 인증하지 않는다.

현재 최대 HP 비교의 384/384 승리는 검사 표본의 결과다. 따라서 바로 적 수치부터 올리지 않고, 1~3단계로 성장과 대응 차이를 측정한 뒤 난도를 조정한다. 새 단계의 신규 선택이 실제 판단을 바꾸지 못하면 기능을 더 쌓기 전에 해당 연결을 수정한다.

신규 캐릭터·파티 확대·판매·대규모 아트 제작·다중 위험 구역·무한 성장·대량 카드 추가는 이번 로드맵의 선행 과제가 아니다. 현재 관전과 보상 비교는 재사용한다.
