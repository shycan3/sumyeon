# 다음 시스템 개발 로드맵 v4.0

## 목표와 현재 기반

덱·배치·운영 방침을 바꾸면 팀이 싸우는 모습과 결과가 달라지고, 이전 실패를 극복할 수 있어야 한다. 파티 확대는 후순위다.

이미 구현한 기반: 4인·20장 덱·손패 5장, 모든 카드의 특성, 공격/보호 오토와 특성 판단, 이동 카드·위험 구역, 적 전술·보스 단계, 출발 덱 편집, 원정 한정 보상·진화, 추격 릴레이, 경로 비용·공개 도전, 기여도·독립 연습·이전 덱 비교. 관전 화면과 카드 비교, 스킬 안내에 따른 전장 크기 변화, 팝업 편집 연속성 등 기본 조작 불편도 개선했다.

이전 계획은 [v3.0 기록](개발_로드맵_v3.0_기록.md)에 보존한다. 해당 기록의 미완료 UI 표기와 기본 도보 회피 계획을 현재 필수 작업으로 이어받지 않는다. 기본 AI에 무료 기믹 회피를 일괄 추가하지 않고, 보유 카드와 보호·회복·공격 대응을 중심으로 검증한다.

## 다음 개발 순서

| 단계 | 개발 묶음 | 플레이어가 얻는 변화 |
|---|---|---|
| 1 · 적용 | 전투 전 간단한 배치 | 같은 덱도 접근·보호·공격 시작이 달라짐 |
| 2 | 덱·배치·오토 검증과 판단 보완 | 준비한 전략을 오토가 실제로 실행함 |
| 3 | 행동을 바꾸는 원정 규칙 확장 | 보상으로 팀의 전투 방식이 달라짐 |
| 4 | 전략별 장단점이 드러나는 적과 경로 | 적에 따라 편성·배치·보상을 바꿀 이유가 생김 |
| 5 | 6방 원정 성장과 공개 도전 완성도 | 덱 변경으로 실패를 극복하는 반복 목표가 선명해짐 |

기간과 세부 수치는 고정하지 않는다. 단계별 검증 결과로 후속 범위를 조정한다. 1단계는 `formation1`에 적용했으며, 다음은 2단계의 현재 버전 검증이다. [배치 구현·검증과 한계](전투_배치_구현.md). 2~5단계는 후속 개발 제안이다.

배치 확장 조사: TFT·Mechabellum·The Last Flame을 참고한 [12자리 배치와 표적·공간 효과 설계](배치_고도화_레퍼런스_설계.md)를 추가했다. 아래 적용 기록에 따라 순차 구현하고 있다. 기존 72회 검사는 승패에 미치는 배치 중요도를 입증하지 못했으므로 비교 검증과 연결한다.

확장 1단계의 표적 안정화·동거리 보호자 우대·보호 안내 공통화는 `targetrules1`에 적용했다. [구현·저장 호환·288회 비교 결과](표적_보호_규칙_구현.md). 다음 작업은 적 배치를 확인하는 준비 상태와 12자리 배치이며, 공간 효과 추가는 그 뒤다.

배치 확장 2단계는 `preparation1`에 적용했다. 적 확인 준비 상태, 12자리 편집, 저장·과거 연습 버전 보존을 포함한다. [구현·72회 비교·PC/모바일 검증](적_배치_준비_12자리_구현.md). 다음은 보호 범위와 공간 효과의 표시·활용 검증이다.

배치 확장 3단계는 `spatial1`에 적용했다. 보호·공간 범위 표시, 주변 회복·직선 공격 보상 카드 두 장, 실제 범위에 따른 오토 평가를 포함한다. [구현·호환·검증과 한계](공간_효과_카드_구현.md). 다음은 같은 덱·HP·방침의 배치 비교와 공개 적 조합의 선택 이유 검증이다.

배치 확장 4단계의 비교 도구와 표본 검증은 `deploymentstudy1`에 적용했다. [독립 연습 비교·384회 관측·한계](배치_비교_검증_구현.md). 96개 조건 중 11개에서 배치에 따라 승패가 달랐지만 만전 HP 표본은 모두 승리했고 위치 차이도 빠르게 줄었다. 전략적 완성도를 완료로 판정하지 않으며, 다음은 기존 공개 적 조합과 위협 안내를 보완해 준비 선택의 비용을 드러내는 작업이다.

`enemyplans1`에는 일반 신규 원정의 방벽 사수 국소 폭발, 돌격수 개전 지원가 추격, 지도·준비 화면의 위협/대응/배치 비용 안내를 적용했다. [구현·전후 384회 비교·호환·한계](적_전술_공개_대응_구현.md). 공개 도전 버전 1과 이전 원정은 기존 규칙을 유지한다. 다음 검증은 원정의 누적 체력 소모·경로·보상 선택을 묶어 후반 준비의 결과 차이를 확인하는 작업이다.

`expeditionreview1`에는 원정 결과의 체력·덱 변화 흐름, 큰 소모 전투의 독립 연습 연결, 출발 덱 재현을 적용했다. [144회 경로/보상 비교·48쌍 보스 스트레스 검사와 한계](원정_체력_성장_검증_구현.md). 회복 경로가 HP 보존에 유리했고 제한적 자동 교체에서는 일부 성장 덱이 출발 덱보다 불리했다. 다음은 기존 보상 비교 UI를 재사용한 교체 비용 안내 보완이며, 선택 구조와 교체 휴리스틱을 분리한 뒤 난도를 조정한다.

## 1. 전투 전 간단한 배치

전열·중열·후열에 각 2자리, 총 6자리 중 4자리에 캐릭터를 배치하는 안을 우선한다. 추천 배치로 시작하고 캐릭터 선택 후 빈자리 선택 또는 자리 교환으로 수정한다. 자유 좌표 지정이나 전투 중 수동 이동은 추가하지 않는다. 추천 배치에 별도 능력치 보너스를 붙이지 않는다.

배치는 시작 위치와 평상시 선호 구역에 영향을 준다. 검사의 추격, 방패병의 보호, 사수의 거리 유지, 지원가의 회복은 필요한 위치로 이동할 수 있다. 행동 잠금·카드 이동·역할 행동·선호 위치의 관계를 명시해 원위치 복귀가 추격이나 카드 이동을 취소하지 않게 한다. 배치 기능에 무료 기믹 회피를 끼워 넣지 않는다.

전열이라는 이유만으로 모든 공격을 대신 받지는 않는다. 기존 표적 규칙과 도발·보호 효과를 유지하고 실제 거리·접근·보호 가능 범위에서 배치의 영향을 만든다. 위치가 무의미한 공격에 가상의 배치 효과를 표시하지 않는다.

완료 기준:

- 같은 덱·방침에서 두 배치의 접근 경로, 첫 공격 시점, 보호 또는 위험 노출 차이를 확인한다.
- 불필요한 왕복 이동·추격 중단이 없고, 사망과 이동 카드 처리도 정상이다.
- 배치를 저장과 동일 조건 연습에 포함한다. 기존 저장은 추천 배치로 호환한다.
- 특정 배치가 모든 상대에서 유리한지 비교한다. 효과가 작다면 조작을 복잡하게 만들기 전에 원인을 확인한다.

## 2. 현재 버전 검증과 오토 판단 보완

기존 AutoLab·일괄 검사·연습 엔진을 재사용한다. 비교 도구를 처음부터 만들지 않는다. 과거 일부 저체력 단일 전투의 결과를 현재 원정 전체의 난도 근거로 사용하지 않는다.

세 출발 컨셉과 혼합 덱, 공격/보호 방침, 대표 배치, 레벨 1/상한 조건을 비교한다. 조건을 통제한 단일 전투와 실제 6방 원정의 HP·보상·경로 누적 비교를 분리한다. 승패·시간·남은 HP 외에 첫 전투불능, 유효 카드 기여, 빈 효과 사용과 대응 기회 누락을 기록한다.

검증에서 드러난 문제부터 수정한다. 실제 판정과 공개 정보 예측의 불일치, 과잉 회복·피해, 보호 타이밍과 공유 명령시간 충돌이 우선이다. 숨겨진 손패·미래 난수는 보지 않고 손플레이 우위를 위한 고의적인 실수도 넣지 않는다.

완료 기준: 덱이나 배치 수정으로 실패를 극복하는 사례가 여러 조건에서 재현된다. 강한 편성의 장단점과 두 방침의 차이가 설명되고, 수정한 판단은 실제 효과에 연결된 회귀 검사로 확인된다. 모든 덱의 승률을 같게 맞추지는 않는다.

## 3. 행동을 바꾸는 원정 규칙 확장

기존 추격 릴레이의 실제 후속 카드 빈도와 비용을 먼저 검증한다. 이후 호위·공명 안에서 각각 한 후보를 소규모로 시험한다. 예시 후보는 보호 후 반격 연결, 지원 후 다음 기술 강화다. 구체 효과는 아직 확정하지 않는다.

새 특성을 늘리기보다 기존 세 특성의 전투 방식 차이를 강화한다. 기존 진화와 경쟁하는 규칙 선택을 활용한다. 정상 카드 사용·명령시간·발동 횟수 제한을 두고 무료 추가 행동의 무한 연결을 막는다.

완료 기준: 카드 사용 순서나 지원/공격 연결이 달라지는 장면이 보인다. 선택 비용 때문에 다른 규칙이나 진화도 유효하다.

## 4. 전략에 대응하는 적과 경로

이미 추가한 지원자 방벽·돌격대·보스 전환을 중복 개발하지 않는다. 2단계에서 차이가 부족한 축을 대상으로 적 조합을 소수 추가하거나 수정한다. 분산/밀집, 보호/공격, 집중/다수 대응의 장단점을 드러내되 특정 카드 한 장만 정답인 구조는 피한다.

지도에서 위협과 대응 계열을 미리 보여주고 덱·배치·경로를 선택하게 한다. HP만 올려 난도를 만들거나 완벽한 이동 회피가 필수인 기믹을 추가하지 않는다.

완료 기준: 각 위협에 두 가지 이상의 대응 계열이 있고, 왜 준비를 바꿔야 하는지 전투 전 정보와 결과로 이해할 수 있다.

## 5. 원정 성장과 공개 도전 완성도

실제 원정 기록으로 주 컨셉 심화·약점 보완·다른 컨셉 전환의 가능성과 최종 편성 반복을 점검한다. 필요한 보상 제안 가중치와 경로 비용만 수정한다. 보상 수를 무작정 늘리거나 컨셉 완성을 확정 지급하지 않는다.

공개 도전은 무한 레벨 상승 대신 제한 조건과 적 조합으로 목표를 제공한다. 결과·이전 덱 비교·재도전을 연결해 실패 후 수정 방향을 찾는 흐름을 완성한다.

완료 기준: 같은 출발 덱에서도 다른 최종 편성이 관찰되고 실패 후 합리적인 수정으로 재도전할 수 있다. 원정 보상·진화 초기화, 저장 복구, 연습의 원정 격리를 유지한다.

## 미루는 작업

파티·캐릭터 확대, 판매·수집 경제, 대규모 아트, 새 특성 대량 추가, 자유 위치 조작, 전투 중 필수 수동 개입은 후순위다. UI는 새 기능의 사용성과 화면 안정성을 검증하되 전면 개편을 반복하지 않는다.
