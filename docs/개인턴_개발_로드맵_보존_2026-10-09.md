# 《수면》 전투 개발 로드맵과 새 대화 인수인계

갱신: 2026-10-09 / 1단계 구현·검증 완료 / 다음 작업: **2단계 — 개인 카드 운용**

이 문서는 최신 대화에서 사용자가 선택한 방향과 현재 구현을 구분해 정리한 기준이다. 이전 풀오토 중심 로드맵과 충돌하는 부분은 이 문서를 우선한다. 아래 개발 완료 표시는 실제 코드 상태이며, 제안한 기본값을 최종 합의로 취급하지 않는다.

## 1. 목표 경험

플레이어는 캐릭터의 차례마다 카드를 판단하고, 캐릭터는 선택한 기술을 직접 움직이며 실행한다. 파티·전열/후열·덱을 바꾸면 해결 방법과 전투 장면이 달라지고, 이전에 넘지 못한 상대를 돌파하는 성장감을 준다.

- 슬더슬: 손패와 제한된 자원에서 공격·방어·성장의 기회비용을 선택한다. 원정 보상으로 덱이 변화한다.
- 오토체스: 파티 조합과 전투 전 배치, 조합이 실제 싸움에 나타나는 경험을 활용한다.
- 서브컬쳐: 캐릭터마다 다른 기본행동·고유 특징·소수의 전용 기술과 대표 연출을 제공한다.

**최근에는 직접 카드 판단과 캐릭터별 턴을 중심으로 방향을 바꿨다.** 이전 풀오토는 비교용으로 남으며, 과거의 풀오토 최우선 기획을 새 전투의 기준으로 되돌리지 않는다.

### 카제나 분석을 반영한 개발 기준 · 2026-10-09

[반면교사 설계 기준](카제나_반면교사_설계_기준.md)을 이후 단계의 판단과 검사에 적용한다. 핵심은 적은 학습 부담, 조합 실험의 접근성, 선택 결과의 신뢰, 성장한 빌드의 활용처다. 제공된 분석에서 도출한 기준이며 카제나의 최신 제품 규칙을 독립 검증한 기록은 아니다.

- 출발부터 전체 파티의 복잡한 카드 연계를 암기하게 하지 않는다. 현재 행동자의 소수 선택지와 새 보상 한 장씩을 이해하도록 만든다.
- 캐릭터 정체성은 유지하되 매 원정 보상에 따라 운용이 달라져야 한다. 고정 연계 반복이나 높은 육성 비용으로 조합 실험을 제한하지 않는다. BM·영구 성장 방식은 여전히 미정이다.
- 사전에 안내한 원정 종료 초기화는 유지한다. 진행 중 만들어진 덱을 숨겨진 한도나 사후 보정으로 자동 훼손하지 않는다. 변경·제약은 선택 전에 공개하고 플레이어의 선택을 따른다.
- 접속 일수·비전투 반복 횟수로 핵심 전투 진행을 차단하지 않는다. 패배 후 바꿔볼 카드·배치·전술이 읽혀야 한다.
- 원정 후반에서 성장한 빌드를 충분히 사용하게 한다. 영구 저장 덱·엔드 콘텐츠 추가는 별도 결정이며 기존 원정 한정 카드 합의를 자동 변경하지 않는다.
- 캐릭터의 기여와 매력은 행동·전용 기술·정식 서사에서 드러낸다. 전투 UI에는 판단에 필요한 정보만 남긴다. 지금 새 일러스트·4인·서사 변경을 추가하는 요청으로 확대하지 않는다.

현재 고정 선택지는 덱빌딩 완성이 아니다. 특히 카드 한 장/비용 한도 2에서 비용 차이가 실제 기회비용으로 이어지는지, 개인 공급에서 중복·교체가 실제 운용을 바꾸는지를 2단계에서 확인한다. 원정 길이·적 공격 강화 +2는 임시 값으로 유지하며 다양성을 저해하는지 후속 단계에서 검증한다.


## 2. 사용자와 정한 최신 구조

1. 캐릭터마다 행동 게이지와 자신의 턴이 있다. 자신의 턴에서 자신의 카드를 사용한다.
2. 결정 중에는 시간이 멈추고, 선택한 카드 한 장의 결과를 확인한 뒤 다음 판단을 한다.
3. 전열·후열은 캐릭터의 기본 배치다.
4. 자기 턴에는 앞으로 나와 행동하고, 기본적으로 원래 배치로 돌아간다.
5. **행동을 위한 일시적인 진출과 실제 배치 변경은 구분한다.** 견인 등 배치 변경을 명시한 카드만 새 자리에 남긴다.
6. 전열은 일반 공격을 우선 받아 후열을 보호하며, 전열이 비면 후열도 직접 노출된다. 이 전술 규칙은 3단계에서 구현한다.
7. 일반 공격은 기본 배치를 기준으로, 반격은 지금 공격한 캐릭터를 대상으로 처리하는 방향이다.
8. 적 행동 순서와 의도는 플레이어가 읽을 수 있어야 한다. AI가 명시한 대상과 선택 결과를 몰래 바꾸지 않는다.
9. 모든 카드에는 특성이 존재한다. 이동도 카드로 제공한다.
10. 보상 카드와 진화는 원정 한정이다. 획득한 카드는 보상 이후 다음 전투부터 활용한다.
11. 현재는 시스템 구축이 우선이다. 파티 확장은 뒤에 하고, 일러스트는 임시 표현으로 만든다.

## 3. 현재 구현과 보존한 비교 버전

현재 `tactical.html?v=individual1`은 **개별 게이지·개인 턴 1단계**다. 아군 결정 중 게이지가 정지하고, 현재 행동자의 카드 한 장 또는 기본행동만 처리한다. 적은 개별 차례에 공개 의도를 실행한다. 현재 행동자·다음 6회 순서는 왼쪽 세로 초상 목록으로 표시한다. 게이지·시각 숫자는 상시 표시하지 않는다. 진출/복귀는 표현 상태이며 견인은 실제 기본 배치를 바꾼다.

1단계 임시 값: 게이지 100, 초기 0, 도윤 속도 12·하린 10·적 8. 정수 시각으로 다음 준비 순간까지 진행하고 동시 준비는 아군 표시 순서 다음 적 표시 순서다. 준비 시 게이지를 0으로 소비하고 대기자는 100에서 유지한다. 카드 한 장 또는 기본행동 1회, 비용 한도 2, 고정 선택지다. 보호·반격은 대상의 다음 개인 턴 시작에 종료, 결속 감소는 적의 다음 행동 1회, 기술 추가 피해는 다음 기술 타격 1회까지 유지한다. 적 강화 +2는 해당 적의 행동 완료 후 새 예고에만 적용한다. 상세 기록은 `개인_행동_게이지_1단계_구현.md`를 참조한다.

개인 덱·개인 손패는 미구현이다. 세 출발 구성의 고정 선택지는 같다. 원정 보상은 다음 전투에서 소유자의 고정 선택지에 추가하는 임시 연결이다.

### 보존한 공용 턴 비교 버전 (이하 이전 구현 기록)

이전 비교 버전은 **2인 파티, 공용 턴, 공유 덱 12장, 손패 5장, 파티 행동력 3**이다. 이전 비교 버전에는 캐릭터별 게이지·개인 턴·개인 손패가 없다.

- 카드 선택 → 대상 → 사용. 효과를 한 장씩 확정하고 기본행동은 결정 중 멈춘다.
- 현재 턴 종료는 아군 전체의 기본행동 1회씩 → 적 전체의 예고 행동을 처리한다. 이 결산 구조를 1단계에서 개인 턴으로 바꾼다.
- 결속 피해 감소·기술 1회 추가 피해, 직접 공격, 보호, 회복, 반격, 전열/후열 견인.
- 개체 대상 공격과 전열/후열 구역 공격 구분. 이동만으로 개체 공격을 회피하지 않는다.
- 균형·공격·보호 출발 덱과 3전투 원정. 첫 두 승리에서 카드 한 장 교체 또는 생존자 HP 8 휴식.
- 보상 비교에는 시전자·비용·효과·특성을 표시. 같은 카드는 장수로 묶고 실물 한 장만 교체한다.
- 모든 카드에 호위·추격·공명 표시. **특성 단계 보너스와 궁극기는 미구현**이다.
- 전투불능 캐릭터 카드는 해당 전투에서 제외. 원정 카드가 영구 삭제되지는 않는다. 전투 중 부활은 없다.
- 저장 없는 독립 실험이며, 기존 풀오토 저장을 읽거나 덮어쓰지 않는다.

현재 전열/후열은 구역 공격과 이동 판정에 사용한다. **전열 우선 일반 공격·전열 공백 보호 규칙은 아직 없고, 현재 적의 일반 공격은 지정된 캐릭터를 겨냥한다.**

## 4. 7단계 로드맵

| 단계 | 개발 범위 | 완료 기준 | 상태 |
|---|---|---|---|
| 1. 캐릭터별 행동 게이지·턴 | 아군·적의 개별 순서, 준비 시 자동 정지, 동시 준비의 일관된 처리, 자기 턴 진출·행동·복귀 | 누가 언제 행동하는지 분명하고 카드 선택 중 게이지가 진행되지 않음 | 구현·검증 완료 (임시 규칙) |
| 2. 개인 카드 운용 | 행동자의 카드 공급·손패 갱신·행동력·비용, 개인 덱/손패 우선 실험 | 자신의 카드가 없어 턴을 허비하지 않고 공격·보호의 선택이 생김 | 미구현 |
| 3. 전열·후열 전술 | 기본 배치/진출 구분, 전열 우선 공격과 공백, 구역 공격, 지속 위치 변경, 반격 | 누구를 앞에 세우고 언제 이동시키느냐가 결과를 바꿈 | 일부 구역·이동 기반만 있음 |
| 4. 캐릭터 개성과 연계 | 소수 전용 카드·패시브, 특성 보너스, 결속→공격·보호→반격 | 캐릭터와 덱을 바꾸면 해법과 장면이 달라짐 | 일부 기술 기반 있음 |
| 5. 짧은 로그라이크 원정 완성 | 새 개인 턴에 맞춘 3전투·보상·휴식·진화·카드 비교·원정 리셋 | 보상 카드가 다음 전투에서 새 해결책을 제공 | 기존 공용 턴 원정만 있음 |
| 6. 적·보스와 밸런스 | 전열 압박·후열 위협·회복·충전, 여러 덱 비교 | 같은 전략만으로 모두 해결하지 않고 패배 이유를 이해함 | 기존 적과 검사 기반 있음 |
| 7. 파티 확장과 대표 연출 | 검증 후 4인, 궁극기, 신규 캐릭터 공통 구조, 중요도별 연출 | 인원이 늘어도 판단이 과도하게 길어지지 않고 각 기여가 읽힘 | 이후 작업 |

### 추가 비평 반영 · 투명성·연구·도전·서사

반면교사 설계 기준 9절을 추가했다. 간결한 전투 화면은 유지하면서 선택한 대상의 조건·추가 피해·지속 판정은 필요한 순간에 확인할 수 있게 검토한다. 강한 원정 조합의 발견을 보상하고, 선택을 독점하는 상태·오류·종료하지 못하는 순환은 구분한다. 적 기믹도 특정 빌드를 일괄 무효화하지 않고 복수의 예고된 대응을 제공하는지 검사한다. 너프 금지·무조건 상향·스트레스 보너스 강제 전환을 설계 원칙으로 채택하지 않는다.

스트레스·랭킹은 현재 미구현이며 이번 분석으로 도입하지 않는다. 2~3단계는 설명/실행 일치와 실패 원인 이해, 4~6단계는 강한 조합의 활약·대체 해법, 7단계는 역할·서사·연출의 일관성을 추가로 확인한다. 프롤로그 설정과 원정 한정 카드 방향은 유지한다.

### 이후 단계에 추가하는 재미 검사

2단계는 현재 행동자의 소수 카드만으로 판단 가능하고 비용·공급의 기회비용이 실재하는지 확인한다. 3단계는 배치 대응, 4단계는 고정 연계 외 운용, 5단계는 보상 이후 활용 전투와 선택 결과의 일치, 6단계는 다양한 해법과 납득 가능한 패배, 7단계는 파티 증가의 학습 부담과 캐릭터 기여 표현을 확인한다. 코드 경로 완주와 사람의 재미 검사를 구분한다. 상세 관찰 항목은 반면교사 설계 기준 8절을 따른다.

**1~3단계가 다음 전투 골격 개발 묶음이다.** 한 번에 모두 만들지 않고 단계별 실제 플레이와 검사를 거친다. UI·모바일·예측의 정확성은 매 단계에서 함께 확인한다.

## 5. 1단계 개발 범위와 완료 기준 (구현·검증 완료)

기존 `tactical-*` 구조를 먼저 읽고, 개인 턴을 실제 플레이할 수 있는 첫 버전을 만든다. 이전 풀오토의 복잡한 판단 AI를 새 전투로 가져올 필요는 없다.

- 2인 파티와 임시 연출을 유지한다. 4인·궁극기·새 고품질 일러스트는 이 단계에서 추가하지 않는다.
- 게이지는 다음 준비된 행동자를 결정한다. 사용자가 카드와 대상을 선택하는 동안 아군·적 게이지와 효과 시간이 흐르지 않는다.
- 아군 턴에서는 해당 캐릭터만 행동한다. 현재처럼 턴 종료마다 아군 전체 기본공격을 반복하지 않는다.
- 적도 자신의 준비된 턴에 공개한 의도를 실행한다. 예고 없는 추가 공격을 만들지 않는다.
- 일시 진출 뒤 기본 배치로 복귀하고, 실제 이동 카드는 변경된 배치로 복귀한다. 표현 좌표가 논리 배치를 덮어쓰지 않게 한다.
- 다음 행동 순서와 현재 행동자를 UI로 보여준다. 정확히 같은 시점에 준비된 경우의 우선순위는 명시하고 재현 가능하게 한다.
- 개인 덱·비용의 완성은 2단계다. 1단계에서는 행동자별 고정된 유효 카드 선택지를 제공하는 작은 검증 방식도 가능하다. 임시 공급 규칙이라면 화면과 구현 기록에 명시한다.
- 공용 행동력 3을 캐릭터마다 그대로 지급하는 것을 확정하지 않는다. 전체 행동량이 달라지는 만큼 테스트 비용을 판단해야 한다.
- 효과의 ‘이번 적 행동까지’·적 공격의 ‘턴마다 +2’는 공용 턴을 전제한 현재 규칙이다. 개인 턴에서 언제 종료·증가할지 명시적인 검증 기본값으로 바꾼다. 캐릭터 행동마다 무조건 적 공격을 강화하면 안 된다.
- 기존 프로토타입의 비교 기준을 유지할 수 있도록 버전 또는 별도 실험 진입점을 둔다. 현재 검사 결과를 새 개인 턴의 통과 결과로 그대로 인용하지 않는다.

### 1단계 검증

행동 순서 재현·동시 준비 처리, 결정 중 정지, 자신의 턴에 자신의 카드만 사용, 사망자 턴 제외, 정확히 한 번의 기술/기본행동, 개인 턴 종료 뒤 다음 행동자로 전환을 확인한다. 진출/복귀와 배치 변경 구분, 연출 1배/2배/끄기의 동일한 결과, 전장 크기 고정, 데스크톱/모바일 실제 조작도 확인한다. 구현 기록과 이 문서의 상태를 갱신한다.

### 1인 덱빌딩과 4인 파티의 차이 · 방향 제안

2~3단계에서 공급·비용과 보호 지속을 확인하고, 4~6단계에서 교체 가능한 연계·보상·다양한 해법을 검증한 뒤 7단계에서 4인으로 확장한다. 현재 보호가 대상의 다음 개인 턴에 종료되어 적보다 먼저 오는 동료 차례에 사라질 수 있는 문제도 검사한다. 4인 통과 기준에는 전투당 판단·연출 횟수와 중심 캐릭터 외 동료의 실제 선택을 추가한다. 손패 장수와 자원 방식은 제안 후보이며 미확정이다. 이번 비교로 4인 구현이나 규칙 변경을 완료 처리하지 않는다.
