# 게임 기본 구조 v1.0

> 2026-10-09 이후 현재 플레이 제안은 [4인 공용 카드 v3](플레이_시스템_설계_v3.md)와 [현재 로드맵](현재_개발_로드맵.md)이다. 아래는 이전 관전/캐릭터 소유 카드 버전의 기록이며 새 구현 요구사항이 아니다.

갱신일: 2026-10-06

최신 방향은 **캐릭터를 보유하고, 그 캐릭터의 기초 카드로 출발해, 이번 원정만의 보상 카드 조합을 완성하는 관전 PvE 게임**이다. 상세 규칙·초안·미정 사항은 [캐릭터와 원정 카드 설계](캐릭터와_원정_카드_설계.md)를 따른다.

새 [캐릭터 원정](../prototype/character.html)에 검사 한 명의 기초 4종·보상 2종, 캐릭터 ID·고유 행동·대표 검무·원정 종료 초기화를 구현했다. 6개 방의 검증 범위이며 기존 [브라우저 게임](../prototype/index.html)의 저장과 원정도 별도로 유지한다. 새 범위와 검사 결과는 [캐릭터 버전 구현 기록](캐릭터_검증_버전_구현.md), 기존 결과는 [README](../prototype/README.md), [시스템 고도화](시스템_고도화.md), [전투 자동 운영](전투_자동_운영.md)에서 확인한다.

## 1. 만들고 싶은 경험

매력적인 캐릭터가 스스로 움직이고, 자신의 성격과 전투 특성에 맞는 기술로 적을 처치하는 모습을 구경한다. 플레이어는 동료와 시작 덱을 고르고, 필요할 때 카드 한 장으로 보호·회복·공격·이동을 지시한다.

캐릭터의 외형·성격·기본 행동·태세·전용 카드·대표 연출을 하나로 연결한다. 캐릭터를 얻으면 대표 스킬을 포함한 기초 키트를 바로 사용할 수 있고, 해당 캐릭터를 편성한 원정에서 전용 보상 카드를 얻을 수 있다.

원정에서 얻은 카드는 다음 판에 가져가지 않는다. 같은 캐릭터라도 추격·반격·엄호 같은 서로 다른 보상 운영과 동료 조합으로 전투 장면이 달라지는 것을 목표로 한다.

## 2. 전체 플레이 흐름

`캐릭터·기초 덱 편성 → 원정 → 전투 관전·카드 개입 → 보상 카드·교체·진화 → 경로·회복 → 보스 → 결과·캐릭터 기록 → 새 원정`

한 판은 원정 한 번이다. 전투를 마칠 때마다 보상 카드를 초기화하지 않는다.

| 단계 | 플레이어의 선택 | 규칙 |
|---|---|---|
| 준비 | 보유 캐릭터와 기초 카드로 파티·시작 덱 편성 | 캐릭터별 비율 자유. 4명·20장·손패 5장은 검증값 |
| 전투 준비 | 적 전술·시작 태세·수동 또는 오토 확인 | 전투 시작 전 다른 경로로 돌아갈 수 있음 |
| 전투 | 관전하거나 카드·대상을 직접 판단 | 기본 행동·이동은 캐릭터 AI가 수행 |
| 카드 보상 | 현재 파티의 보상 후보 중 선택 | 전투 승리·보상 방에서 획득, 다음 전투부터 사용 |
| 덱 조정 | 새 카드를 기존 카드와 교체 | 총 장수 유지. 빠진 카드는 이번 원정의 대기 목록에 보관 |
| 원정 성장 | 강화 방에서 개별 카드 한 장 진화 | 인스턴스당 원정 최대 1회 |
| 경로 | 회복·진화·보상·위험을 고려 | 연결된 분기 경로에서 선택 |
| 종료 | 성공·패배·자발적 귀환 | 보상 카드와 진화 모두 초기화 |
| 다음 판 | 캐릭터와 기초 키트로 새 덱 구성 | 캐릭터 보유·레벨·기록은 유지 |

## 3. 캐릭터와 전투

직업은 역할을 설명하는 태그다. 방패병·검사·사수·지원가가 실제 캐릭터의 행동과 카드를 모두 결정하는 구조에서, **캐릭터 ID별 기본 AI·태세·전용 카드·보상 풀·연출**을 갖는 구조로 발전시킨다.

같은 근접 태그도 추격형 검사와 보호형 검객은 움직임·표적·카드·어울리는 동료가 다르다. 캐릭터의 매력이 일러스트에만 머무르지 않도록 전투 행동과 스킬 장면에 연결한다.

아군과 적군은 모두 기본 행동과 카드 행동을 가진다. 위치·거리·범위는 중요하지만 개별 목적지를 반복 입력하지 않는다. 이동 카드는 좌표보다 대상과 목적을 선택하고, 잠시 그 목적을 유지한 뒤 기존 태세로 돌아간다.

공용 덱·손패·명령 회복을 사용한다. 카드 한 장이 시전자와 기술을 함께 결정하고, 대상은 추천 후 변경할 수 있다. 카드의 명령 회복시간과 실제 액션의 준비·타격 시간을 구분한다. 명중이 보장된 공격도 타격 전 발동한 방어 효과로 대응할 수 있다.

| 운영 | 전투 진행 |
|---|---|
| 수동 | 명령 준비 완료에서 정지. 카드 선택·확정 후 재개 |
| 오토 | 명령 준비와 적 예고에도 진행. 현재 손패·공개 전황으로 카드·대상 판단 |
| 오토 중 직접 개입 | 시간을 멈춰 직접 선택. 확정 후 오토 복귀 또는 취소 후 재개 |

오토는 플레이어가 설정한 태세를 유지하고, 같은 효과·이동·회복시간·교체 제한을 사용한다. 충전 중에도 정지할 수 있으나 카드를 사용할 수 있는 시점은 바뀌지 않는다. 수동 대기는 준비된 명령을 보유하고 새 적 예고에 다시 정지한다.

## 4. 기초 카드와 원정 보상

기초 키트는 캐릭터 획득 시 함께 제공하는 초안이다. 별도 복사본 수집 없이 카드 계열 상한 안에서 시작 덱의 장수를 정한다. 대표 이동과 대표 스킬은 기초 키트에 포함한다.

보상은 캐릭터의 이번 원정 운영을 여는 카드·기존 조합과 이어지는 카드·큰 장면을 만드는 강한 기술로 구성한다. 카드 한 장은 기초 키트와 함께 사용할 수 있고, 다른 보상 카드를 꼭 먼저 얻어야만 작동하는 구성을 줄인다.

- 현재 파티의 원정 보상 카드 중 서로 다른 후보 3장으로 시작한다.
- 생존 캐릭터의 유효 후보가 있으면 최소 한 장 포함한다.
- 현재 조합과 연결되는 후보와 다른 운영을 여는 후보를 섞는다.
- 현재 덱과 대기 목록의 같은 계열을 합쳐 일반 3장·특수 1장에 도달하면 후보에서 제외한다.
- 후보 수가 부족하면 있는 만큼 제시하고, 모두 소진하면 카드 보상을 넘긴다.
- 후보·선택 결과를 저장해 이어하기로 새 보상을 추첨하거나 중복 획득하지 않는다.

종류 수·후보 수·장수 제한은 설계자가 조정할 검증 초안이다. 비평 후 첫 제작은 캐릭터 한 명의 기초 4종·보상 2종으로 줄였으며, 해당 검증 버전을 구현했다. 보상 6종은 이후 확대 예시다.

## 5. 무엇이 남고 초기화되는가

| 상태 | 같은 원정의 다음 전투·이어하기 | 새 원정 |
|---|---|---|
| 캐릭터 보유·기초 카드 사용권 | 유지 | 유지 |
| 레벨·승리한 전투의 경험치 | 기록 | 유지, 성장한 성능은 새 출발에 반영 |
| 출발할 때 가져온 기초 카드 인스턴스 | 유지 | 새로 생성 |
| 보상 카드·대기 목록 | 유지 | 초기화 |
| 개별 카드의 진화 | 유지 | 초기화 |
| HP·전투불능 | 유지 | 전원 최대 HP로 시작하는 초안 |
| 손패·버림패·게이지·전투 상태 | 현재 전투에서만 유지 | 각 전투 시작 때 초기화 |
| 지도·보상·선택·난수 | 이어하기에서 유지 | 새로 생성 |
| 발견·교전·완주 기록 | 기록 | 유지, 카드 사용권과 구분 |

성공해도 보상 카드를 영구 반출하지 않는다. 이미 승리한 전투의 경험치는 나중에 원정에 실패해도 남는 초안이며, 패배한 전투는 경험치를 지급하지 않는다. 게임을 잠시 종료하고 이어 하는 것은 귀환과 다르다.

캐릭터 레벨은 비교적 쉽게 올리고 상한을 둔다. 카드 영구 수집을 무한 성장으로 대체하지 않으며, 추가 영구 전투력 계층은 별도 결정 사항이다.

## 6. 경로·정비·덱 관리

기존 10개 방의 분기 원정을 검증 출발점으로 사용한다. 기존 카드 확보 방은 **정비 방**으로 바꾸고, 보상 카드 한 장 또는 생존자 HP 15% 회복 중 하나를 선택하는 초안이다. 전투불능 복귀는 회복 방이 맡는다.

영구 카드 확보·미확보 보상·초과 카드 조각·조각 교환·조각 첫 손패 예약은 새 설계에서 사용하지 않는다. 관련 구현은 새 규칙의 게임 전환 단계에서 변경한다.

출정 중 파티는 고정한다. 시작 때 실제로 가져온 카드와 이번 원정에서 얻은 카드로만 전투 사이 덱을 재편성하며, 가져오지 않은 기초 카드의 새 복사본을 도중에 생성하지 않는다. 캐릭터별 카드 비율은 자유이고 시전자가 다른 카드끼리 교체할 수 있다.

빼둔 카드도 대기 목록에서 다시 편성할 수 있다. 진화 상태는 카드 인스턴스에 연결해 빼고 넣어도 유지한다. 전투불능 카드 제외는 전투 안의 처리이며, 캐릭터가 복귀하면 해당 원정 카드를 다시 사용할 수 있다.

## 7. 캐릭터의 획득 가치와 검증

캐릭터의 획득 가치는 대표 연출·고유 행동·전용 카드·동료와의 조합에서 만든다. 기초 키트로 그 매력을 바로 경험하고, 원정 보상으로 다른 운용을 펼친다. 보상 카드와 진화는 플레이로 얻는 구조다.

첫 제작은 검사 원형 하나의 기초 4종·보상 6종과 대표 스킬 한 종의 전용 연출을 연결한다. 나머지 카드 연출은 기본 동작과 효과 변형을 공유할 수 있다. 다음에는 같은 근접 태그의 두 번째 캐릭터로 경험의 차이를 검증한다.

규칙 검사는 카드 수명·후보·덱·진화·저장·오토·이동을 확인한다. 재미 검증은 다음 기준으로 한다.

- 자동 전투에서도 캐릭터의 성격과 역할이 보이는가?
- 대표 스킬을 다시 보고 싶은가?
- 보상 선택 후 전투 장면과 판단이 달라지는가?
- 그 캐릭터를 자신의 파티에 넣고 싶은가?

구체적인 제작 순서와 완료 기준은 [개발 로드맵](개발_로드맵.md)을 따른다. 기존 베이스와 인터뷰는 당시 결정의 기록으로 보존하고, 영구 카드 수집과 충돌하는 부분은 최신 설계가 대체한다.

## 8. 남겨둔 중요 결정

캐릭터 획득·판매 방식과 포함 상품, 레벨 이후 영구 성장의 범위, 정식 플랫폼·아트·세계관·첫 출시 규모는 아직 확정하지 않았다. 가격·확률·중복 구매 성장 규칙을 임의로 확정하지 않는다.

덱·손패·후보 수, 카드 종류 수, 피해·회복·명령 시간, 정비 효과와 방 배치, AI 점수·정보 표시 등은 설계자가 초안과 검증으로 채운다. 현재 설계 고도화를 완료하는 데 추가 수치 인터뷰는 필요하지 않다.
