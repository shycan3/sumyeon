# 경로 비용과 공개 도전 — challenges1

6방 구조와 기본 원정의 보상/회복 수치는 유지했다. 방 선택 전에 현재 HP 기준 회복량과 포기하는 혜택을 보여준다. 휴식↔진화/추격 릴레이, 휴식↔강적 카드/추가 정비, 정비 카드↔생존자 회복을 명시한다. 선택한 방과 대가는 결과에 남는다. 카드 보상 한 장의 가치를 숫자 하나로 환산하지 않는다.

## 공개 조건

기본 원정 1회 완주 후 출발 덱 화면에서 선택한다. 레벨 5, 고정 시드, 오토 전투, 기존 20장 출발 덱과 원정 한정 보상. 영구 경험치·능력치 보상은 없다. 오토 방침/덱/태세/보상/경로는 전투 사이에 조정할 수 있다. 관전 일시정지와 배속은 유지하고 카드 수동 개입 및 단축키는 막는다.

- 지원망 공략(51021): 첫 방 회복자 방벽, 중간 방벽/돌격대, 강적에 기존 치유사 동행. 휴식은 생존자만 회복하여 전투불능 복귀가 없다. 추가 목표는 강적 격파 후 최종 전투 종료 시 전원 생존이다.
- 정비 물자 제한(51022): 정비 방 및 강적 추가 정비에서 HP 회복 선택 불가. 카드 회복과 휴식 방 회복/복귀는 유지한다. 추가 목표는 휴식 방을 선택하지 않고 최종 전투 종료 시 전원 생존이다.

완주와 목표 달성은 별도 기록이다. 종료된 시도/완주/목표 달성 횟수, 완주 최단 시간과 최고 잔여 HP, 목표 달성 최단 시간을 도전별로 보존한다. 최단 시간/최고 HP는 서로 다른 완주일 수 있다. 진행 중 시도는 종료 기록에 집계하지 않는다. 중도 귀환도 종료 시도로 기록한다. 새 원정에서 보상 카드·진화·전술은 초기화한다.

## 저장·연습

이전 저장의 도전/경로 필드는 선택 사항이다. 기존 진행 원정을 새 조건으로 변경하지 않는다. 새 도전은 ID/규칙 버전/고정 시드/레벨/지도/오토 조건을 검증한다. 적 치유사도 전투 시작 기록에 저장되므로 기존 연습 기능에서 실제 조건 그대로 재현된다. 연습은 도전 성적/원정/경험치를 변경하지 않는다. 임의 저장 파일 조작에 대한 경쟁 보안 시스템은 아니다.

## 검증 결과와 한계

`challenges-check.cjs`: 두 도전×세 추천 덱×두 방침×두 경로의 실제 24개 원정. 매 단계 저장 검사, 첫 교전 저장 재현과 동일 조건 연습, 도전 제한/원정 초기화/영구 레벨·경험치 불변 검증. 모두 완주; 성장 경로 12개만 목표 달성. 안전 경로는 모두 더 빠르지만 추가 목표를 놓친다. 성장 경로가 더 높은 최종 HP를 남긴 비교는 12개 중 4개다. 원정 시간에는 추가 강적 전투도 포함되므로 서로 다른 경로의 시간 차이를 덱 성능만의 차이로 해석하지 않는다.

`challenges-browser-check.cjs`: PC 1280/모바일 390, 미해금/선택/공개 조건, 수동 차단·관전 정지 허용, 재접속, 경로 비용, 제한 정비, 결과와 누적 성적, 가로 넘침/브라우저 오류 확인. `character-check.cjs`, `character-browser-check.cjs`, `route-choice-check.cjs`, `relay-browser-check.cjs` 회귀 검사도 수행했다.

현재 레벨 5에서는 두 목표 모두 쉽게 달성된다. 목표/경로 기록의 첫 틀이며 도전 난도 완성은 아니다. 강적 진화 혜택이 체력 소모를 항상 보상하거나 모든 덱에서 최선이라고 주장할 수 없다. 이후에는 같은 시드와 경로에서 덱 변경의 극복 차이를 비교하고 적 조합/공개 목표를 소수씩 조정한다. 방/화폐/상점을 추가하여 판단 비용을 늘리지 않는다. 로드맵 1단계의 전체 오토 UI 정리·제한 기본 회피·공통 예측은 계속 미완료다.
