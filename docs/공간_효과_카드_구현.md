# 배치 확장 3단계 · spatial1

보호와 카드 범위를 실제 판정에 연결했다. 배치는 시작 위치이며, 전투 중 이동에 따라 유효 대상이 달라진다.

- 준비 화면: 선택 캐릭터의 기본 사거리, 보호 태세 방패병의 반경 110. 편성한 공간 카드는 별도로 조회한다. 직선 미리보기는 가까운 적을 향한 출발 위치 기준 예시다.
- 관전 화면: 보호 태세 반경 110, 엄호 반경 115와 실제 보호 연결, 선택·시전 중 공간 카드 범위. 전황 상세에서 범위 표시를 끌 수 있다. 카메라 크기는 범위 표시로 변경하지 않는다.
- **모여드는 온기**: 지원가 주변 반경 130 안 생존 아군을 36 회복, 명령 회복 7초, 준비 0.3초. 시전 완료 시 위치로 판정한다.
- **빛의 사선**: 길이 460·폭 60, 적마다 피해 33, 명령 회복 6초, 준비 0.45초. 시전 시작 위치·방향을 고정하며, 완료 시 범위 안 적에게 적중한다. 적이 움직여 벗어나면 빗나간다. 카드 차단은 한 번으로 공격 전체를 막는다.

두 카드는 공명 특성, 원정 보상 전용, 종류별 최대 2장이다. 출발 덱에 지급하지 않으며 기존 전역 회복과 광역 공격은 유지한다. 진화는 기존 규칙대로 한 번만 가능하고 원정 종료 시 초기화된다. 그림은 범위를 설명하는 SVG이며 최종 캐릭터 아트는 아니다.

오토는 실제 범위 안의 회복 결손과 공격 대상을 평가한다. 범위 밖 위기 아군으로 주변 회복의 점수·보호 우선순위를 올리지 않는다. 직선 카드는 사거리 안 적별 방향을 비교한다. 이동·밀집 유도·무료 기믹 회피는 새로 추가하지 않았다.

`spatialRulesVersion`을 원정·교전·연습 기록에 저장한다. 기존 원정의 보상 후보와 기존 적 기본 카드 구성은 유지한다. 새 원정부터 공간 카드를 제안한다. 시전 중 직선의 원점·방향도 저장·검증한다.

## 검증

- `spatial-check.cjs`: 실제 회복 대상·기여도, 원 경계, 직선 폭·길이·방향 고정, 다중 피해·전체 차단, 잘못된 공간 예고 거부, 이전 보상 호환, 시작 카드 미지급, 24회 오토 교전과 저장 검증.
- `spatial-browser-check.cjs`: PC 1280×720·모바일 390×844에서 편성 카드 범위, 화면 넘침, 실제 직선 시전·저장 복구. 준비 화면은 기존 4개 화면 크기 검사도 통과.
- 보상 성장 검사: 300회 첫 보상 제안과 96회 다단계 원정, 95회 완주. 신규 카드 포함 전체 후보가 제안되고 최종 덱과 실제 사용 기술이 달라졌다. 이는 표본 검증이며 카드 간 균형이나 배치의 전략적 완성도를 입증하지 않는다.
- 기존 효과·AI·표적·기여도·캐릭터 원정·관전 조작 검사를 수행했다.

다음은 같은 덱·HP·방침에서 배치만 바꾸는 비교다. 첫 표적·첫 타격 시간·보호 분담·동시 피격·첫 전투불능·최종 결과를 비교하고, 공개 적 조합에서 밀집/산개/측면 선택의 장단점이 충분한지 확인한다. 기본 이동으로 위치가 빠르게 수렴하는 문제와 완주율이 높은 표본은 별도 검토가 필요하다.
