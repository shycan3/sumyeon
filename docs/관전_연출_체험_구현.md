# 세린 관전 연출과 비교 체험

적용일: 2026-10-06. [세린 원정](../prototype/character.html)에 실제 판정과 연결한 관전 표현을 적용하고, [비교 체험](../prototype/spectator.html)을 추가했다.

## 실제 행동과 표현

- 기본 이동은 실제 좌표 변화로 보행을 표시한다. 공격·피격·반격·회복·기술 준비·전투불능·승리 자세를 구분한다.
- 동료는 방패·검·활·지팡이로 역할을 표현하며, 세린은 은빛 머리·스카프·검 동작을 유지한다.
- 잔광 검무는 준비 자세와 실제 타격 신호에 따른 세 번의 궤적·마무리 강조를 사용한다. 타격 간격이나 피해량은 바꾸지 않았다.
- 도발을 반영한 실제 대상에 타격 표현을 연결한다. 차단 또는 대상 사망으로 후속 공격이 끝나면 존재하지 않는 타격 연출을 재생하지 않는다.
- 엄호·추격 연결, 보호·회복 효과와 실제 피해·회복 숫자를 표시한다. 동시에 그리는 최근 효과·숫자 수를 제한해 화면을 가리지 않게 한다.
- 전투가 모이는 구간을 천천히 확대한다. 카메라는 화면 표현만 바꾸고 실제 좌표·사거리·선택 대상을 바꾸지 않는다. 운영체제의 움직임 줄이기 설정에서는 자동 카메라와 보행 흔들림을 끈다.

효과음은 브라우저 Web Audio로 생성한다. 사용자가 **소리 켜기**를 누른 뒤 준비·검무 타격·마무리·반격·보호·회복을 재생한다. 음성·외부 음원은 사용하지 않으며, 소리 끄기를 제공한다. 저장 복귀나 일시정지 중 다시 그리는 것만으로 과거 타격 소리를 반복하지 않는다.

렌더러와 효과음이 소비하는 판정 신호는 전투 인스턴스의 임시 정보다. 전투 저장·난수·카드 소비·AI 판단에는 포함하지 않는다. 이전 저장은 기존 진행 상태 그대로 이어가며 진행 중인 준비 자세는 예약된 실제 사건에서 읽는다.

## 비교 체험

레벨 1·동일 적·시작 HP·태세·난수로 세 가지 구성을 최대 45초 관찰한다. 지원가와 적 검사는 부상 상태로 시작하고, 공통 첫 손패에 잔광 검무를 포함한다. 실제 오토가 사용 시점과 대상을 결정하며 결과를 미리 재생하지 않는다.

| 구성 | 차이 | 실제 검사 결과 |
|---|---|---|
| 기초 키트 | 원래 20장 | 23.46초 승리, 검무 2타 |
| 추격 보상 | 간격 베기·돌진 각 1장을 이어지는 섬광으로 교체 | 17.08초 승리, 검무 3타, 추가 추격 1회 |
| 엄호 보상 | 같은 두 장을 너의 곁으로로 교체 | 21.08초 승리, 검무 3타, 엄호 피해 3.52, 반격 1회 |

기초 구성의 검무는 대상 처치로 2타에서 끝난다. 이를 가짜 세 번째 타격으로 보완하지 않는다. 세 구성의 전투 시간은 이 특정 전황의 결과이며 운영의 보편적인 강약이나 최종 난이도를 증명하지 않는다.

구성 선택·일시정지·같은 조건 다시 보기·실제 사용 카드 기록을 제공한다. 체험용 보상 카드와 전투 결과는 원정·캐릭터 성장·발견 기록·저장에 지급하지 않는다. 원정 거점에서 **관전 비교 체험**으로 들어갈 수 있다.

## 검증

- `spectator-check.cjs`: 실제 3타의 순서·시각, 전부/후속 차단, 임시 신호와 저장 분리, 정지·복귀·소리 중복 방지, 동일 전황과 세 구성의 실제 효과.
- `spectator-browser-check.cjs`: 1280×720·390×844의 세 전투·재시작·정지·효과음 켜기/끄기·움직임 줄이기·저장 격리·화면 넘침·렌더링의 전투 상태 불변성. 브라우저 오류 0건.
- `character-browser-check.cjs`: 원정의 카드 조작·보상·보스 완주·저장 복귀와 이전 저장 보존.
- `character-check.cjs`, `layered-ai-check.cjs`, `smoke.cjs`: 기존 전투·다층 AI·원정 규칙 회귀 검사.

현재 표현은 Canvas로 만든 프로토타입 캐릭터와 합성 효과음이다. 정식 캐릭터 아트·음성·애니메이션 제작과 별개이며, 다시 보고 싶은 장면인지와 캐릭터 매력은 실제 관전 감상으로 확인한다.
