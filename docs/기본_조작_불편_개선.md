# 기본 조작과 관전의 불편 개선

적용 버전: `character.html?v=comfort1`.

## 발견하고 수정한 동작

1. **조회창 열기·닫기가 전장을 확대/축소했다.** 전체 details를 고정 위치로 이동하면서 원래 버튼이 화면 흐름에서 빠졌다. 버튼은 하단에 그대로 두고 조회 내용만 띄우도록 변경했다. 버튼을 짧게 정리하여 모바일에서도 한 줄에 배치한다. 동일 버튼으로 닫거나 다른 조회창으로 전환할 수 있으며, 긴 내용 아래에서도 상단 닫기 버튼이 유지된다.
2. **오토 판단 문장의 줄 수에 따라 전장이 줄었다.** 적 예고·명령 상태·판단 문장·동료 HP의 공간을 안정적으로 배정했다. 긴 정보는 영역 안에서 읽거나 전황 상세에서 전체 내용을 확인할 수 있다. 매우 짧은 가로 화면은 판단 문장을 상세에 두고 전장과 하단 조회 버튼을 함께 보이게 했다. 배속·정지 버튼과 시계도 문구/숫자 변경에 따라 배치를 밀지 않게 정리했다.
3. **멈춘 전투에서도 대상 버튼의 키보드 포커스가 BODY로 빠졌다.** 실제 내용이 바뀌지 않았는데 매 프레임 같은 DOM을 다시 생성했다. 동일한 마크업은 유지하고, 대상 선택 등으로 내용이 바뀌더라도 같은 대상/행동의 버튼에 포커스를 복원한다. 읽던 카드 설명의 텍스트 선택도 불필요한 재생성으로 사라지지 않는다.
4. **연습 덱은 한 장을 수정할 때마다 창이 닫혔다.** 편집 후 해당 조회창을 다시 연결하고 실제 대화창 스크롤·조작 버튼·내부 펼침 상태를 복원한다. 모바일의 파티/추가 정보 창과 PC의 직접 연습 덱 창에서 모두 연속으로 편집할 수 있다. 태세 편집과 대기 카드 정리도 같은 복원 규칙을 사용한다. 출발 덱 선택과 보상 비교의 실제 스크롤 요소도 복원 대상에 포함했다.
5. **연습 시작 시 2배속이 1배속으로 돌아갔다.** 배속을 연습 세션의 UI 상태에 보관한다. 시작·종료·재편성 후에도 유지하며 1/1.5/2배를 제공한다. 이 상태는 원정의 덱·보상·저장을 변경하지 않는다.
6. **연습 정지 버튼이 멈춘 상태에서도 ‘일시정지’라고 표시됐다.** 멈추면 ‘관전 재개’, 재개하면 ‘관전 일시정지’로 표시한다. 실제 정지 상태를 aria-pressed에도 반영한다.
7. **설명을 고정해 읽는 동안 카드가 손패에서 사라져도 구분이 없었다.** 사용/교체된 카드 설명에는 `이전 손패 · 설명 유지 중`을 표시한다. 다른 카드를 누르면 해당 설명으로 바뀐다. 실험 도구에서는 현재 선택/사용 규칙을 유지한다.

전투 계산·카드 수치·AI 판단·원정 보상 규칙은 변경하지 않았다. 저장과 분리된 브라우저에서 검사했다.

## 근거와 검증

- `comfort-audit-before.json`: 320×568에서 조회 시 전장 높이 약 198→227px, 첫 자동 명령 이후 198→184px 변화. 대상 포커스 이탈, 편집창 닫힘, 배속 초기화, 정지 버튼의 잘못된 문구를 재현했다.
- `comfort-audit-after.json`: 같은 재현에서 전장 높이 약 173px 유지, 대상 버튼 포커스 유지, 연습 편집창 유지, 시작 후 2배속과 ‘관전 재개’ 표시를 확인했다. 보상 스크롤 표본에는 실제 스크롤이 없었으므로 그 표본을 보상 관련 결함의 증거로 사용하지 않았다.
- `comfort-browser-check.cjs`: 1280×720, 390×844, 320×568, 844×390, 768×1024, 360×640. 실제 첫 전투/보스전의 시간 진행과 네 조회창 열기·같은 버튼 닫기·Escape에서 전장 경계를 비교했다. 대상 포커스, 카드 설명 텍스트 선택, 긴 조회창의 닫기 버튼, 실제 오토가 소모한 카드의 설명 표시, 연습 창 연속 편집과 스크롤/포커스, 배속·정지·원정 비변경을 검사했다.
- `stable-watch-browser-check.cjs`: 화면별 115개 카드 연출/결과/대기 상태의 전장 경계와 연출 내용 경계.
- 기존 회귀 검사: `compare-ui-browser-check.cjs`, `battle-insights-browser-check.cjs`, `watch-ui-browser-check.cjs`, `watch-frame-browser-check.cjs`, `character-browser-check.cjs`, `card-structure-browser-check.cjs` 통과.

측정은 `prototype/comfort-browser-results.json`, 화면은 `prototype/comfort-battle-*.png`, `prototype/comfort-popup-*.png`, `prototype/comfort-practice-*.png`에 있다. 자동 검사 통과가 모든 기기·확대 배율·미래 장문에서의 완성을 뜻하지는 않는다.
