## 공통 비교와 판정 절차

세 비교를 구분한다: **같은 덱·다른 파티 / 같은 파티·다른 덱 / 같은 파티와 덱·다른 전황**. 고정 손패는 특정 선택을 분리해 보는 도구이며 정상 드로우의 반복 경험을 대신하지 않는다.

각 관문 기록에는 구현 버전·조건·실제 관찰·플레이어의 이유·해석·미확인 사항·판정 근거를 남긴다. 결과는 `관찰 대기 / 수정 후 재관찰 / 통과 / 해당 시스템 제외`로 기록한다. 관찰이 없는 상태를 추정으로 통과 처리하지 않는다. 통과 판단과 그 근거는 사용자에게 보고한다.

실패하면 해당 문제를 먼저 수정하고 같은 조건에서 재관찰한다. 이를 가리기 위해 새 자원·캐릭터·카드 수를 늘리지 않는다. 브레이크가 제외되어도 P4 이후를 브레이크 없이 진행할 수 있다. 처음부터 모든 브레이크 변형을 만들지 않고, 문제 관찰 후 반감과 후속 공격 보너스를 분리해 원인을 확인한다.

기존 전문성 원안과 잠수자의 환급은 우선 시험 대상으로 보존한다. 능력 두 개를 모든 인물의 영구 규격으로 강제하지는 않되, 실제 문제가 확인되기 전에 일괄 재설계하지 않는다.

관찰 양식: [P0 직접 플레이 관찰](P0_직접_플레이_관찰.md). 이 양식은 빈 기록이며 완료된 관찰 결과가 아니다.


## 반복 판단 개선의 현재 표본

B와 동일 초기 상태에서 공격 패턴만 바꾼 [비교 D](P0_변동_패턴_비교.md)를 구현했다. 사용자 직접 관찰은 아직 대기 중이다. 기존 조합을 유지하면서 위협에 따라 카드·실행자·자원 지출을 재평가할 이유가 생기는지 확인한다. 단순히 쉬워져서 좋았던 것인지와 구분한다. 전문성·브레이크·신규 카드 시험으로 넘어가지 않는다.

**D 플레이 후 갱신:** 사용자는 더 쉬워졌지만 전술적 다양성이 생겼다고 보고했다. 패턴 다양성의 긍정 근거로 기록하며 난이도·반복 판단의 재미와 구분한다. 후속 답변에서 “상황에 따라 카드·실행자를 다시 고르는 재미가 있었다”라는 보고를 확보했다. 이 표본의 실행자 재선택의 재미를 긍정 근거로 인정한다. 순서·조작 피로 근거를 추가 확인하기 전 P0 전체 통과를 판정하지 않는다. 압박을 조정한다면 같은 패턴에서 수치 한 항목만 달리하는 별도 비교를 사용한다. 새 시스템을 추가하거나 여러 수치를 동시에 변경하지 않는다.


**현재 다음 작업:** D의 패턴을 유지하고 카드 순서에 따른 유의미한 결과 차이의 이해와 반복 클릭의 피로를 확인한다. 난이도 하락만으로 긍정적인 선택 경험을 무효화하거나 즉시 수치를 올리지 않는다. 필요할 때 압박 수치 비교를 분리한다.


**사용 순서 관찰 표본:** [비교 E](P0_사용_순서_비교.md)를 추가했다. E 내부에서 같은 카드·실행자·대상을 선택하고 순서만 바꿔 결과를 비교한다. D를 보존하며 난이도·카드 성능·고유 효과·조작 방식은 조정하지 않는다. 기술 검사59개 통과는 사람의 순서 이해·조작 만족을 대신하지 않는다. 두 항목의 직접 보고 후 P0 전체 통과와 P1 진행을 판단한다.
