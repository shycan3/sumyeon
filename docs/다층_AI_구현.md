# 다층 AI 구현 계약

적용일: 2026-10-06. [기존 비평](다층_AI_비평.md)의 여섯 문제를 `character.html`의 세린 원정에 적용했다. 기존 4인 편성과 원정·카드 콘텐츠 범위를 유지한다.

## 판단과 실행

`actor-ai.js`는 읽기 전용 전투 정보로 행동안을 만든다. `character-engine.js`가 캐릭터 ID에 맞는 정책을 연결하고, `engine.js`의 공통 실행기가 이동·기본 행동·피해를 적용한다.

1. 행동할 캐릭터의 최신 전투 정보를 복사하고 동결한다.
2. 역할 정책이 살아 있는 적의 표적 후보를 만든다.
3. 캐릭터 정책이 정해진 조건에서 선호를 수정한다.
4. 카드 목적과 도발을 적용해 이동·기본 행동을 확정한다.
5. 실행기가 대상·진영·거리·회복시간을 재검사하고 실행한다.

실행 주체는 고유 `actor.id`로 식별한다. 캐릭터 정책은 `characterId`로 찾는다. 세린의 이동 판단에 `a1` 슬롯을 직접 사용하지 않는다. 정책 함수는 전투 상태와 기존 판단 기억을 쓰지 않고 새 행동안·기억을 반환한다.

현재 고유 정책은 세린 하나다. 호위 태세에서는 HP 70% 미만인 동료 주변의 적을 선호하고, 추격 태세에서는 역할 정책의 약한 적 선호를 사용한다. 다른 캐릭터와 적은 역할 정책을 사용한다.

## 점수와 판단 주기

역할·캐릭터 표적 선호는 공통 함수 `1 / (1 + 비용 / 기준값)`으로 0~1 범위에 맞춘다. 세린의 호위 조건이 성립하면 해당 후보 점수를 동료와 적의 거리 기준으로 교체한다. 서로 다른 척도의 임의 가산점을 합치지 않는다.

도발·대상 생존·진영은 점수 경쟁의 대상이 아니다. 카드 목적을 반영한 뒤 도발을 최종 공격 표적에 적용한다. 공용 카드의 효과/명령 시간 점수는 기본 행동 선호 점수와 별도로 평가한다.

세린은 일반 표적을 0.2초 간격으로 판단하고, 새 표적을 0.6초 유지한다. 유지 시간이 지난 뒤에도 새 후보 점수가 현재보다 0.08 이상 높아야 전환한다. 표적 무효화·태세 변경은 재판단을 허용하며, 카드 목적과 도발은 이 유지 규칙보다 우선한다. 나머지 역할은 매 틱 판단한다.

## 목적과 강제 표적

| 상태 | 이동 | 기본 공격 |
|---|---|---|
| 일반 | 역할·태세에 맞춰 접근 또는 거리 유지 | 최종 일반 표적 |
| 추격 | 지정 적에게 접근 | 지정 적 우선 |
| 추격 + 도발 | 도발한 적에게 접근 | 도발한 적 |
| 엄호 | 지정 동료 곁을 따라감 | 동료 주변의 적 |
| 엄호 + 도발 | 지정 동료 곁 유지 | 도발한 적, 사거리 밖이면 보류 |

도발은 기존 목적을 삭제하지 않는다. 도발이 끝나면 유효한 추격·엄호 목적을 다시 따른다. 목적 만료, 대상 사망·소실, 시전자 전투불능이면 기본 행동 처리 전에 목적을 정리한다. 공격 대상이 없거나 사거리 밖이면 공격 회복시간을 소비하지 않는다.

단일 공격 카드도 실제 효과 시점의 도발을 따른다. 돌진·연쇄의 후속 추격 목적은 실제로 타격한 적을 기록한다. 카드 점수의 피해·처치 예상도 같은 표적 판정을 사용한다. 지원가의 기본 회복은 공격 표적 강제와 별도로 처리한다.

## 카드 수락과 실패

카드 데이터의 `purposeMode`는 `compatible`·`replace`·`reject`를 구분한다. 현재 이동 카드와 세린의 간격 베기·엄호는 대체, 그 밖의 카드는 양립이다. 목적 때문에 사용을 금지하는 카드는 아직 없지만 금지 규칙은 실행기에 있다.

| 관계 | 명령 수락 시 처리 |
|---|---|
| 양립 | 기존 이동 목적 유지. 예: 받아치기, 회복 |
| 대체 | 기존 목적 즉시 종료. 새 목적은 새 기술 효과에서 생성 |
| 사용 불가 | 유효한 목적이 있으면 명령 거부 |

시전자 생존·손패 소유·공용 명령 준비·대상 유효성부터 검사한다. 기술 실행 중이거나 접근 이동 중이거나 시전자에게 예약된 후속 효과가 있으면 새 카드 명령을 거부한다. 수동·오토가 같은 검사와 수락 경로를 사용한다.

거부된 명령은 손패·명령 회복·목적·예약 효과·난수를 보존한다. 수락하면 목적 전환, 카드 소비, 효과 예약, 공용 기회 소비가 한 번 확정된다. 이후 대상 사망 등으로 효과가 실패해도 카드 소비와 목적 종료를 되돌리지 않는다. 이동 목적 대체만으로 이미 얻은 보호막·반격 효과를 제거하지 않는다.

## 틱 순서와 저장

틱은 시간 진행·접근 이동 → 예정 카드 효과 → 종료 검사 → 적 태세 → 캐릭터별 기본 행동 → 충돌 보정 → 손패 정리 → 적 카드 → 명령 준비 → 플레이어 오토 순서로 진행한다.

기본 행동은 기존 캐릭터 배열 순서로 판단하고 즉시 실행한다. 뒤 캐릭터는 앞 캐릭터가 적용한 이동·피해·사망을 읽는다. 모든 캐릭터를 같은 스냅샷에서 계획하는 동시 행동 규칙으로 바꾸지 않았다. 각 행동의 읽기 전용 정보는 해당 캐릭터 판단 직전에 만든다.

전투 저장은 `aiVersion: 2`와 캐릭터별 표적·다음 판단 시점·유지 시점·태세·목표·판단 이유를 기록한다. AI 버전이 없는 기존 세린 저장은 새 판단 기억만 초기화한다. 시간·난수·손패·확정 카드 효과·남은 목적·접근 이동·실행 시간을 보존하며, 기존 목적의 `source`·`controls` 누락도 허용한다.

기존 저장 키 `afterglow-character-v2`를 유지한다. 지원하지 않는 AI 버전과 잘못된 판단 필드는 가져오기 검증에서 거부한다. 같은 새 버전의 저장 복귀는 결정적으로 이어지지만, 업데이트 전 AI와 이후 일반 판단 결과까지 같다고 보장하지 않는다.

## 검증과 남은 범위

`layered-ai-check.cjs`는 도발 중 실제 기본·카드 타격, 엄호 위치 유지, 명령 거부 불변성, 수락 즉시 목적 전환, 후속 효과 중복 방지, 목적 정리, 읽기 전용 정책, 일시정지·저장 복귀·구형 저장 변환을 검사한다. 같은 역할의 정책 차이와 다른 슬롯의 세린 이동도 격리된 엔진에서 확인했다.

캐릭터 원정 검사에서 안전 경로 32회는 모두 승리했고, 강화·정예 경로 8회는 4회 승리했다. 수동 검사는 카드 점수를 사용하는 자동 선택 절차이므로 실제 사람의 우위나 재미를 증명하지 않는다. 기존 엔진 smoke 검사와 1280×720·390×844 브라우저 원정·저장·보상 흐름 검사도 통과했다.

`layered-ai-browser-check.cjs`에서 두 화면 규격의 목적 종료 안내·시전 중 사용 불가 사유·키보드 거부 원자성·명령 한 번 소비·시전 중 저장/복귀를 확인했다. 임시 비교 검사에서는 변경 전 기본 행동 루프와 새 공통 실행기의 전투 6종 × 2시드, 총 12회가 매 0.05초 스냅샷 기준으로 일치했다.

실제 원정 편성·HP/레벨 배열·카드 소유·저장 검증은 여전히 역할별 4인 구조다. 임의 파티와 같은 역할 여러 캐릭터의 실제 편성, 피해·회복 예약, 추가 캐릭터 정책은 다음 범위로 남긴다. 이번 변경은 판단 충돌과 실행 계약을 해결한 것이며 오토의 최적 플레이를 보장하지 않는다.
