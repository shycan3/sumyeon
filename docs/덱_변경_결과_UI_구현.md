# 덱 변경 결과 UI 구현

2026-10-07 · `character.html?v=growthui1` · UI 로드맵 4단계.

## 결과 요약

전투 결과와 원정 보고서에 `이번 덱이 보여준 변화`를 제공한다. 첫 교전은 원정 출발 덱, 이후 교전은 직전 교전의 시작 덱을 기준으로 구성/진화별 장수 차이를 표시한다. 한 전투 사이에 여러 번 편성했더라도 최종 구성 차이를 보여주며 변경 조작 이력을 추정하지 않는다. 과거 덱 기록이 없으면 비교 불가를 표시한다.

실제 교전 시작 덱으로 특성 종류 수/단계 변화를 계산한다. 추가·증가·진화한 카드의 기록을 우선하여 최대 3개를 요약한다. 변경 카드가 없으면 실제 사용된 카드부터 보여준다. 바뀐 카드가 3개를 넘으면 전체 구성 변경 목록과 상세 카드 기여도에서 확인한다.

요약 수치는 기존 insights의 실제 HP 피해/회복, 보호막 흡수, 차단, 피해 분담, 이동, 특성 강화를 재사용한다. 사용 수·손패 미등장·등장 후 미사용을 구분한다. 부분/과거 기록에서 미사용을 확정하지 않는다. 보호막/분담을 모두 제거한 피해로 합산하거나 과회복을 회복량에 추가하지 않는다. 기존 통계는 카드 종류별 합산이므로 사본/진화별 사용 효과로 나누어 주장하지 않는다.

특성 장면은 기존 타임스탬프/문구에서 최근 2개를 표시한다. 특정 변경 카드가 그 장면 또는 승리 원인이었다고 추정하지 않는다. 도발 등 합산 수치가 없는 지원은 상세 사용 기록과 함께 판단한다.

역할별 고정 검무/추격/엄호/반격 수치와 큰 기여도 표는 `전체 전투 통계·운영 기록` 안으로 이동했다. 승리/시간/잔여 HP를 요약에 합쳐 큰 배너 공간을 줄였다. 강적 추가 정비 선택은 별도로 유지했다. `덱 비교 연습`과 보상 진행은 결과의 고정 행동 영역에서 바로 접근한다.

## 비교 연습

기존 시작 조건 보존/연습 엔진을 사용한다. `이번 교전 덱으로`와 `변경 전 덱으로`를 제공한다. 변경 전 덱의 카드 종류/진화 상태/장수를 당시 보유 풀에서 정확히 복원할 수 있는 경우만 활성화한다. 처분된 카드·이미 진화해 남지 않은 진화 전 카드·과거 미기록 덱을 임의로 생성하지 않는다.

두 버튼은 기초 키트 확장 실험을 해제하고 당시 보유 풀로 되돌린다. 이전 편성은 같은 종류·진화 상태의 실제 사본을 선택한다. 원본 시드/적/HP/레벨/태세/원정 규칙/오토 방침은 유지하며, 전투 중에는 편성을 수정하지 못한다. 결과는 기존 시간/남은 HP/카드 기여도 비교를 사용한다. 난수 소비와 수동 원본의 차이 때문에 단일 비교를 완전한 인과 증명으로 표시하지 않는다.

원정 저장/보상/경험치/난수/덱을 변경하지 않는다. 분석은 기존 저장 기록에서 읽기 전용으로 계산하며 새 저장 버전이나 기록 필드를 추가하지 않았다.
