조사일: 2026-10-09 / 상태: 1차 출처 확인과 설계 추론 / 플레이 검증 전

## 1. 조사 범위와 읽는 방법

이번 분석의 최신 전제는 **전투 시작부터 4인 파티 필수, 모든 카드 완전 공용, 카드 → 실행자 → 대상 선택, 행동 게이지 없음**이다. 이전 개인 덱·소유자 카드·개인 턴·2인 또는 3인 축소 권장안은 이번 분석의 채택 조건이 아니다.

아래 ‘확인 사실’은 개발사·퍼블리셔가 작성한 공식 소개에서 확인한 범위다. ‘가능한 장점’, ‘설계 비용’, ‘채택 판단’은 우리 게임에 적용했을 때의 가설이다. 해당 작품이 실제로 그 문제를 겪었다는 평가나, 기능이 성공을 일으켰다는 인과 증거로 읽지 않는다. 공개 소개만으로 정확한 카드 공급·밸런스·저장 규칙 전체를 검증하지도 않았다.

출처는 개발사 공식 사이트와 개발사·퍼블리셔의 Steam 소개 본문, 공식 보도자료, 제작자의 발표 자료를 사용했다. 상점의 이용자 리뷰·평점·사용자 태그와 커뮤니티 공략은 아래 사실 판단의 근거로 사용하지 않았다. 직접 인용 없이 짧게 요약했다.

## 3. 학습과 판단에 적용할 총론

카드가 완전 공용이면 특정 인물 카드가 없어 개인 차례를 낭비하는 문제는 구조상 줄일 수 있다. 대신 카드 효과와 네 실행자의 특징, 대상을 함께 비교해야 한다. 소유자 문제를 없앴다고 판단 부담도 해결되었다고 가정하지 않는다.

- 출발부터 네 인물을 사용하되 공통 카드 문법은 적게 둔다. 실물 사본 수와 새로 배워야 할 효과 수를 구분한다.
- 각 캐릭터의 첫 특징은 한 문장으로 설명 가능한 수준으로 둔다. 개별 자원·여러 패시브·궁극기·별도 지속 시계를 동시에 더하지 않는다.
- 보상마다 새 카드 또는 강화 하나를 이해하게 한다. 전체 카드 목록을 외워야 첫 결정을 할 수 있는 구조는 피한다.
- 카드를 고른 뒤 네 실행자에게 생기는 차이를 바로 비교할 수 있어야 한다. 같은 카드의 해석이 인물별로 달라진다면 그 차이를 선택 순간에 보여준다.
- 기본 결과와 조건을 짧게 보여 주되 상세 규칙은 필요할 때 펼친다. 간결한 화면과 판정 투명성은 함께 검사한다.
- 네 명을 매 라운드 모두 클릭하게 해야 파티성이 생긴다는 가정은 하지 않는다. 실제로 누구를 실행자로 선택하느냐가 위협·빌드·HP에 따라 달라지는지를 본다.

## 4. 원정의 목적과 성과 보존

추천 목적은 ‘이번 조건으로 파티 해법을 만들고 후반 전투에서 충분히 사용하기’다. 최고 덱을 외부 콘텐츠의 필수 성능 자산으로 수집하는 파밍을 첫 제품의 중심으로 두지 않는다.

| 후보 | 기대 경험 · 설계 추론 | 추가 비용과 실패 위험 · 설계 추론 | 이번 권장 |
|---|---|---|---|
| 한 원정 모드 안에서 제작·활용 완결 | 보상에 맞춰 운용을 바꾸고 만든 빌드로 돌파 | 원정 종료 후 소유감이 부족할 수 있음 | 중심 구조로 먼저 검증 |
| 영구 저장 덱과 별도 활용 모드 | 빌드 소유·정밀 최적화·고정 상대 재도전 | 최고 옵션 반복 파밍, 정답 덱 고착, 저장 성능 통제 압력, 두 콘텐츠의 목적 충돌 | 첫 제품에서는 제외 |
| 빌드 기록·시드 재현 | 선택 회고·애착·다른 판단 비교 | 규칙 버전과 재현 가능성 관리 필요 | 정확한 이어하기 뒤 최소 기록부터 |
| 완주 빌드로 선택형 추가 전투 | 좋은 결과를 더 사용할 기회 | 필수 보상과 연결되면 후속 파밍 의무가 됨 | 필요성이 확인된 뒤 후보 비교 |

첫 큰 보상은 초반에 주고, 마지막 큰 보상 이후에도 실제 사용할 전투를 두 번 이상 남기는 것을 시험 방향으로 권한다. 카드가 사용되지 않았다면 공급 문제·효과 가치·전투 위치를 구분한다. 보상을 받았다는 사실이나 한 번 사용했다는 사실만으로 덱빌딩 재미가 입증되지는 않는다.

원정 종료 초기화는 시작 전에 안내한다. 중단 후 이어하기는 덱·강화·HP·난수·적 의도·선택을 그대로 복원한다. 숨은 가치 한도로 카드·등급·삭제 결과를 사후 변경하지 않는다. 제약이 필요하면 선택 전에 공개하고 사용자가 수정하거나 취소한다.

무귀속 카드에서는 전투불능을 카드 공급 압축 보상으로 바꾸지 않는다. 실행 가능한 인물만 줄어들며, 카드의 실물 영역·장수·공급은 바꾸지 않는 것이 기본 후보다. 신규 캐릭터는 반복 육성 재료를 모으기 전에 동일한 기준으로 시험할 수 있어야 한다.

## 5. 제공된 카제나 비평의 사용 범위

사용자가 제공한 비평은 학습 부담, 정답 덱 파밍, 세이브 결과 훼손, 수직 육성, 불투명한 판정, 스트레스에 따른 통제력 상실, 특정 캐릭터를 요구하는 랭킹, 빌드 사용처 부족, 세계와 인물 표현의 불일치를 경계하게 하는 설계 입력이다.

이 조사에서는 원본 영상과 모든 패치 기록을 대조하지 않았다. 특정 전투원 루프가 어떤 이유와 수치로 조정됐는지, 저장 가치 초과 시 정확히 어떤 변경이 적용됐는지, 강제 행동 불능의 현행 지속, 육성 재화량, 랭킹의 특정 캐릭터 의존도, 현재 엔드 콘텐츠의 충분성은 독립 검증한 사실로 쓰지 않는다. 주관적 불쾌감과 제품 규칙의 사실도 구분한다.

확인한 현재 개선 근거는 [스마일게이트의 2026-05-27 공식 업데이트 발표](https://newsroom.smilegate.com/bbs/board.php?bo_table=news&wr_id=2255)다. 이 발표는 대균열의 현 시즌 세이브데이터만 사용해야 했던 제한 해제, 출격의 선별 전투원 특수 효과 강화, 카오스 자동 전투, 획득 세이브데이터의 장비를 편집하는 신규 코어 도입을 설명한다. 따라서 초기 비평을 2026-10-09에도 그대로 적용되는 전체 규칙이라고 표현하지 않는다. 이 발표만으로 초기 문제 전부가 해결됐다거나 사용자의 현재 평가가 좋아졌다고 결론내리지도 않는다.

현재 제품 전체를 평가하는 대신, 우리 게임에서 같은 실패가 생기지 않는지 직접 검사한다.

## 6. 개발 범위와 재미 관문에 대한 총론

레퍼런스들의 수백 카드·수십 적·여러 모드를 우리 최소 제품의 필수 수량으로 복사하지 않는다. 카드 효과 하나도 네 실행자 특징·대상·적 의도와 상호작용한다. 4인 조건을 지키면서 카드·적·성장 축 수를 억제하는 편이 초기 검증 비용을 낮춘다.

개발은 4인 단일 전투 → 소수 보상과 후반 활용 → 한 원정 완결 → 같은 조건의 여러 해법 → 캐릭터 표현 → 검증된 콘텐츠 확장 순서가 적절하다. 현재 관문이 약하면 카드와 모드를 더 만들기 전에 규칙·공급·표현을 수정한다.

| 관찰 | 재미의 증거 후보 | 수정해야 할 신호 |
|---|---|---|
| 실행자 선택 | 같은 카드라도 위협·HP·보상에 따라 실행자가 달라짐 | 특정 한 명이 언제나 정답이고 다른 인물을 바꿔도 변화 없음 |
| 보상 | 보상 전후의 순서·실행자·대응이 실제로 달라짐 | 새 카드는 숫자만 높고 전술은 동일하거나 쓸 곳이 없음 |
| 원정 | 일반전도 선택의 재미가 있고 후반에 빌드를 사용함 | 최종 보상 때문에 앞 전투를 숙제로 처리함 |
| 패배 | 중요한 원인과 다음 시도에서 바꿀 선택을 설명함 | 결과를 보아도 규칙을 모르거나 특정 옵션이 안 나와서 끝났다고 느낌 |
| 반복 | 더 할 의무가 없어도 다른 해법을 시도하고 싶어 함 | 영구 전투력·정답 덱·필수 재료 때문에 반복함 |

자동 검사는 상태·공급·예측·저장 일치와 교착을 검사한다. 사람은 선택 이유·이해 오류·지루한 구간·보상 기여·재시도 의향을 확인한다. 자동 완주율·사용률·플레이 시간만으로 재미 관문을 통과 처리하지 않는다.

## 7. 근거의 한계

[Mega Crit 공동 창업자의 GDC 발표](https://media.gdcvault.com/gdc2019/presentations/Giovannetti_Anthony_SlayTheSpire.pdf)는 반복 설계, 카드별 사용 자리, 사람의 피드백과 수치의 병행을 설명한다. 발표가 소개하는 개발 사례를 다른 게임의 성공 공식으로 확정하지 않는다. 발표의 개발 연수·인원·콘텐츠 수는 우리 작업량 견적도 아니다.

이번 조사에 동료 심사를 거친 학술 연구나 인지부하 실험을 적용하지 않았다. 제작자의 발표는 1차 개발 경험이며 학술적 인과 검증과 다르다. 공식 소개 역시 기능이 존재한다는 근거이지 그 기능의 재미·접근성·밸런스를 입증하는 실험은 아니다.

[Subset 공동 창업자의 GDC 발표](https://media.gdcvault.com/gdc2019/presentations/Into%20the%20Breach%20Postmortem%20Final.pdf)는 가독성·적은 메뉴·작은 수치·시간 낭비 최소화·흥미로운 선택을 제약으로 두고, 복잡한 턴 순서가 깊이를 주지 못한 실험을 설명한다. 우리에게 주는 추론은 게이지 대신 공개된 문제를 깊게 만들고, 네 사람의 선택을 보여 주기 위해 메뉴와 규칙을 계속 늘리지 않는 것이다.

현재 한 가지 권장 룰셋은 [플레이 시스템 설계 v3](플레이_시스템_설계_v3.md), 다음 제작 관문은 [현재 로드맵](현재_개발_로드맵.md)에 있다.

최신 전제인 **4인 필수·카드 완전 공용·카드 → 실행자 → 대상·행동 게이지 없음**을 유지하는 방향을 권장한다. 공동 카드의 새로움보다 해결·발견·캐릭터 기여·재시도가 실제 플레이에서 성립하는지가 채택의 최종 근거다.
