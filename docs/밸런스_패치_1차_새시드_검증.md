# 1차 밸런스 패치 새 시드 검증

2026-10-10. 시드 31~32의 개발 비교와 별도로, 시드 51~52에서 기존 규칙과 새 규칙을 각각 90원정 실행했다. 전체 15편성, 3개 자동 정책, 일반 난이도, 브레이크 끔, 단계·턴 상한은 같다. 자동 정책과 적 HP·피해 수치를 추가 조정하지 않았다.

새 시드 실험은 같은 수정 후 소스를 읽고 `--balance legacy`와 `--balance current`로 규칙만 선택했다. 양쪽 manifest의 소스 SHA-256은 일치하며 밸런스 버전은 `voyage-balance-0` / `voyage-balance-1`이다. 이전 개발 비교는 실제 패치 전·후 프로세스가 수집한 별도 기록이다. 원래 684회 관찰 표본에는 이번 표본을 합산하지 않는다.

## 전체 결과

| 표본 | 기존 규칙 | 새 규칙 |
|---|---:|---:|
| 개발 시드 31~32 원정 승패 | 89승·1패 | 85승·5패 |
| 새 시드 51~52 원정 승패 | 89승·1패 | 89승·1패 |
| 새 시드 실제 전투 | 615 | 615 |
| 새 시드 HP 피해 / 완료 전투 | 8.27 | 8.64 |
| 새 시드 보호 흡수 / 완료 전투 | 15.66 | 17.25 |
| 새 시드 턴 / 완료 전투 | 2.99 | 3.26 |
| 새 시드 전투불능 이벤트 | 24 | 33 |

새 시드 양쪽 모두 중단·오류·HP 검산 불일치 0이다. 90개 원정 시작 조건의 짝을 모두 찾았으며 원정 승패가 바뀐 짝은 없었다. 개발 표본에서 나온 새 패배 4회는 새 시드에서 반복되지 않았다. 2개 시드씩의 표본으로 패치가 전체 난이도를 올렸거나 내렸다고 확정하지 않는다.

## 정예 쌍둥이의 선택 기회

아래 수치는 해당 예고·실행을 한 번 이상 관찰한 **전투 수**다. 쌍둥이 두 개체의 행동 횟수를 전투 수처럼 합산하지 않았다. 광역 적용에는 보호가 피해를 전부 흡수한 실제 공격도 포함한다.

| 시드·구역 | 전투 수 전후 | 준비 예고 전후 | 준비 실행 전후 | 광역 예고 전후 | 실제 광역 적용 전후 | 평균 HP 피해 전후 | 전투불능 전후 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 31~32 · 7구역 | 26 / 30 | 20 / 30 | 5 / 25 | 5 / 25 | 4 / 9 | 5.12 / 4.20 | 0 / 0 |
| 51~52 · 4구역 | 31 / 38 | 9 / 35 | 0 / 13 | 0 / 13 | 0 / 4 | 5.61 / 4.42 | 0 / 0 |
| 51~52 · 7구역 | 12 / 17 | 12 / 17 | 4 / 17 | 4 / 17 | 0 / 3 | 4.58 / 3.47 | 0 / 0 |

개발 시드와 새 시드 모두 준비·광역 예고를 볼 기회가 늘었다.

새 규칙에서도 광역 예고를 보고 전투를 먼저 끝내는 경우가 많다. 이는 예고가 실제로 선택에 도움이 되었는지 직접 플레이에서 살펴볼 구간이다. 예고를 본 비율과 적 공격이 반드시 실행된 비율을 같게 취급해서는 안 된다.

평균 HP 피해는 두 표본 모두 정예 쌍둥이에서 낮아졌고 전투불능과 패배는 없었다. 하지만 보상 후보 변화로 덱과 경로도 바뀌었으므로 준비 시점 하나의 효과를 분리한 결과는 아니다. 정예 체력·피해를 이번 결과에 맞춰 추가 조정할 근거는 아직 부족하다.

## 같은 보스 표적 선택이 새 시드에서도 반복됨

새 시드 유일한 패배는 두 규칙 모두 시드 52, cautious, 항해사·도선사·측심사·인양사였다. 파수꾼과 관측자 보스에서 다음 기록이 남았다.

| 관찰 | 기존 규칙 | 새 규칙 |
|---|---:|---:|
| 전투 진입 파티 HP | 88 | 97 |
| 전투 턴 | 13 | 14 |
| 실제 HP 피해 | 88 | 97 |
| 보호 흡수량 | 170 | 162 |
| 파수꾼에게 입힌 실제 피해 | 63 | 63 |
| 종료 시 파수꾼 HP | 5 | 5 |
| 종료 시 관측자 HP | 18 | 18 |

두 규칙에서 관측자는 시작 HP 18을 끝까지 유지했다. 실제 타격과 견제 카드가 손패에 도달하고 사용되었으므로, 이 사례를 공격 카드를 전혀 뽑지 못한 패배로 설명할 수는 없다. 보호가 실제로 많은 피해를 막았지만 오토는 적 숫자를 줄이는 선택을 하지 않고 보스에 공격을 집중했다.

이 표적 선택 양상은 이전 시드 32의 자연 패배와 비슷하다. 보스 수치를 낮추기 전에 자동 판단의 표적 선택을 별도 조사할 근거가 늘어났다. 이번 새 시드 기록은 표적만 바꾼 인과 실험은 아니며, 승리하는 대안을 실제로 재생하기 전에는 표적 선택 하나가 패배 원인이라고 확정하지 않는다.

## 비교의 한계와 다음 관찰

새 시드에서 같은 경로인 원정 짝은 74/90, 같은 성장 선택·최종 덱인 짝은 각각 0/90이다. 같은 구역·노드·적 패턴 전투 592쌍 중 공개 진입 상태가 완전히 같은 표본은 135쌍이었다. 이 실험은 동일한 원정 시작 조건에서 패치 전체를 비교한 것이다.

공통으로 반복된 신호는 정예 준비와 광역 예고가 더 자주 보인다는 점이다. 다음 직접 플레이에서는 예고를 본 순간 처치·약화·보호 사이에 다른 선택을 고민하는지 관찰한다. 보스 패배는 경로·덱 성장과 자동 표적 선택을 함께 분석하고, 승률에 맞추기 위해 적 수치를 억지 조정하지 않는다.
