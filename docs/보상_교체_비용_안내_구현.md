# 보상 교체 판단 · rewardcost1

2026-10-08 · 개발 로드맵 v5.0의 1단계.

## 적용

보상 획득 전 비교와 획득 후 대기 카드 교체에 같은 순수 계산을 적용한다. 계산은 편성 카드·빠질 사본·들어올 사본만 읽고 원정·저장·난수·제안 목록을 변경하지 않는다.

- 기존 효과·시전자·특성·준비/다음 명령 시간·진화 수치 비교를 유지했다.
- 교체할 사본 선택을 비교 본문 위로 옮겨 후보를 바꾸기 쉽게 했다.
- 사본 수와 덱 비중, 편성된 진화 사본 수의 전후 변화를 표시한다. 같은 원본 카드의 일반/진화 사본을 합쳐 비중을 계산하지만 교체 대상은 선택한 상태의 한 장이다.
- 진화된 사본이 대기로 이동하는 것과 특성 단계 하락·비활성화를 알린다. 일반/진화 교체가 같은 원본 종류의 특성 수를 늘리지 않는다.
- 마지막 단일/전체/주변 회복, 적 카드 차단, 도발, 자기/동료 보호막, 피해 감소, 이동 대응, 반격·분담 카드 기능이 빠지는 것을 알린다.
- 보호막·차단·도발은 서로 다른 기능이다. 전체 회복이 남아 있어도 단일 회복이 사라질 수 있고, 주변 회복은 전체 회복과 구분한다.
- 구출·재배치 카드는 실제 이동 기능으로 분류하며, 데이터의 종류가 회복/차단이라는 이유로 없는 회복·차단을 표시하지 않는다.
- 새로 편성되는 기능과 사라지는 기능을 표시한다. 중요한 손실은 요약하고 같은 기능의 경고와 설명을 중복 나열하지 않는다.
- 카드 기능 기준의 안내다. 지원가의 기본 회복이나 방패병의 기본 보호·태세가 없어졌다고 표시하지 않는다. 덱 비중은 실제 사용 횟수·효과 예측이 아니다.
- 빠지는 카드는 진화 상태 그대로 대기에 남는다. 손실 안내는 선택을 막는 확인 팝업이 아니며, 기존 교체·보관·넘기기·되돌리기를 유지한다.

후보 목록에도 진화 사본·중요 기능·특성 단계 손실을 짧게 표시한다. 보상 전 비교와 보상 후 교체의 안내가 서로 다른 계산을 사용하지 않는다.

## 자동 원정 검사 보완

기존 검사의 '앞에서 찾은 중복 사본부터 교체'는 진화된 사본이나 중요한 기능을 제거할 수 있었다. 기본 검사에서는 아래 비용이 없는 합법적인 교체를 먼저 찾는다.

1. 진화 사본 제외, 중요한 카드 기능 제거, 활성 특성 단계 하락을 피한다.
2. 가능한 후보 중 특성 종류 손실을 줄이고 중복 사본을 우선한다.
3. 조건을 만족하는 교체가 없으면 획득 카드를 대기로 보관한다.

이는 검사용 보수적인 선택 규칙이다. 게임이 플레이어의 교체를 자동으로 결정하거나 최적 구성을 보장하는 기능은 아니다. 보상 선택의 주 특성·새 종류 선호는 기존 규칙 그대로다.

이전 결과 파일은 보존했다. 새 기본 결과는 별도 파일에 저장하며, 기존 교체 규칙 재검사는 --legacy-replacements 옵션으로 별도 결과를 만든다.

## 144회 결과와 한계

기존과 같은 세 출발 컨셉·8개 시드·공격/보호 방침·회복/성장/보상 건너뛰기 선택 묶음으로 검사했다. 새 교체는 288회였고, 진화 사본 제외·집계된 중요 기능 제거·활성 특성 단계 하락은 0회였다. 이 표본에서는 보관으로 넘기는 사례가 없었으며, 보관 대안은 별도 검사로 확인했다.

| 선택 묶음 | 완주 | 보스 진입 평균 HP | 마지막 전투 종료 평균 HP |
|---|---:|---:|---:|
| 회복 위주 | 48/48 | 422.6 | 382.4 |
| 성장 위주 | 48/48 | 320.6 | 296.8 |
| 보상 건너뛰기 | 47/48 | 314.7 | 291.3 |

48조건 중 완주 여부 차이가 난 것은 여전히 1조건이다. 중요한 기능을 보존한다고 최적 성장이나 승률 개선이 보장되는 것은 아니다. 교체 변경에 따라 이후 덱·보상 후보·전투 HP도 바뀌므로 새 수치를 카드 한 장의 효과로 해석하지 않는다.

같은 교전 기록에서 HP를 25%로 낮춘 별도 보스 스트레스 검사 48쌍은 출발 덱 39승, 성장 덱 34승이었다. 성장 덱만 승리한 것은 2쌍이다. 이 HP 변경은 게임에 적용하지 않았고, 카드·경로 선택도 최적 플레이가 아니므로 성장 카드 전체의 강약 판정에 사용하지 않는다.
