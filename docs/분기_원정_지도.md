# 《수면》 분기 원정 지도

적용일: 2026-10-10 · 실행: [심층 원정](http://127.0.0.1:8765/party-expedition.html)

원정의 경로 선택을 슬레이 더 스파이어처럼 노드와 연결선으로 표현했다. 선택할 전투뿐 아니라 이후 정비 장소와 보스까지 보고 항로를 결정할 수 있다. 게임을 새로 시작해야만 볼 수 있는 기능이 아니며, 진행 중 원정에도 지도를 연결한다.

## 실제 동작

- 새 원정은 세 갈래에서 출발한다. 전투 7층에 각 3개 조우와 그 뒤의 정비 장소를 배치하고, 8번째 전투인 파수꾼으로 합류한다. 전체 지도는 출발 포함 44개 지점이다. 한 판에서는 8전투와 7정비를 방문한다.
- 전투·강적·정박지·상점·관측실·파수꾼을 아이콘으로 구분한다. 지도는 아래에서 위로 진행하며, 현재 위치는 금색, 지나온 경로는 밝은 녹색, 지금 선택 가능한 지점은 빛나는 테두리로 표시한다.
- 지점을 누르면 정보를 먼저 확인한다. 현재 위치와 연결된 전투에서만 ‘이 경로로 진입’ 버튼이 나타난다. 미래 지점 열람은 이동이 아니며 미연결 지점·층 건너뛰기·되돌아가기는 규칙 엔진에서도 거부한다.
- 선택한 항로에 따라 다음에 갈 수 있는 경로가 달라진다. 전투 뒤 정비 장소도 미리 보이므로 회복·강화·카드 구매의 필요를 경로 선택에 반영할 수 있다.
- 위쪽 ‘지도’ 버튼은 전투·보상·정비 중에도 동작한다. 전투 중 조회에는 이동 버튼이 없고 카드 선택이나 라운드를 진행하지 않는다. ‘현재 위치’와 ‘최심부 보기’는 스크롤과 상세 정보만 바꾼다.
- 앞으로의 조우에는 초기 HP를 표시한다. 현재 실행 중이거나 막 끝난 전투에는 실제 남은 HP를 표시한다. 설명은 선택한 지점의 상세 패널에 모았다.

‘강적’은 기존 원정의 강한 문지기 조우를 구분한 표시다. 이번 지도 작업에서 능력치나 별도 강적 보상을 추가하지 않았다. 관측실 역시 현재 구현된 카드 획득·회복·강화 선택이다. 경로에 따른 새로운 서사 사건은 별도 후속 개발 범위다.

## 저장과 구현

`party-expedition-run.js`가 전체 노드·연결·현재 위치·방문 경로를 저장한다. `Run.mapView()`는 복사한 조회 객체를 반환하고 `choosePath()`는 연결된 노드 ID 또는 기존 선택 인덱스를 받는다. 지도 생성의 난수는 전투·보상 난수와 분리되어 있어 지도 조회 횟수로 손패나 보상을 바꿀 수 없다.

기존 저장 버전 `expedition-run-2`와 브라우저 저장 키 `sumyeon-expedition-professions-v2`를 유지했다. 지도 없는 이전 저장에는 현재 공개된 경로·전투·보상·정비와 확인 가능한 실제 과거 항로를 보존해서 지도를 붙인다. HP·덱·강화·손패·적 의도·전투 난수는 바꾸지 않는다. 신규 지도에서 임의 생성한 분기를 이유로 기존 선택을 지우지 않는다.

렌더링은 `party-expedition-map.js`와 `party-expedition-map.css`, 상세 정보·조회 창·진입 조작은 `party-expedition-app.js`가 담당한다. 연결선은 SVG이며 버튼과 같은 좌표를 사용한다. 좁은 화면에서는 지도와 상세 정보를 세로로 배치한다.

## 확인한 범위

| 검사 | 결과 |
|---|---:|
| 전투 규칙 회귀 | 83개 통과 |
| 원정 단계·보상·정비·저장 | 24개 통과 |
| 지도 연결·이동 제한·마이그레이션·난수 | 16개 통과 |
| 통합 검사 | 23개 통과 |

총 146개 검사 통과. 지도 전용 검사는 64개 시드의 모든 지점이 출발에서 도달 가능하고 막다른 길 없이 보스로 이어지는지 확인했다. 통합 검사는 15개 편성 × 브레이크 OFF/ON의 30원정을 실제 합법 입력 3,104회로 완료했다. 이는 연결·규칙·저장 검사이며 재미나 편성 균형의 통과 판정이 아니다. 상세 결과는 [분기 지도 기술 검토](분기_지도_기술_검토.md)를 참조한다.

브라우저에서는 사용자가 진행 중인 7/8구역 원정을 그대로 둔 채 지도 조회·미래 보스 조회·현재 위치 복귀·새로고침을 확인했다. HP·손패·에너지·적 예고는 보존되었고 오류 로그는 없었다. 별도 테스트 주소의 브라우저 접근은 승인 검토에서 거부되어 신규 원정의 지도 진입 UI 전체 조작 검사는 수행하지 않았다. 반응형 CSS와 좌표는 코드 검토했으며 임시 viewport 설정이 실제 탭 크기를 변경하지 않아 모바일 실화면 검증은 남아 있다.

이번 변경은 P5·P6의 경로 선택 구현에 해당한다. 이후 플레이에서는 ‘회복·구매·강화 계획 때문에 다른 길을 고를 이유가 있는가’를 평가한다. 노드 수나 자동 완주만으로 좋은 원정이라고 판정하지 않는다.
