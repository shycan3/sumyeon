# 분기 지도 기술 검토

검토일: 2026-10-10. 대상은 `prototype/party-expedition-run.js`의 원정 지도와 `prototype/party-expedition-integration-check.cjs`의 독립 통합 검사다. 이번 작업은 기존 두 경로 목록에 선을 그리는 데서 끝나지 않고, 선택한 노드가 다음에 갈 수 있는 노드를 제한하는 실제 분기 지도를 구현하는 범위다.

## 지도와 원정의 연결

지도에는 전투와 그 전투 뒤 정비 장소가 별도 노드로 존재한다. 앞선 일곱 전투 층의 세 갈래에는 정박지, 유실물 상점, 관측실이 배치되고 마지막 층은 최종 보스로 합류한다. 시작점의 세 선택 이후에는 현재 정비 장소에 연결된 다음 전투만 선택할 수 있다. 아직 가지 않은 경로와 미래 장소는 확인할 수 있지만, 층을 건너뛰거나 지난 전투로 돌아갈 수는 없다.

`Run.mapView()`는 노드·연결선·방문 경로·현재 위치·현재 선택 가능한 노드를 공개한다. 반환 값을 수정해도 원정 상태가 변하지 않아야 한다. `choosePath`는 기존 화면의 인덱스 입력과 실제 노드 ID 입력을 함께 지원하며, 두 입력은 동일한 연결 제한을 따른다. 전투·카드 보상·정비 선택이 진행 중이면 다음 노드 이동은 잠긴다.

전투 수 여덟, 앞 여섯 전투의 카드 보상, 마지막 두 전투의 완성 덱 활용, 카드 사본의 강화·제거, HP 유지, 에너지 이월과 여섯 문양의 능력은 그대로 연결한다. 새 지도 생성의 무작위성과 전투·보상 무작위성은 분리한다.

## 독립 확인 항목

- 여러 시드에서 새 지도 모든 노드가 시작 갈래 중 하나로부터 도달 가능하고, 모든 노드에서 보스까지 이어지는지 검사한다. 분기와 합류가 실제로 존재하는지도 확인한다.
- 매 원정 입력 뒤 방문 경로의 인접한 두 노드 사이에 실제 연결선이 있는지 검사한다. 공개된 다음 선택과 지도 이동 가능 노드가 정확히 일치해야 한다.
- 미래 층, 연결되지 않은 같은 층, 이미 방문한 노드, 전투 진행 중 재이동을 상태·난수 변경 없이 거부하는지 확인한다.
- 지도·전투·보상·정비에서 저장 후 지형, 방문 경로, 현재 위치, 선택 가능 범위 및 다음 동일 입력의 결과를 비교한다.
- 지도 없는 실제 이전 v2 저장의 공개 경로와 적 수치를 고정 fixture로 검증한다. 이전 저장의 HP, 덱, 활성 전투, 손패 선별 대기, 카드 보상, 정비 장소 및 현재 RNG를 바꾸지 않고 지도를 덧붙여야 한다. 이전에는 표시되지 않은 세 번째 갈래까지 소급하여 다 방문 가능한 것으로 만들 필요는 없다.
- 서로 다른 15개 4인 편성에 브레이크 OFF/ON을 적용한 총 30개 원정을 합법 입력으로 진행한다. 연결된 경로를 따라 실제 승리 또는 파티 전멸에 도달해야 하며, 실패를 불법 상태 전환으로 감추지 않는다.

## 평가의 한계

자동 정책은 공개된 손패와 적 의도로 전투 행동을 고르고 정비에서 회복을 우선한다. 새로운 경로의 장기 가치, 카드 구매와 강화 사이의 고민, 플레이어가 지도를 보고 느끼는 긴장감은 측정하지 않는다. 자동 승률과 입력 수는 연결·복원·종료 가능성을 설명하는 기술 표본이며 재미 또는 편성 균형의 통과 판정이 아니다.

## 검사 결과

독립 통합 검사 **23개를 모두 통과**했다. 여섯 시드 `0`, `1`, `803`, `941`, `20261009`, `4294967295`에서 새 지도의 44개 노드는 모두 시작점에서 도달할 수 있고 보스로 이어졌다. 연결 제한과 반환 뷰의 분리, 실제 이전 저장 복원, 모든 원정 단계의 동일 입력 재현도 통과했다.

시드 20261009, 보통 난도에서 첫 번째 현재 연결 경로, 고정 카드 보상 선호, 회복 중심 정비라는 단순 정책을 사용한 **30개 원정은 모두 여덟 전투를 완주**했다. 총 합법 입력은 3,104회다. 검사 코드는 정상적인 파티 전멸에 따른 패배도 합법 종료로 허용하며, 모든 편성의 승리를 통과 조건으로 강제하지 않는다. 이번 표본에서의 승리를 게임 균형의 근거로 사용하지 않는다.

기존 여섯 문양 기술 검토의 지도 없는 원정 결과는 당시 버전의 기록이며, 이번 분기 지도의 결과와 구분한다. 원정 버전은 v2를 유지하고 별도 지도 버전 `expedition-map-1`을 저장하므로, 기존 활성 저장은 새 원정을 강제로 시작하지 않고 이어갈 수 있다.

지도상의 강적 분류는 기존 강한 문지기 전투를 표시하는 구분이다. 이번 지도 변경만으로 별도 유물이나 추가 정예 보상이 생기는 것은 아니다.
