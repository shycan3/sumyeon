# 《수면》 비주얼 바이블 초안

작성: 2026-10-11. 적용: 독립 탐험 프로토타입 P5. **임시 제작 규격이며 공식 화풍·인물 외형·스토리 캐논은 미확정이다.**

## 1. 공통 표현

목표는 절제된 2D 서브컬처 캐릭터와 조용한 공간의 불안함이 공존하는 화면이다. 배경은 큰 명암 덩어리와 분명한 소품 실루엣을 먼저 읽게 하고, 얼굴·손의 세부 밀도는 인물 초상에 집중한다. 가는 선화를 사용할 경우 배경과 인물의 외곽선 굵기·광원 방향을 맞춘다. 고채도 장식·과도한 노이즈·서로 다른 렌더 스타일의 합성은 피한다.

현재 납품 자산은 코드로 직접 작성한 **벡터 플레이스홀더**다. 실제 인물 일러스트, AI 생성 이미지, 승인된 지역 앵커를 제작했다고 주장하지 않는다. 원근·레이어·장소 실루엣·UI 배치를 검증하는 용도다.

## 2. 지역 테마

| 지역 | 팔레트/광원 | 구조와 반복 소품 | 이상현상 표현 | 제한 |
|---|---|---|---|---|
| 병원 | 청록 #8cd7ce, 먹색 #0c1922, 벽 #294449, 종이 #b6c7b8, 비상등 #b65b62 | 복도 문틀·천장 배관·형광등·기록 선반·수술대·침대 | 반복되는 소리, 기울어진 문틀, 멎은 기계 | 혈흔/괴물의 정체로 미탐사 조우를 확정 표시하지 않음 |
| 도시 | 기존 시험색 #d3a077, 푸른 그림자, 젖은 반사광 | 배수관·닫힌 상점·가로등·자판기 | 흐르는 방향이 다른 비, 늘어진 그림자 | 이번 단계에서 신규 지역 전체 배경 양산하지 않음 |
| 역 | 기존 시험색 #b7a1e4, 어두운 플랫폼, 제한된 안내등 | 대합실 문·배관·안내판·빈 선로 | 역순 방송, 도착하지 않는 열차의 잔향 | 미탐사 연결구 위치를 배경/지도에 선공개하지 않음 |

병원 대표 5곳: 비상등 복도, 간호사 대기실, 멈춘 수술실, 빈 병실, 연결구 홀. 콘텐츠와 장소 분류를 연결한다. 사건/시설을 해결해도 같은 방의 시각 정체성은 유지한다. 방문한 장소명은 방향 정보와 지도 접근성 이름으로 사용하되 미방문 장소명은 공개하지 않는다.

## 3. 캐릭터 앵커 규정

현재 6개 직군 ID와 공식 인물의 매핑은 미결이다. 기존 noa/serin/ria 등 다른 시제품의 자산을 새 직군의 공식 외형으로 재사용하지 않는다.

| 항목 | 공식 앵커에 필요 | 현재 상태 |
|---|---|---|
| 얼굴/눈/머리 | 정면·3/4·측면, 눈 간격·윤곽·고정 색 | 미정, 익명 실루엣만 사용 |
| 의상 | 앞/뒤 실루엣, 장식 위치, 재질·색 | 미정, 새 공식 복장 창작하지 않음 |
| 비율 | 신장·머리/몸 비율·어깨 폭 | 미정 |
| 유지 형태 | 눈·헤어 가닥·의상 문양 등 고정 포인트 | 공식 설정 확인 후 지정 |
| 표정 | 기본/긴장/미소의 소수 기준 세트 | 얼굴 승인 후 제작 |
| 직군 매핑 | 공식 인물↔직군 ID | 사용자 결정 필요 |

현재 직군별 색상과 256×320 익명 초상은 UI 구분용이다. 표정·얼굴 동일성 검증을 대신하지 않는다. 외형 승인 전 주요 인물 2~3명의 최종 초상 및 5개 표정/포즈 파생 제작은 진행하지 않는다.

## 4. 시점과 공간 합성

- 배경/사물의 공통 좌표계: 1600×900, 16:9, 소실점 (800,360). 임시 1인칭 기준 눈높이 목표 1.65m, 수평 시야각 목표72°. 이는 3D 카메라 실측값이 아닌 후속 제작 기준이다.
- 배경, 사물, 조명/이펙트, 인물, UI를 분리한다. 그림에 버튼·카드·한국어 설명을 구워 넣지 않는다.
- PC에서는 배경/사물을 장면 뒤에서 함께 합성한다. 좁은 모바일은 원근을 찌그러뜨리거나 주요 소품을 과도하게 크롭하지 않도록 전체16:9 장면을 위쪽에 보존하고 방향/조사 UI를 아래에 둔다.
- 이벤트 그림은 별도 자유 구도를 허용하되 현재 단계에서는 동일 장소 레이어를 재사용한다. 이벤트 선택/비용은 실제 HTML로 표시한다.
- 좌우 문 버튼과 중앙 조사 카드는 텍스트가 충분히 대비되는 독립 패널이다. 인물 반응은 장면 밖 비차단 행에 두어 방향 버튼을 가리지 않는다.

## 5. UI 규격

상시 정보: 현재 시간·체력·장소 배경·방향·짧은 기척·조사 대상. 법칙은 첫 진입에 정확한 효과를 공개하고 이후 요약/재열람한다. 지도·기척 전문·대화 기록은 무료 패널로 제공한다. 법칙/사건/화자 문구는 기술 용어를 늘리기보다 행동과 결과를 설명한다.

1242px/390px/320px에서 확인한다. 작은 헤더는 3열로 정리하고 방향/조사/사건 선택의 터치 공간을 유지한다. 흰 본문과 짙은 패널을 사용하며 이미지 밝기에 텍스트 대비를 맡기지 않는다. 키보드 포커스가 보이고 지도 목적지를 Enter/Space로 실행할 수 있어야 한다. 설정에서 임시 장소 아트를 꺼 이전 CSS와 동일 규칙으로 비교할 수 있다.

## 6. 자산 규격과 매니페스트

- 현재 배경/투명 사물: SVG 1600×900. 초상: 투명 SVG256×320. 확대 가능한 코드 자산이며 최종 일러스트의 세밀함을 주장하지 않는다.
- 후속 래스터 시험 목표: 배경1920×1080 또는2560×1440, 투명 초상768×960 이상. 실제 생성/브라우저 측정 후 용량과 해상도를 확정한다. 배경 WebP, 투명 인물 PNG/WebP를 비교한다.
- 명명: `hospital-{place}-bg.svg`, `hospital-{place}-props.svg`, `profession-{id}-portrait.svg`. 레이어는 동일 캔버스에서 정렬한다.
- 현재 파일의 실제 bytes/SHA-256/해상도/투명 여부는 `prototype/assets/exploration/manifest.json`에 기록한다. 임시 파일별 초기 목표는50KB 미만이며 향후 래스터 목표를 그대로 강제하지 않는다.
- 자산별 도구·버전·공통 프롬프트 모듈/장면 변형·앵커 참조·출처/권리·편집 이력·검수·승인 상태를 관리한다. 프로젝트 자체 벡터 외의 아트/참조는 사용하지 않았다. 프로젝트 자산의 배포 라이선스는 아직 지정하지 않았다.

## 7. 제작·수정·승인 절차

1. `visual-review.html`에서 배경/사물/UI 레이어를 각각 비교하고 대표 장면 후보를 선택한다. 후보 선택은 승인으로 처리하지 않는다.
2. 사용자가 지역의 색감·시점·대표 장면을 승인하면 해당 자산 ID와 파일 해시를 앵커로 기록한다. 공식 인물 외형/직군 매핑도 별도 승인한다.
3. 공통 스타일 + 지역/인물 고정 요소 + 카메라/샷 + 변형 + 금지 조건으로 프롬프트를 조합한다. 가능하면 승인 앵커를 참조/편집해 파생한다. 텍스트 프롬프트·시드만으로 동일인·동일 화풍을 보장하지 않는다.
4. 자산별 생성·수정·검토·승인 시간을 기록한다. 현재 코드 생성/개별 SVG 기록 시간은 측정했지만 디자인 작업·사람의 수정/승인 시간은 `null`이다. 후보 검토 화면은 시작 시각과 경과 시간을 기록한다. 기록 시간은 파일 쓰기 범위이며 최종 일러스트 제작 시간을 주장하지 않는다.
5. 팔레트·소실점·광원·인물 고정 특징·소품·권리/출처·UI 대비를 체크한다. 소실점 이탈, 같은 인물의 헤어/눈/의상 변화, 읽기 어려운 밝기, 캐논 불일치, 미탐사 정보 누설은 리젝 사유다.
6. 승인된 이미지가 있을 때 같은 병원 배경5개와 같은 인물 표정/포즈5개의 추가 생산을 확인한다. 이번 코드 벡터의10개 메모리 변형 검사는 기하/팔레트 재생산만 증명하며 승인 일러스트·얼굴 생산성의 증거가 아니다.
7. 소규모 슬라이스의 실제 플레이/아트 검토 후 대량 자산 제작을 별도 결정한다. 승인되지 않은 앵커를 자동 승인하거나 미결 공식 외형을 추측해 양산하지 않는다.
