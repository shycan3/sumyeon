# 세린 표현 완성 · v7 4단계 검증

적용일: 2026-10-09 · 플레이 버전: `serinlook1`

## 적용한 표현

세린의 은빛 짧은 머리·붉은 스카프·청록 외투·금색 장식·가느다란 검을 기준으로 새 초상화와 대표 검무 카드 그림을 제작했다. 성인 모험가의 실루엣과 단단하지만 동료를 지키는 표정을 사용했다. 초상화는 거점·대표 기술/궁극기·발견 장면에 공유하고, 검무 그림은 대표 카드에 연결했다. 다른 캐릭터 그림이나 세린의 기존 원본 자산은 덮어쓰지 않았다.

전장의 캐릭터는 기존 Canvas 형태를 유지하면서 코트 자락·금색 장식·스카프와 자세를 보강했다. 완성된 일러스트를 움직이는 리깅 캐릭터로 전환한 것은 아니다.

- **추격:** 실제 유효 추격 목적 또는 접근 기술 준비일 때 앞쪽으로 기울고 보폭·스카프·검의 방향이 바뀐다.
- **엄호:** 실제 유효 엄호 목적 또는 보호 기술 준비일 때 자세를 낮추고 검을 세운다. 실제 반격이 나오면 고정 엄호 자세를 우선하지 않고 검 동작을 표시한다.
- **준비/타격/마무리:** 현재 시전과 타격 신호를 읽어 구분한다. 잔광 검무는 3번째, 궁극기는 2번째 타격이 마지막이다. 마지막 타격의 자세·빛·효과음도 공유 기술 정의의 실제 타수에 맞춘다.
- **특성 연결:** 이미 실제 발생한 호위 보호 성공/강화 타격, 추격 후속 타격, 공명 강화의 짧은 문구를 표시한다. 후속 타격 연결선은 실제 발동 신호가 있을 때만 나온다. 없는 협동이나 성공을 예고 연출하지 않는다.

기본 공격·보호·회복·반격·대표 검무·궁극기 효과음은 기존 합성 음향을 사용하고 음량 조절을 추가했다. 녹음 음성·성우 연기는 추가하지 않았다. 스킬 대사는 짧은 텍스트다.

## 연출 접근성과 관전 유지

설정은 전체 / 간소 / **장식 연출 끔** 세 가지다. 끔에서는 초상화·대사·장식 타격 효과와 동작 진폭을 억제하고, 스킬명·진행 단계·실제 피해/회복/보호/차단·위험 구역·상태 정보는 유지한다. 기존 반복 설정 매번/주요 장면/전투당 첫 사용을 유지했다.

음량은 0~100%, 기본 60%다. 소리는 사용자가 직접 켠다. 0%에서는 오디오 노드를 만들지 않는다. 음량은 연출 설정에만 저장되며, 모드/반복 변경으로 초기화되지 않는다. 예전 음량 없는 연출 저장에는 기본 음량을 적용한다. 원정 저장과 분리했다.

긴 준비 시간에는 기술 단계 정보가 효과 완료까지 유지되지만 초상화·대사는 처음의 짧은 구간만 표시한다. 모바일에서 별도 단계 배지가 숨겨져도 캐릭터 이름 옆에 준비·1타·2타·마무리·차단이 표시되도록 수정했다. 초상화 출입은 기존 고정 크기 오버레이에서 처리하며 전장 크기를 변경하지 않는다.

## 검사

- `serin-expression-check.cjs`: 추격/보호 자세 구분과 읽기 전용 처리, 실제 특성 문구, 2타/3타 마지막 타격 음향, 음량/무음/설정 유지/과거 설정 마이그레이션, 긴 시전의 단계 유지, 전체·간소·끔에서 각 시뮬레이션 단계의 전투 상태 완전 일치.
- `serin-expression-browser-check.cjs`: 1280×720, 390×844, 320×568에서 새 초상화와 실제 카드 그림 로딩·설정·재로딩, 실제 검무 3타와 마지막 단계, 끔 상태에서도 차단 표시, 전장 경계 완전 일치, 오류/가로 넘침 없음. 거점·카드·시전·마무리 화면을 직접 확인했다.
- 기존 기술 연출 검사: 실제 타격/중단/처치, 같은 초상화 반복 억제, 우선순위·재개·일시정지·보호 정보 검사를 통과했다. 오래된 브라우저 검사에 현재 전투 준비 단계와 실제 명령 실행 경로를 반영했다.
- 관전 검사: 기본/추격/엄호의 실제 판정, 음향 중복 방지, 전투와 표현 분리.
- 기존 96개 전체 전투 기록 비교 유지. 실제 프레임 1배/2배·일시정지, 전체 원정 진행·저장/재개·보상/성장/복기/연습 검사도 통과했다.

일러스트의 매력·기억에 남는 동작·실제 소리의 청감·모바일 기기 성능은 자동 검사만으로 평가하지 않았다. 반응과 경험 검증은 실제 플레이에서 남아 있다.

## 제작 비용 기록

신규 이미지 **2개**, 재생성 0회. 기본 제공 imagegen으로 초상화 1개를 생성하고 그 이미지를 참조해 대표 카드 1개를 제작했다. 원본은 보존하고 프로젝트 자산으로 복사했다. 다음 캐릭터도 얼굴/의상 기준 한 장과 대표 기술 그림 한 장을 공유하는 소수 자산 방식을 먼저 시험할 수 있다.

| 자산 | 크기 | 용도 |
| --- | --- | --- |
| serin-portrait-v2.png | 2,473,564 bytes | 거점·대표 스킬·궁극기·발견 장면 |
| serin-dance-v2.png | 2,815,354 bytes | 대표 카드 그림 |

총 약 5.29 MB의 원본 PNG다. 반복 카드에서 같은 파일을 캐시하고 카드 그림에는 지연 로딩·비동기 디코딩을 사용했다. 화면 검사에서 이미지가 정상 로딩됐지만 저속 네트워크에서의 배포 부담은 측정하지 않았다. 다음 실제 배포용 자산 파이프라인에는 압축 포맷과 적절한 크기의 파생본이 필요하다.

작업 규모는 이미지 2개 + Canvas 자세/효과 확장 + 기존 음향/설정 확장이다. 실행 경과를 따로 계측하지 않아 전체 작업 시간을 숫자로 추정하지 않는다. 대표 카드 생성 호출의 도구 기록 대기 시간은 약 76.5초였고, 생성 대기 외에 코드 연결·모바일 확인·수정·검사가 필요했다. 비용은 이미지 생성 시간만으로 추정할 수 없다.

주요 구현 변경 파일: `spectator.js`, `skill-director.js`, `presentation-data.js`, `presentation-settings.js`, `card-visuals.js`, `character-app.js`, `character.css`. 공유 모듈 캐시 버전 갱신: `character.html`, `support-lab.html`, `spectator.html`, `auto-lab.html`, `boss-lab.html`, `combat-lab.html`. 신규 검사 2개, 기존 기술 브라우저 검사 갱신. 전투 엔진·카드 수치·원정 난이도는 이 단계에서 바꾸지 않았다.
