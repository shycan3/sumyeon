# 셀프 피드백에 따른 개선

적용일: 2026-10-06. 사용자가 셀프 평가에서 나온 문제의 수정과 적용을 요청한 뒤 반영한 버전이다. 수치는 후속 플레이로 조정할 초기값이며, 새 규칙을 이전 인터뷰의 확정 사항으로 취급하지 않는다.

아래 본문은 첫 개선 당시의 기록이다. 현재 적용 규칙과 재검증 결과는 마지막의 **2차 개선**을 따른다.

## 전투 관찰과 조작

전장과 손패를 데스크톱에서는 나란히, 모바일에서는 짧은 세로 구성으로 배치했다. 선택 카드의 상세 설명과 대상 버튼을 따로 제공한다. 카드 확정·대기·교체를 전장과 함께 볼 수 있고, 전투 진입 시 지도에서 남은 스크롤을 초기화한다. 충전 중에도 손패의 상세 효과를 살펴볼 수 있다.

## 카드 선택의 차이

- 강격은 먼 표적에게 자동 접근하는 준비시간이 최대 1.2초 추가된다. 명령 회복 시간은 그대로다. 돌진은 즉시 접근한다.
- 넓게 베기·방패 충격파는 선택한 위치 주변 반경 125·160 안의 적에게 적용한다. 확정 시 범위 중심을 고정하며, 준비 중 범위와 현재 적중 대상을 표시한다. 화살비와 보스의 붕괴의 파동은 전체 공격이다.
- 구속 사격은 둔화와 함께 표적이 준비 중인 공격 카드 발동을 1초 늦춘다. 같은 공격을 여러 번 지연시키지는 않는다. 차단과 도발을 준비할 시간을 만든다.
- 적 AI는 실제 광역 적중 수, 표식·둔화·지연 가치와 방어가 발동할 시간을 평가한다.

개별 이동을 반복 지시하는 조작은 추가하지 않았다. 캐릭터의 이동은 태세와 카드가 처리한다.

## 경로와 위험 보상

새 출정 지도에는 방 사이의 연결이 있다. 현재 방의 선택이 다음 줄의 접근 가능한 방을 바꾸며, 화면에서 다음 연결을 미리 확인할 수 있다. 확보 지점에서는 합류한다. 이전 저장의 연결 없는 지도는 기존처럼 이어간다.

강적의 HP 배율은 1.18에서 1.10, 기본 피해 배율은 1.15에서 1.08로 낮췄다. 첫 개선에서는 강적 승리 시 생존자 12% 회복과 진화 보상을 함께 제공했다. 2차 개선에서 둘 중 하나를 선택하도록 변경했다. 특수 카드 후보 보장은 유지한다. 휴식 방은 계속 전투불능 복귀와 30% 회복을 담당한다.

## 수집과 완주

보상은 영구 보유 수량과 아직 확보하지 않은 획득 수량을 함께 고려해 편성 상한에 못 미친 카드를 우선한다. 상한을 넘긴 후보는 출정 한정 진화 카드로 사용할 수 있고, 확보할 때 전술 조각 1개가 된다. 이미 갖고 있던 초과 복사본은 보존한다.

거점의 카드 수집 화면에서 전술 조각 3개로 원하는 카드 한 장을 얻는다. 해당 기술의 편성 상한까지 수집하면 교환할 수 없다. 조각은 카드 진화 재료가 아니며, 진화는 계속 출정 종료 시 초기화된다.

보스 완주 시 기존 보상 외에 상한 미달 특수 카드를 우선해 영구 카드 한 장을 추가 지급한다. 특수 카드가 모두 찼으면 일반 카드, 모든 카드가 찼으면 조각 3개를 지급한다. 자동 보너스 지급도 정산과 저장에 기록한다.

## 오류와 검증

늦게 발동하는 차단에 적이 명령을 낭비하던 문제를 고쳤다. 전투 80초 이후 압박은 카드 공격 버프와 별도 곱으로 계산해 기존 버프를 덮어쓰지 않는다.

기존 규칙 검사에 재현 검사를 추가하고, 서로 다른 덱·즉시 사용 전략·대기와 교체를 활용하는 전략을 비교한다. 자동 전략도 새 보상 카드를 실제 덱에 넣고, 사용한 개별 카드 ID로 이후 전투에서의 사용을 확인한다. 강화 대상 역시 덱의 전략에 맞춰 고른다.

실행: `node prototype/smoke.cjs`, `node prototype/simulation.cjs`, `node prototype/browser-check.cjs`, `node prototype/layout-check.cjs`.

최종 확인 결과:

- 기존 규칙·새 오류 재현·경로·보상·교환·기존 저장 호환 검사 통과. 보관한 단일 전투 검사와 JavaScript 문법 검사도 통과.
- 실제 브라우저에서 연결 경로 선택, 강화, 두 확보 지점, 강적과 보스 승리, 완주 보너스, 조각 교환, 전투와 보상 화면 새로고침, 저장 파일 복원을 확인했다. 완주 검사는 알려진 합법 경로 한 개를 사용하며, 난이도 평가는 아래 별도 비교로 수행한다.
- 1280×950·1280×720·390×844에서 전장·손패·예고·확정 버튼이 동시에 화면 안에 표시되고, 대상 버튼이 실제 표적을 바꾸는 검사 통과.
- 새 보상 카드의 실제 사용, 전략에 따른 강화 선택, 대기·교체·태세 변경을 포함해 총 120회 출정을 비교했다. 보스 전체 공격 앞에서 명령을 보유한 경우와 먼저 강격을 사용한 경우의 체력 차이도 별도 재현했다.

| 초기 덱과 자동 전략 | 안전 경로 | 위험 경로 |
|---|---:|---:|
| 기본 수집·기본 덱, 대응 전략, 일반 즉발 | 10/12 | 5/12 |
| 기본 수집·기본 덱, 대응 전략, 기존 준비시간 | 12/12 | 5/12 |
| 기본 수집·기본 덱, 즉시 사용 전략, 일반 즉발 | 12/12 | 6/12 |
| 전체 수집·공격 덱, 대응 전략, 일반 즉발 | 5/8 | 0/8 |
| 전체 수집·제어 덱, 대응 전략, 일반 즉발 | 8/8 | 2/8 |
| 전체 수집·지원 덱, 대응 전략, 일반 즉발 | 7/8 | 3/8 |

위험 전략은 접근 가능한 강적을 우선하며, 안전 전략은 회복을 우선한다. 덱 비교는 동일한 전체 수집 목록과 레벨 1에서 시작한다. 각 전략은 출정 중 보상과 강화를 사용한다. 따라서 이 표는 완성된 덱별 플레이어 승률이나 수정 전후의 순수 비교가 아니다. 대응 전략이 모든 출정에서 우월하지 않으며, 공격 덱의 연속 강적 경로는 여전히 어려웠다. 대기는 특정 위협에 대한 수단이지 매 명령마다 사용할 필수 기능으로 만들지 않았다.

자동 검사는 구현과 선택의 결과를 확인한다. 사람에게 재미있는지, 난이도가 적당한지까지 확정하지 않는다. 카드 목록은 여전히 20종으로 유한하며, 수집 완료 이후 장기 콘텐츠는 별도 확장이 필요하다.

## 2차 개선 · 2026-10-06

후속 비판의 여섯 항목을 반영했다.

1. 강격 피해를 52에서 66으로 높였다. 회복 6초와 접근·준비시간은 유지한다. 돌진 두 번은 총 54 피해로 빠른 대응과 손패 순환에 장점이 있고, 강격은 순수 피해 효율에 장점이 있다. 적도 같은 카드 수치를 사용한다.
2. 강적 승리 후 특전을 먼저 선택한다. 진화 보상 또는 생존자 최대 HP 12% 회복 중 하나이며 카드 한 장과 특수 후보 보장은 공통이다. 수집 상한 초과라도 회복을 골랐다면 기본 카드로 받는다. 이미 지급된 옛 저장의 특전은 회수하지 않는다.
3. 태세는 다음 기본 행동 판단 때 적용된다. 준비 중인 카드는 마친 뒤 적용하며, 적용 후 3초간 유지한다. 공용 명령은 소모하지 않는다. 적용 전 예약 취소와 저장 복원을 지원하고 적에게도 같은 규칙을 적용한다.
4. 새 지도의 1·5번째 교전 뒤에는 두 갈래 선택이 있고, 2·6번째 방 뒤에는 휴식과 다른 방 중 선택할 수 있다. 예상보다 큰 피해를 입은 뒤 경로를 수정할 수 있다. 기존 저장의 지도는 유지한다.
5. 거점 수집 화면에서 조각 3개로 시작 덱의 한 기술을 예약한다. 다음 출정의 첫 전투 첫 손패에 그 기술의 복사본 한 장이 들어간다. 예약 시 결제하고 변경은 무료, 취소 또는 시작 덱에서 제외하면 환불한다. 출정 시작 시 예약을 소비한다. 이후 전투나 다음 출정에는 이어지지 않는다. 영구 능력치와 진화 재료는 추가하지 않았다.
6. 카드 상세에 현재 시점부터 발동·확정된 적 타격·다음 아군 명령 시점을 시간순으로 표시한다. 적의 다음 명령만 알 때는 공격 미정으로 구별한다. 자동 비교에는 대기·손패 교체·태세를 하나씩 끈 실험과 HP·전투불능·차단 집계를 추가했다.

### 재검증

규칙 검사, 실제 브라우저에서 첫 손패 예약·취소와 강적 특전 선택을 포함한 완주·저장 복원, PC 두 해상도와 모바일 화면 검사를 통과했다. 200개 지도에서 교전 뒤 분기와 휴식 출구를 확인했다. 자동 출정은 기존 비교 120회에 독립 제거 실험 36회를 더해 총 156회다.

| 기본 덱 · 일반 즉발 · 안전 경로 · 동일 시드 1~12 | 완주 | 전투 직후 평균 총 HP | 전투불능 집계 | 차단 |
|---|---:|---:|---:|---:|
| 모든 대응 기능 | 12/12 | 326.2 | 1 | 32 |
| 대기만 제외 | 12/12 | 321.0 | 4 | 23 |
| 손패 교체만 제외 | 12/12 | 326.9 | 1 | 31 |
| 태세 변경만 제외 | 12/12 | 341.7 | 2 | 34 |
| 모든 대응 기능 제외 | 12/12 | 339.5 | 2 | 22 |

HP는 각 전투 종료 직후의 총 HP이며, 방 회복·강적 특전·전투 후 레벨 상승을 적용하기 전이다. 전투불능 집계는 각 전투 종료 때 HP 0인 동료 수의 합으로, 같은 동료가 여러 전투에 걸쳐 집계될 수 있다. 생존·편성·특전 선택의 차이도 결과에 반영된다.

위험 경로에서는 기본 덱 대응 전략이 일반 즉발 3/12, 기존 준비시간 4/12를 완주했고, 일반 즉발 즉시 사용 전략은 1/12였다. 전체 수집의 공격·제어·지원 덱은 안전 경로에서 각각 8/8, 위험 경로에서는 0/8·2/8·1/8였다.

대기를 제외해도 안전 경로 완주율은 같지만 HP와 전투불능 집계에는 차이가 있었다. 손패 교체의 영향은 작았고, 현재 자동 태세 정책은 HP를 더 보존하지 못했다. 따라서 대응 전략을 최적 전략이라고 보지 않는다. 긴 공격의 최종 균형과 사람에게 맞는 태세·대기 사용성은 실제 플레이를 바탕으로 추가 조정할 수 있다.
