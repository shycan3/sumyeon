# 스킬 안내에 따른 전장 크기 변화 수정

2026-10-07 · `character.html?v=stablewatch1`.

스킬 안내가 idle일 때 숨겨지고, 기본/대표 기술에 따라 높이가 달라져 전장이 줄었다 커졌다. 관전 전투의 안내 공간을 72px, 높이 600px 이하 화면에서는 48px로 고정했다. 대기 중에도 같은 공간에서 현재 행동 방침을 안내한다. 스킬 사용과 종료는 안내 내용만 교체한다. 전투 계산과 기존 카메라는 변경하지 않았다.

`stable-watch-browser-check.cjs`로 1280×720, 390×844, 320×568, 844×390, 768×1024, 360×640을 검사했다. 각 화면에서 대기·전체 카드·전체/간략 연출·결과 알림·사용 후 대기 등 115개 표시 상태의 전장 위치와 크기가 같았다. 사용자/기술명/대사/초상화와 결과 알림이 안내 영역 안에 들어가고 동료 HP가 화면 안에 유지됐다. 전투 스냅샷 비변경도 확인했다.

측정은 `prototype/stable-watch-browser-results.json`에 있다. 기존 refinement-browser 및 실제 프레임·배속·정지/재개 회귀 검사도 통과했다. 게임 진행으로 다른 전황 설명이 변경되거나 카메라가 움직이는 동작까지 정지시키는 변경은 아니다.
