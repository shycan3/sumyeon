# 시스템 고도화 · 전투 준비에서 복기까지

적용일: 2026-10-06. 사용자가 카드 밸런스 대신 게임 시스템 고도화를 요청하고, 적 전술·보스 단계·전투 전 준비·빠른 보상 교체·원정 기록의 방향에 동의한 뒤 구현했다.

## 달라진 플레이 흐름

지도에서 전투 방을 누르면 준비 화면을 연다. 적 구성·HP·사용 기술과 전술을 확인하고, 시작 태세와 현재 출정 덱을 준비한 뒤 전투를 시작한다. 아직 방에 입장한 상태가 아니므로 다른 연결 경로로 돌아갈 수 있다. 준비 화면과 태세는 저장되고, 확인만으로 HP·보상·난수 상태가 바뀌지 않는다.

적 전술은 실제 판단에 반영된다. 길목은 공격 우선, 추격대는 부상자 집중, 주술사 호위는 보호·회복 유지, 칼날 포위는 범위 공격·이동 방해, 돌격대장은 지원가 단일 카드 공격을 우선한다. 이는 현재 손패의 사용 가능한 행동 안에서 선택하는 방침이다. 회복 대상·차단 시점 등 기존 전술 평가도 유지한다. 부상자 추격은 기본 공격에도 적용되고, 도발은 계속 표적을 유도한다.

보스는 HP 50% 이하에서 한 번만 2단계로 전환한다. 1단계는 전체 공격, 2단계는 부상자 단일 공격을 우선한다. 피해·HP·명령 시간이나 덱을 바꾸지 않는다. 이미 확정한 예고의 카드·표적·발동 시점도 바꾸지 않는다. 단계와 전환 시점을 저장해 이어하기로 초기화되지 않게 한다.

보상 획득 직후 기존 복사본 한 장을 눌러 새 카드와 바로 교체할 수 있다. 전체 20장·기술별 상한을 먼저 검증하고 한 번에 적용한다. 잘못된 교체는 기존 덱을 보존하며, 다음 방으로 넘어가기 전에는 되돌릴 수 있다. 덱 편집기를 통한 기존 편성도 계속 사용할 수 있다.

전투마다 동료별 받은 실제 피해, 적 카드별 누적 실제 피해, 전투불능 시각·마지막 공격과 보호 중 대신 받은 피해에 의한 전투불능을 기록한다. 보호막·피해 감소·남은 HP를 적용한 값이다. 원정 결과의 교전 기록을 펼치면 확인할 수 있다. 누적 피해 최다 카드가 패배의 유일한 원인이라는 판단은 하지 않는다.

원정 중 선택한 방·획득 카드·덱 교체·강화·강적 특전·시작 태세·귀환 사유를 선택 기록에 남긴다. 지도와 최종 결과에서 확인할 수 있고, 저장·파일 복원을 지원한다.

## 호환과 검증

- 기존 저장·진행 중 전투·기존 지도를 이어갈 수 있다. 이전에 존재하지 않은 선택 기록은 소급 생성하지 않는다.
- 이전 전투 저장의 피해 기록은 업데이트 후 이어간 구간부터 수집하며 화면에 부분 기록임을 표시한다. 이전 전투는 당시의 상황 대응 AI를 유지하고 새 전투부터 적 전술을 적용한다.
- 새 저장 필드는 선택 항목으로 검증한다. 전술·단계·기록·미리보기 대상·교체 복사본과 피해 수치가 잘못된 파일은 거부한다.
- 카드 수치와 효과는 이번 작업에서 변경하지 않았다.

규칙 검사와 추가 시스템 검사에서 준비·취소의 상태 보존, 시작 태세 반영, 교체 실패·되돌리기·저장 복원, 도발과 적 전술, 보스 단계 전환과 기존 예고 보존, 실제 피해·전투불능 집계를 확인했다.

실제 브라우저에서 준비 화면과 태세의 새로고침 복원, 보상 빠른 교체·되돌리기·복원, 원정 기록 열기, 강적·확보 지점·보스 완주, 교전 결과 펼치기를 확인했다. 1280×950·1280×720·390×844에서 전장·손패·타이밍·명령 버튼도 함께 표시된다.

자동 출정 156회로 기존 설정·다른 덱·경로와 독립 기능 제거 실험을 다시 실행했다. 기본 덱 대응 전략은 안전 경로에서 두 준비시간 설정 모두 12/12 완주했고, 위험 경로에서는 일반 즉발 2/12·기존 준비시간 4/12였다. 자동 전략의 결과이며 사람의 체감이나 최적 전략을 확정하는 수치는 아니다.
