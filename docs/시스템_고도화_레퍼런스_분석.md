# 시스템 고도화 레퍼런스 분석

조사일: 2026-10-07. 분석 대상: `prototype/character.html?v=cardlook1`. 코드·기존 검사 결과·대표 게임의 개발사/배급사 공식 설명을 함께 확인했다. 본 문서의 레퍼런스 사실과 우리 게임의 설계 제안은 구분한다. 플레이 감상이나 신규 난이도 실험 결과를 만들어 보고하지 않는다.

## 1. 판단

기본 전투 엔진과 카드 관리 기능은 상당 부분 구현됐다. 지금 가장 큰 공백은 **보상으로 덱을 발전시키고, 달라진 싸움을 관찰하고, 실패 원인을 배워 다음 덱으로 극복하는 반복 구조**다. 신규 캐릭터와 카드 수량보다 이 연결을 우선한다.

확정된 기준은 4인·20장·모든 카드의 특성·원정 보상/진화 초기화·전투 풀오토다. 수동 카드 게임의 손패 운영, 에너지, 자유 이동을 그대로 가져오면 플레이 목표가 달라진다. 아래의 제안은 이 기준 안에서 전투 밖의 판단을 강화한다.

## 3. 확정된 구조적 부족점

### A. 보상이 고정되고 출발 컨셉의 성장 경로가 막힌다 — 최우선

`character-campaign.js:42–43`은 보유 상한 미달 보상 전부를 후보로 제공한다. 현재 풀은 `character-data.js`의 재배치·추격·엄호·구출 4종이다. 일반전·정비·강적이 같은 풀을 사용한다. 보상 넘기기는 이미 있으나 판마다 다른 보상을 발견하는 구조는 없다.

원정 시작 시 선택한 20장만 원정 pool로 복사하며, 도중에는 보상 4종만 새로 생성한다. 출발하지 않은 기초 카드는 자동으로 대기에 제공되지 않는다. 카드 종류 중복은 특성 종류 수를 늘리지 않는다.

| 추천 출발 덱 | 출발 종류 수: 호위/추격/공명 | 현재 획득 경로의 최대 단계: 호위/추격/공명 |
|---|---:|---:|
| 호위 | 3 / 2 / 2 | 2 / 1 / 0 |
| 추격 | 2 / 3 / 2 | 1 / 2 / 0 |
| 공명 | 2 / 2 / 5 | 1 / 1 / 2 |

이는 출발 카드 종류와 모든 보상 종류의 합집합을 평가한 상한이다. 덱에 원래 종류를 유지하고 한 장씩 교체하면 해당 상한의 편성이 가능하지만, 실제 제안·획득·승리는 보장하지 않는다. 재계산 자료는 [감사 데이터](시스템_고도화_감사_데이터.json)에 남겼다.

**호위·추격 출발에서 공명 특성을 활성화하는 혼합 운영은 현재 경로로 불가능하다.** 공명만 세 특성을 모두 활성화할 수 있다. 또한 추격·공명은 보상 한 종류로 주 특성 2단계, 호위는 엄호와 구출 두 종류가 필요하다. 이것이 곧 불공정한 승률이라는 증거는 아니지만, 보상 기회비용이 비대칭인 것은 확정 사실이다.

개선: 출발 덱별 ‘주 컨셉 심화/약점 보완/다른 컨셉 연결’ 지도를 먼저 만들고 필요한 보상 종류를 소수씩 추가한다. 미편성 기초 카드의 원정 한정 사본을 보상으로 제공하는 대안도 비교한다. 기본 카드를 무료로 모두 대기에 넣어 출발 선택의 비용을 지우지는 않는다. 새 카드에도 특성을 부여하고 보상은 다음 원정에 남기지 않는다.

풀을 넓히기 전에 4종에서 3종을 무작위로 숨기면 좋은 선택지만 줄어든다. 충분한 용도 차이를 확보한 뒤 후보 제안을 제한하고 원정에 저장한다. 후보는 심화·즉시 대응·다른 운영의 기회가 경쟁하도록 만들되, 원하는 완성 카드가 매번 확정 지급되지는 않게 한다.

### B. 덱 변경의 효과를 확인하고 재시도하는 흐름이 없다 — 최우선

메인 결과에 복기·오토 이유·특성 장면이 있다. 따라서 결과창 전체가 없다는 평가는 틀리다. 다만 아군 카드별 실제 피해는 `stats.byCard`에 일부 기록돼도 메인 결과에 충분히 노출되지 않으며, 개별 카드의 유효 회복/보호와 발동하지 못한 이유는 별도 계측이 필요하다.

패배 시 `character-campaign.js:47,79–80`은 결과를 남기고 원정을 끝낸다. 보고서에는 출발/최종의 정확한 편성과 전투 시작 조건 전체가 보존되지 않는다. AutoLab은 고정 7편성·레벨 1의 비교 도구이며 현재 사용자 덱을 그대로 바꿔 비교하는 기능은 없다.

개선: 출발/전투 시작/최종 편성, 레벨·HP·태세·적 설정·시드·규칙 버전을 저장하고, 카드 사용·유효 피해/회복·실제 방어·특성 기여를 보여준다. 보상 없는 연습에서 같은 시작 조건으로 덱/방침만 바꿔 재전투한다. 연습 승리는 종료된 원정을 복구하거나 보상을 지급하지 않는다.

한 번의 승패와 오토의 선택 이유는 최선의 선택을 입증하지 않는다. 같은 초기 조건의 비교 뒤 여러 시드에서도 반복해야 한다. 기존 저장에 없는 지표는 ‘기록 없음’으로 표시한다. 미사용 카드도 ‘약함’으로 단정하지 않고 미드로우·시전자 전투불능·조건 미충족 등을 구분한다.

### C. 풀오토 목표와 기본 이동·화면이 일치하지 않는다 — 최우선

기본 역할 AI는 보호·접근·거리 유지를 하지만 위험 구역을 보고 회피하지 않는다. 카드 오토에는 보호·회복·구출·재배치 대응이 있다. **기본 회피가 없다는 것은 설계상 제한이지 확인된 실행 버그가 아니다.**

메인 화면에는 수동 전환·직접 개입·명령 확정·리롤·대기·전투 중 태세 변경이 남아 있다. 이는 초기 수동 개입 중심 설계의 흔적이다.

개선: 메인은 관전·속도·정지·기술 정보 중심으로 정리한다. 수동 검사는 비교 도구로 옮긴다. 도보 회피 가능한 예고는 정상 이동속도·행동 잠금 안에서 기본 AI가 제한적으로 대응하고, 나머지는 덱의 카드 대응으로 처리하는 명시적 규칙을 설계한다. 전투 전 덱/방침으로 해결할 방법이 없는 손조작 전용 기믹은 도입하지 않는다. 무료 완벽 회피로 이동·보호 카드의 가치를 없애지도 않는다.

### D. 적의 요구와 특성 성장의 변화가 좁다 — 높은 우선순위

메인 일반전은 집중 공격/다수전 두 종류, 강적/보스는 직선/원형 위치 고정 예고와 빈틈 구조다. 메인 보스는 `strategy:'front'`이므로 `engine.js:185`의 옛 boss 단계 전환을 사용하지 않는다. 현재 메인 보스에 두 단계가 있다고 표현하면 안 된다.

특성은 표식·반격 준비·순서 축적을 실제로 만들고 오토도 이를 활용한다. 그러나 2단계 차이는 호위/추격 피해 10→20%, 공명 15→25%와 축적 단축이 중심이다. 덱 종류를 늘린 보상이 싸우는 장면을 크게 바꾸는 여지가 제한적이다.

개선: 보호막을 두른 적, 후열 지원자, 긴 공격 준비처럼 다른 약점을 드러내는 적 조합과 보스 단계 변화를 소규모로 만든다. 각 위협은 최소 두 가지 대응 계열을 남기고 특정 카드 한 장이 없다고 반드시 실패하지 않게 한다. 그다음 공동 반격·처치 후 표식 전달처럼 실행 모습이 달라지는 보상/특성 변형 하나를 검증한다. 예시는 신규 설계 후보이며 아직 구현되지 않았다.

### E. 도전과 경로의 반복 목표가 짧다 — 다음 우선순위

레벨 상한 5까지 필요한 경험치는 20이고, 첫 레벨부터 강적 경로 완주는 11, 회복 경로는 8을 준다. 동일 경로 완주를 가정하면 2~3회로 상한에 도달한다. 이후 공개된 도전 단계나 새 전술 조건 해금은 없다. 유한 레벨 자체는 기존 합의에 맞는다.

6방 경로는 첫 전술 추첨, 중간 전술 선택, 회복/진화, 정비, 강적/휴식이 있지만 방의 목적과 최종 보스는 대부분 고정이다. 상점·화폐·이벤트는 현재 없다. 그것들이 없다는 이유만으로 결함이라고 판단하지 않는다.

개선: 적/보상 다양화 뒤 같은 6방에 서로 다른 공개 조건과 혜택을 연결한다. 강화/회복/원정 규칙 변경 사이의 비용을 만들고, 이후 난이도 단계와 제한 도전을 제공한다. 무한 영구 능력치 상승이나 보상 카드 영구 보유로 해결하지 않는다.

## 4. 밸런스 가설과 검사 한계

최대 HP의 기존 출발 덱 검사에서는 4편성×4전투×24조건이 모두 승리해 **384/384**다. 낮은 HP 스트레스는 차이를 보이지만 실제 원정 체력 분포를 대표하지 않는다. ‘현재 게임 전체가 너무 쉽다’는 체감 판단이나 ‘모든 추천 덱이 동등하다’는 결론은 아직 확정할 수 없다.

일반 카드 점수와 특성 가산은 유효 피해 예측의 정밀도가 다르다. 보호막·과잉 피해·검무의 여러 타격·강화/빈틈을 같은 공개 정보 평가 함수로 정리할 필요가 있다. 현재 코드에서 오판 가능성은 확인되지만 승률 악화가 실증된 것은 아니다. 실행 규칙을 따르는 공통 예측을 만들고 숨은 적 손패·미래 난수는 읽지 않는다.

향후 검사에는 실제 6방의 HP/보상 연속 상태, 레벨 1/상한, 주/혼합 특성, 동일 카드 복사본 수, 공격/보호 방침, 여러 시드를 포함한다. 새 조건은 보상 전후 승률만 보지 않고 시간·피격·유효 효과·행동 변화도 비교한다. 기능 정확성은 자동 검사로, 관전 재미·보상 만족감·피로는 실제 플레이로 판단한다.

## 5. 지금 우선하지 않을 작업

- 신규 캐릭터·파티 확대·판매 시스템: 현재 고정 파티에서 성장 반복을 검증한 뒤.
- 카드 수백 장·대규모 키워드·특성 추가: 현재 3특성의 성장 연결과 전투 기능부터 검증.
- 상점·경제·삭제 전용 방: 고정 20장, 대기 보관/폐기/되돌리기가 이미 있어 우선 근거가 약함.
