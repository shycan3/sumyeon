# 《수면》 심층 원정 통합 개발 — 2026-10-09

> **2026-10-10 갱신:** 이 문서의 임시 역할과 최초 자동 검사 수치는 이전 버전 기록이다. 현재 원정은 [항해사·잠수자·도선사·측심사·인양사·등대지기](여섯_문양_원정_적용.md)의 원본 지속/실행 특성을 적용했다. 새 저장 버전과 화면을 사용하며, 에너지 이월·24카드·8전투 흐름은 유지한다. 최신 확인 결과는 [여섯 문양 기술 검토](여섯_문양_적용_기술_검토.md)를 따른다.

상태: 플레이 가능한 8전투 원정 구현, 전투·원정·통합 자동 검사와 브라우저 흐름 확인. 사람의 원정 재미·편성 균형·최종 난이도는 미검증.

## 최신 요청과 개발 방식

사용자는 “하나하나 테스트 하지 말고, 최대한 많은 분량의 개발을 진행해봐”라고 요청했다. 이에 개별 고정 전황을 추가하고 응답을 기다리던 방식을 종료하고 여러 기능을 연결한 원정을 구현했다. P0~P6은 판단 기준으로 유지하지만 각 단계의 직접 피드백을 구현 전제조건으로 삼는 이전 대기 절차는 이번 요청으로 변경한다. 단계가 모두 재미 검증을 통과했다고 기록하지 않는다.

E는 기존 추격 효과를 재확인하는 기술 표본이었으며 새로운 플레이 개선이 아니었다. 사용자가 이를 지적했고 추가 E 플레이를 요구하지 않기로 했다. 이번 범위는 기존 규칙 확인이 아니라 카드 성장·전투 위협·자원 배분을 실제 연속 플레이로 묶는 개발이다.

## 실행과 한 판의 흐름

실행: [심층 원정](http://127.0.0.1:8765/party-expedition.html). 기존 [단일 전투](http://127.0.0.1:8765/party-v3.html)에서도 ‘심층 원정’ 링크로 이동한다.

파티 준비 → 공개된 경로 선택 → 카드 전투 → 3장 중 보상 또는 거절 → 정비/상점/관측실 → 다음 구역 → 완성한 덱으로 마지막 두 전투 → 파수꾼 → 결과·재도전.

- 8전투, 일반 구역은 2경로 중 선택. 경로마다 적 HP·위협 유형·전투 뒤 장소를 공개한다. 마지막은 보스와 보조 적.
- 첫 6전투에서 공격·생존·도구 카드 한 종류씩 세 선택지를 제시한다. 마지막 두 전투는 전투 보상 없이 완성한 덱을 사용한다.
- 보상 카드는 즉시 다음 전투 덱에 반영된다. 추가를 거절할 수 있고, 강화·삭제는 플레이어가 지정한 카드 사본에만 적용한다.
- HP는 전투 사이에 이어진다. 정박지의 회복, 상점 회복, 관측실 회복은 쓰러진 동료도 표시된 HP로 복귀시킨다. 카드 회복은 생존 동료에만 적용한다.
- 재화는 원정 내 ‘기록 조각’. 반복 계정 성장·가차·신뢰도·물리적 타임게이트·저장 가치 제한은 구현하지 않는다.

새 역할은 기존 GDD의 여섯 전문성 전체를 그대로 구현한 것이 아니다. 특히 항해사·측심사·인양사·등대지기의 지속/실행 특성 개편은 별도 시험안으로 남는다. 역할 이름은 정식 인물이나 세계관 직종을 확정하지 않는다. 브레이크와 새로운 효과는 구현된 선택지이며 재미가 검증된 확정 사양이 아니다.

추격은 공격 뒤 보호 카드에서도 발동한다. 재현 보관은 다음 손패5장 중 한 장을 확보한다. 소진 카드는 재현으로 보관할 수 없으며 첫 카드 기회는 소비한다. 소진은 이번 전투에서만 빠지고 다음 전투에는 원정 덱의 동일 사본이 돌아온다. 반격은 보호가 공격을 흡수하고 해당 아군이 생존했을 때 한 번 발생한다. 이 조건들은 카드·도움말·자동 검사와 맞췄다.

## 정비와 선택 보존

- 정박지: 전원 HP+6/쓰러진 동료HP10, 카드1장 강화, 카드1장 제거 중 하나. 건너뛰기도 가능.
- 관측실: 공개된 기록 카드 획득, 전원HP+4/복귀HP8, 카드1장 강화 중 하나.
- 상점: 카드20·회복12·제거12 기록 조각. 구매 가능한 사본과 재화·가격을 먼저 보여주고 출발 전 여러 선택 가능. 회복은 한 번.
- 덱 최소6장, 강화는 카드별 한 번. 제한은 UI와 실행 규칙에 표시한다.
- 원정 저장은 지도·손패·HP·예고·실물 카드·보상·구매 목록·난수 상태를 함께 보존한다. 복원 때문에 카드를 복구·삭제·하향하거나 보상을 재추첨하지 않는다.
- 저장 키 `sumyeon-expedition-v1`는 기존 v3 저장과 분리된다. 새 원정 준비 화면으로 이동만 하면 기존 저장이 사라지지 않는다. ‘원정 시작’으로 새 여정을 선택할 때 새 저장을 쓴다.

## 조작과 화면

카드→실행자→대상 기본 조작을 유지하고 실행자 조건, 대상에 대한 실제 피해·보호·회복·브레이크 결과를 선택 시에 보여준다. 당장 받는 공격과 보호 후 HP 피해를 아군 상태에서 읽을 수 있다. 상세 설명은 덱·규칙 패널로 모았다. 전투 로그나 전체 종료 예상 패널을 상시 노출하지 않는다.

키보드: 1~9 손패 / A·S·D·F 실행자 또는 아군 대상 / Q·W 적 대상 / E 종료 / Esc 선택 취소. 연출0/1/2배와 단축키 표시 선택. 전투·원정 전환 시 위로 이동해 이전 화면의 스크롤 위치가 남지 않도록 한다. 좁고 짧은 화면에서는 세로 스크롤·손패 가로 스크롤을 허용한다.

## 검증과 현재 한계

신규 자동 검사: 전투50 + 원정21 + 독립 통합10 =81개. 기존 v3 자동 검사59개도 통과. JavaScript 문법 검사를 완료했다. 통합 검사에서 15편성×브레이크OFF/ON의30원정을 합법 입력으로 정상 종료시켰다. 기본4인 편성은 두 방식 모두8전투 완주했다. 자동 정책은 편향된 보상·정비 선택을 쓰므로 승률을 실제 난이도·편성 균형으로 해석하지 않는다.

브라우저에서는 새 원정, 공개 경로, 실제 카드→실행자→대상, 보관/이월, 전투 승리→3카드 보상, 보상 거절, 보상 사본 강화, 다음 전투에 강화 카드 등장, 상점 구매·지정 사본 제거, 지도·전투·보상 새로고침 복원,4인 편성 제한, 대체 편성과 브레이크 표기를 확인했다. 데스크톱1280×720·모바일390×844와 기본 좁은 화면의 배치를 확인했고 콘솔 오류·경고는 없었다. 현재 사용자 탭은 기본4인·표준 난이도·브레이크OFF의 새 원정 준비 화면이다.

시험값 한계: 마지막 보스에서 일부 자동 편성이 패배하고 브레이크가 자동 정책의 결과에 큰 영향을 준다. 도선은 시작 덱이 전부비용1이므로 고비용 보상을 얻기 전에는 특성이 발동할 수 없다. 관측실 이벤트는 아직 하나의 선택 템플릿이다. 시각 연출은 단순한 전투 인형이며 정식 캐릭터·서사 컷신·음악·출시 아트는 추가되지 않았다. 원정 단위의 실제 재미·피로·보상 선택의 변화는 전체 플레이에서 평가할 항목이다.

## 다음 개발의 기준

개별 비교를 다시 요청하며 중단하지 않는다. 한 판 전체에서 카드 보상이 운용을 바꾸는지, 전투마다 위협을 재평가할 이유가 이어지는지, 후반에 만든 빌드가 활약하는지, 실패 뒤 다른 원정을 시작할 이유가 있는지를 모아 평가한다. 관찰에 따라 위협·카드·편성·전환 UX를 묶어 다음 개발분을 진행하되 사람의 재미 검증과 기술 완성을 구분한다.
