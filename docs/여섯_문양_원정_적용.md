# 《수면》 여섯 문양의 원정 적용

갱신: 2026-10-10. 사용자가 제시한 v7 설계의 항해사·잠수자·도선사·측심사·인양사·등대지기를 현재 심층 원정에 적용했다. 버팀·추격·돌봄·재현을 새 이름으로만 바꾸지 않고 지속 특성과 조건부 실행 특성을 교체했다.

## 현재 실행 규칙

카드 귀속 없는 공용 덱, 여섯 문양 중 네 명 편성, 카드→실행자→대상, 개인 행동 게이지 없는 턴제를 유지한다. 기존 원정의 24종 카드·8전투·경로·보상·정비·상점·카드 사본 강화와 제거도 연결한다.

원본 GDD의 라운드 에너지 4 초기화보다 이후 사용자 플레이에서 승인한 규칙을 우선한다. 전투 시작 4, 라운드 잔량 이월과 회복 +2, 최대 5다. 잠수자의 환급도 이 자원 규칙을 따른다. 브레이크는 원정 시작 시 선택하며 기본은 사용하지 않는다.

| 문양 | 생존 중 지속 특성 | 라운드 첫 적격 실행 특성 |
| --- | --- | --- |
| 항해사 | 이전 유료 카드와 실행자가 다른 유료 직접 공격의 첫 타격 +2. 매 적격 카드 적용 | 다른 생존 동료의 유료 카드 뒤 사용하면 첫 타격 +4. 직접 공격이 아니면 본효과 뒤 HP 비율 최저 동료 보호 4 |
| 잠수자 | 파티가 라운드 처음 실제 노출을 소비하면 에너지 +1 | 유료 적 대상 카드의 본효과 뒤, 대상 생존 시 노출 4와 선택형 브레이크의 추가 균형 −1 |
| 도선사 | 유료 선행 카드 뒤 첫 인쇄 기본 비용 2 이상 카드: 첫 타격 또는 지정 아군 보호 +3 | 이번 카드 이전 지출이 2 이상일 때 유료 카드: 첫 타격 +5, 직접 공격이 아니면 본효과 뒤 자신 보호 5 |
| 측심사 | 예약 반환 뒤 6장까지 뽑고 적의 의도를 공개. 실제 6장이면 한 장을 골라 버림 | 첫 유료 카드 본효과 뒤 한 장 뽑기 |
| 인양사 | 인양한 동일 사본의 다음 라운드 타인 사용 비용 −1, 최소 1 | 첫 유료 비소진 카드 사본을 버림 대신 다음 손패에 예약 |
| 등대지기 | 적 행동 뒤 남은 보호가 가장 많은 생존 동료 한 명에게 최대 4 이월. 동률은 편성 순서 | 첫 유료 카드 본효과 뒤 자신 보호 4 |

실행 조건이 맞지 않는 카드로 기회를 소비하지 않는다. 유료 여부는 실제 비용으로 판단하고, 도선사 지속 특성만 명시적으로 인쇄 기본 비용을 본다. 0비용 카드·기본 공격·반격은 새 유료 손패 실행을 만들지 않는다. 항해사의 이전 실행자 기억은 보호·제어 카드도 갱신한다.

인양한 사본은 다음 손패의 한 자리를 차지한다. 다른 사본을 복제하거나 카드 종류 전체에 할인하지 않는다. 인계 표식은 실제 사용 또는 미사용 버림으로 소멸한다. 잠수자가 본효과로 대상을 처치하면 침투 기회는 소비하지만 사후 노출·균형 감소는 발생하지 않는다. 신규 노출·브레이크 보너스는 같은 카드의 이미 끝난 타격에 소급하지 않는다.

광역 카드의 노출·브레이크·문양 추가 피해와 균형 감소는 선택한 주 대상에 적용한다. 적의 전체 공격은 모든 대상의 피해·사망을 처리한 뒤 생존 반격을 편성 순서로 처리한다. 첫 반격이 적을 처치했다고 같은 전체 공격의 뒤쪽 피해를 취소하지 않는다.

## 화면과 세계관

편성 화면에는 원본의 나침반·물결, 아래로 향한 창·물방울, 길잡이 등불, 측심추·파문, 갈고리·인양선, 등대·광선 모티프를 코드로 그린 문양을 표시한다. 간단한 역할 설명을 먼저 읽고 자세한 조건은 규칙 패널에서 확인할 수 있다. 전투에는 선택한 카드의 문양 추가 효과, 대상별 실제 결과, 실제 지불 비용을 표시한다. 인계 가능한 고비용 사본에는 원래 비용→할인 비용을 표시한다.

측심 선별 중에는 카드마다 ‘버리기’를 표시하고 기본 공격·라운드 종료를 잠근다. 카드 한 장을 클릭하거나 숫자 단축키로 선별하면 정상 실행으로 돌아온다. 적의 의도는 선별 전에 이미 보인다.

여섯 이름은 사용자가 제시한 전투 전문성 문양이다. 정식 인물 이름이나 세계관의 여섯 직종으로 확정하지 않는다. 전장 인형은 여전히 임시 표현이며 정식 인물 디자인·서사 연출은 이번 작업 범위에 포함하지 않는다.

## 저장과 평가

전투 저장 버전은 `expedition-combat-2`, 원정 저장 버전은 `expedition-run-2`다. 브라우저 저장 키는 `sumyeon-expedition-professions-v2`로 분리하여 이전 능력으로 진행한 원정을 다른 능력으로 몰래 복원하지 않는다. 기존 `sumyeon-expedition-v1` 데이터와 v3 단일 전투 저장은 삭제하지 않는다. 새 규칙으로 새 원정을 준비한다.

자동 검사와 브라우저 확인 결과는 별도 [기술 검토](여섯_문양_적용_기술_검토.md)에 기록한다. 기술 검사 통과와 자동 정책의 완주는 실제 재미·편성 균형의 통과 판정이 아니다. P0~P6은 평가 기준으로 유지하되 개별 플레이 응답을 기다리며 개발을 중단하지 않는다.

## 이번 확인 결과

- 전투 83개·원정 24개·독립 통합 19개, 총 126개 검사 통과. 전투/원정/화면 JavaScript 문법 검사 완료.
- 15편성 × 브레이크 OFF/ON의 30개 자동 원정이 정상 종료했다. 이 고정 정책 표본의 완주를 난이도·편성 균형 평가로 사용하지 않는다.
- 브라우저에서 측심 선별 중 저장·복원과 종료 잠금, 인양 예약의 동일 사본 반환, 에너지 1에서 2→1 인계 및 예약자 실행 잠금, 실제 비용 지불, 측심 추가 드로우, 항해사 +2/+4 합산, 등대지기 잔광, 잠수자 노출 소비 환급과 균형 감소, 도선사 선행 지출 뒤 비공격 실행을 확인했다.
- 1280px 데스크톱과 390px·320px 모바일 폭에서 배치와 조작을 확인했다. 실행 설명·미리보기가 늘어나면 아군과 조작 영역의 간격 및 전장 최소 높이를 자동 조정한다. 전체 보호 미리보기는 공통 증가량을 묶어 같은 내용을 네 번 반복하지 않는다.
