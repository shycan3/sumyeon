# 여섯 문양 적용 기술 검토

검토 대상은 `party-expedition-core.js`, `party-expedition-run.js`와 원정 화면이다. 기준은 사용자 제공 `SUMYEON_GDD_v7_Six_Professions_Break_Codex.md`의 6장 전문성 규칙과 8장 판정 순서다. 기존 버팀·추격·돌봄·재현에 이름만 붙이지 않고, 항해사·잠수자·도선사·측심사·인양사·등대지기의 지속 특성 및 조건부 실행 특성을 각각 구현했는지 독립적으로 확인한다.

이번 범위에서는 최근 직접 플레이에서 채택한 공동 에너지 규칙을 유지한다. 전투 시작 4, 이후 남은 에너지 +2, 최대 5다. GDD의 매 라운드 4 초기화로 되돌리지 않았다. 원정 경로·카드 후보·보상·정비는 이미 구현한 원정 구성을 유지하며, v7 전체 콘텐츠 사양을 모두 구현했다고 주장하지 않는다. 정식 인물·술식·서사는 이번 문양 적용으로 변경하지 않는다.

## 독립적으로 확인한 규칙

| 문양 | 확인 사항 |
| --- | --- |
| 항해사 | 유료 손패의 직전 실행자와 모든 실제 손패의 직전 실행자를 구별. 0비용 카드와 기본 공격은 유료 기억을 바꾸지 않음. 실행자 교대의 지속 +2와 자신의 조건부 실행 +4가 구별되어 합산. 직전 동료 사망 시 실행 특성은 불발하지만 별도 지속 조건은 유지 |
| 잠수자 | 본효과 피해 뒤 노출 4 및 추가 균형 -1. 새 노출과 브레이크 +4가 같은 카드에 소급 적용되지 않음. 다른 카드가 노출과 브레이크를 함께 소비하고, 노출 실제 소비에 한해 라운드 첫 에너지 +1. 이후 재노출 소비는 추가 환급 없음 |
| 도선사 | 인쇄 비용 2와 인계 할인 후 실제 비용 1을 구별. 선행 유료 카드 조건에 지속 +3, 선행 지불 2에 실행 +5가 적용. 기본 공격 지출은 선행 손패 지출이 아님. 효과 없는 적격 제어 카드도 지속 기회를 소비 |
| 측심사 | 예약 반환과 6장 확보 뒤 적 의도가 공개된 상태에서 한 장 선택. 미선택 중 카드 실행·라운드 종료를 상태 변경 없이 거부. 이 단계 저장과 다음 동일 선택이 정확히 재현. 자신의 드로우 카드 본효과 2장 후 실행 특성 1장, 총 3장. 라운드 중 추가 드로우에는 별도 강제 6→5 선택 없음 |
| 인양사 | 0비용·소진 카드로 실행 사용권을 잃지 않음. 첫 유료 비소진 카드는 실제 사본 하나를 예약. 반환 사본은 타인 사용 비용 -1, 최소 1. 인양사 사망은 예약 사본을 파괴하지 않지만 신규 할인은 제공하지 않음. 측심 선택에서 반환 사본을 버리면 인계 표식 소멸 |
| 등대지기 | 적 행동 종료 뒤 잔여 보호 최댓값 아군 한 명만 최대 4 이월. 동률은 편성 순서. 다음 라운드 추가 보호와 합쳐도 이월 상한 4. 등대지기가 쓰러졌으면 새 보호 보존 없음 |

추가로 공유 덱의 무귀속 사본, 미편성 실행자 거부, 현재 공개 공격의 사망 표적 취소, 준비 시 약화 보존, 광역 약화, 물리적 사본 단위 강화·제거, 지도·전투·보상·정비 저장, 구매 중복 거부와 RNG 보존을 확인한다.

## 자동 원정 표본

독립 통합 검사 **19개를 모두 통과**했다. 이 집계는 전투·원정 구현 담당자의 별도 단위 검사와 구별한다.

`prototype/party-expedition-integration-check.cjs`는 현재 화면에 공개된 손패·의도에 기초한 단순한 정책으로 실제 합법 입력을 수행한다. 측심 선택을 직접 처리하고 실행자별 `costFor`로 인계 할인을 반영한다. 미리보기는 원본 상태를 변경하지 않으며, 예고된 적 구간을 실행했을 때 생존·피해·카드 순환을 비교한다. 미래 보상이나 숨겨진 덱 순서를 읽어 행동을 고르지 않는다.

시드 20261009, 보통 난도, 첫 경로, 고정 보상 선호 및 회복 중심 정비 조건에서 **15개 편성 × 브레이크 OFF/ON, 총 30개 원정**이 정상 완료됐다. 이 표본에서 모두 8전투를 완주했으며 입력은 총 3,290회였다. 기본 항해사·측심사·인양사·등대지기 편성도 두 조건 모두 완주했다.

이 결과는 상태 전환과 합법 행동으로 전체 원정을 연결할 수 있다는 근거다. 전문성이 재미있는지, 원정 난이도가 적당한지, 모든 파티가 균형 잡혔는지는 별도의 판단이다. 특히 비교 정책은 장기 계획·도선 고코스트 준비·인양 반복의 가치와 실제 조작 피로를 충분히 측정하지 않는다. 승률만으로 P0~P6의 재미 관문을 통과 처리하지 않는다.

## UI 확인에 필요한 정보

- 측심의 버리기 단계에서는 적 의도와 여섯 장이 함께 보여야 한다. 카드 클릭 한 번으로 선택하고 그 전에는 다른 실행 입력을 잠근다.
- 카드의 인쇄 비용, 인계 할인 가능 여부와 선택 실행자의 실제 비용을 구별한다. 한 실행자가 할인을 받을 수 있다는 이유로 모든 실행자의 버튼을 활성화하지 않는다.
- 실행 특성은 첫 카드에서 무조건 사라지지 않는다. 조건을 만족하지 않은 행동 뒤에도 준비 표시가 남아야 하며, 선택 카드의 실제 발동 효과는 `effectInfo`로 표시한다.
- 인양은 같은 사본의 예약과 반환이다. 할인 표식과 적용 범위를 보여주고, 등대지기의 보호 이월은 라운드 종료 뒤 실제 남은 보호에 반영한다.
- 잠수자의 노출·브레이크 생성과 후속 카드의 소비를 구분한다. 환급 에너지, 다음 예고 피해와 소진 여부는 동일 룰 엔진의 미리보기 결과를 따른다.

이전 `docs/원정_통합_기술_검토.md`의 임시 역할 결과는 당시 구현의 기록이다. 이번 원정 버전은 새 규칙 저장 버전을 사용하며, 이전 저장을 새 문양 규칙으로 조용히 재해석하지 않는다.
