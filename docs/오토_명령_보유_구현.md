# 오토의 제한된 명령 보유

세린 원정과 비교 체험의 플레이어 카드 오토에 적용했다. 기본 캐릭터 AI의 위험 구역 인식·자동 회피, 적 AI, 카드 수치는 변경하지 않았다. 이전 원정(index.html)의 오토 규칙도 유지한다.

## 기준

현재 화면에 예고된 적 공격 중 3초 이내에 발생할 강한 공격(위력 35 이상 또는 현재 대상 2명 이상)을 살펴본다. 명령이 준비되어 있고 손패에 사용 가능한 대응 카드가 있을 때만 보유를 고려한다. 이미 차단으로 덮인 공격은 제외한다.

대응 후보는 차단·유효한 방어 강화·위협받는 대상의 보호막/엄호/반격·실제로 가능한 구출/재배치다. 발동 준비가 0.25초를 넘는 카드로 늦은 대응을 계획하지 않는다. 캐릭터가 기술 실행 중이거나 대상이 유효하지 않으면 후보에서 제외한다.

- 판단 간격 0.6초.
- 명령 한 번당 보유는 한 번만 허용한다.
- 보유 목표는 0.6초 또는 1.2초이며, 예고 시각과 한 판단 간격 이상의 여유를 고려한다. 시뮬레이션 틱에 따른 작은 지연이 있을 수 있다.
- 대기 후에는 기존 카드 점수로 다시 선택한다. 미리 정한 카드를 무조건 쓰거나 여러 수 앞의 조합을 최적화하지 않는다.
- HP 25% 이하 아군에게 가능한 유효 회복이 있으면 새 보유를 시작하지 않는다. 대기 중 아군이 위급해지거나 위협이 사라지면 보유를 해제한다.
- 수동 전환·카드 사용·새 명령 충전·전투 종료 시 해당 보유 상태를 정리한다. 플레이어의 일시정지는 전투 시계와 보유 시간을 함께 멈춘다.

아직 예고되지 않은 공격, 적 손패·드로우 순서·다음 명령 시각, 보스의 내부 다음 패턴 시각은 보유 계획에 사용하지 않는다. 따라서 사람이 패턴을 기억하고 예고 전부터 명령을 보유하는 이점은 남는다. 판단을 느리게 하되 고의로 잘못된 카드를 쓰거나 숨은 보정을 넣지는 않는다.

## 저장과 표시

버전 1 `autoHold` 상태에 시작 시각·목표 종료 시각·명령 충전 식별 시각·단계·이유를 저장한다. 이전 저장에는 새 대기를 소급 생성하지 않는다. 시간·버전·단계·최대 목표 시간과 보유 횟수를 검사한다.

원정의 오토 설명과 비교 체험의 명령 상태에 ‘공개된 강공격에 대비 · 명령 잠시 보유’를 표시한다. 화면 조회는 판단을 실행하지 않는다.

## 비교 결과와 한계

동일한 스냅샷·손패·난수에서 기존 0.25초 간격 오토와 새 규칙을 비교했다. 4개 패턴별 12개 시작 손패 구성, 총 48쌍이다. 파티·카드 수치·적 패턴은 동일하게 유지했다.

| 패턴 | 기존 승리 | 새 승리 | 기존 평균 받은 피해 | 새 평균 받은 피해 | 새 보유 횟수 합계 |
|---|---:|---:|---:|---:|---:|
| 집중 공격 | 12/12 | 12/12 | 177.01 | 177.01 | 0 |
| 다수의 적 | 12/12 | 12/12 | 216.11 | 216.11 | 0 |
| 예고된 강공격 | 12/12 | 12/12 | 262.63 | 244.82 | 10 |
| 위험 구역 보스 | 12/12 | 12/12 | 277.93 | 277.93 | 0 |

강공격 패턴의 평균 피해가 약 6.8% 감소했다. 다른 패턴은 평균 피해와 승률이 같았다. 특정 공개 예고·손패 상태를 같은 스냅샷으로 나눈 검사에서는 즉시 공격하는 기존 오토가 강공격을 맞았고, 새 오토는 명령을 보유한 뒤 실제 차단을 사용했다.

이 비교는 현재 기본 조건에서 불필요하게 모든 오토가 강화되지 않는지 확인하는 회귀 검사다. 각 패턴의 기본 난이도 자체는 쉬워 두 오토가 모두 완주했고, 사람의 숙련도와 비교하는 실험이나 전체 게임 밸런스의 증명은 아니다. 새로운 패턴·덱·난이도가 들어오면 재측정해야 한다.

## 검사
