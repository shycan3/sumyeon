# 오토 방침·관전 안정화 구현

적용일: 2026-10-07. 로드맵 업데이트 4와 공격·보호 오토 방침을 함께 적용했다. 주 플레이 화면은 `prototype/character.html?v=autotactics1`, 별도 비교 체험은 `prototype/auto-lab.html?v=autotactics1`이다.

## 운영과 선택

새 출정의 기본 방침은 공격 중심이다. 지도 또는 설정에서 공격 중심·보호 중심을 선택하고 전투 사이에 변경한다. 같은 원정의 다음 교전에 유지하고 저장 후 이어하기에서도 보존한다. 전투 중에는 방침을 바꾸지 않는다.

| 방침 | 실제 카드 운영 |
| --- | --- |
| 공격 중심 | 공격의 우선도를 높이고 최근 공격 대상 집중·처치 가능한 적·추격 연계를 고려 |
| 보호 중심 | 위협받는 동료·부상 정도를 고려해 보호와 회복의 우선도를 높이고 안전할 때 공격 |

덱이 사용할 수 있는 기술을 정하고 방침이 사용 우선도를 정한다. 현재 손패의 카드와 합법 대상 조합을 함께 평가한다. 기존처럼 카드당 추천 대상을 하나 먼저 고정하는 방식으로 새 방침을 제한하지 않는다. 실행 불가능한 카드와 무효 대상은 후보에서 제외한다. 공격 중심에서도 위기 회복을 고려한다.

능력치·카드 수치·비용·명령 회복·드로우·역할 기본 행동·캐릭터 성향·태세·카드 목적의 실행 우선순위는 방침의 효과로 변경하지 않는다. 기본 AI의 무료 기믹 회피도 추가하지 않았다. 실제 보유한 이동·차단·엄호·회복 카드로 대응한다. 판단 간격 0.6초, 공개 강공격에 대한 명령 보유 최대 1.2초와 단일 보유 규칙은 공통 안전 장치로 유지한다. 적의 숨겨진 손패·드로우 순서·다음 명령 시각을 새 평가에 사용하지 않는다.

기존 진행 중 원정과 전투는 이전 오토를 `기존 운영`으로 보존한다. 전투 사이에 새 방침을 선택하면 이후 교전부터 적용한다. 저장 키나 원정 카드 수명 규칙을 변경하지 않는다. 기존 수동·명시적인 일시 개입도 유지한다. 이번 구현은 자동 관전 중심의 운영 검증이며 수동 기능을 삭제한 버전은 아니다.

## 관전과 안정화

- 자동 전투 중 손패 클릭은 기술 정보 조회로 처리해 시간을 멈추지 않는다. 직접 개입은 별도 버튼으로 연다.
- 전투 화면에서 방침·관전 일시정지·1/1.5/2배 속도를 표시하고 조정한다.
- 사용 가능/명령 충전/시전자 실행 중/현재 목적 종료 후/기믹 예고 중/유효 대상 없음 등 카드 상태를 표시한다.
- 실행한 오토 명령의 카드·대상·방침·이유·시각을 최대 40개 저장한다. 화면과 결과에서 마지막 운영을 볼 수 있다. 이것은 수락된 명령의 기록이며, 실제 피해·차단·피해 분담 결과는 기존 복기에 따로 기록한다.
- 카메라는 살아 있는 동료와 적, 공개 위험 구역의 범위를 고려한다. 재배치로 시야 밖에 나가거나 더 넓은 시야가 필요하면 즉시 넓혀 동료를 놓치지 않는다. 이름·HP 표시가 겹치면 표시 위치만 분리하고 연결선을 그린다. 실제 전투 위치와 판정은 바꾸지 않는다.
- 화면은 렌더 프레임마다 한 번 갱신하고 물리는 기존 0.02초 고정 간격으로 진행한다. 배속으로 화면 갱신이 불필요하게 반복되는 것을 줄였다. 연출의 중복 방지와 캐시 상한을 유지한다.

## 무한 교전 방지

지원가만 살아남아 회복을 반복하고 낙하 보스도 처치하지 못하는 실제 조건을 발견했다. 새 교전은 **180초 안에 적을 처치해야 한다.** 지도 설명과 전투 시계에 표시한다. 수동과 오토, 두 방침에 같은 제한을 적용한다.

시간 초과는 패배로 종료하고 `교전 시간 초과 (180초)` 사유와 실제 남은 HP를 기록한다. 생존자를 전투불능으로 꾸미지 않는다. 예약 타격·행동·위험 구역·재배치 유지·오토 보유를 정리하며 사용한 카드나 명령을 반환하지 않는다. 일시정지 시간은 포함하지 않는다. 기존 진행 중 전투에서 제한 시간이 없는 저장은 그대로 유지한다.

## 덱·방침 비교 체험

현재 원정의 네 적 구성과 실제 공통 엔진을 사용한다. 캐릭터 Lv.1·태세·적·시드는 고정해 비교하고, 기초/추격/엄호/기믹 이동의 합법 20장 덱, 공격/보호 방침, 시작 HP 100/45/25%를 선택한다. 보강 덱은 기초 카드 두 장을 기존 원정 보상 카드로 교체한 체험용 편성이다.

전투 중 설정은 잠그고 자동으로 진행한다. 일시정지·배속·연출·소리를 조절할 수 있다. 최근 결과 8개에서 시간·남은 HP·회복·엄호·차단·추격·카드 이동·사용 카드·마지막 운영을 비교한다. 원정 저장을 읽거나 덮어쓰지 않으며 체험 결과는 화면을 닫으면 사라진다. URL의 유효한 비교 조건을 사용할 수 있지만 자동 시작하지 않는다.

## 남은 판단

프로토타입의 관전·저장·배속·종료 흐름과 두 방침은 연결됐다. 기본 체력 조건에서는 아직 쉬운 전투가 많다. 서로 다른 덱의 행동 차이와 특정 돌파 사례는 확인했지만, 반복해서 덱을 바꾸고 싶게 하는 난이도·보상 가치와 매력적인 관전 경험은 추가 플레이로 판단해야 한다. 정식 아트·캐릭터 확장·모든 카드의 최적 운영까지 완료했다고 주장하지 않는다.
