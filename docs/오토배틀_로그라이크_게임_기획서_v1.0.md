# 캐릭터와 카드로 전투를 만드는 오토배틀 로그라이크

기획서 v1.0 · 2026-10-08

> 매력적인 캐릭터를 모으고, 그들이 싸울 방식을 카드와 배치로 설계한다. 전투를 지켜보고 결과를 이해한 뒤, 구성을 바꿔 이전에 넘지 못한 적을 돌파한다.

이 문서는 지금까지의 방향을 통합한 **기획안**이다. 게임 코드를 변경하지 않으며, 아래의 새 제안을 구현 완료 사항으로 취급하지 않는다. 기존 문서와 충돌하는 경우 최근에 합의한 풀오토·오토체스 지향을 우선한다.

## 1. 기획의 중심

장르는 **PvE 파티 오토배틀 로그라이크 + 카드 구성**이다. 플레이어의 주요 결정은 전투 사이에 있고, 전투는 그 결정이 실제 행동으로 나타나는 무대다.

목표 경험은 다음과 같다.

1. 적의 위협을 보고 이번 전투의 문제를 이해한다.
2. 캐릭터·카드·특성·배치·운영 방침으로 대응을 준비한다.
3. 캐릭터가 서로 보호하고, 추격하고, 기술을 연계하는 모습을 관전한다.
4. 준비한 의도가 어디에서 통했고 어디에서 무너졌는지 확인한다.
5. 보상과 재편성으로 전투 방식을 바꾸고, 이전에 실패했던 상대를 돌파한다.

핵심 보상은 **“내가 구성한 팀이 이렇게 싸우는구나”와 “구성을 바꾸니 이길 수 있구나”**다. 성장 수치와 화려한 궁극기는 이 경험을 강화하는 수단이다.

오토체스에서 가져올 재미는 조합·배치·상대 대응·성장에 따른 전투 변화다. PvP, 공용 상점, 이자 경제, 동일 캐릭터 합성, 시간 제한 구매를 이번 기획에 추가하지 않는다.

## 2. 방향과 구현 상태

| 구분 | 내용 | 문서에서의 취급 |
|---|---|---|
| 합의한 방향 | PvE, 캐릭터 관전의 재미, 덱에 따른 행동 변화, 전투 밖의 전략 선택 | 기획의 중심으로 유지 |
| 합의한 성장 구조 | 캐릭터 소유·기초 기능과 원정 보상을 분리, 보상 카드·진화는 원정 종료 시 초기화 | 유지 |
| 합의한 카드 원칙 | 모든 카드에 특성 존재, 이동도 카드로 제공, 카드 진화는 한 번 | 유지 |
| 현재 검증 기준 | 4인 파티, 편성 덱 20장, 손패 5장, 공격/보호 방침, 공유 명령시간 | v1 개발의 기준값. 최종 상품의 불변 규칙은 아님 |
| 현재 구현 | 기본 행동·카드 오토, 출발 덱, 특성, 보상 교체·보관·폐기, 배치, 적 전술, 복기·독립 연습 | 활용하되 게임성 검증은 계속 필요 |
| 새 제안 | 소수 전용 카드와 공유 카드, 캐릭터별 궁극기, 대표 기술의 원정 분기, 동일 역할 캐릭터 교체 | 아래 규칙으로 단계별 검증 |
| 미정 | 정식 명칭·세계관·플랫폼·캐릭터 판매 방식·최종 콘텐츠 규모 | 전투 핵심 검증 이후 결정 |

현재 프로토타입의 수동 개입 기능은 실험·검증에 활용할 수 있다. 정식 플레이의 난이도와 보상은 **전투 중 개입 없이 진행되는 조건**을 기준으로 설계한다.

## 3. 플레이 구조와 선택의 비용

### 3.1 전체 흐름

**캐릭터 선택 → 출발 덱·배치·방침 준비 → 원정 진입 → 자동전투 → 결과·보상 → 경로 선택·재편성 → 보스 → 원정 정산**

현재 원정의 방 구조를 검증에 사용한다. 방 수를 늘리기보다 서로 다른 선택이 실제 전투를 바꾸는지 먼저 확인한다.

| 시점 | 플레이어의 결정 | 얻는 것 | 함께 감수할 비용 |
|---|---|---|---|
| 출발 | 캐릭터와 출발 덱 선택 | 기본 전투 방식 | 다른 조합·기능을 편성하지 못함 |
| 전투 전 | 배치와 공격/보호 방침 | 첫 표적·지원 범위·기술 우선순위 변화 | 밀집에 따른 범위 피해, 추격에 따른 보호 공백 등 |
| 전투 후 | 보상 카드 선택·교체·보관·넘기기 | 새 기능과 특성 성장 | 기존 카드 빈도·필수 기능·특성 단계 손실 가능 |
| 원정 갈림길 | 회복·진화·보상·강적 경로 | 현재 생존 또는 이후 성장 | 반대 경로의 기회를 포기 |
| 정비 | 현재 카드 보상 또는 회복 선택 | 새 카드 또는 생존 여유 | 다른 정비 선택의 기회를 포기 |
| 진화 기회 | 기존 진화 또는 기술 운용 변경(새 제안) | 대표 기술 강화·역할 전환 | 다른 카드·다른 운용을 강화하지 못함 |

보상을 받는 것과 덱이 강해지는 것은 구분한다. 좋은 보상도 부적절한 교체로 팀을 약하게 만들 수 있다. 다만 플레이어가 그 비용을 읽을 수 있어야 하며, 모르고 손해를 보는 과정이 주된 난이도가 되어서는 안 된다.

### 3.2 전투 중의 경험

- 명령이 준비되어도 전투는 계속되고, 오토가 사용 시점과 카드를 판단한다.
- 플레이어는 일시정지·배속·정보 확인으로 관전 속도를 조절한다. 직접 카드 사용이나 실시간 이동이 승리의 전제는 아니다.
- 손패는 팀의 다음 기술 후보를 보여준다. 관전자가 모든 카드를 계속 읽어야 전황을 이해하는 구조는 피한다.
- 위협 예고는 캐릭터가 무엇에 맞서고 있는지 보여준다. 모든 예고를 인간이 즉시 조작해서 피하도록 요구하지 않는다.

## 4. 캐릭터와 카드의 관계

### 4.1 캐릭터는 전투 원리, 카드는 그 원리를 운영하는 선택

캐릭터와 대표 기술은 플레이에서 연결한다. 제작에서는 역할 행동·효과 처리·오토 평가·일반 연출을 공유한다.

| 구성 | 기능 | 캐릭터의 개성이 드러나는 지점 |
|---|---|---|
| 기본 행동 | 카드가 없어도 수행하는 공격·이동·회복·보호 | 누구를 따라가고, 어느 거리를 유지하고, 어떤 동료를 돕는가 |
| 고유 패시브 | 조건에 따라 기본 행동과 기술의 활용을 바꿈 | 피해 분담 후 반격, 추격 성공 후 연계 등 고유한 작동 원리 |
| 개인 기술 카드 | 대표 공격·방어·지원 행동을 덱에 편성 | 고유 동작·대사·대상 선택·타격 순서 |
| 공유 카드 | 호환되는 캐릭터에게 전투 기능을 제공 | 같은 기능을 고유 패시브와 다르게 연결 |
| 궁극기 | 캐릭터의 대표 장면과 전투 전개를 만듦 | 무엇을 준비해야 하고, 어떤 상황에서 강한가 |
| 원정 보상 | 위 구성의 빈도·조건·연계를 바꿈 | 같은 캐릭터의 다른 운영을 매판 구성 |

역할은 공통 임무를 정의한다. 캐릭터는 그 임무를 수행하는 고유 원리를 가진다. 같은 보호 역할이라도 한 명은 피해를 받아 반격을 준비하고, 다른 한 명은 동료 사이에 보호를 연결할 수 있다. 숫자와 외형만 바뀐 캐릭터는 이 기준을 충족하지 못한다.

### 4.2 첫 캐릭터 제작 규모 — 제안

캐릭터당 **시작 전용 카드 3~4종, 전용 보상·변형 2종, 고유 패시브 1개, 궁극기 1개**를 초기 제작 예산으로 제안한다. 카드 종수와 사본 수는 다르다. 20장 편성 덱을 만들기 위해 캐릭터마다 수십 종의 전용 카드가 필요한 것은 아니다.

궁극기는 먼저 한 캐릭터에서 검증한다. 표의 수량을 모든 캐릭터에 한꺼번에 적용하거나, 기존 네 캐릭터의 카드 풀을 즉시 전면 교체하지 않는다.

공유 카드는 역할·무기·기능 조건에 맞는 캐릭터에게 **편성 시 시전자를 지정**한다. 전투에서 한 장의 시전자가 계속 바뀌지 않는다. 카드에 시전자 초상화를 표시하고, 해당 캐릭터의 동작과 대사로 연출한다.

캐릭터의 핵심 기능은 획득 시 사용 가능하게 한다. 기본 정체성까지 별도 카드 획득에 의존시키지 않는다. 원정 보상은 그 캐릭터를 완성시키기보다 이번 판에 다르게 운영하도록 만든다.

### 4.3 파티와 역할

첫 범위는 4인 파티를 유지한다. 캐릭터 ID, 역할, 파티 슬롯, 전투 개체 ID를 분리해 같은 역할의 캐릭터를 교체할 수 있게 한다. 역할별 한 명씩만 넣는 제약은 구조에 고정하지 않는다.

동일 역할 중복 편성의 최종 허용 범위와 동일 캐릭터 중복은 이후 검증한다. 이번 단계에서 다섯 번째 파티 슬롯이나 대규모 캐릭터 목록을 추가하지 않는다.

## 5. 카드·덱·특성

### 5.1 덱의 의미

덱은 기술 사용 빈도와 연계 기회를 설계하는 도구다. 정확한 사용 순서를 보장하는 행동 스크립트는 아니다. 손패와 전황에 따라 오토가 가능한 행동을 선택하고, 기본 행동이 그 사이를 이어 준다.

현재처럼 사용한 카드는 버린 카드 더미로 이동하고 손패를 보충한다. 뽑을 카드가 없으면 버린 카드를 다시 섞는다. 같은 캐릭터의 행동 충돌과 사망한 시전자의 카드는 기존 유효성 규칙으로 처리한다.

| 기준 | v1에서 유지할 값·규칙 | 목적 |
|---|---|---|
| 편성 덱 | 20장 | 추가와 교체에 비용을 부여 |
| 손패 | 최대 5장 | 판단 후보를 제한하고 덱 빈도 차이를 반영 |
| 사본 제한 | 현재 카드별 제한 유지 | 강한 한 종류만 반복 편성하는 문제 억제 |
| 손패 교체 | 전투당 현재 2회, 오토와 기존 수동 기능이 공유 | 손패 정체 완화. 핵심 전략을 리롤에 의존시키지 않음 |
| 카드 시간 | 준비시간과 다음 명령까지의 회복시간 구분 | 강한 카드의 사용 비용과 동작을 표현 |
| 진화 | 해당 원정에서 카드 사본당 최대 한 번 | 무한 강화 억제, 정비 선택에 의미 부여 |

카드 설명은 **시전자·효과·특성·대상/범위·시간 비용**을 같은 위치에 표시한다. 화려한 그림이나 테두리만으로 필요한 정보를 대신하지 않는다.

### 5.2 모든 카드에 특성 부여

호위·추격·공명을 초기 특성으로 유지한다. 특성은 주로 피해량 보너스보다 팀의 전투 흐름을 바꾸는 방향으로 발전시킨다.

| 특성 | 현재 기반 | 발전시킬 경험 |
|---|---|---|
| 호위 | 실제 보호 성립 후 후속 공격 지원 | 보호한 뒤 반격하거나 동료가 안정적으로 공격하는 팀 |
| 추격 | 공격 표식과 다른 동료의 후속 공격 | 여러 캐릭터가 같은 적을 이어서 압박하는 팀 |
| 공명 | 서로 다른 캐릭터의 기술 사용 연계 | 한 명의 독주보다 동료 기술이 이어지는 팀 |

특성 수는 **편성한 서로 다른 원본 카드 종류**를 기준으로 센다. 사본·진화·그림만 다른 변형이 새 종류 수를 늘리지 않는다. 보관 중인 카드는 편성 특성에 기여하지 않는다.

출발 덱은 방향을 이해할 수 있는 발판을 주고, 강력한 최종 조합을 보장하지 않는다. 화면에는 각 카드의 특성과 함께 ‘현재 단계·다음 단계까지 부족한 종류 수’를 보여준다. 현재 발동 수치와 단계는 검증값이며 이후 조정할 수 있다.

### 5.3 대표 기술의 성장 분기 — 제안

한 기술을 집중형·엄호형·연계형 등으로 운용할 수 있게 한다. 초기에는 **기존 진화 기회를 사용하는 대안**으로 시험해 별도 강화 재료와 추가 관리창을 만들지 않는다.

한 카드 사본에서 분기를 동시에 중첩하지 않는다. 원본 특성 집계 ID를 유지하고, 변경 후 효과·범위·시간 비용을 다시 표시한다. 분기가 없는 기존 카드의 진화는 그대로 유지한다.

## 6. 개인 스킬과 궁극기 — 새 제안

### 6.1 세 기능의 경계

- **기본 행동·패시브:** 언제든 관전 중 드러나는 캐릭터의 정체성.
- **개인 스킬:** 카드로 편성하고, 빈도·성장·연계를 구성하는 대표 기술.
- **궁극기:** 덱과 기본 행동으로 준비한 조건을 전투의 큰 장면으로 바꾸는 기술.

일반 고유 스킬을 별도의 자동 타이머 기술로 계속 추가하지 않는다. 카드 기술과 기능이 중복되면 손패와 편성의 의미가 약해진다.

### 6.2 첫 궁극기 구현 규칙 — 검증안

| 항목 | 첫 검증 규칙 |
|---|---|
| 보유 | 캐릭터 기본 키트에 포함, 원정 보상으로 잠금 해제하지 않음 |
| 준비 자원 | 캐릭터별 게이지. 표시 상한 100은 초기 제안값 |
| 전투 시작 | 게이지 0에서 시작하고 전투 사이에 이월하지 않음 |
| 자원 획득 | 추격 성공·실제 피해 분담·유효 회복 등 캐릭터의 고유 행동과 연결 |
| 낭비 방지 | 초과 회복, 흡수하지 못한 보호, 무효 공격으로 게이지를 얻지 않음 |
| 발동 | 게이지 충족 후 오토가 현재 카드와 함께 가치 평가 |
| 명령 비용 | **첫 실험에서는 기존 공유 명령 기회를 사용**하고, 정의된 다음 명령 회복시간을 적용 |
| 자원 소비 | 최종 유효성 확인 후 시전을 수락할 때 게이지 100과 명령 기회를 함께 소비. 수락 전 실패는 소비 없음 |
| 시전 후 중단 | 시전자 사망·차단 등으로 중단되어도 이미 소비한 자원과 명령을 되돌리지 않음. 첫 실험은 기존 카드와 같은 원칙 적용 |
| 전투불능 | 게이지와 발동 예약을 정리. 진행 중 효과는 기술의 중단 규칙에 따름 |
| 카드 더미 | 손패를 소비하거나 보충하지 않음. 궁극기는 덱의 카드 한 장으로 집계하지 않음 |
| 행동 충돌 | 시전자 행동 잠금 적용. 진행 중 기술을 임의로 끊거나 동시 시전하지 않음 |
| 연쇄 제한 | 궁극기 자체 효과로 자신의 게이지를 다시 채우지 않음. 추가 타격·반격은 발동 상한 적용 |
| 플레이어 조작 | 수동 궁극기 버튼의 정확한 타이밍을 요구하지 않음 |

저장 복원은 해당 전투의 게이지·시전 상태·규칙 버전을 함께 복원한다. 기존 기록에 새 궁극기를 소급 적용하지 않는다. 자원과 명령 소비는 한 번의 수락으로 처리해 저장·재개 때 이중 소비나 무료 재발동이 생기지 않게 한다.

공유 명령을 사용하는 안은 기존 카드와 궁극기의 경쟁을 한 규칙으로 다루기 위한 출발점이다. 궁극기가 자주 선택되어 손패 운영이 정체되거나, 게이지가 준비되어도 지나치게 오래 쓰지 못하면 회복시간·가치 평가·자원 획득을 먼저 조정한다. 독립된 발동 시간축이 더 나은지는 그 결과를 보고 판단한다.

게이지가 가득 찼다고 즉시 쓰지는 않는다. 공격 궁극기는 유효 대상과 낭비 가능성을, 보호 궁극기는 실제 위협과 보호 대상을 확인한다. 미래 손패나 공개되지 않은 적 행동을 미리 아는 오토는 만들지 않는다.

궁극기의 강함에는 준비 비용과 사용 후 기회비용이 있어야 한다. 모든 덱에서 같은 시간에 같은 궁극기만 반복되는 결과는 실패로 본다.

### 6.3 카드와 궁극기의 연결 예시

추격 캐릭터는 접근·표식·동료 후속 공격을 통해 대표 공격을 준비할 수 있다. 보호 캐릭터는 실제 분담·방어가 성립해야 대표 보호 기술을 준비한다. 회복 캐릭터는 유효 회복과 동료 지원을 연결한다.

게이지 획득은 초기에는 공통 행동 기록에서 계산한다. 한 행동의 연속 타격·다중 대상·반격이 자원을 과도하게 만들지 않도록 행동별 획득 상한을 둔다. 단순한 수치 변경을 위해 캐릭터마다 별도 오토 프로그램을 만들지 않는다. 새로운 자원 원리가 필요할 때만 추가 모듈을 정의한다.

## 7. 오토의 역할과 구성

오토의 목표는 최고 승률만이 아니라 **플레이어가 준비한 의도를 일관되게 실행하는 것**이다. 풀오토 게임에서 일부러 멍청하게 만들어 수동 조작을 유도하는 방침은 채택하지 않는다. 한편 오토가 모든 덱의 약점을 즉석에서 해결해서도 안 된다.

### 7.1 판단 순서

1. 생존·상태·대상·시전자·거리 등 행동의 유효성을 확인한다.
2. 도발과 행동 잠금, 시전·이동·추가 타격의 충돌 규칙을 적용한다.
3. 공개된 위협에서 실제로 가능한 생존·보호 대응을 평가한다.
4. 공격/보호 방침과 캐릭터의 고유 선호를 반영한다.
5. 카드·궁극기의 예상 효과와 시간 비용을 비교하고 한 행동을 선택한다.

실행 직전에 유효성을 다시 확인한다. 대상 사망·시전자 사망·시전 차단·보호 만료가 발생하면 기술별 규칙대로 정리한다. 오토가 이동과 공격을 서로 덮어쓰거나 매 판단마다 시전을 취소하지 않게 한다.

### 7.2 공통 행동과 고유 행동

| 층 | 책임 |
|---|---|
| 역할 행동 | 전열 유지, 근접 추격, 거리 유지, 회복·보호 대상 선정 |
| 캐릭터 정의 | 패시브, 선호 대상·거리, 고유 자원, 대표 기술 조건 |
| 카드·궁극기 정의 | 효과, 대상, 범위, 시전·회복시간, 발동 조건 |
| 운영 방침 | 공격 기회와 보호 안정성 중 무엇에 더 가치를 둘지 결정 |
| 실행 엔진 | 행동 예약·잠금·효과 처리·중단·정리 |

효과 모듈은 실제 실행과 예상 효과 계산이 같은 정보를 읽게 한다. 연속 타격의 실제 실행은 세 번인데 오토가 한 번의 피해로 평가하는 식의 불일치를 막는다.

새 캐릭터가 기존 피해·회복·보호·이동·반격 모듈을 쓰면 이름별 예외 없이 제작할 수 있어야 한다. 소환·변신 등 새 원리는 대상 규칙, 효과 예상, 실행, 중단, 저장, 연출을 함께 확장한다.

### 7.3 운영 방침

초기에는 공격 중심과 보호 중심 두 방침을 유지한다. 공격은 처치·집중·연계를 우선하고, 보호는 실제 위협과 동료 유지에 더 가치를 둔다. 두 방침 모두 무효 행동이나 명백한 효과 낭비를 피한다.

방침만 바꿔 모든 덱이 모든 역할을 수행하지 않는다. 보호 카드가 없는 팀은 보호 방침을 선택해도 없는 방어 기술을 만들어 내지 못한다. 새로운 캐릭터마다 플레이어가 익혀야 하는 전용 오토 모드를 추가하지 않는다.

## 8. 배치와 적의 기믹

전투 전 위치 선택은 첫 표적, 지원 범위, 적 접근 경로, 범위 공격의 노출을 바꾼다. 현재 12자리 배치를 출발점으로 사용한다. 전투 중 이동은 연속 좌표의 기본 행동과 카드 기능이 담당한다. 격자 배치를 넣었다고 전투 이동까지 TFT식 칸 이동으로 구현되어 있다고 보지 않는다.

초기 배치의 차이가 곧 사라지는 경우에는 지원 범위·표적·공격 방향처럼 지속되는 관계를 검토한다. 자리를 고정해 움직임을 죽이는 방식으로만 해결하지 않는다. 또한 화면상 방패병이 앞에 서 있다는 이유만으로 실제 판정에 없는 투사체 차단을 암시하지 않는다.

### 8.1 풀오토에서의 기믹 원칙

- 적의 전술과 주요 범위·표적 원리를 전투 전에 공개한다.
- 대응은 배치·카드·특성·방침·경로의 조합으로 가능해야 한다.
- 기본 AI에게 모든 위험 구역을 무료로 완벽하게 피하는 능력을 주지 않는다.
- 대응 카드의 이동·보호·회복·빠른 처치가 실제 대응 수단이 된다.
- 특정 희귀 카드 한 장 없이도 실용적인 대응 대안이 있어야 한다.
- 지속 피해 압박, 회복 방해, 위험 구역 등은 서로 다른 덱에 다른 비용을 요구한다.

| 적 전술 | 대응 방향 A | 대응 방향 B | 선택 비용 |
|---|---|---|---|
| 범위 공격 | 분산 배치·거리 유지 | 보호·회복으로 버티며 처치 | 분산은 근처 지원 효율이 낮고, 버티기는 긴 전투 비용이 큼 |
| 후열 압박 | 보호 대상·엄호 동선 조정 | 추격·집중 공격으로 압박원을 제거 | 보호는 공격 속도를, 집중은 다른 적의 대응을 희생 |
| 장기전 압박 | 회복·안정적 순환 | 짧은 시간의 연계 공격 | 유지력과 순간 공격 사이의 편성 기회비용 |

위 표는 콘텐츠 설계 기준이다. 기존 적 전부가 이 구조를 완성했다는 의미는 아니다. 적 체력만 높여 난이도를 올리기 전에 서로 다른 대응의 장점·약점을 확인한다.

## 9. 원정 성장과 영구 성장

| 영구 유지 | 원정 종료 시 초기화 |
|---|---|
| 캐릭터 소유, 기초 기능과 시작 카드 이용 가능 범위 | 전투·보상 방에서 얻은 원정 카드 |
| 제한된 캐릭터 레벨 성장 | 해당 원정의 카드 진화·운용 분기 |
| 기록·연습에서 확인할 과거 구성 | 해당 원정의 보관 카드와 전술 보상 |

현재 레벨 1~5를 검증 기준으로 사용한다. 원정 중간에 영구 레벨 상승으로 팀 조건이 바뀌지 않도록 현재 방식처럼 출발 레벨을 고정한다. 캐릭터 레벨이 빠르게 상한에 도달한 뒤에도 원정 내 구성 선택이 남아야 한다.

전투 보상과 보상 방을 주요 카드 획득 경로로 유지한다. 얻은 카드는 다음 전투부터 활용한다. 보관·교체·폐기는 전투 사이에 처리하고, 보상 넘기기도 정상적인 선택으로 인정한다.

출발 덱은 매판의 방향을 고르게 한다. 보상은 원하는 조합에 다가가거나 새로운 방향으로 전환할 기회를 준다. 원하는 카드가 안 나오면 무조건 실패하는 구조와, 모든 보상이 모든 덱을 자동으로 강화하는 구조를 모두 경계한다.

캐릭터 판매는 장기 방향으로 유지하되 획득 방식·가격·중복 보상은 미정이다. 초기 상품 설계 원칙은 **캐릭터의 완전한 기초 키트를 제공하고, 고유한 전투 경험을 소유하게 하는 것**이다. 새 캐릭터 판매를 위해 기존 캐릭터를 지속적으로 무력화하는 구조는 제안하지 않는다.

## 10. 관전 연출과 UI

캐릭터의 매력은 초상화가 나타나는 순간뿐 아니라 평소 움직임에서도 드러나야 한다. 보호 시 동료 곁으로 가는 동작, 추격의 속도·자세, 사수의 거리 유지, 지원가의 회복 대상과 반응이 보여야 한다.

### 10.1 연출 등급

| 등급 | 대상 | 연출 |
|---|---|---|
| 가벼움 | 기본 행동·자주 사용하는 기술 | 짧은 동작·이펙트·필요한 수치 |
| 강조 | 대표 카드·중요한 보호·연계 | 짧은 초상화·대사·차별화된 효과 |
| 절정 | 궁극기·큰 전환 | 대표 동작·컷인·음성, 전황을 읽을 수 있는 지속시간 |

연출은 전장 크기를 바꾸지 않는다. 동시에 발동한 강조 연출은 제한된 순서·시간으로 처리하고, 작은 효과를 과도하게 누적하지 않는다. 반복 관전에서는 긴 컷인의 간략화 설정을 제공하는 방향으로 설계한다.

### 10.2 한 화면의 정보 우선순위

- **준비:** 중앙 배치판, 적 위협 요약, 덱·특성·방침. 상세 설명은 선택한 카드 중심으로 연다.
- **관전:** 전장, 캐릭터 상태, 다음 기술 후보, 짧은 주요 사건. 개발용 판단 로그는 상세로 보낸다.
- **보상:** 새 카드와 교체 후보를 나란히 표시. 효과·특성·시전자·시간 비용·진화 여부를 같은 양식으로 비교한다.
- **결과:** 승패·주요 손실·실제로 발생한 대표 연계·준비 변경의 확인점을 요약하고, 독립 연습으로 연결한다.

보상 교체 시 ‘편성된 유일한 회복 카드 제거’, ‘진화 사본 제거’, ‘호위 단계 감소’처럼 구체적 손실을 보여준다. 기본 행동의 회복과 카드 회복을 구분해 회복 카드가 없다는 이유로 팀의 모든 회복이 사라진다고 표시하지 않는다. 자동 추천은 이유를 표시하고, 카드 한 장의 편성을 강제하지 않는다.

기여도는 실제 사용·회복·흡수·타격을 근거로 보여준다. 카드가 사용되었다는 사실만으로 승리의 원인을 확정하거나, 통계 합계만으로 최적 교체를 단정하지 않는다.

## 11. 구체적인 플레이 예시 — 설계 예시

같은 추격 캐릭터 세린을 두 방식으로 준비한다고 가정한다. 아래 효과·궁극기 연결은 확정 수치가 아닌 기획 예시다.

| 선택 | 집중 추격 구성 | 엄호 반격 구성 |
|---|---|---|
| 주요 카드 | 접근·표식·연속 타격 | 엄호·보호·반격·회복 지원 |
| 특성 방향 | 추격 위주 | 호위 위주 |
| 배치 | 공격 대상에 접근하기 좋은 위치 | 지켜야 할 동료와 지원 범위를 맞춘 위치 |
| 운영 방침 | 공격 중심 | 보호 중심 |
| 보이는 행동 | 동료가 같은 적을 이어 공격, 처치 후 다음 적으로 접근 | 동료 곁에서 피해를 분담하고 공격 기회를 되돌림 |
| 궁극기 준비 | 유효 추격·공격 연계가 준비를 돕는 후보 | 유효 엄호가 다음 공격 기회를 만드는 후보 |
| 약점 | 진입 후 보호 공백·범위 공격 노출 | 처치가 늦어 장기전 압박을 받을 수 있음 |

후열을 압박하는 적에게 집중 추격이 실패했다면, 플레이어는 ‘세린의 수치가 부족하다’ 외에도 ‘압박원을 먼저 제거할지, 후열을 지킬지’를 선택할 수 있어야 한다. 변경한 카드·배치가 실제 보호 또는 빠른 처치 장면으로 나타나고, 재도전 결과에서 확인되는 것이 목표다.

이 예시는 세린에게 두 개의 궁극기를 추가하자는 뜻이 아니다. 하나의 고유 키트를 덱과 지원으로 다르게 운영할 수 있는지를 검증한다.

## 12. 현재 부족한 부분과 검증 근거

최근 144회 원정 비교에서 회복 위주 48/48, 성장 위주 48/48, 카드 보상 건너뛰기 47/48이 완주했다. 48조건 중 선택 묶음에 따라 완주 여부가 달라진 조건은 1개였다. 건강하게 출발한 일반 원정에서는 준비 차이가 승패로 충분히 드러나지 않는 문제가 남아 있다.

별도로 동일 보스 조건의 시작 HP를 25%로 낮춘 스트레스 검사에서는 출발 덱 37/48, 성장 덱 32/48이 승리했다. 이 HP 변경은 실제 게임에 적용한 것이 아니다. 제한된 보상 교체 규칙이 진화·중요 보호 카드를 뺄 수 있어 ‘성장 카드가 일반적으로 약하다’는 결론은 낼 수 없다.

따라서 다음 두 문제를 분리한다.

1. **선택을 읽는 문제:** 어떤 기능과 특성을 잃는지 모른 채 교체하는 상황.
2. **선택이 중요한지의 문제:** 읽고 합리적으로 선택해도 대부분 같은 결과에 도달하는 상황.

첫 문제는 비교 UI와 추천 근거로 개선한다. 두 번째는 대응이 다른 적·경로 기회비용·건강한 조건에서도 발생하는 적절한 실패 가능성으로 검증한다. HP를 일괄 낮추거나 적 피해를 올리는 것만으로 해결했다고 판단하지 않는다.

기존 검사는 배치·카드·오토의 기능적 차이를 확인하는 근거다. 사람이 그 차이를 이해하고 재미있게 느끼는지, 반복 플레이하고 싶은지는 별도 플레이 검증이 필요하다.

첫 완성 구간의 목표는 ‘캐릭터가 많다’가 아니라 **‘동일 캐릭터의 다른 덱, 동일 역할의 다른 캐릭터, 서로 다른 적 대응’이 모두 의미 있게 구별된다**는 것이다.

## 14. 검증 계획과 판단 기준

### 14.1 자동으로 확인할 것

- 행동 잠금, 도발, 대상 사망, 시전 중단, 추가 타격, 효과 만료와 정리.
- 카드와 궁극기의 명령 소비·예약·자원 처리, 중복 발동과 무한 연쇄 방지.
- 모든 카드의 특성·시전자 존재, 진화·분기의 원본 종류 집계, 덱·보관 규칙.
- 새로운 ID 구조의 저장·과거 결과·독립 연습 호환.
- 같은 적·HP·레벨·시드·배치·방침을 유지한 덱 비교. 변경 변수는 명시.

### 14.2 게임성으로 확인할 것

| 질문 | 확인 방법 | 실패 신호 |
|---|---|---|
| 덱이 행동을 바꾸는가? | 공격 대상·이동·보호 대상·기술 순서·연계 사건 비교 | 피해 수치만 바뀌고 관전 행동은 같음 |
| 같은 역할의 캐릭터가 다른가? | 공유 카드 조건에서 기본 행동·패시브와 대표 장면 비교 | 초상화와 숫자를 빼면 구별하기 어려움 |
| 성장으로 돌파할 수 있는가? | 같은 어려운 전투에서 출발 구성과 합리적 성장 구성 비교 | 보상 설명은 강해졌는데 실전 기능·결과가 계속 악화 |
| 여러 전략이 유효한가? | 적 유형별 공격·보호·분산·연계 구성 비교 | 모든 적에게 한 구성·한 방침이 일관되게 최선 |
| 궁극기가 덱을 살리는가? | 여러 덱의 게이지 준비·발동·후속 전개 비교 | 모든 덱이 같은 궁극기 반복으로 승패 결정 |
| 선택 결과를 읽을 수 있는가? | 상세 로그 없이 주요 장면과 결과를 보고 다음 변경 설명 | 원인을 모르고 카드 등급만 높이는 선택으로 회귀 |

처음부터 특정 승률이나 전체 완성도를 성공 기준으로 삼지 않는다. 초반 안전 구간과 대응을 요구하는 전투를 구분하고, 표본·선택 방식·변경 조건을 함께 기록한다. 원정 경로가 다르면 전투 수와 회복 기회도 다르므로 승률 차이를 카드 한 장의 효과로 해석하지 않는다.

자동 검증은 실행의 일관성과 조합 차이를 확인한다. 관전의 즐거움, 캐릭터에 대한 애착, 선택의 부담은 사람이 플레이하며 확인한다. 두 종류의 검증을 서로 대신하지 않는다.

## 16. 우선 결정하지 않아도 되는 것

정식 캐릭터 명단, 세계관 세부, 최종 플랫폼, 판매 방식, 대규모 아트 물량은 핵심 전투 검증 이후로 둔다. 상세 상점 경제나 영구 카드 수집을 먼저 설계해 원정 초기화 원칙을 흔들지 않는다.

보상 교체 비용·전투 돌파·원정 성장 방향·식별과 공유 기술 기반을 적용했다. 동일 역할 시험 캐릭터 리아와 세린/리아의 공유 명령 궁극기·수호 검무 운용까지 구현했다. **7단계 slice1에서 단계별 안내·관전 설정·관측 기록에 근거한 연습 연결·이전 기초 출발 덱 불러오기까지 연결했다.** 다음은 실제 플레이의 이해도와 대표 장면을 확인해 조정하고, 8단계 content1에서 제작 정의 검사·격리 캐릭터 제작 예제·교차사격 체험을 먼저 적용했다. 신규 콘텐츠 균형 검증과 일반 원정 편입, 성장 목표·기록 및 상품 범위 결정은 이어서 진행한다. 회복 편향과 상한 난도도 후속 검증한다. 궁극기의 초기 수치는 게이지 100, 각 캐릭터 전투당 2회, 동일 캐릭터 발동 간격 18초, 궁극기 사이 카드 명령 2회다. 현재 세린은 유효 공격/보호, 리아는 기본 사격/집중 적중으로 준비한다. 충분히 준비되어도 현재 카드의 가치와 생존 대응을 우선할 수 있다. 체감과 방침별 발동 대기는 후속 검증한다.
