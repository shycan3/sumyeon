# 원정 갈림길·보상 연결 구현

적용일: 2026-10-06. 대상은 `prototype/character.html?v=routes1`의 새 출정이다. 파티 4명·덱 20장·손패 5장·6개 방과 기존 카드/오토 규칙을 유지한다.

## 경로와 준비

| 방 | 새 출정의 구성 |
| --- | --- |
| 1 | 집중 공격 추격대 또는 다섯 포위병 중 하나 |
| 2 | 회복 또는 카드 진화 |
| 3 | 집중 공격과 다수전 중 선택 |
| 4 | 정비 |
| 5 | 직선 기믹 강적 또는 회복 |
| 6 | 낙하 기믹 보스 |

첫 교전과 중간 선택지의 표시 순서를 출정 시 확정한다. 별도 경로 난수로 기존 노드의 전투 난수를 불필요하게 소비하지 않는다. 지도에는 실제 적 구성·전술·예고와 방의 보상을 표시한다. 전투 결과·카드 보상·교체·진화·정비 화면에도 다음 교전 선택을 보여줘 다음 적을 고려해 편성할 수 있다. 회복 예상치는 현재 HP 기준이며, 도착 시 HP를 예측한 값은 아니다.

원정 보상 풀 4종은 모두 선택 가능하게 유지한다. 지도와 보상 조회는 난수나 실제 상태를 변경하지 않는다.

## 강적 도전의 보상과 비용

강적 승리 시 기존 카드 보상에 앞서 **현재 덱의 미진화 카드 한 장 진화** 또는 **생존자 최대 HP의 20% 회복**을 한 번 선택한다. 추가 정비를 넘기고 카드 보상으로 진행할 수도 있다. 진화는 카드 복사본마다 한 번이고 이번 원정에서만 유지한다. 같은 카드를 재진화하거나 보너스를 두 번 수령할 수 없다.

대체 회복 방은 최대 HP의 30%를 회복하며 쓰러진 동료도 복귀한다. 강적 후 20% 회복은 쓰러진 동료를 복귀시키지 않는다. 따라서 강적의 추가 전투·카드·진화를 감수할지, 동료 복귀와 회복을 우선할지 선택한다. 정비는 생존자 15% 회복으로 기존 규칙을 유지한다.

## 저장과 호환

새 원정은 `routeVersion:1`과 기존 `encounterVersion:2`를 사용한다. 경로 전체와 보너스의 미수령/수령 상태를 저장하고, 새로고침으로 경로를 재추첨하거나 보너스를 다시 받지 않는다. 저장 검사는 시드에 맞는 지도, 강적 승리 상태, 수령 카드와 진화 여부를 확인한다.

기존 진행 중 원정은 기존 고정 경로와 보상을 유지한다. 원정 종료 시 보상 카드·진화·추가 정비 상태는 초기화한다. 실제 사용자의 저장을 테스트에 사용하지 않았다.

## 검증

- `route-choice-check.cjs`: 24개 시드의 경로 다양성·결정성·조회 독립성·기존 저장 호환·잘못된 저장 거부·보너스 단일 수령·종료 초기화. 두 중간 경로와 두 강적 보너스를 조합한 실제 6개 방 원정을 검사했다. 적용 시점의 기존 운영은 32회 모두 완주했으며, 후속 공격 방침 재검사는 32회 중 30회 완주했다. 원본 32회 기록은 최신 재검사 결과다.
- `route-path-check.cjs`: 같은 상태에서 회복/강적 후 회복/강적 후 진화를 비교한 48회 조건 검사. 아래에 실패 결과도 포함했다.
- `route-choice-browser-check.cjs`: PC 1280×720, 모바일 390×844에서 전체 원정·보상 교체·다음 교전 미리보기·새로고침·저장 가져오기·보너스 중복 방지·종료 초기화를 확인했다. 가로 넘침과 브라우저 오류가 없었다.
- 기존 캐릭터·전투 패턴·적 미리보기·카드 구조·위험 구역 원정의 엔진 검사와 관련 브라우저 검사도 통과했다. 기존 고정 경로를 전제하는 테스트는 과거 지도 fixture로 명시하고 새 경로는 별도 검사했다.

검사 결과 원본: [32회 원정](../prototype/route-choice-results.json), [48회 경로 비교](../prototype/route-path-results.json).

## 조건별 경로 비교

아래 48회 수치는 업데이트 3 적용 시점의 기존 운영 기록이다. 후속 공격/보호 방침의 결과는 [별도 비교](오토_방침_관전_안정화_구현.md)를 따른다.

실제 원정을 5번째 방 앞까지 진행한 뒤, 비교 목적의 HP를 명시적으로 설정했다. 네 시드(2·7·19·37)에서 동일 지도·덱·상태를 복제해 세 경로를 실행했다. 강적 진화는 잔광 검무 한 장을 선택했고 일반 카드 보상은 넘겨 추가 정비 효과를 비교했다. 자동 운영으로 수행했으며 최적의 수동 선택을 평가한 실험은 아니다.

시간은 앞선 공통 교전을 포함한 원정 전체의 실제 전투 시간 합계이며, 화면 선택 시간은 제외한다. 최종 HP 평균에는 패배 결과도 포함한다.

전투불능 조건에서 회복 방의 동료 복귀가 실질적인 차이를 만들었다. 정상 체력 조건에서 강적 경로는 약 27초의 전투를 더 거치며 카드·진화 기회를 제공한다. 이 실험에서는 건강한 파티의 승률 차이가 없었고 회복이 최종 HP에 유리한 경우가 많았다. 강적 진화의 이득이 모든 덱에서 위험과 시간을 상쇄한다고 결론낼 수 없다.

32회 완주는 기본 진행 가능성의 증거이며, 48회 조건 검사는 실제 플레이에서 해당 부상 상태가 발생하는 빈도를 보여주지 않는다. 반복 재미와 보상 가치의 최종 균형, 숙련자의 경로 판단은 추가 플레이로 확인할 부분이다.
