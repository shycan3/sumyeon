# 원정 통합 기술 검토

작성: 2026-10-09. 사용자 요청에 따라 작은 비교 표본마다 개발을 멈추는 대신, 여러 전투와 보상·정비를 이어서 플레이할 수 있는 별도 원정 버전을 검토한다. 이전 v3 및 저장은 보존한다. 사람의 재미 관문이 통과된 것으로 소급 기록하지 않는다.

## 검사할 경계

- 같은 손패의 어떤 카드도 생존한 편성 캐릭터가 사용할 수 있다. 카드 소유자가 없어도 공유 덱·실행자 선택이 성립해야 한다.
- 다음 행동의 대상과 피해가 공개되어야 한다. 카드 사용이나 미리보기로 현재 예고가 몰래 바뀌지 않는다.
- 공격 대상의 사망으로 현재 공격이 취소되는 것과 다음 라운드에 생존자를 다시 예고하는 것을 구분한다.
- 보호와 약화의 종료 시점, 보관된 실물 카드의 복귀, 브레이크의 적용 여부가 저장·미리보기와 실제 실행에서 일치해야 한다.
- 원정의 지도·전투·보상·정비 상태를 그대로 복원한다. 복원으로 보상 후보를 재추첨하거나 완료한 선택을 두 번 지급하지 않는다.
- 새 카드를 초·중반에 얻어 후반 전투에서 사용할 수 있다. 원정 종료 직전의 보상만으로 카드빌딩이 완성됐다고 주장하지 않는다.
- HP 이월과 전투불능은 선택 전에 확인할 수 있어야 한다. 정비·복귀 기회를 경로에 두고, 특정 캐릭터만 기본 덱을 운용할 수 있게 만들지 않는다.

## 기술 검사의 해석

자동 완주는 합법적인 입력으로 전투·보상·다음 방·결과까지 흐름을 연결할 수 있다는 근거다. 같은 파티나 전략이 재미있는지, 모든 조합의 전략적 가치가 비슷한지, 적의 난이도가 적당한지는 자동 완주율만으로 판정하지 않는다.

원정의 여러 합법 경로와 6명 중 4명인 15개 편성을 검사하되, 특정 최적 덱이나 전원 생존 해법을 플레이어에게 정답으로 제시하지 않는다. 브레이크 OFF/ON의 기능 검사는 채택 판단과 분리한다.

## 완료 기록

`prototype/party-expedition-integration-check.cjs` 독립 통합 검사 10개를 실행하여 통과했다. 별도의 전투·원정 단위 검사는 해당 모듈의 구현 기록에서 집계한다.

| 검사 | 확인한 결과 |
| --- | --- |
| 6명 중 4명인 15개 편성 | 같은 10장 공용 덱으로 전투 생성·합법 행동 가능. 미편성 실행자의 입력은 상태 변경 없이 거절 |
| 전투 중 저장·미리보기 | 보관된 카드, 사용한 첫 효과, 공격 기억, HP·에너지, 난수를 그대로 복원. 미리보기와 실제 실행 결과 일치 |
| 사망한 고정 표적 | 현재 공격 취소·약화 보존. 새로운 공개 공격은 생존 표적을 사용 |
| 준비·광역·보호 | 준비는 약화를 소비하지 않으며, 광역 공격에는 각 생존 대상에게 약화 적용. 적 행동 뒤 보호 종료 |
| 30개 원정 표본 | 15개 편성 × 브레이크 OFF/ON에서 3,652회의 합법 입력 후 정상 승리 또는 전원 패배로 종료 |
| 잘못된 단계의 입력 | 재경로 선택·중복 보상·무효 실행자 입력이 상태와 난수를 바꾸지 않음 |
| 보상 거절·카드 제거 | 거절로 덱을 자동 변경하지 않음. 플레이어가 지정한 사본만 제거하며 다음 전투에서 복구하지 않음 |
| 보상 카드의 강화 | 획득한 실제 사본의 강화가 지도 저장·다음 전투에 같은 효과로 남음 |
| 원정 저장 | 지도·전투·보상·정비 상태를 정확히 복원하고 다음 같은 입력의 결과 일치 |
| 대체 경로 | 사건·상점 진입 가능. 구매 후 저장 결과 일치 및 같은 상점 후보의 중복 구매 거절 |

### 자동 완주 표본의 한계

시드 20261009·보통 난도·첫 경로·일정한 보상 선호·회복 중심 정비를 사용했다. 전투 정책은 현재 손패의 합법 입력을 비교하고, 공개 예고를 실행했을 때의 피해·생존·처치와 카드 순환을 평가하는 단순한 탐색이다. 미래 보상이나 숨겨진 적 정보를 읽지 않는다. 플레이어의 이해·조작 피로·재미를 대신하지 않는다.

| 조건 | 15개 편성의 정상 종료 | 완주 | 패배 위치 |
| --- | --- | --- | --- |
| 브레이크 OFF | 15 | 7 | 8개 모두 최종 보스 |
| 브레이크 ON | 15 | 11 | 4개 모두 최종 보스 |

기본 버팀·추격·돌봄·재현 파티는 두 조건 모두 8전투를 완주했다. 브레이크 효과가 큰 표본이며, 최종 보스에서 편성별 생존 차이가 난다. 정책은 잠수의 다음 공격 보너스나 도선의 준비 조건을 장기 계획하지 않아 두 추가 역할의 가치를 낮게 평가할 수 있다. 고정 보상·회복 경로도 결과에 영향을 준다. 이 표본으로 특정 편성이 열등하다거나 모든 편성이 균형 잡혔다고 결론 내리지 않는다.

### 아직 직접 플레이로 판단할 것

새 카드를 실제로 쓰며 전술이 발전하는지, 보스까지 재미가 이어지는지, 반복 클릭·정비 관리가 과한지, 브레이크가 선택을 풍부하게 하는지 확인이 남아 있다. 이번 요청에 따라 개발은 원정 전체까지 진행했으나, 전문성·브레이크의 재미와 채택은 확정하지 않았다.
