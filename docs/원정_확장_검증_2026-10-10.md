대상: 새 원정 `voyage-1`, 기존 원정 콘텐츠·저장의 호환 경계. 전체 요구와 설계 이유는 [역설계 문서](슬더스_역설계와_원정_확장.md)를 따른다.

## 현재 확인한 결과

- 기능 검사 25개: 유물 12종의 발동/원정 효과, 각인 5종, 도구 6종과 휴대 제한, 실제 결과와 미리보기, RNG·사본·단계 복원, 상점 가격/제거, 사건과 중간 계약의 모든 대가/대안, 신규 적 패턴, 기존 저장.
- 제품 자동 판단으로 정상 시작 덱 원정 24회: 서로 다른 시드 24개, 세 편성으로 진행하고 모든 의사결정 단계의 저장/복원이 동일한지 검사했다. 최신 결과 파일 `prototype/party-expedition-voyage-results.json`은 22승·2패다. 단계 수는 전투 행동 수가 아니며 승률은 사람의 재미·균형 판정에 쓰지 않는다.
- 확장 모듈을 먼저 로드한 기존 원정 검사 24개와 자동 전투 검사 18개 통과. 이전 `draft` 보상 검사 9개도 통과. 기존 손패/예고/HP/덱/난수와 이전 보상·효과를 보존한다.
- 브라우저 실제 QA 원정: 시드 178, 항해사·잠수자·도선사·등대지기. 정상 시작 덱, 브레이크 OFF. 모든 전투는 제품 자동 전투로 처리하고 경로·보상·각인·강화·복제·교환·구매·제거만 직접 선택했다.
- 브라우저 최종 결과: 8구역·7전투, 16장 덱, 생존 4/4, HP 22/30·30/30·30/30·30/30. 최종 파수꾼 4라운드. 의도적으로 3구역의 기록실 경로를 골라 전투를 우회했다.
- 실제 UI에서 섬광 각인 후 물결 칼날을 복제했고, 타격 한 사본을 공개 후보 틈새 추적으로 교환했다. 기존 각인을 다른 사본에 덮어씌우지 않으며, 강화와 소진 후 다음 전투 복귀도 유지했다. 중간 계약의 HP 대가, 상점의 실제 금화 감소와 제거 1회 제한, 마지막 보상의 X 카드 활용을 확인했다.
- 도구 전용 UI fixture: 신호탄은 적만 선택 가능하고 노출 6을 미리 표시한다. 처치함은 생존 아군을 선택하며 HP 20→28을 표시한다. 이 fixture는 실제 원정 완주·밸런스 증거로 쓰지 않는다.
- 브라우저 QA 콘솔의 오류·경고 없음. 사용자 원정 저장을 QA에서 쓰지 않는다.

## 확인 범위와 남은 사람 관찰

구현과 기술 검증은 완료했지만 새 유물·각인·적의 재미와 최종 밸런스를 확정하지 않았다. 자동이 이겼다는 사실은 사람이 즐거운 선택을 했다는 증거가 아니다. 기존에 사용자가 재밌었다고 한 판은 이번 확장 이전 버전의 관찰이다.

P0~P6을 유지하며 다음 원정에서 ‘유물 뒤 카드/경로 선택 이유가 달라지는가’, ‘새 적에 따라 실행자/순서를 다시 고르는가’, ‘새 규칙을 이해하는 부담이 얻는 재미보다 큰가’를 관찰한다. 특히 네 갈래 신호기와 잠수자의 공급이 결합했을 때 매 라운드 손패를 기계적으로 모두 쓰는 상태가 되는지 확인해야 한다. 현재 조건 3명의 유료 실행과 라운드당 1회, 에너지 상한 5로 제한되지만 사람의 판단 경험은 별도다.

도구 자동 정책은 기본 직접 사용이다. 위기 사용을 허용해도 카드 한 장으로 현재 치명타를 막을 수 있으면 그 카드를 먼저 사용한다. 예비 해도의 미래 카드 정체를 미리 읽고 사용 여부를 고르지 않으며 이 도구는 직접 사용한다.
