# 일반 전투 차별화 구현

적용일: 2026-10-06. 세린 원정의 `character.html?v=choices1`에 로드맵 2번을 적용했다. 4인·20장·6방과 보상 4종은 유지한다.

## 두 가지 일반 교전

첫 교전 ‘길목의 추격대’는 검사 HP 125와 사수 HP 110이다. 부상자 추격 방침과 단일 공격 위주의 실제 카드 묶음을 사용한다. 검사는 돌진·마무리·강격, 사수는 속사·관통 화살을 보유한다. 도발은 실제 기본/단일 카드 대상을 호위병으로 돌리며, 보호 태세·받아치기·집중 회복·빠른 한 명 처치로 대응한다. 첫 교전에는 아직 원정 보상을 받지 않았으므로 엄호를 준비 카드처럼 안내하지 않는다.

두 번째 ‘다섯 칼날의 포위’는 근접 적 다섯이다. 개별 기본 HP 62, 깊이 2 배율 적용 후 각각 HP 66이다. 기본 공격 피해 설정은 3.4이며 기존 깊이 배율과 피해 판정을 적용한다. 실제 돌진·넓게 베기 카드로 압박한다. 화살비가 여러 적을 함께 줄이고 전체 회복이 다수의 부상에 대응한다. 도발이 광역 공격을 다른 캐릭터로 돌리지 못하는 점을 미리보기에서 설명한다.

시작 위치를 전장 안에 배치하고 모바일에서도 다섯 적의 이름/HP가 줄바꿈돼 모두 보이게 했다. 원정의 선행 전투 체력, 휴식·진화·정비·보상 교체와 직선 강적·최종 보스는 계속 이어진다.

## 실행과 AI

캐릭터 전투의 명시적 `profileVersion:1` 적 정의에만 기본 공격 설정·배치·5장씩의 실제 적 카드 구성을 적용한다. 기존 역할/캐릭터 AI와 공통 명령·행동·피해 실행기가 판단하고 판정한다. 적 행동을 별도 가짜 이벤트나 피해로 연출하지 않는다.

플레이어 오토 점수·0.6초 판단·최대 1.2초 보유·공개 정보 제한·기본 AI의 기믹 비회피는 변경하지 않았다. 카드 수치·복사본 상한·영구 성장·보상 초기화도 그대로다. 기존 비교 체험과 일반 원정(index.html)은 새 프로필의 적용 대상이 아니다.

## 저장

새 출정의 `encounterVersion`은 2다. 표시가 없는 기존 원정은 이전 일반전과 추격대 강적을, 버전 1 원정은 이전 일반전과 직선 강적을 유지한다. 버전 2에서만 새 일반전 두 종류를 쓴다. 저장 규칙 버전 2와 지도 생성/ID는 바꾸지 않았다.

전투 재개는 저장된 실제 적 위치·피해·카드 묶음·행동 예약을 사용한다. 새 프로필을 재적용해 드로우를 재추첨하거나 위치를 초기화하지 않는다. 미리보기와 입장은 같은 원정 버전에 맞는 적 정의를 사용한다.

## 비교 결과와 검증

[전투 선택 조건 비교](전투_선택_조건_비교.md)에 100%/70%/45% 체력·6시드·기초/추격/엄호/이동 덱의 288조건과 한 장 개입 171쌍을 기록했다. 보상 덱은 검사에 사전 제공한 것이며 첫 교전의 실제 획득 권한을 바꾸지 않았다.

기본 덱만으로 두 일반전의 6시드 전부 승리했다. 체력이 45%인 다수전은 네 덱 총 24회 중 21회 승리했고 생존자·남은 HP가 달랐다. 화살비 사용 합계는 집중 공격 72회에서 11번, 다수전 72회에서 55번이었다. 단순 도발 우선 개입은 평균 성적을 낮추기도 해 불리한 결과를 숨기지 않았다. 사람의 우위나 최종 밸런스를 입증한 결과로 표현하지 않는다.

`combat-patterns-check.cjs`는 새/구버전 원정과 실제 적 구성/HP/묶음, 부상자 목표·실제 도발, 여러 적에 대한 한 번의 광역 피해, 예약 중 저장과 동일 재개를 검사한다. `combat-patterns-browser-check.cjs`는 1280×720·390×844에서 실제 집중 공격→보상 엄호 편성→휴식→다수전→한 번 카드 개입→결과/복기를 확인했다. 다섯 적 HP의 가시성·가로 넘침·브라우저 오류·이전 저장 격리도 통과했다.

기존 캐릭터 원정/브라우저, 카드 관리, 다층 AI, 효과·행동, 직선 강적 엔진/브라우저, 최종 보스 통합 엔진/브라우저와 오토 명령 보유 비교를 함께 확인했다. 독립 효과 검사의 원래 방패병 적 가정은 버전 1로 명시했고 전체 원정 검사는 새 구성을 사용한다. 기존 오토 48쌍 비교 결과는 유지됐다.
