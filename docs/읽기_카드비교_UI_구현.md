# 읽기·카드 비교 UI 구현

2026-10-07 · `character.html?v=compareui1` · UI 로드맵 1·2단계.

## 적용

- PC는 선택/상태를 나란히 표시. 좁거나 높이가 짧은 화면은 파티·덱 상태를 조회 창에 표시하여 선택 영역을 확보한다.
- 출발, 방 선택, 덱 편성, 보상 획득/넘기기, 편성 확정, 정비 선택, 다음 방 버튼에 별도 고정 행동 영역을 제공한다. 내용만 세로로 스크롤한다.
- 비교 본문 14px, 보조 정보 12px, 주요 행동 높이 44px를 기준으로 수정했다. 모든 기존 화면/위젯의 글꼴을 일괄 변경한 것은 아니다.
- 짧은 운영 규칙/특성 계산 설명은 펼쳐서 읽고, 긴 상세는 이름 있는 팝업에서 조회한다. Escape/닫기와 포커스 복귀를 지원한다.
- 보상 후보 3~4개의 이름·사용 캐릭터·특성을 요약 목록으로 제공한다. 선택 후보와 교체 대상의 기술 설명, 진화 수치, 명령 시간, 최종 덱 특성 종류 수/단계 변화를 함께 표시한다.
- 미리보기는 원정 상태·난수·저장·제안 목록을 변경하지 않는다. 확정 전에 현재 대상/보상/사본 제한/정확한 20장을 검증한다.
- 획득과 대기 보관 또는 한 장 교체를 명시적으로 확정한다. 빠지는 카드는 대기로 보관한다.
- 편집 후 스크롤·포커스를 복원한다. 방금 누른 버튼이 사본 상한으로 비활성화되면 같은 카드의 반대 조작 버튼으로 포커스를 옮긴다.
- `편집 처음으로`는 편집 창 진입 당시 덱으로 되돌린다. `편성 취소`는 미확정 편집을 버린다.
- `편성 되돌리기`는 마지막 확정 덱 변경 한 번을 되돌린다. 보상·진화·난수·전투를 되감지 않는다. 획득 카드는 보유 목록에 남는다. 다음 교전 시작/새로고침까지 유효하고 이전 카드가 처분되어 복원할 수 없으면 제공하지 않는다. 여러 변경을 거슬러 올라가는 기록 기능은 아니다.
- 여러 캐릭터의 태세를 한 창에서 연속으로 변경할 수 있다.

## 검증

`compare-ui-browser-check.cjs`: 1280×720, 390×844, 320×568, 844×390, 768×1024, 360×640. 출발/지도/보상/교체 후 행동 영역의 실제 경계, 44px 높이, 최소 읽기 영역 90px 이상, 가로 넘침, 기본 루트 글꼴을 두 배로 바꾼 경우를 검사했다. 이는 모든 고정 px 글꼴과 브라우저 확대를 포함한 전체 200% 접근성 감사와는 다르다.

같은 검사에서 미리보기 전후 원정 스냅샷 동일성, 선택 변경, 교체 대상 포커스, 정확한 20장, 보상 유지, 되돌리기, 편집 초기화/확정/취소, 마지막 카드의 가로 위치/포커스, 태세 연속 수정, 팝업 이름/Escape를 확인했다.

`workspace-ui-browser-check.cjs`: PC/모바일 조회, 경로, 보상 보관 후 교체, 편성, 저장 재개.

`character-browser-check.cjs`: PC/모바일 실제 원정 완주, 수동/오토, 보상 실제 사용, 저장 재개, 다운로드/불러오기, 손상 저장 복구, 기존 저장 분리.

`character-check.cjs`, `starting-decks-check.cjs`, `challenges-check.cjs`: 전투/출발 덱/도전 규칙 회귀.

사용자 이해도, 전체 보조 기술, 모든 기기의 실제 글꼴 렌더링은 아직 실측하지 않았다. 풀오토 관전 화면 정리와 결과 요약은 다음 단계다.
