# 《수면》 자동 전투

2026-10-10 · `party-expedition.html`에 적용

전투 화면 상단의 **자동 전투**를 누르면 카드·실행자·대상, 측심에서 버릴 카드와 라운드 종료를 자동 선택한다. 켠 동안 버튼은 **자동 중지**로 바뀌고 명령 영역에는 마지막 실행 카드와 실행자·대상을 표시한다. 기존 연출 속도 설정이 자동 행동 간격에도 적용된다.

- 자동 중지 버튼, 수동 카드 선택, 수동 라운드 종료, 새 원정 준비로 해제한다.
- 설명·덱·지도·설정 창이 열렸거나 탭이 숨겨졌으면 행동을 대기한다. 닫거나 복귀하면 이어간다.
- 전투 종료 시 자동을 해제한다. 경로·보상·정비는 직접 결정한다.
- 새로고침 후에는 자동을 켜지 않는다. 기존 저장 형식과 전투 규칙은 그대로 사용한다.

## 판단과 실행

현재 공개된 적의 예고와 실제 카드 미리보기로 공격·처치, 아군 생존·회복, 보호·약화·반격, 노출 준비, 드로우·보관, 에너지 사용을 평가한다. 인계 할인과 문양 능력은 기존 엔진의 실제 결과로 반영한다. 다음 뽑기 순서나 다음 라운드 의도를 보고 선택하지 않는다.

현재 행동을 하나씩 평가하는 보조 기능이다. 여러 턴을 탐색하는 최적 전략 보장이나 원정 전체 자동 선택 기능은 아니다. 같은 에너지·카드·실행 조건으로 수동과 자동이 실행된다.

예약 행동은 하나만 유지한다. 중지하면 다음 예약을 취소하며, 이미 실행된 행동은 되돌리지 않는다. 연출 중 중지·재개가 중복 행동을 만들지 않도록 제어한다. 실행 오류나 한 전투의 자동 입력 300회 초과 시 멈춘다. 원본 상태와 RNG를 미리보기 평가로 바꾸지 않는다.
