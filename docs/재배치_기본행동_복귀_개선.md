# 재배치 후 기본 행동과 복귀 개선

위험 구역 보스 체험에 두 가지 개선을 적용했다. 기본 AI의 위험 구역 인식·자동 회피는 계속 비활성 상태다. 일반 원정·세 가지 비교 전투의 행동 규칙은 바꾸지 않았다.

## 안전 지점에서는 이동만 대기

재배치 카드가 지정한 안전 지점 유지 동안 기본 행동 의도를 지우던 처리를 제거했다. 이동 의도만 대기 상태로 바꾸고 사격·회복·근접 공격은 기존 공통 실행기에서 처리한다.

- 공격 대상과 사거리, 실제 위치, 기본 공격 주기, 시전 중 행동 잠금을 모두 기존 규칙대로 검사한다.
- 지원가는 기존 조건에 맞는 부상자를 계속 회복한다.
- 사거리 밖인 근접 캐릭터가 멀리서 공격하지는 않는다.
- 이동 카드로 중단한 다른 기술을 되살리거나 기본 행동 쿨타임을 초기화하지 않는다.
- 낙하 후 이동 대기가 끝나면 역할에 따른 이동으로 돌아간다.

화면에 ‘재배치 유지 · 남은 시간 · 기본 행동 계속’을 표시하고, 이동 지시가 끝나면 표시를 제거한다.

## 복귀거리와 빈틈을 함께 처리

낙하가 판정되는 순간, 해당 낙하에 대해 카드로 재배치된 살아 있는 근접 캐릭터의 실제 위치에서 보스의 공격 사거리까지 필요한 이동시간을 추정한다. 방패병 보호 태세의 속도와 현재 둔화도 반영한다. 그중 가장 긴 시간에 공격 여유 1.5초를 더하고, 보스의 빈틈을 3~5초 범위로 제한한다.

일반적인 공격은 기본 3초를 유지한다. 이미 쓰러진 캐릭터, 재배치되지 않은 캐릭터, 먼 곳의 사수·지원가는 연장 계산에 포함하지 않는다. 실제 복귀는 기존 이동 속도로 실행하며 순간 복귀나 자동 회피를 추가하지 않는다.

피해 증가 종료와 보스 행동 재개는 동일한 시각을 사용한다. 전원 회피·차단 여부와 관계없이 동일한 계산을 사용하며, 보스를 낙하 전에 처치하면 빈틈을 만들지 않는다. 복귀 예상은 낙하 순간의 거리·상태에 기반하므로 이후의 대상 이동이나 새 카드 명령까지 공격 성공을 보장하는 것은 아니다.

실제 빈틈 시간을 판정 기록에 저장한다. 이전 저장의 이미 열린 빈틈은 기존 종료 시각을 유지하고 다음 낙하부터 새 계산을 적용한다.

## 측정 결과

사수와 지원가가 재배치되는 조건에서 안전 지점의 실제 기본 사격·회복이 계속됐다. 사거리 밖 공격, 기본 주기 초기화, 시전 중 추가 공격은 발생하지 않았다.

둔화된 검사의 복귀를 재현한 조건에서는 빈틈 약 3.40초, 낙하 후 첫 기본 공격까지 약 2.10초가 측정됐다. 검사는 기존 속도로 실제 이동해 빈틈 동안 기본 공격을 넣었다.

기존 첫 재배치 개입 예시는 3초로도 복귀가 가능하고 사수·지원가는 이동 대상이 아니어서 전체 결과가 그대로였다. 전후 모두 52.44초 승리·받은 피해 381.02였다. 이 사례의 성적이 좋아졌다고 주장하지 않는다. 고정 난수의 순수 오토는 48.02초 승리·받은 피해 145.86·빈틈 중 피해 160.16이었다.
