# 적 능력치 상향 · 원정 밸런스 버전 2

사용자의 ‘적 체력과 공격력을 전체적으로 올려 달라’는 요청을 적용했다. 새 원정과 새 연구실 배치의 규칙은 `voyage-balance-2`다.

## 적용 범위와 계산

모든 일반 적·정예·두 최종 보스·보스 동행 적에 적용한다. 보통과 차분 난이도 모두 기존 난이도 조정 이후 HP를 1.15배 반올림, 기본 단일·광역 공격력을 1.10배 올림한다. 공격력이 작은 적도 강해지며, 0인 항목은 0으로 보존한다.

공격력 올림 때문에 실제 증가율이 정확히 10%인 것은 아니다. 광역 기본 피해 3→4는 33.3%, 2→3은 50% 증가다. 준비 공격의 추가 피해와 패턴별 가감값은 그대로 둔다. 예를 들어 감시자의 준비 광역은 기본 3+2=5에서 4+2=6으로 바뀐다. 전투 화면에는 계산한 실제 피해를 표시한다.

| 보통 난이도 예시 | HP 전→후 | 기본 단일 전→후 | 기본 광역 전→후 |
|---|---:|---:|---:|
| 1구역 사냥꾼 | 26→30 | 8→9 | 3→4 |
| 4구역 종을 지키는 자 | 46→53 | 10→11 | 3→4 |
| 4구역 분열된 감시자 한 명 | 25→29 | 7→8 | 3→4 |
| 7구역 분열된 감시자 한 명 | 31→36 | 7→8 | 3→4 |
| 파수꾼 | 68→78 | 14→16 | 6→7 |
| 파수꾼 동행 관측자 | 18→21 | 9→10 | 5→6 |
| 해류의 심장 | 76→87 | 11→13 | 4→5 |
| 심장 동행 감시자 | 18→21 | 6→7 | 2→3 |

지도 생성의 모든 조우 교체가 끝난 뒤 한 번 적용하고 지도 설명의 HP도 갱신한다. 저장을 읽거나 전투에 들어갈 때 다시 배율을 곱하지 않는다. 1차 패치의 정예 감시자 2턴 준비·3턴 실행과 브레이크 끔의 균형 탐사 후보 제외를 버전 1·2 모두 유지한다.

## 동일 조건 자동 원정 비교

시드 31·32·51·52 × 전체 15편성 × balanced/aggressive/cautious 3정책, 일반 난이도·브레이크 끔·1,500단계/60턴 상한. 이전 버전 1의 기존 원본 기록 180회와 버전 2 새 실행 180회를 비교했다. 원본 기록을 덮어쓰지 않았다.

| 지표 | 버전 1 | 버전 2 |
|---|---:|---:|
| 원정 승리 / 패배 | 174 / 6 | 162 / 18 |
| 원정 승률 | 96.7% | 90.0% |
| 전투 승리 / 패배 | 1,239 / 6 | 1,223 / 18 |
| 실제 HP 피해 합계 | 12,752 | 20,883 |
| 전투당 평균 HP 피해 | 10.24 | 16.83 |
| 전투당 평균 보호 흡수 | 17.14 | 24.03 |
| 전투당 평균 라운드 | 3.32 | 4.06 |
| 전투불능 이벤트 | 94 | 244 |
| 중단·실행 오류·HP 검산 불일치 | 0 | 0 |

버전 2 패배는 6구역 문지기+관측자 129전 중 2패, 파수꾼 보스 88전 중 16패였다. 해류의 심장 90전, 정예 전체 328전은 모두 승리했다. 강해진 적이 행동하는 기회가 늘었으며 두 보스의 부담 차이는 계속 남아 있다. 이 관찰만으로 추가 패치를 시행하지 않는다.

180개 시작 조건의 짝을 모두 확인했다. 경로가 같은 짝은 137회, 최종 덱이 같은 짝은 72회였다. 피해·턴 평균은 적 수치와 달라진 후속 선택을 함께 포함한다. 네 시드와 전투 판단을 공유하는 세 정책의 결과이므로 전체 시드나 사람의 승률·재미를 대표하지 않는다. P0~P6의 재미 통과 조건은 직접 플레이로 평가한다.

## 적용·호환성·검사

페이지를 새로고침하고 새 원정을 시작하면 적용된다. 연구실도 새로고침 후 새 배치를 실행한다. 진행 중인 버전 0·1 저장의 지도·HP·전투 의도는 그대로 복원하며 기존 규칙을 이어간다. 누락된 밸런스 버전은 기존 규칙 0으로 해석한다.

CLI `--balance current`는 버전 2, `--balance previous`는 버전 1, `--balance legacy`는 버전 0이다. 같은 조건의 새 표본을 만들 때 출력 폴더 이름을 새로 지정한다.

전용 검사 8건에서 지도 적 124개를 짝/홀 시드와 두 난이도로 비교했다. 모든 적 유형과 동행 적의 수치, 공개 HP, 중복 강화 방지, 저장 0·1·2 호환, 9종 패턴의 준비 큐·실행·실제 보호 흡수, 1차 패치와 보상 난수 보존을 확인했다. 기존 밸런스 검사 10건, 원정 검사 25건, 수집기 검사 16건도 통과했다. 버전 1의 실제 원정 로그 재생 결과도 정확히 일치했다.

독립 QA에서 정상 시작 덱과 실제 Run API로 4구역 감시자까지 진행했다. 임의 HP·덱·적·난수 변경 없이 HP 29/29·공격 피해 8이 표시됐고 브라우저 경고·오류가 없었다. 실제 원정 저장에는 쓰지 않았다.
