# 배치 고도화 2단계 — 적 확인과 12자리 준비

적용: `character.html?v=preparation1`. 전투 전 적 확인·12자리 편집·명시적인 시작·저장 호환을 구현했다. 공간 카드·몸막음·투사체 충돌은 이번 범위에 추가하지 않았다.

## 플레이 흐름

교전 방 선택 → 실제 시작 배치 확인 → 아군 배치·덱·태세·오토 방침 조정 → 전투 시작이다. 준비에는 시간 제한이 없다. 준비를 취소하고 다른 방을 선택할 수 있으며 배치 편집은 유지한다. 휴식·진화·정비 방은 기존 흐름을 유지한다.

준비 상태에서는 전투 객체·손패를 생성하지 않으므로 시간이 흐르거나 HP가 줄지 않는다. 새로고침/이어하기에서도 준비 상태를 유지한다. 전투를 시작할 때 현재 HP·레벨·덱·방침·태세·배치를 시작 기록에 보존하고 한 번만 전투를 생성한다. 미리보기를 다시 보거나 배치를 옮겨도 보상이나 초기 손패를 재추첨하지 않는다.

아군과 적이 실제 전투와 같은 좌우 관계로 보인다. 적 좌표는 프로필의 좌표 또는 엔진의 기본 생성 위치를 사용하며, 실제 시작 좌표 일치를 검사했다. 적 전술·체력·역할·보상 안내도 제공한다. 보스의 이후 공격 위치나 숨겨진 카드 순서를 예측하지 않는다.

## 12자리 배치

전후 3단계 × 측면 4자리, 총 12자리를 사용한다. 육각형 형태의 슬롯에 캐릭터를 드래그하거나 캐릭터 → 목적지 순서로 선택한다. 점유 자리에 놓으면 교환한다. 키보드 Enter 선택, 터치 드래그, 추천 배치, 선택 취소, 직전 편집 되돌리기를 지원한다. 되돌리기는 현재 편집 세션의 한 단계이며 저장 후 복구 이력까지 보존하지 않는다.

신규 좌표는 전열/중열/후열 x=330/225/120, 각 열 y=60/140/220/300이며 중열은 y+35다. 슬롯의 배치 방향과 전체 전장 미리보기를 함께 보여준다. 새 추천은 방패병·세린 전열, 사수 중열, 지원가 후열이다. 쓰러진 동료는 미리보기에서 흐리게 표시하고 전투불능을 명시한다. 배치 변경으로 복귀하지 않는다.

육각형은 준비 단계의 좌표 선택 UI다. 전투는 기존 연속 좌표를 사용하고 칸마다 이동하는 방식으로 변경하지 않았다. 새 배치 버전에서는 사수·지원가의 선호 열 정렬을 제거했다. 전투가 시작되면 역할·표적·카드 행동이 이동을 결정한다. 초기 위치로 복귀시키지 않는다.

작은 화면에는 별도 12자리 선택 격자를 제공하며 셀 높이는 최소 44px이다. 적 전장 미리보기 자체의 작은 점을 직접 누를 필요는 없다. 상세 설명은 접을 수 있고 준비 본문은 내부 스크롤을 사용한다. 다른 방 선택·덱 편성·전투 시작은 하단에 유지한다. 특히 작은 높이에서는 모든 설명과 격자를 동시에 표시하지 않고 스크롤로 탐색한다.

## 저장·이전 기록

`formationVersion` 1은 기존 6자리와 선호 열 규칙, 2는 12자리와 출발 위치 규칙이다. 기존 숫자의 의미를 덮어쓰지 않는다. 진행 중인 이전 교전의 실제 위치와 이벤트를 유지하며, 과거 연습은 기록된 버전을 사용한다. 버전이 없으면 이전 6자리로 해석한다.

기존 원정이 새 준비 화면에 들어갈 때에는 각 이전 시작 위치에 가까운 빈 12자리로 변환한다. 이후 실제 시작 기록은 새 버전으로 보존한다. 과거 연습의 원본 배치를 복구하면 해당 과거 버전으로 돌아간다.

배치와 전투 기록의 버전 불일치, 중복/범위 밖 자리, 교전이 아닌 방의 준비 상태, 준비 중 전투 객체가 섞인 저장은 거부한다. 시뮬레이션과 이전 검사 호환을 위해 직접 `Campaign.enter()`는 즉시 전투 생성 경로를 유지하며, 실제 화면은 `prepare()`와 `beginBattle()`을 사용한다.

## 검증

- `preparation-check.cjs`: 준비 중 HP·카드·난수 동결과 읽기 전용 미리보기, 12자리 입력, 실제 아군·적 좌표 일치, 준비 저장→시작과 재개 결정성, 중복 시작 거부, 취소·재선택, 잘못된 저장, 이전 진행 전투·과거 연습·원정 변환, 선호 열 복귀 제거, 비전투 방 흐름 통과.
- `preparation-browser-check.cjs`: 1280×720, 390×844, 320×568, 844×390. 탭 이동·교환·되돌리기, HTML 드래그와 터치 Pointer 이벤트, 키보드, 준비 저장 복원, 덱 편집 복귀, 방침, 시작 버튼 가시성, 실제 전투와 연습 배치 버전 통과. 페이지 오류 없음. 터치 드래그는 브라우저 이벤트 검사이며 실제 모바일 기기 체감 검증과 구분한다.
- `preparation-simulation-check.cjs`: 적 4종 × 시드 3개 × 방침 2종 × 배치 3종, 72회. 모두 승리·정상 종료·유한 좌표 및 전장 범위를 확인했다. 24개 조건 묶음 모두 시간 또는 남은 HP 차이가 있었다. `prototype/preparation-simulation-results.json`에 보존했다.
- 기존 캐릭터·기여도·표적 규칙·다층 AI·효과·6개 화면 관전 안정성 검사 통과. PC/모바일 원정 보상·실제 보스 완료·저장 내보내기/가져오기·잘못된 원본 보존도 통과.

기존 6자리 브라우저 검사는 이전 배치 버전을 명시하도록 조정했고, 실제 새 UI 흐름은 준비 전용 검사에서 검증한다. 기존 원정 브라우저 검사에는 명시적인 전투 시작을 반영했다. 보상 엄호 카드의 자동 사용 여부는 위치·위협 기회에 따라 달라지므로 그 브라우저 사례는 다음 전투 덱에 보상이 포함되는지 확인한다. 실제 엄호 사용·분담·반격은 별도 캐릭터/효과 검사에서 확인한다.

## 아직 확인하지 못한 것

72회는 기초 덱·레벨 1·전원 최대 체력의 단일 교전이다. 배치가 저체력 패배를 극복한다거나 모든 적에서 다른 정답이 존재함을 증명하지 않는다. 기존 캐릭터 검사의 진화/강적 경로 8개 원정은 7회 완주했다. 전체 원정 난도와 새로운 추천 배치의 최적성은 후속 검증 대상이다.

다음 단계는 실제 보호 범위와 공간 효과를 보기 쉽게 표시하고, 필요하면 주변 지원·직선 공격 등 공간 카드와 대응 적을 소수 추가하는 것이다. 덱·배치 선택을 결과와 연결해 확인한다.
