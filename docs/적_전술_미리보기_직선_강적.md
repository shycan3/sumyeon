# 적 전술 미리보기와 중간 직선 강적

적용일: 2026-10-06. 전투 시스템 로드맵의 첫 업데이트를 세린 원정에 적용했다. 메인 실행 주소는 `character.html?v=tactics1`이다.

## 지도에서 전투 준비

현재 줄의 방을 카드 형태로 표시한다. 교전 방에는 실제 적 이름·역할·인원·깊이/강적 배율 적용 후 HP·핵심 전술·예고 유형·대응 설명을 표시한다. 회복·진화·정비에는 실제 선택 효과를 표시한다. 같은 지도에서 기존 원정 덱 편성과 태세를 변경하고 바로 입장한다.

`Campaign.encounter(node)`를 실제 입장과 읽기 전용 미리보기에서 공통 사용한다. 미리보기는 난수·원정 상태·손패를 변경하지 않으며 적 구성과 HP를 임의 추정하지 않는다. 별도의 필수 준비 화면이나 준비 시간은 추가하지 않았다.

## 균열 창기사

새 출정의 다섯 번째 방에서 선택 강적을 고르면 만난다. 휴식 대안과 6방 구조는 유지한다. 적 한 명이며 기본 HP 260, 깊이 4와 강적 배율 적용 후 HP 326이다.

- 공격: 균열 찌르기. 세로 직선 구역(길이 500·폭 100·각도 π/2)을 전장에 고정한다. 전장 밖으로 나간 부분에는 캐릭터가 없으며, 구역 양옆에는 재배치 가능한 안전 지점이 있다.
- 첫 예고는 약 7초, 이후 시작 간격 11초. 예고 2.2초 뒤 실제 위치로 범위를 판정한다.
- 위력 설정 42를 기존 공격·방어·보호막·피해 분담 처리에 전달한다. 수치는 최종 체력 피해가 아니다.
- 타격 후 3초 빈틈. 재배치한 근접 동료의 실제 복귀거리에 따라 최대 5초로 늘고, 이때 받는 피해 30% 증가.
- 구출·재배치 보상을 그대로 사용한다. 이동 카드 없이도 차단·보호·회복·빠른 처치로 대응할 수 있으며 새 카드는 추가하지 않았다.

`line_zone` 공격 정의와 공통 기믹의 선택 공격 키를 연결했다. 원형 낙하의 기존 공격 키와 결과는 유지한다. 구역 중심은 같은 실제 도형 판정으로 가장 많은 동료가 포함되는 위치를 정한 뒤 고정한다. 한 번에 활성 구역은 하나다. 예고/연출/복기에 직선 공격의 실제 이름을 표시한다.

기본 AI는 위험 구역을 조회해 회피하지 않는다. 기존 역할 이동, 제한된 카드 오토, 명령 보유 기준을 유지한다. 이동 카드가 다른 동료의 미완료 기술을 끊는 규칙과 회복시간 미반환도 그대로다.

## 저장 호환

새 출정은 `encounterVersion:1`을 보유한다. 표지가 없는 기존 진행 중 원정은 종전 추격대 강적을 유지한다. 이 표지는 지도 ID·기존 저장 버전을 바꾸지 않는다. 이전 저장을 불러온 뒤 새로 출정하면 새 강적을 사용한다.

직선 예고의 공격 키·중심·길이·폭·각도·발동 시각·행동 예약을 공통 전투 상태로 저장한다. 예고 도형과 실제 예약이 불일치하면 저장을 거절한다. 기존 원정과 이전 게임의 별도 저장 키는 변경하지 않는다.

## 검증 결과

`tactics-check.cjs`:

- 순수 미리보기와 실제 이름/HP/공격 유형 일치, 새 표지 검증, 기존 원정의 적 유지.
- 실제 보상 획득·교체 후 직선 예고 저장/동일 재개, 중심/각도/폭/발동 시각 불일치 거부.
- 구출·재배치의 실제 안전 이동과 첫 타격 회피, 이동이 가짜 차단을 만들지 않음.
- 기초 차단으로 실제 공격 방어, 시전 취소 시 예고 정리 및 빈틈 미생성, 기본 역할 AI가 기믹을 읽지 않음.
- 레벨 1·기초 덱·이동 보상 없음으로 실제 원정 12개에서 선택 강적 승리. 앞선 전투·휴식·정비의 체력을 이어받았다. 이는 진행 가능성 검사이며 전체 난이도나 사람의 우위를 확정하는 결과가 아니다.

`tactics-browser-check.cjs`:

- PC 1280×720 / 모바일 390×844에서 미리보기·실제 HP·덱 편성 복귀·태세 준비.
- 실제 보상 획득과 편성, 강적/휴식 선택 정보, 지도 저장 재개.
- 직선 예고의 실제 표시·저장/새로고침·수동 이동 카드 확정·피격 회피·승리 결과.
- 이전 게임 저장 격리, 가로 넘침과 브라우저 오류 없음. 지도와 직선 전투 캡처를 확인했다.

기존 원정 엔진/브라우저, 보스 기믹, 위험 구역 통합 엔진/브라우저와 오토 명령 보유 비교도 통과했다. 이전 48쌍 오토 비교와 기존 낙하 보스 체험의 결과가 유지됐다. 후속 업데이트는 일반 전투별 선택 차이와 낮은 시작 체력·다른 보상 덱까지 조건을 넓힌 검증이다.
