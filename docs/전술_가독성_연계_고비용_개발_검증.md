# 《수면》 문양의 쓰임·카드 연계·고비용 선택 개발과 검증

개발일: 2026-10-10 · 대상: `prototype/party-expedition.html`

사용자가 기존 원정을 재미있게 완료한 뒤 보고한 세 부족함을 순서대로 구현했다. 기존의 상황 판단, 4인 공용 덱, 카드→실행자→대상, 공개 적 의도, 에너지 이월을 유지한다. 이번 완료는 구현·기술 QA 완료이며, 변경 이후의 사람 재미 관문 통과는 아니다.

## 1. 캐릭터에게 무엇을 맡길지 전달

각 동료의 HP 위에 짧은 사용 목적을 상시 표시한다. 카드를 선택하면 현재 조건에 맞는 실행 이익과 준비 부족 이유가 바뀐다. 실제 전투 엔진의 미리보기로 추가 수치를 계산하여, 항해사의 교대 효과와 동료의 지속 효과가 함께 적용되는 상황도 정확히 표시한다.

| 문양 | 화면의 목적 | 대표 사용 |
|---|---|---|
| 항해사 | 동료를 바꿔 이어가기 | 동료의 유료 카드 뒤 공격을 맡기기 |
| 잠수자 | 틈을 만들고 에너지 회수 | 적에게 노출을 남기고 동료가 소비하기 |
| 도선사 | 준비 뒤 큰 카드 실행 | 앞선 지출을 만든 뒤 공격·보호 실행 |
| 측심사 | 필요한 손패 찾기 | 시작 손패 선별과 실행 후 추가 드로우 |
| 인양사 | 좋은 카드를 다음 손패로 | 사용한 사본을 보관하고 동료에게 인계 |
| 등대지기 | 보호를 다음 라운드까지 | 자신 보호와 남은 보호 이월 |

실행자를 고른 뒤에는 다른 동료를 아군 대상으로 표시한다. 아군마다 해당 대상의 보호·반격·뽑기 변화만 보여주고, 전원 보호나 다음 손패 예약처럼 공통인 결과는 손패 위에 한 번 표시한다. 상단의 **문양**에서 여섯 문양의 예시와 지속·실행 조건을 확인할 수 있다.

## 2. 준비가 후속 카드의 쓰임을 바꾸도록 구성

카드에 소유자나 필수 문양을 추가하지 않는다. 세 신규 연결 카드는 준비 없이도 기본 효과가 있으며, 이미 있던 노출·보호를 활용하면 결과가 달라진다. 연결 관계를 카드에 짧게 표시한다.

| 카드 | 비용 | 기본 효과 | 준비를 활용한 변화 |
|---|---:|---|---|
| 틈새 추적 | 1 | 피해 5 | 공격 전 대상에게 노출이 있으면 추가 드로우 2 |
| 압력 전환 | 1 | 적 약화 3 | 실행자의 기존 보호 최대 4를 소비하여 그만큼 약화 증가 |
| 등불 아래 | 1 | 대상 보호 4 | 사용 전 대상에게 보호가 있으면 드로우 1 |

조건은 카드 사용 전 상태로 판정한다. 해당 카드가 새로 만든 보호나 실행 특성이 뒤늦게 만든 노출로 스스로 추가 효과를 켜지 않는다. 노출의 기존 추가 피해·소비 규칙은 유지한다. 틈새 추적이 적을 처치해도 추가 드로우를 얻는다. 압력 전환은 보호를 버리는 대가가 실제로 발생한다.

강화는 피해·드로우·보호 소비 한도를 실제로 변경하며, 미리보기·저장 복원·다음 전투에서도 유지된다.

## 3. 고비용으로 서로 다른 전술 선택

| 카드 | 비용 | 효과와 선택의 성격 |
|---|---:|---|
| 심층 강습 | 4 | 피해 26. 기존 노출이 있으면 추가 피해 10. 에너지를 모아 강한 한 타격에 집중 |
| 귀환의 등대 | 3 | 전원 보호 6, 선택 대상 추가 보호 6·반격 6. 전체 위협과 집중 공격을 함께 대응 |
| 총력 정비 | 3 | 전원 보호 4, 마지막 버린 실제 카드 최대 2장을 다음 손패에 보관. 이번 방어와 다음 라운드 운용 준비 |

총력 정비는 카드 복사본을 만들지 않는다. 소진 카드나 현재 해결 중인 자신을 가져오지 않으며, 보관된 사본은 기존 손패 규칙으로 복귀한다. 인양사의 별도 보관·인계 효과와 구분한다. 도선사의 준비 지출과 지속 효과, 잠수자의 노출 소비 회복, 기존 최대 에너지 5·회복 2·잔량 이월과 함께 작동한다.

카드 풀은 기존 24종에서 **강화 가능한 공용 카드 30종**으로 늘었다. 기존 카드의 수치는 바꾸지 않았으며 약점 포착의 텍스트만 후속 타격 관계가 읽히게 정리했다.

## 4. 원정에서 발견하고 활용할 기회

새 원정은 `contentVersion: tactics-1`을 사용한다. 첫 두 전투의 도구 보상에는 약점 포착·등불 아래·압력 전환·건져 올리기 중 한 장을 제시한다. 세 번째 전투에는 결정타 또는 심층 강습, 네 번째 전투에는 귀환의 등대 또는 총력 정비를 제시한다. 나머지 보상은 무작위로 제공하며 선택과 거절은 자유다. 완성 조합 전체를 확정 지급하지 않는다.

이전 저장에서 콘텐츠 버전이 없으면 기존 카드 풀과 보상 난수 흐름을 유지한다. 기존 원정의 ‘같은 조건으로 재도전’도 기존 풀을 사용하고, ‘새 원정’에서 최신 풀이 적용된다. 기존 완료 원정의 덱·선택·생존 기록을 임의로 변경하지 않는다.

| 준비·활용 카드 | 11 | 준비 유무·처치·보호 소비·강화·공용성·이전 보상 호환 |
| 고비용 전술 | 12 | 서로 다른 결과·보관 사본·에너지·강화·보상 기회·이전 재도전 |
| 합계 | **178** | 기술 검사 완료 |

15개 4인 편성 × 브레이크 OFF/ON의 **30개 원정**을 3,217개의 합법 행동으로 자동 완주했다. 이 표본의 30회 승리는 기능 연결과 종료 가능성의 근거이며, 난이도가 적절하다거나 편성 균형·재미가 검증됐다는 뜻은 아니다.

별도 QA 페이지는 실제 저장과 환경설정을 읽거나 쓰지 않는다. 브라우저에서 실제 클릭으로 다음을 확인했다.

- 보호 뒤 교대 공격의 실행 이익, 준비 부족 안내, 여섯 문양 설명창.
- 노출→틈새 추적: 피해 9·드로우 2·잠수자 지속 효과 에너지 회복.
- 압력 전환: 기존 자기 보호 4 소비, 약화 7, 예고 피해 감소.
- 심층 강습: 앞선 유료 준비와 노출을 반영한 미리보기 피해 43과 실제 동일한 HP 감소.
- 등불 아래: 보호 있는 대상에 추가 드로우. 귀환의 등대: 전원·대상 보호와 적 행동 후 반격.
- 총력 정비: 실제 버린 보호·타격을 다음 손패로 복귀.
- 데스크톱과 390×844·320×740 화면: 문서 가로 넘침 없음, 적·아군·명령 영역 겹침 없음. 좁은 화면에서는 세로 스크롤로 전체 전투를 본다.
- 브라우저 경고·오류 없음. 사용자의 기존 완료 원정은 유지.

## 6. 이후 재미 판단

새 전체 원정에서 문양의 목적을 이해할 수 있는지, 준비 보상 때문에 이후 카드 선택이 바뀌는지, 고비용 공격·방어·다음 손패 준비를 상황에 맞춰 고를 이유가 생기는지를 관찰한다. 사용자가 이전 판에서 좋아한 상황 판단을 해치지 않는지도 확인한다. 카드 종류나 자동 검사 수만으로 P1·P2·P5·P6을 통과 처리하지 않는다.
