# 전투 기여도와 동일 조건 연습 · insights1

2026-10-07. 로드맵 v3 1단계의 첫 작업 묶음. 대상은 `prototype/character.html?v=insights1`.

## 사용 흐름

교전 결과 또는 귀환 결과 → **이 조건으로 덱 수정·연습** → 당시 보유 카드로 정확히 20장 편성 → 공격/보호 방침 선택 → 연습. 승리와 패배 교전 모두 시작 조건을 보존한다. 원정 결과에는 출발/최종 덱과 선택 기록도 표시한다.

기본 편집 범위는 당시 장착·대기 카드다. 별도 **전체 기초 키트 실험**은 알려진 4인 기초 카드의 남은 사본만 추가한다. 원정 보상 카드는 새로 지급하지 않으며 종류별 장수 제한과 원본 진화 상태를 유지한다. 이 옵션을 변경하면 편성을 원본으로 복원한다.

전투 시작 체력·레벨·태세·적 프로필/위험 구역·시드·규칙 설정을 복사한다. 덱과 방침만 편집한다. 연습 중에는 편집을 잠그며 일시정지는 관전만 멈춘다. 원정 보상·경험치·발견·저장 편성에는 영향을 주지 않는다. 최근 연습 6개는 화면에서 비교하며 새로고침하면 사라진다. 원본 교전 조건과 기여도는 기존 저장/내보내기에 포함된다.

## 지표의 의미와 한계

- 손패 등장, 실제 명령 사용, 실제 HP 피해/회복, 보호막 흡수, 카드 차단 횟수, 엄호로 받은 분담 피해, 카드로 이동한 인원, 특성 강화가 실제 효과를 낸 횟수.
- 연속 타격·추가 추격·반격 피해는 원본 카드에 귀속한다. 기본 회복은 카드 회복에 포함하지 않는다. 과잉 회복/과잉 피해도 제외한다.
- 보호막은 강한 기존 수치가 유지되면 기존 효과 카드, 교체되면 새 카드에 흡수를 귀속한다. 기여도는 효과의 출처 기록이며 ‘그 카드가 없었으면 발생할 피해’라는 가상 추정치가 아니다.
- 피해 분담은 보호자가 받은 피해다. 피해 제거와 합산하지 않는다. 기본 방패병 분담, 방어 감소·도발·강화의 모든 간접 가치는 이 표에서 점수화하지 않는다.
- 첫 전투불능과 적 기본 공격/상위 카드 피해는 주요 위협이다. 마지막 타격만으로 패배 원인을 확정하지 않는다. 미사용은 손패 미등장과 등장 후 미사용을 나눠 표시한다.
- 같은 덱·방침·고정 0.02초 시뮬레이션은 재현된다. 덱 변경은 이후 난수 소비와 행동 순서를 바꿀 수 있다. 원본에 수동 조작이 포함되면 오토 연습이 그 조작을 재현하지 않는다고 안내한다. 엔진 버전이 다른 과거 조건은 지원하지 않는다.
- 이전 교전의 없는 지표/시작 조건을 역산하지 않는다. 진행 중인 이전 저장은 불러온 시점 이후 부분 기록, 완료된 이전 결과는 기존 사용/피해만 표시한다. 시작 조건이 없는 교전의 연습은 제공하지 않는다.

## 구현과 검증

`character-engine.js`: 판정 지점의 계측과 검증/이전 저장 처리. `character-campaign.js`: 시작 조건 및 출발/최종 덱의 저장, 결과 합산. `battle-insights.js`: 지표 표시. `battle-practice.js`: 캠페인을 참조하지 않는 독립 복사본. `character-app.js`: 연습 편집·관전·비교 화면.

통과한 검사:

- `battle-insights-check.cjs`: 실제 회복/보호막/차단/분담/반격/특성 강화, 사용 집계, 동일 조건 재현, 저장 이어하기, 원정 불변, 패배 후 원본 보존, 편집 잠금·장수 제한·잘못된 저장 거부.
- `battle-insights-browser-check.cjs`: 1280px/390px 결과·연습·일시정지·편집·6개 결과 상한·새로고침·이전 저장 부분 기록·가로 넘침 없음·브라우저 오류 0.
- 기존 캐릭터 원정/저장·카드 그림 비교 브라우저 검사와 전투 효과/행동 처리 검사.

이는 지표와 연습의 동작 검증이다. 재미나 특정 덱의 우위를 보증하는 밸런스 실험은 아니다.
