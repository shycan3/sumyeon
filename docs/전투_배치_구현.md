# 전투 전 배치 구현 — formation1

## 사용 흐름과 실제 효과

지도 하단의 **전투 배치**를 열고 캐릭터 → 목적지 순서로 선택한다. 빈자리는 이동, 다른 캐릭터 자리는 교환이다. 전열·중열·후열 각 2자리 중 4자리를 사용한다. 추천 배치와 선택 취소를 제공하고 편집 중 팝업·스크롤·포커스를 유지한다. 전투 중에는 배치를 바꿀 수 없다.

전열/중열/후열의 시작 x는 각각 330/225/120, 위/아래 y는 135/255다. 실제 거리·접근과 기존 거리 기반 표적 선정에 영향을 준다. 부상자 추격 등 다른 기준을 사용하는 적이 전열만 공격하도록 변경하지 않았다. 도발과 보호 효과는 기존 판정을 유지한다.

사수·지원가가 정상 공격 사거리 안에 있고 역할 행동에 방해가 없으면 선택한 위/아래 열 쪽으로 천천히 정렬한다. 사거리를 벗어나는 정렬은 하지 않는다. 시작 x로 돌아가는 명령은 없다. 근접 캐릭터는 추격·견제를 계속한다. 기술 잠금, 카드 엄호·추격, 도발, 위험 구역 재배치 유지, 기본 회복, 사수의 가까운 적 거리 유지가 열 정렬보다 우선한다. 위험 구역 자체를 보고 무료로 회피하지 않는다.

배치는 별도 능력치 보너스를 주지 않는다. 원정마다 추천 배치로 출발하고 다음 교전까지 수정한 배치를 유지한다. 전투 시작 기록과 연습에 포함된다. 연습에서는 원본 배치 복구와 독립 편집이 가능하며 원정 배치와 보상을 바꾸지 않는다.

## 이전 저장

배치 정보가 없는 진행 중 교전은 현재 좌표와 기존 이동을 그대로 유지한다. 다음 교전부터 추천 배치를 사용한다. 과거 연습 기록은 원본 배치를 유지하면 이전 시작 좌표를 재현하고, 배치를 편집하면 새 배치 규칙을 사용한다.

중복 자리·범위 밖 자리·배치와 전투 시작 기록 불일치를 거부한다. 재개 시 시작 좌표를 다시 적용하지 않으므로 저장된 현재 위치가 유지된다.

## 검증

- `formation-check.cjs`: 자리 이동/교환·입력 검증, 실제 이동과 거리 기반 적 표적 차이, 결정적 저장 재개, 이전 저장, 전투 중 편집 금지, 실제 위험 구역 재배치 우선, 원본 연습 재현·원정 격리 통과.
- `formation-browser-check.cjs`: 1280×720, 390×844, 320×568, 844×390에서 반복 편집·팝업 유지·교환·새로고침 저장 복원·실제 시작 좌표·연습 배치 변경·실행 중 잠금 통과. 페이지 오류 없음.
- `formation-simulation-check.cjs`: 적 4종 × 시드 3개 × 방침 2종 × 배치 3종, 총 72회. 모든 교전이 제한 시간 내 종료되고 좌표가 전장 안에 유지됨. 24개 조건 묶음 모두 배치 간 시간 또는 종료 HP 차이가 있음. 결과는 `prototype/formation-simulation-results.json`에 보존.
- 기존 `character-check.cjs`, `battle-insights-check.cjs`, `layered-ai-check.cjs`, `character-browser-check.cjs`, `comfort-browser-check.cjs` 통과. 기존 원정 흐름·저장·카드 효과·다층 AI·6개 화면 크기 관전 안정성을 확인.

기존 `reposition-return-check.cjs`는 BossLab에서 덱을 교체한 뒤 이전 특성 키 목록을 유지하는 시험 설정 때문에 특성 검증에서 실패했다. 새 배치 엔진 코드를 제거한 진단에서도 동일 오류가 재현됐다. 이번 검증에서는 메인 보스의 실제 재배치가 선호 열보다 우선하는 것을 별도 검사했다. BossLab 설정 오류는 이번 작업에서 수정하지 않았다.

## 균형에 관한 한계와 다음 작업

72회 조건은 레벨 1·기초 덱·전원 최대 체력이다. 세 배치 모두 24/24 승리했으며 평균 종료 HP는 추천 375.89, 방패병 후열/사수 전열 389.61, 세린 중열/원거리 후열 387.49였다. 이 표본에서 추천이 가장 강하지 않았다는 것은 확인했지만, 모든 상황에 좋은 배치가 없다는 증명은 아니다.

첫 교전의 세 배치 비교에서는 종료 시간이 같았고 두 배치의 남은 HP도 같았다. 배치가 항상 큰 차이를 만드는 것은 아니다. 다음 단계에서 실제 6방 원정의 체력 누적, 저체력, 출발 덱 3종과 혼합 덱을 포함해 중요도를 검증한다. 숫자 보너스나 필수 수동 조작으로 억지로 중요도를 높이지 않는다.
