# 전투 자동 운영 · 구현과 검증

적용일: 2026-10-06. 관전하면서 필요할 때 카드를 직접 사용하는 기획을 바탕으로, 처음부터 사용할 수 있는 선택형 오토를 구현했다.

후속 방향인 [캐릭터와 원정 카드 설계](캐릭터와_원정_카드_설계.md)는 아직 구현 전이다. 아래 시뮬레이션은 기존 역할·카드·영구 수집 규칙에서 얻은 결과이며, 새 캐릭터 키트와 원정 보상 구조의 밸런스를 검증한 수치로 사용하지 않는다.

## 운영 규칙

- 기본값은 수동이다. 설정·전투 준비에서 오토를 선택하거나 전투 중 전환할 수 있다. 선택은 저장되고 다음 전투에도 적용된다.
- 수동은 기존처럼 명령 준비 완료에서 정지한다. 오토는 명령 준비와 적 예고에도 계속 진행하고, 현재 손패로 카드와 대상을 판단한다.
- AI는 현재 HP·보호 상태·거리·공개된 공격 예고를 활용한다. 긴급 회복과 차단을 평가하며, 적의 숨겨진 손패를 참고하지 않는다. 캐릭터 이동과 기본 행동은 기존 태세 AI가 맡는다.
- 플레이어가 정한 아군 태세를 AI가 변경하지 않는다. 전투 중 직접 변경한 태세도 유지한다.
- 플레이어와 같은 카드 효과·준비시간·명령 회복시간을 사용한다. 한 장 교체 2회는 오토와 플레이어가 공유한다. 유용한 행동이 없으면 준비된 명령을 보유하고 계속 관전한다.
- 화면에 마지막 자동 카드·대상·판단 이유를 표시한다. 지도·보상·진화·덱 편성은 직접 선택한다.

**직접 개입** 또는 준비된 손패 선택으로 시간을 멈춘다. 직접 카드 확정 후에는 오토로 돌아간다. **오토로 돌아가기**로 취소하면 명령을 소비하지 않는다. 충전 중에도 정지할 수 있지만, 충전이 끝나기 전에는 카드를 사용할 수 없다. 복귀·모드 전환으로 기존 충전 시간을 그대로 이어간다. 탭을 숨기면 정지하며, 돌아온 뒤 직접 재개한다.

키보드는 A로 모드 전환, Space로 오토 개입·재개, Esc로 개입 취소·복귀를 지원한다. 기존 수동 단축키도 유지한다.

## 검증 결과

실제 엔진으로 6개 적 구성 × 12개 시드의 독립 전투를 실행했다. 모든 캐릭터 레벨은 1, 깊이는 0, 기본 덱과 고정 태세를 사용했다.

| 운영 | 승리 | 평균 종료 HP 합 | 종료 시 전투불능 합 | 차단 합 | 평균 카드 사용 |
|---|---:|---:|---:|---:|---:|
| 게임의 오토 | 72/72 | 355.0 | 3 | 69 | 6.5 |
| 즉시 사용 비교 도구 | 72/72 | 355.8 | 2 | 71 | 6.6 |

비교 도구도 자동 검사 전략이며 사람의 플레이가 아니다. 이 결과는 기본 전투 진행과 카드 사용을 확인하며, 오토의 최적 판단을 입증하지 않는다.

열 개 방 원정에서는 검사 도구가 경로·보상·덱 교체·진화를 결정하고, 모든 전투의 카드 판단을 게임 오토에 맡겼다. 총 72회 원정을 검사했다.

| 준비시간 | 경로 | 시작 덱 | 완주 |
|---|---|---|---:|
| 일반 즉발 | 안전 | 기본 | 12/12 |
| 기존 준비시간 | 안전 | 기본 | 12/12 |
| 일반 즉발 | 위험 | 기본 | 1/12 |
| 기존 준비시간 | 위험 | 기본 | 2/12 |
| 일반 즉발 | 안전 | 공격 특화 | 8/8 |
| 일반 즉발 | 안전 | 방해 특화 | 8/8 |
| 일반 즉발 | 안전 | 지원 특화 | 8/8 |

위험 경로의 실패는 실제 HP 유지와 전투불능을 포함한 결과다. 오토는 기본 전투와 안전 경로를 운영할 수 있으나, 어려운 경로에서의 생존이나 최적 판단을 보장하는 수준은 아니다. 특화 덱 비교는 동일한 전체 수집 목록·레벨 1로 시작했고, 기본 덱은 초기 수집으로 시작했다. 카드 수치는 이번 작업에서 변경하지 않았다.

규칙 검사에서 긴급 회복·실제 공격 차단·공격 예고 없는 차단 보류, 숨겨진 적 손패 변경에 따른 판단 보존, 태세 유지, 전투불능 카드 제외, 교체 상한, 개입 정지와 명령 한 번 소비, 충전 유지, 자동 상태의 동일한 저장 후 진행을 확인했다. 이전 저장은 수동 기본값으로 복원하고 잘못된 새 저장 필드는 거부한다.

별도 브라우저 저장 공간에서 설정·자동 시작·충전 중 개입·복귀·수동 카드·저장 후 이어하기·자동 승리·다음 전투 모드 유지를 확인했다. 기존 수동 전체 원정 검사도 통과했다. 데스크톱과 모바일에서 전장·손패·명령 버튼이 함께 표시되는지 확인했고, 브라우저 오류는 없었다.
