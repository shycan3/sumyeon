# 전투 전체 화면 UI — viewport1

전투 중 전장을 화면 전체로 확장했다. 일반 원정과 지원가 제작 체험, 진행 중 연습 전투에 동일하게 적용한다.

## 변경

- 전장이 브라우저 화면을 전부 채운다. 거점 헤더·제작 체험 배너·페이지 여백은 전투 중 숨기고, 나가면 기존 준비·결과 화면으로 돌아간다.
- 전투 제목·속도·일시정지·예고는 위쪽에, 파티 HP와 궁극기·손패·전투 기록·전황 상세는 아래쪽에 띄운다. 관전 판단의 자세한 내용은 전황 상세에서도 확인할 수 있다.
- 스킬 초상화·대사는 전장 위에 표시한다. 연출이 없으면 배너를 숨기며 공간을 따로 예약하지 않는다. 연출·손패·실험 도구·상세 창을 열어도 전장 크기는 바뀌지 않는다.
- 캔버스는 실제 화면 크기와 기기 픽셀 비율에 맞춰 그린다. 캐릭터 비율을 유지하는 동일 축척을 쓰며, 남는 영역에도 전장 배경을 그린다. 캐릭터를 늘이거나 위험 구역을 잘라서 화면을 채우지 않는다.
- 카메라는 생존 캐릭터와 전체 위험 구역을 함께 담는다. 세로 화면에서는 좌우로 퍼진 초기 배치가 작게 보일 수 있으며, 전투 중 가까워지면 시야가 조정된다. 전투 좌표·이동·피해·저장 규칙은 변경하지 않았다.

## 검증

- 일반 원정/지원가 체험 × 1280×720, 390×844, 320×568, 844×390, 1920×1080에서 전장 경계가 화면 경계와 일치하는지 검사한다.
- 실제 위험 구역 전체, 배경의 가장자리, 균등한 축척, 조작 버튼 범위, 손패·상세·실험 도구, 거점 복귀, 연습 전투 시작/종료를 확인한다.
- 기존 안정적 연출 검사 6개 화면 × 143개 연출 상태에서 전장 경계를 유지했다. 관전 프레임의 1배/2배 전투 진행, 일시정지, 저장 복원과 지원가의 보상·연출·연습 경로도 확인했다.

검사: `battle-viewport-browser-check.cjs`, `stable-watch-browser-check.cjs`, `watch-frame-browser-check.cjs`, `watch-ui-browser-check.cjs`, `content-support-browser-check.cjs`, `spectator-check.cjs`.

이 작업은 로드맵 5단계 콘텐츠 비교에 앞선 관전 UI 수정이다. 새 캐릭터의 실전 밸런스나 콘텐츠 편입 여부를 바꾸지 않는다.
