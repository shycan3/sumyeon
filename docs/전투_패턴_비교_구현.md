# 전투 패턴 3종과 결과 비교

현재 4인 파티와 카드 시스템으로 성격이 다른 전투를 만들고, 거점의 ‘전투 패턴 비교’에서 실행하도록 연결했다. 실제 원정·카드 보관·성장 저장과 분리한 combat-lab.html에서 먼저 검증한다. 기존 관전 카드 구성 체험도 유지한다.

## 전투 구성

| 전투 | 적 구성과 행동 | 확인할 선택 |
| --- | --- | --- |
| 집중 공격 | 검사와 사수가 기존 hunt 방침으로 HP 비율이 낮은 동료를 추격. 도발을 실제 공격 대상으로 반영 | 도발·엄호·회복과 빠른 처치 |
| 다수의 적 | HP 62의 근접 적 5명. 기존 swarm 방침과 범위 공격 카드 사용 | 광역 공격·처치 순서·전체 회복 |
| 예고된 강공격 | HP 320의 파수꾼 1명. 공격 카드 준비시간 2.8초, 느린 기본 공격 | 명령을 보유하고 타격 시점에 맞춰 차단 |

카드 효과·아군 AI·전투 처리 규칙은 기존 엔진을 사용한다. 비교 전투에 한정해 적 구성·기본 공격 수치·카드 묶음을 정하고, 강공격의 예고 시간만 별도 정의한다. 원정의 기존 적 AI나 전투 난이도를 변경하지 않는다.

세 전투의 아군은 레벨 1, 시작 HP 140/115/95/70, 태세 보호/추격/거리 유지/지원, 초기 난수 37로 동일하다. 기초 20장 덱에서 간격 베기와 돌진 한 복사본을 각각 추격·엄호 보상 한 복사본으로 바꾼 공통 덱을 사용한다. 손패 5장, 전투당 교체 2회다. 대표 기술의 첫 손패 출현을 강제하지 않는다.

같은 아군 조건과 덱·초기 난수를 사용하더라도 적 수·총 체력·공격 구조는 다르다. 세 전투의 난이도가 동일하거나 오토가 모든 상황에서 최선이라는 의미는 아니다.

## 관전·개입·비교

- 오토 관전이 기본이고, 수동 운영으로 바꾸면 같은 전투를 새로 시작한다.
- 명령이 준비됐을 때 손패를 선택하면 시간을 멈추고 대상·카드를 확정한다. 기존 중복 시전 검사와 카드별 대상 제한을 적용한다.
- 수동은 명령을 보유하고 관전할 수 있다. 오토로 돌아가기도 제공한다.
- 실제 적 카드의 공격 대상·남은 준비시간을 표시한다. 선택 카드의 발동 시간·명령 회복시간·효과 지속시간도 표시한다.
- 차단 방패의 지속시간은 2.5초이므로 2.8초 예고가 시작되는 즉시 쓰기보다는 타격 시점에 맞춰 사용할 필요가 있다.
- 전투가 끝나면 승패·시간·생존자/남은 HP·캐릭터별 실제 받은 피해·회복량·분담량·차단 횟수·카드 사용 횟수와 카드별 피해를 기록한다.
- ‘세 전투 오토 비교’는 독립 전투 3개를 실제 엔진으로 계산한다. 현재 관전 중인 전투의 상태·난수·손패를 변경하지 않는다.
- 각 전투의 오토 기준과 최근 직접 플레이 결과를 나란히 남긴다. 수동 카드 사용이나 손패 교체·기회 보유 후 오토 복귀는 개입 결과로 구분한다.
- 결과는 현재 탭 메모리에만 남으며 새로고침하면 초기화한다. 원정 저장 키에는 쓰지 않는다. 소리는 사용자가 켜고 기존 연출 설정을 공유한다.

보호막이 흡수한 양과 보호자가 나누어 받은 양을 혼동하지 않도록 ‘분담한 피해’로 표시한다. 회복량에는 기본 회복과 카드 회복이 함께 포함되며, 카드별 피해는 실제 체력 감소 기록이다. 피해를 나눠 받은 보호자의 피해는 역할별 받은 피해에도 포함한다.

집중 공격은 엄호·집중 회복을, 다수의 적은 화살비·전체 회복을, 강공격은 차단과 단일 공격을 사용했다. 실제 선택 차이를 확인했지만 한 가지 덱·시드의 결과이므로 밸런스 완성의 증거로 보지 않는다. 특히 세린이 집중 공격에서 쓰러지는 결과는 보호·회복의 개입 타이밍을 검증할 과제다.

## 검증

- combat-lab-check.cjs: 동일 아군/덱/첫 손패, 전투의 결정적 재현, 집중 표적과 도발 전환, 실제 광역 피해, 2.8초 준비 중 피해 없음, 실제 차단, 수동 기회 보유 후 첫 강공격 차단, 서로 다른 카드 선택, 읽기 전용 결과 집계, 저장 스냅샷의 동일 재개, 수동 정지·한 번 사용·개입 표시.
- combat-lab-browser-check.cjs: 1280×720와 390×844에서 세 전투 오토 비교·현재 관전 상태 격리·수동 카드 확정·개입 결과·실제 강공격 예고·일시정지·연출 모드 무변경·화면 넘침 없음·원정/이전 저장 키 무변경, 브라우저 오류 없음.
- card-structure-browser-check.cjs: 거점 링크 추가 후 기존 보상·교체·보관·폐기·복원 흐름 회귀 통과.
- spectator-check.cjs: 기존 카드 구성 비교 체험의 결과·연출·실제 효과 회귀 통과.
