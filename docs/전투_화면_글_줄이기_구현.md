# 전투 화면 글 줄이기 · quiet2

2026-10-09. 브라우저 주석 4개를 반영했다.

- 화면을 가로지르던 행동 순서·게이지 판을 왼쪽 가장자리의 세로 초상 목록으로 바꿨다. 현재 행동자는 색 테두리와 작은 화살표로 표시하고 다음 행동자는 위에서 아래로 읽는다. 전투 시각·게이지 숫자는 상시 표시에서 뺐다. 개체 이름만 작게 남겼으며 상세 수치는 마우스 도움말에 있다.
- 기본행동 이후 피해 예상 패널과 전투 기록 버튼을 전투 화면에서 제거했다. 규칙 엔진의 예측 API와 전투 이력 데이터는 유지한다.
- 공용 설명 판을 제거하고 현재 행동자 이름·기본행동 버튼만 카드 위에 남겼다. 비용 한도·결정 중 정지·개인 턴 횟수·전투 시각·실험 표시는 전투 중 화면에 나오지 않는다. 규칙 안내는 기존 ? 도움말에 있다.
- 카드 선택 시 중복 효과 설명과 다음 교전 전체 로그를 제거했다. 카드 이름·대상·취소·사용만 표시하고 카드 본문의 실제 효과·비용·특성은 유지했다.
- 적 예고의 중복 HP 줄과 죽은 적 예고 판도 숨겼다. 생존한 적의 공개 의도는 유지한다.

구도 참고: [스타레일 전투 소개의 Action Order](https://www.hoyolab.com/article/17237205). 왼쪽 세로 순서 표현을 참고했으며 초상은 기존 임시 캐릭터 색상으로 코드에서 그렸다.

실제 인앱 브라우저에서 1242×668 및 390×844 크기로 확인했다. 행동 목록은 각각 왼쪽 14px/6px, 폭 64px/46px이며 전장 중앙을 가로지르지 않는다. 카드 선택·대상 지정·사용·개인 턴 전환·적 행동·기본행동을 실제 버튼으로 확인했다. 기본 명령줄은 현재 행동자와 기본행동 두 항목만 남고 예상/기록 패널 DOM은 없다. 페이지 넘침 없음, 콘솔 오류 없음. 브라우저의 임시 화면 크기는 검증 후 기본값으로 복구했다.

전투 엔진·수치·저장·이전 공용 턴 비교 버전은 변경하지 않았다. 기존 브라우저 검사에도 세로 목록 위치·삭제한 패널·짧은 명령줄 검사 항목을 추가했다. 이번 검증은 화면 변경과 실제 조작에 집중했으며 3전투 전체 검사는 이전 1단계 결과다.
