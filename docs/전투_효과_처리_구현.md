# 전투 효과 처리 시스템

현재 4인 파티의 세린 원정과 관전 체험에 적용했다. 카드 수치와 파티 구성은 그대로이며, 효과가 겹쳤을 때의 처리 규칙을 통일했다. 이전 index.html의 처리 결과는 회귀 검사로 유지했다.

## 피해 처리 순서

1. 카드 차단은 카드 이벤트 전체를 막는다. 기본 공격은 막지 않는다. 차단된 카드에는 피해·보호막 소모·엄호·반격이 없다.
2. 표식 피해 증가 → 보호 태세 감소 → 방어 강화 감소를 계산한다. 관통은 태세·방어 감소를 건너뛰며 표식과 보호막은 적용한다.
3. 피격자의 유효 보호막을 소모한다.
4. 남은 피해를 한 번만 분담한다. 유효한 세린 엄호 25%가 우선이며, 없으면 가까운 방패병 보호 20%가 적용된다. 동시에 두 보호자에게 나누지 않는다.
5. 분담 피해는 최종 체력 피해다. 보호자의 표식·방어·보호막을 다시 계산하거나 다른 보호자에게 재분담하지 않는다. 보호자가 감당할 양은 남은 체력으로 제한하고 나머지는 원래 대상이 받는다.
6. 실제 체력 감소만 피해·카드·역할별 통계에 기록한다. 보호자 전투불능은 보호 중 사망으로 기록하고 실제 공격자를 연출에 전달한다.
7. 살아 있는 반격 보유자가 실제 살아 있는 적 공격자에게 한 번 반격한다. 엄호자가 실제 피해를 분담했다면 그 반격이 우선이다. 아니면 직접 피격자의 반격을 확인한다. 반격이 반격을 부르지 않는다.

보호막이 공격을 전부 막으면 엄호 피해와 엄호 반격이 발생하지 않는다. 직접 받은 공격은 자신의 보호막이 모두 막아도 받아치기가 발동한다. 공격자를 찾을 수 없거나 이미 전투불능이면 반격 기회를 소모하지 않는다.

## 재사용·중첩·만료

| 효과 | 재적용 규칙 |
| --- | --- |
| 보호막 | 현재 남은 보호막과 새 수치 중 큰 값, 종료 시각 중 늦은 값. 합산하지 않음 |
| 방어·공격 강화 | 유효한 기존 수치와 새 수치 중 큰 값, 종료 시각 중 늦은 값 |
| 표식·둔화 | 종료 시각 중 늦은 값. 피해 배율·둔화 배율은 중첩하지 않음 |
| 차단 | 보유 횟수 최대 1, 유효 종료 시각 중 늦은 값 |
| 반격 | 보유 횟수 최대 1, 강한 위력·늦은 종료 시각 유지. 위력에 대응하는 카드가 원인으로 기록됨 |
| 도발 | 마지막 시전자와 그 카드의 종료 시각으로 교체 |
| 추격·엄호 이동 목적 | 기존 다층 AI 규칙대로 새 이동 카드가 기존 목적을 교체 |
| 정화 | 표식·둔화를 즉시 제거 |

만료된 수치는 재사용 시 비교 대상에서 제외한다. 만료 시각과 같은 순간에는 효과가 적용되지 않는다. 프레임 안에서 늦게 처리된 카드도 해당 이벤트의 예약 시각으로 효과를 평가한다. 기본 공격은 현재 전투 시각을 사용한다. 같은 시각의 보호막·방어·차단·도발은 기존 방어 우선 정렬을 사용한다.

수치와 지속시간을 각각 유지하는 정책은 간단하고 약한 재사용이 강한 효과를 덮어쓰는 일을 방지한다. 대신 약한 카드로 강한 효과를 연장할 수 있다. 현재 콘텐츠에서는 허용하며, 서로 다른 강화 등급의 독립 지속시간이 필요해질 때 효과별 인스턴스로 확장한다.

## 저장과 적용 범위

전투 상태에 effectRulesVersion: 1을 기록한다. 이전 저장은 기존 체력·보호막·남은 시간·손패·예약 이벤트를 유지하며 이 규칙으로 이어간다. 과거의 통계는 재계산하지 않는다. 알 수 없는 효과 버전, 음수·비정상 효과 수치, 두 번 이상의 차단 횟수는 불러오기를 거부한다. 기존 저장 키와 원정 규칙 버전은 유지했다.

설정·저장 화면의 ‘전투 효과 규칙’에서 핵심 규칙을 확인할 수 있고, 엄호 카드 설명에도 보호막 이후의 피해 분담을 명시했다.

## 검증과 실제 영향

- effect-check.cjs: 중첩·갱신·만료, 도발 교체, 차단과 반격 1회 제한, 방어→보호막→엄호, 보호 우선순위, 관통, 정화, 분담 중 사망·통계·공격자 기록, 비재귀 반격, 정확한 만료 시각, 동일 시각 방어 우선, 저장 검증·이전 저장 변환·동일 재개.
- effect-browser-check.cjs: 두 화면 크기에서 게임 내 규칙 설명, 보호막 이후 실제 3/9 피해 분담, 전투 저장 재개, 기존 저장 격리 확인.
- layered-ai-check.cjs와 presentation-next-check.cjs: 목적·도발·반격·실제 처치 연출 회귀.
- character-check.cjs: 수동·오토 및 보상 카드 두 종류 × 8개 시드의 안전 경로 원정 32/32 성공. 강화·강적 경로는 2/8 성공.
- character-browser-check.cjs와 presentation-next-browser-check.cjs: 1280×720, 390×844에서 실제 원정·저장 재개·보상·보스·초상화·결과·저장 격리, 브라우저 오류 없음.
- smoke.cjs: 이전 게임의 카드·전투·원정·오토 검사 통과.

40 피해를 엄호 보호막 28로 받으면 남은 12 중 세린이 3, 동료가 9를 받는다. 이전에는 보호막 계산 전에 10을 세린에게 옮겨 동료가 2를 받았다. 처리 순서 통일로 엄호와 방패병 보호의 연쇄 분담이 제거되었고 엄호 반격 빈도도 낮아졌다. 안전 경로 검사에서는 모두 완주하지만 강적 경로의 성공률은 기존 4/8에서 2/8로 변했다. 이 결과는 제한된 시드 검사이며 실제 난이도의 일반적인 성공률은 아니다. 별도 카드 수치 조정은 하지 않았다.

다음 범위는 준비·돌진·다단 공격의 중단과 취소 결과를 공통 행동 수명 주기로 묶는 작업이다.
