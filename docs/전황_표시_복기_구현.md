# 전황 표시와 주요 장면 복기

현재 4인 파티와 전투 AI·카드 수치·획득 규칙을 유지하면서 관전 중 판단 근거를 표시했다. 세린 원정과 전투 패턴 비교 화면에 적용한다.

## 전투 중 표시

- 가는 점선은 공격 가능한 적 AI가 현재 노리는 대상이다. 준비 중인 기술이나 회복 행동과 구분하며, 다음 공격의 확정 대상이라고 표현하지 않는다.
- 주황 실선과 대상 발밑 표시는 예정된 적 카드 공격이다. 발동까지 남은 시간과 기술명을 표시하고, 광역 공격은 현재 범위에 들어온 대상들을 표시한다. 도발·이동으로 실제 대상은 변경될 수 있다.
- 보호막 수치와 남은 시간, 반격 1회와 남은 시간, 방어 강화·도발·파티 차단의 남은 시간을 표시한다.
- 엄호는 유효 목적과 거리 115 미만을 함께 확인한다. 멀리 있으면 ‘엄호 접근’, 범위 안이면 ‘엄호 가능’이다. 피해 분담 가능 표시는 실제 판정과 같은 엄호 우선·방패병 우선순위와 거리 조건을 사용한다.
- 화면의 조회와 렌더링은 AI 상태나 전투 스냅샷을 변경하지 않는다. 연출 간소 모드에서도 전황 정보를 유지한다.

## 실제 판정에 연결한 복기

전투 엔진에 버전 1 복기 기록을 추가했다. 체력 감소·차단·보호막 소모·분담·반격·위기 회복의 실제 결과를 기록하며, 일시적인 연출 신호와 독립적으로 저장한다. 전투 결과와 원정 귀환 기록에도 복사한다.

- 전투불능: 실제 공격자, 기술 또는 기본 공격, 마지막 체력 피해와 분담 여부. 적 처치도 기록한다.
- 차단: 실제로 막힌 카드 공격. 가상의 피해량은 계산하지 않는다.
- 보호막: 실제 소모한 보호막 수치.
- 보호·엄호: 보호자가 실제 나눠 받은 체력 피해. ‘피해 예방량’으로 표기하지 않는다.
- 반격: 실제 체력 피해 합계.
- 위기 회복: 회복 전 HP 25% 이하인 아군의 실제 회복량. 초과 회복과 0 회복을 제외한다.

저장 기록은 최근 80건으로 제한한다. 화면은 그 안의 전투불능, 최근 주요 회복·차단·반격 8건, 흡수·분담 3건을 발생 순서대로 보여준다. 같은 시각에 발생한 보호막·분담·반격의 순서도 보존한다. 이는 전체 전투 로그나 전략의 인과관계 분석은 아니다.

기존 저장은 읽을 수 있다. 이전 결과의 기록은 만들어내지 않으며, 진행 중 전투를 불러온 경우 해당 시각부터 새 기록을 수집한다. 버전·수치·시간·종류·카드·배우 참조를 검증한다.

## 검증

`node readability-check.cjs`와 `node readability-browser-check.cjs`를 추가했다. 실제 광역 대상 조회의 순수성, 차단 1회와 무피해, 보호막 이후 치명적 엄호 피해의 실제 출처, 엄호 거리 경계·효과 만료, 회복 상한, 저장 제한·이전 저장 변환·잘못된 참조 거부, 기록을 끈 전투와의 결과 동일성을 검사한다.

1280×720과 390×844에서 실전 예고·복기 펼치기·원정 결과 저장/새로고침을 확인했으며 가로 넘침과 브라우저 오류가 없었다. 기존 효과·행동 처리·다층 AI·관전·연출 독립성·카드 구조·원정 및 비교 화면 검사도 통과했다. 세 비교 전투의 기존 승패·피해·카드 사용 결과는 유지된다.
