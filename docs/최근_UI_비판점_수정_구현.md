# 최근 UI 비판점 수정

2026-10-07 · `character.html?v=refineui1`.

[비판적 검토](최근_UI_업데이트_비판적_검토.md)의 확인된 결함과 관전/편성/성장 분석 문제를 수정했다. 사용자 저장을 직접 조작하지 않고 격리 브라우저에서 검사했다.

## 조작·기록 결함

- 대표 스킬은 사용자/기술명/대사/초상화가 들어갈 높이를 확보했다. 긴 내용은 영역을 늘리고, 짧은 화면에서는 사용자+기술명과 대사를 두 줄로 배치한다. 더 이상 76px 내용 전체를 28px 영역에 잘라 넣지 않는다.
- summary의 Enter/Space는 기본 조회 동작을 사용한다. 관전 배경에서만 Space로 정지/재개한다.
- 손패 재생성 전 카드 ID와 위치/조회창 스크롤을 보존한다. 카드가 남으면 같은 카드로, 소모되면 같은 위치의 다음 카드로 포커스를 복원한다. 읽고 있던 기술 상세는 새 기술을 직접 선택할 때까지 유지한다.
- 실험 도구를 닫으면 오토로 복귀하되 정지 상태는 유지한다. 자동 관전 정지/브라우저 비활성 정지는 직접 개입 횟수를 늘리지 않으며, 정지 재개가 오토 스케줄을 초기화하지 않게 했다. 수동 기본 설정은 설정 페이지의 실험용 펼침 항목으로 옮겼고 기존 저장의 수동 설정은 보존한다.
- 사용 수/등장 상태 판정은 BattleInsights.evidence 하나로 공통화했다. 전체 사용 기록과 부분 효과 기록을 구분하고, 과거 기록이 없는 것을 미등장으로 단정하지 않는다. 표에도 전체 사용과 측정 구간을 표시한다.

## 관전 개선

특성/긴 전황 설명/적 상세 HP는 `전황 상세` 조회로 이동했다. 주요 예고·동료 HP·최근 오토 판단·정지/배속·대표 스킬은 전장과 함께 유지한다. 전장에 공간을 더 배정하고 카메라의 확대 상한/여백을 조정했다. 위치·피해·AI 판정은 변경하지 않았다. 카메라는 실제 생존자와 위험 구역을 기준으로 계산한다.

1280×720 대표 스킬 표본에서 실제 표시 전장 높이 약 251px, 대표 스킬 영역 72px로 측정됐다. 이전 검토의 전장 높이 약 208px/대표 영역 36px보다 공간이 늘었다. 초기와 매 순간의 정확한 표시 크기는 기술/예고/화면에 따라 달라지며 작은 기기의 모든 캐릭터 이름 가독성을 보장하는 주장은 아니다.

## 편성 탐색

가로 카드 레일을 세로 전체 목록+선택 카드 상세로 교체했다. 캐릭터/특성 필터, 그룹별 편성/대기 장수, 일반/진화 상태를 목록에서 확인한다. 상세에서 같은 진화 상태의 사본을 한 장씩 넣고 뺀다. 사본 ID의 실제 조작과 정확한 20장/상한은 유지한다.

320px의 짧은 화면은 선택 상세의 큰 그림보다 효과/명령 시간을 우선한다. 카드 그림은 넓거나 긴 화면에서 유지한다. 목록과 상세의 스크롤은 독립적으로 유지하며 수량 변경/초기화 뒤에도 목록 위치와 적절한 조작 포커스를 복원한다. 대기·폐기 정리는 별도 조회창에서 계속 제공하고 폐기/복원 뒤 창을 유지한다.

## 성장 해석·과거 덱 비교

결과에 실제 회복/보호막 흡수/피해 분담/반격/처치 사건을 최대 3개 표시한다. 변경 카드와 확실하게 연결된 사건을 우선하고, 실제 대상·시간·효과를 표시한다. 기존 recap에 원본 카드 키가 없는 사건은 `카드 연결 미기록`으로 구분한다. 신규 회복/보호 사건에는 선택적인 원본 카드 키를 기록하고 검증한다. 기존 적 공격 키를 보호 카드의 키로 오인하지 않는다. 사본/진화별 합산이나 승리 원인에 대한 인과 추정은 하지 않는다.

`변경 전 덱 재현`은 과거 교전/출발 스냅샷의 실제 카드와 진화 상태를 연습 세션에만 복사한다. 현재 교전의 시드/HP/레벨/태세/적/원정 규칙에서 비교한다. 진화 또는 처분으로 현재 보유 풀에 없는 카드도 과거 기록이 검증되면 재현할 수 있다. 원정 지급/저장/경험치/보상에는 영향이 없다. 연습 결과에 과거 덱 재현임을 표시하며 원래 교전 덱으로 복원할 수 있다. 과거 기록이 없는 덱은 여전히 비교할 수 없다.

## 구조 정리

전투 레이아웃의 중복 높이 override를 watch-ui.css 한 곳에 정리했다. 화면 분류는 DOM 내부 버튼 탐지보다 setContent가 명시한 화면 상태를 사용한다. 공통 어댑터/팝업은 유지하며 전체 앱 재작성을 하지 않았다. 남아 있는 기반 CSS와 패널 이동 어댑터까지 전부 제거한 것은 아니다.

기존 저장 버전은 유지했다. recap.cardKey는 선택 필드이며 기존 기록은 그대로 읽을 수 있다. 알 수 없는 카드 키는 저장 검증에서 거부한다.

## 검증

- refinement-check.cjs: 전체 사용/부분 효과 상태, 진화 전·과거 덱 재현, 연습 시작 기록 검증과 원정 비변경, 원본 복원, 사건 카드 귀속/잘못된 카드 키 거부.
- refinement-browser-check.cjs: 1280×720, 390×844, 320×568, 844×390, 768×1024, 360×640. 필터/선택/장수/목록 위치, Space 조회, 실시간 포커스, 도구 닫기 정지 유지, 대표 기술의 실제 내부 텍스트/초상화 경계 및 동료 HP/전장 경계.
- watch-frame-browser-check.cjs: 실제 프레임 1배/2배 고정 단계 동일성과 정지/재개.
- battle-insights-check.cjs 및 battle-insights-browser-check.cjs: 실제 기여도, 부분 기록, 연습 재현/원정 분리/과거 저장.
- card-structure-browser-check.cjs: 실제 보상/교체, 대기 폐기/복원과 저장 재개, 편집 취소, 정확한 20장, 폐기 복원 기한.
- compare-ui-browser-check.cjs, card-identity-browser-check.cjs: 보상 비교/되돌리기/공통 카드 식별/일반·진화 분리/편집 위치.
- result-story-browser-check.cjs, character-browser-check.cjs: 교전 결과/과거·현재 연습/보고서, 실제 원정 완주/보상 카드 사용/저장 불러오기/복구.

실제 사용자의 카드 비교 시간·탐색 횟수·성장 이해도와 모든 장문/기기/확대 조합은 아직 실측하지 않았다. 자동 검사로 재미나 최종 접근성 적합성을 인증하지 않는다.
