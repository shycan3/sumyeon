# 출발 덱 선택 · 2026-10-07

원정 출발 버튼은 덱 선택 화면을 엽니다. 추천 3종과 저장된 자유 편성을 고른 뒤 카드 구성·특성 단계·오토 방침을 확인하고 출발합니다. 새 사용자의 첫 추천은 추격입니다.

- 모든 카드에 기존 특성을 유지합니다. 추천 덱은 기초 카드 20장, 진화·보상 카드 없음, 추가 능력치 없음, 주 특성 1단계만 활성화합니다.
- 호위: 방패·도발·받아치기, 공격과 다수전 속도를 포기하는 편성.
- 추격: 세린·사수의 단일 집중 공격, 광역 공격·받아치기 없음.
- 공명: 서로 다른 캐릭터의 연속 사용과 광역 공격, 도발 없음. 전체 회복은 1장입니다.
- 자유 편성은 여러 특성을 활성화할 수 있습니다. 추천 조건은 규제가 아니라 입문용 구성입니다.
- 추천 덱 선택은 저장된 자유 편성을 덮어쓰지 않습니다. 직접 편성하고 확정할 때만 자유 편성을 저장합니다. 편성을 취소하면 선택 화면으로 돌아옵니다.
- 현재 원정·과거 저장의 덱은 교체하지 않습니다. 출발 시 선택한 카드만 새 원정으로 복사합니다. 출발 컨셉은 원정 기록에 남습니다.
- 보상 획득·진화·덱 교체와 특성 단계 미리보기는 기존 규칙을 사용합니다. 기본 AI, 카드 성능, 적 난이도는 변경하지 않았습니다.
