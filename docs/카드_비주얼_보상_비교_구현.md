# 카드 그림 및 보상 교체 비교 · 2026-10-07

이전 보상 교체 화면은 카드 이름과 특성 변화만 적힌 버튼으로 기존 카드의 실제 효과를 확인하기 어려웠습니다. 보상·홈 기술·덱 편성에 그림을 적용하고 보상 교체를 비교 후 확정 방식으로 바꿨습니다.

## 표시 및 조작

- 현재 캐릭터 기초/보상 카드 15종 모두 각각의 기술 장면을 사용합니다. imagegen으로 제작한 4×4 아틀라스 원본을 `prototype/assets/card-skills-atlas-v1.png`에 저장하고 CSS 위치로 표시합니다. 마지막 칸은 향후 누락 카드의 임시 공통 이미지입니다. 현재 15종은 모두 개별 매핑됩니다.
- 그림 자체에 특성 정보를 고정하지 않습니다. 특성 색의 테두리와 문양(호위 ◆, 추격 ↗, 공명 ✦), 이름을 동적으로 표시해 그림 색만으로 판별하지 않아도 됩니다.
- 카드에는 소유 캐릭터, 기초/보상, 이름, 효과 설명, 피해/회복/보호막 수치, 준비·지속·다음 명령 시간을 표시합니다. 피해는 보정 전 기본 수치입니다. 실행 중 피해를 예측하지 않습니다.
- 진화 수치는 기존 `GameData.definition`을 사용합니다. 강화 수치를 따로 복제하지 않습니다. 진화는 별도 표시하며 특성은 동일합니다.
- 덱의 동일 카드·동일 진화 상태는 묶어서 장수를 표시합니다. 일반/진화는 다른 후보이며, 선택한 상태의 개별 한 장만 교체합니다.
- 후보를 선택하면 빠지는 카드와 들어오는 카드를 나란히 보여주고 정확한 한 장 교체 후 특성 종류 수·단계 변화를 표시합니다. 비교와 취소는 덱·저장을 변경하지 않습니다.
- 교체 확정 시에만 기존 교체 로직을 실행합니다. 빠진 카드는 대기, 새 카드는 편성됩니다. 교체 없이 보관, 전체 덱 편성도 그대로 사용할 수 있습니다.
- 비교 선택은 일시적인 화면 상태입니다. 새로고침하면 선택을 다시 하지만 실제 보상·편성은 저장됩니다.

## 범위와 검증

전투 수치·AI·출발 덱·보상 규칙·저장 형식은 변경하지 않았습니다. 전투 손패는 기존의 작은 형식을 유지하며 특성 문양을 함께 표시합니다. 대기 카드 목록은 기존 간단한 목록을 유지합니다. 정식 출시용 아트·캐릭터 초상화의 통일 작업과 이미지 개별 파일화는 별도 작업입니다.

`card-visuals-browser-check.cjs`: PC 1280px 및 모바일 390px. 15종 그림 매핑, 이미지 경로, 강화 수치, 일반/진화 후보 분리, 중복 장수, 미리보기 상태 불변, 취소, 한 장 교체·대기 보관, 단계 변화, 저장 재접속, 화면 넘침·브라우저 오류 확인.

기존 `character-browser-check.cjs`, `card-traits-browser-check.cjs`, `starting-decks-browser-check.cjs`도 통과했습니다. 기존 보상 교체 UI 테스트는 비교 이후 명시적 확정을 누르도록 갱신했습니다. 사용자 저장과 분리된 브라우저에서 확인했습니다.
