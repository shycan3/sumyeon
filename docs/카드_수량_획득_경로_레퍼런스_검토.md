# 카드 수량과 획득 경로 검토

2026-10-06. 현재 세린 원정의 구현을 기준으로 검토했다. 게임 규칙을 변경한 문서가 아니라 다음 설계 판단을 위한 조사다. 이전 index.html의 영구 카드 수집 규칙과 구분한다.

## 판단

전투 편성 덱 20장과 손패 5장은 우선 유지할 만하다. 원정 보관 카드 전체에 새 제한을 걸 필요는 없다. 먼저 원정 보상 2종 반복과 최종 보스 뒤의 사용 불가능한 카드 보상을 개선해야 한다. 획득 경로 종류를 늘리는 것보다 각 경로의 보상 목적을 달리하는 편이 효과적이다.

20장은 유사 게임에서 증명된 정답이라는 뜻이 아니다. 현재의 공용 명령, 느린 카드 순환, 4인 파티, 짧은 전투를 기준으로 한 시험 기준이다.

## 현재 실제 규칙

| 구분 | 구현 |
| --- | --- |
| 영구 기초 카드 선택지 | 세린 4종 + 임시 동료 7종 = 11종. 일반 카드 계열당 3복사본, 잔광 검무는 1복사본 |
| 출발 덱 | 정확히 20장. 출발 때 선택하지 않은 기초 카드는 원정 보관 목록에 생성되지 않음 |
| 손패 | 5장. 명령마다 1장 사용하고 즉시 1장 보충 |
| 카드 교체 | 전투당 2회. 수동과 오토 공유 |
| 원정 보상 종류 | 세린 추격·엄호 2종. 기본 카드와 합치면 사용 가능 카드 정의 13종 |
| 보상 후보 | 현재는 3후보 무작위가 아니라, 계열 보유 상한에 도달하기 전에는 두 종류 모두 반복 제공 |
| 보상 보유 상한 | 계열당 3장. 편성·대기, 강화 전후를 합쳐 계산 |
| 보관과 편성 | 기존 카드와 바꿔 편성 20장을 유지. 빠진 카드는 대기로 보관하고 전투 사이 재투입 가능 |
| 종료 | 원정 카드와 진화 초기화. 기초 키트·캐릭터·레벨·발견 기록 유지 |

| 6방 원정 경로 | 보스 전에 쓸 수 있는 획득 카드 | 마지막 보상 포함 획득 | 최대 보관량 |
| --- | ---: | ---: | ---: |

| 정비에서 카드 + 마지막 분기에서 휴식 | 3 | 4 | 24 |

현재 실제 획득 경로는 전투 승리와 정비 방 두 종류다. 일반전·강적·보스는 같은 후보 함수를 사용한다. 보급·상점·이벤트라는 이전 게임의 데이터가 존재하더라도 현재 세린 지도에 모두 구현된 것은 아니다.

최종 보스 승리 후에도 카드 획득·교체를 요구하지만, 그 다음 진행은 원정 종료다. 새 카드는 발견 기록에는 남아도 전투에서 한 번도 쓸 수 없다. 최종 보상은 경험치·발견 기록 등 지속되는 보상으로 정리하거나, 카드 획득 기회를 보스 전에 옮기는 편이 타당하다.

## 조사한 레퍼런스

Exa Search를 사용해 Slay the Spire 1, Chrono Ark, Marvel's Midnight Suns, Chaos Zero Nightmare의 네 조사 방향에서 검색 결과 45개를 검토했다. 공식 개발자·퍼블리셔 설명을 우선하고, Slay the Spire의 세부 규칙은 게임 위키로 보완했다. 이 숫자는 전문을 읽은 독립 문헌 수가 아니라 검색 결과 검토 수다. 보드게임판 Slay the Spire와 2편, 팬이 제시하는 적정 덱 크기는 공식 규칙 근거에서 제외했다.

### Slay the Spire 1

캐릭터마다 10장 또는 12장으로 출발한다. 전투 보상은 서로 다른 3장 중 하나를 선택하며 건너뛸 수 있다. 카드 획득은 전투·상점·이벤트·일부 유물로 이루어지고 덱에는 추가·제거·강화·변환이 가능하다. [카드 규칙](https://slaythespire.wiki.gg/wiki/Cards), [보상 규칙](https://slay-the-spire.fandom.com/wiki/Card_Rewards).

참고점은 보상을 받는 것이 항상 이득은 아니라는 점이다. 우리 게임도 넘기기와 편성하지 않고 보관하기가 의미 있는 선택이어야 한다. 그 게임은 기본적으로 턴마다 5장을 새로 뽑고 여러 장을 쓰므로, 덱 수가 커도 우리와 같은 속도로 순환하지 않는다. [전투·뽑기 규칙](https://slaythespire.wiki.gg/wiki/Mechanics).

### Chrono Ark

공식 소개는 최대 4인 파티의 고유 스킬·특성을 카드로 표현하고, 실패 시 원정에서 얻은 것을 초기화하는 구조를 설명한다. [개발사 공식 소개](https://store.steampowered.com/app/1188930/Chrono_Ark/).

현재 공식 공지에는 스킬 슬롯이 가득 찬 상태에서 새 스킬을 얻을 때 역할에 맞춰 기초 스킬을 우선 제거하는 규칙이 나온다. [공식 업데이트 목록의 1.2.2 안내](https://steamcommunity.com/app/1188930/announcements/).

개발자가 2021년에 설명한 이벤트 개편은 일반 획득 외에 특정 스킬북을 주는 특별 전투 등 경로의 목적을 구분했다. 이 자료는 설계 의도를 보여주는 역사 자료이며 당시 예고한 숫자를 현재 게임의 규모로 사용하지 않는다. [개발자 설명](https://store.steampowered.com/news/posts/?feed=steam_community_announcements&appids=1188930&enddate=1640376865).

참고점은 역할별 카드의 정체성과 교체를 통한 덱 성장이다. 유저 공략의 '캐릭터마다 5~6장을 권장'은 공식 최대치가 아니므로 우리 게임의 수치 기준으로 가져오지 않는다.

### Marvel's Midnight Suns

Firaxis 리드 디자이너는 영웅마다 8장으로 장착 덱을 만들고 참가 영웅의 덱을 섞으며, 턴 시작에 손패를 6장까지 보충하고 기본 카드 사용 기회 3회·리드로우 2회를 준다고 설명한다. [개발자 직접 설명](https://blog.playstation.com/2022/10/26/marvels-midnight-suns-super-heroic-turn-based-combat-and-card-tactics-explained/).

최대 3인 임무라 기본 영웅 카드 합계는 24장으로 계산된다. 그러나 추가 Hero Combo 카드 등이 있어 '실제 덱이 항상 정확히 24장'이라고 단정하지 않는다. [공식 임무 안내](https://midnightsuns.2k.com/en-US/game-guide/gameplay/tactical-missions/), [공식 능력 안내](https://midnightsuns.2k.com/en-US/game-guide/gameplay/hero-abilities/).

임무 보상 Gamma Coil은 초기 시설 기준으로 3개 능력 중 하나를 선택하게 하며, 영웅별 챌린지는 전설 능력을 준다. [공식 Forge 안내](https://midnightsuns.2k.com/game-guide/the-abbey/forge/).

참고점은 장착할 카드 제한과 획득한 능력의 관리가 다른 문제라는 점, 일반 보상과 명확한 도전 보상을 구분하는 점이다. 전체 카드 보관 상한과 동일 카드 2장 제한은 이번 공식 자료로 확인하지 못했으므로 비교 수치에서 제외한다. 지속 캠페인 성장을 우리 원정 종료 초기화와 혼동하지 않는다.

### Chaos Zero Nightmare

공식 2026-09-09 안내는 캐릭터별 Save Data를 팀 프리셋에 장착하고, 콘텐츠의 요건을 만족하지 못하면 기본 Save Data로 교체하는 방식을 설명한다. [공식 업데이트](https://page.onstove.com/chaoszeronightmare/EN/view/14502236).

공식 2026-02-04 안내는 저장 빌드에 복제·삭제·카드별 예산 등의 제약을 두며 시즌 Save Data가 시즌 종료에도 남는다고 설명했다. 이후 모든 변경 이력까지 검증한 것은 아니므로 당시의 상세 숫자를 우리 게임의 현재 권장 상한으로 사용하지 않는다. [공식 안내](https://page.onstove.com/chaoszeronightmare/EN/view/12012929).

개발진이 저장 점수 계산에 외부 도구가 필요한 불편을 인정하고 실시간 표시를 개선한 사례도 있다. [개발자 노트](https://page.onstove.com/chaoszeronightmare/en/view/11319239).

서브컬처 캐릭터와 고유 카드라는 측면에서 가까운 사례다. 다만 이 게임은 빌드를 저장해 다시 장착하는 구조이고, 우리 보상 카드·진화는 원정 종료 때 초기화된다. 복잡한 저장 예산을 도입할 근거로 쓰기보다, 제한을 이해하기 쉽게 보여줘야 한다는 교훈으로 보는 편이 좋다.

## 우리 게임의 카드 순환

대표 관전 체험 세 구성은 같은 시드에서 17.08~23.46초 안에 끝나고 실제 아군 카드 사용은 3~4회였다. 그 체험은 첫 손패에 검무를 예약하므로 대표 기술의 일반적인 등장률을 측정한 실험은 아니다. 다만 20장 전체를 한 전투에서 순환하기 어렵다는 구체적인 사례다.

아래는 시작 손패 5장을 균등 무작위로 뽑고 예약·교체·전투불능 제외가 없다는 가정의 계산이다.

| 전투 덱 | 1장 넣은 카드가 첫 손패에 등장 | 2장 넣은 카드가 하나 이상 등장 |
| --- | ---: | ---: |
| 16장 | 31.25% | 54.17% |
| 20장 | 25.00% | 44.74% |
| 24장 | 20.83% | 38.04% |
| 30장 | 16.67% | 31.03% |

같은 카드 k장 중 하나 이상을 볼 확률은 1 - C(N-k, 5) / C(N, 5)다. 실제 오토의 선택·교체, 전투 길이와 손패 고착은 반영하지 않았다. 첫 손패에 나오지 않는다는 사실만으로 한 전투에서 끝내 쓰지 못한다고 단정하지 않는다.

카드를 더 보관하는 것은 등장률을 떨어뜨리지 않는다. 전투 덱에 실제로 더 넣을 때 떨어진다. 무제한 보관과 무제한 전투 덱을 구분해야 한다.

## 권장 기준과 순서

| 항목 | 초기 권장 |
| --- | --- |
| 영구 기초 카드 목록 | 캐릭터·카드 해금에 따른 사용 가능 목록. 총량 제한 불필요 |
| 원정 전체 보관 | 새 상한 없이 유지. 대기 카드가 손패에 섞이지 않음을 명확히 표시 |
| 실제 전투 편성 | 우선 정확히 20장 유지 |
| 전투 손패 | 5장 유지 |
| 중복 | 일반 계열 3장·대표 기술 1장이라는 현재 규칙 유지. 강화 전후 합산 |
| 보상 풀 | 다음 검증에서는 세린 원정 보상 2종을 서로 다른 용도의 4~6종으로 확장하는 정도부터 검토 |
| 한 번의 보상 후보 | 풀이 커진 뒤 서로 다른 3종 중 1종 + 넘기기. 좁은 풀에서 억지로 3칸을 채우지 않음 |
| 6방의 획득 기회 | 현재 보스 전 2~4회는 무난. 3회 전후를 기본 시험 기준으로 삼고 경로 선택으로 증감 |

우선순위는 (1) 최종 보스 뒤의 무의미한 카드 교체 제거, (2) 같은 2종 반복 대신 보상 선택지 확장, (3) 일반전은 무작위 빌드 확장·강적은 핵심 보상·정비는 회복과 원하는 방향의 카드 선택으로 역할 구분, (4) 16장과 20장의 체험 비교다.

16장과 20장을 비교한다면 개별 시험마다 고정 장수를 사용한다. 16~20장 중 자유롭게 편성하는 규칙은 우선 도입하지 않는다. 현재는 카드를 더 넣는 보상이나 큰 덱의 별도 이점이 적어, 작은 덱만 선택하는 경향이 생길 수 있다. 실제 사용 카드 수·보상 카드 사용률·대표 기술 등장·원정별 덱 차이로 판단해야 한다.

이 수치는 조사에서 도출한 설계 제안이며 확정 밸런스가 아니다. 현재 보유량보다 보상 다양성과 카드가 전투에서 실제로 사용되는지가 우선 과제다.

Slay the Spire와 Monster Train의 상세 제거 규칙은 커뮤니티 규칙 자료로 확인했다. Monster Train의 오래된 가이드가 제시하는 선형 요금 증가는 상점 위키의 비용 표와 달라, 정확한 증가 규칙은 비교에 사용하지 않는다. Chrono Ark와 Across the Obelisk는 공식 개발자 패치에 명시된 범위만 주장한다. 각 게임의 최신 덱 추천 수치를 이 사례들로 확정하지 않는다.

현재 우리 게임에서는 보관 목록에서 삭제하지 않아도 대기 카드가 전투 덱에 섞이지 않는다. 따라서 덱에서 제외하는 기능만으로 이미 불필요한 카드의 등장 방지가 가능하다. 반대로 편성 덱은 정확히 20장이므로 카드를 제거하고 19장으로 싸우는 압축 효과는 없다. 이 조건에서 유료 삭제 노드를 만들면, 전투상 이득이 약한 보관 정리에 성장 기회를 지불하게 된다.

권장하는 현재 정책:

1. 새 카드 획득 시 기존 카드와 교체하거나, 대기로 보관하거나, 획득을 넘기는 선택을 유지한다.
2. 교체된 기존 카드는 기본적으로 대기 보관한다. 매번 보관/폐기 확인을 추가해 관전을 끊지 않는다.
3. 전투 사이 편성 화면에서 대기 카드만 무료로 폐기할 수 있도록 검토한다. 편성 중 카드는 먼저 교체하거나 대기로 빼야 하며 20장 조건을 유지한다.
4. 폐기는 이번 원정의 해당 복사본만 없앤다. 캐릭터·영구 기초 키트·카드 해금·발견 기록은 제거하지 않는다.
5. 폐기로 골드나 진화 재료를 지급하지 않는다. 정리가 매번 해야 하는 자원 획득 절차가 되는 것을 피한다. 다음 전투 시작 전 되돌리기를 제공하는 방식이 적절하다.
6. 총 보관량이 현재 최대 25장이라 폐기는 편의 기능이며, 유료 삭제·삭제 전용 방은 지금의 핵심 성장 수단으로 삼지 않는다.

현행 계열당 3장 제한은 편성+대기 합산 보유 수를 센다. 대기 카드를 폐기하면 그 계열의 보상 후보가 다시 열릴 수 있다. 이 동작을 허용할지, 계열 제한을 실제 편성 수에 적용할지는 별도 규칙이다. 현재 추천은 기존 합산 규칙을 유지하고 폐기 후 다시 획득하는 것을 허용하되, 편성에 들어가는 같은 계열도 3장을 넘지 않도록 하는 것이다.

나중에 덱 압축을 원정 성장 선택으로 삼으려면, 덱 장수 규칙과 함께 검증해야 한다. 그때는 최소 장수, 제거 기회, 회복·진화와의 기회비용을 설계할 수 있다. 지금 단계에서 자유·무제한 압축을 추가하면 적은 수의 강한 공격이나 회복만 반복하는 구성이 유리해질 수 있으며, 여러 캐릭터의 다양한 스킬을 보여주려는 목표와 충돌할 가능성이 있다.
