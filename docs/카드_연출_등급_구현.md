# 카드 연출 등급과 공통 처리기

적용일: 2026-10-06. 고정 4인 파티를 유지하고 연출 로드맵의 1~3단계를 적용했다. [원정](../prototype/character.html)과 [관전 체험](../prototype/spectator.html)에서 같은 처리기를 사용한다.

## 데이터와 등급

`presentation-data.js`에서 카드별 연출 등급·스타일·동작·색·사용 대사·초상화 경로를 정의한다. 피해·회복량·희귀도·기초/보상 구분과 독립적인 정보이며 전투 규칙 데이터나 저장 버전을 변경하지 않는다.

| 카드 | 등급 | 표현 |
|---|---|---|
| 간격 베기 | 기본 | 짧은 베기·타격 효과·사용 표시 |
| 빛을 좇는 걸음 | 강조 | 돌진 표현·사용 대사 |
| 받아치기 | 강조 | 반격 준비·사용 대사·실제 반격 동작 |
| 이어지는 섬광 | 강조 | 마무리·추가 추격 표현·사용 대사 |
| 너의 곁으로 | 강조 | 엄호·보호 표현·사용 대사 |
| 잔광 검무 | 대표 | 세린 초상화·사용 대사·준비 자세·서로 다른 3타·마무리 강조 |

나머지 현재 카드는 기본 등급의 공통 동작과 효과를 사용한다. 새 카드도 연출 프로필을 등록하고 해당 동작/효과를 연결하는 방식으로 확장한다. 새 캐릭터나 파티 편성은 추가하지 않았다.

## 실제 판정과의 연결

`SkillDirector`는 수락된 명령의 카드 ID·시전자·시각을 기준으로 연출을 시작한다. 거부된 명령은 연출을 만들지 않는다. 실제 타격·차단·대상 소실·시전자 전투불능 신호를 받아 준비·1타·2타·마무리·중단 표시를 갱신한다.

잔광 검무의 사용 대사는 **“한 줄기 빛이면 충분해.”**다. 기존 임시 벡터 일러스트를 초상화로 활용하고, 텍스트 대사와 기존 합성 효과음을 연결했다. 음성 녹음은 포함하지 않는다.

초상화·대사는 전장과 손패 밖의 고정 영역에 표시한다. 해당 영역의 크기를 유지해 스킬 사용마다 화면이 움직이지 않게 한다. 등장 진행은 시뮬레이션 시간으로 계산하므로 일시정지하면 함께 정지하고, 배속이면 짧아진다. 연출 완료를 기다리느라 전투를 멈추지 않는다.

타격 순간의 자세·궤적·반짝임·소리는 실제 판정을 따른다. 차단 또는 대상 처치로 후속 공격이 종료되면 가짜 나머지 타격을 재생하지 않는다. 전투 종료 후 준비 표시가 남지 않도록 연출을 정리한다.

## 반복 관전의 기본 제어

- 한 번에 하나의 사용 연출만 표시한다. 대표 연출 동안 낮은 등급의 안내가 이를 덮어쓰지 않는다. 해당 공격·회복의 전장 효과는 그대로 표시한다.
- 같은 명령을 다시 그려도 초상화와 대사를 다시 시작하지 않는다.
- **연출 전체/연출 간소**를 전투와 체험에서 전환할 수 있다. 간소 모드는 초상화·사용 대사·추가 반짝임을 생략하고 실제 타격·회복·보호 정보는 유지한다.
- 연출 상태·대사 재생 이력은 저장하지 않는다. 저장 복귀는 이미 지나간 초상화·대사를 재생하지 않고 예약된 실제 준비·타격을 이어간다.

## 검증

`skill-presentation-check.cjs`에서 등급 분리, 수락 신호, 실제 세 타격의 단계, 중복 방지, 우선권, 차단·대상/시전자 전투불능, 정지·복귀, 간소화 시 전투 상태 불변성을 검사했다.

`skill-presentation-browser-check.cjs`에서 1280×720·390×844의 실제 초상화 자산·텍스트 대사·전장 밖 배치·전체/간소 전환·실제 1타/2타/마무리를 확인했다. 원정의 수동 카드 확정과 시전 중 저장 복귀도 확인했고 브라우저 오류는 0건이다.

기존 관전·원정·다층 AI·전투 검사도 통과했다. 원정 검사 결과는 안전 경로 32회 완주, 강화·강적 경로 4/8로 이전과 동일하다. 현재 결과는 표현과 규칙의 동기화 검증이며 캐릭터 매력의 최종 평가는 실제 관전 감상으로 확인한다.

후속 작업으로 [반복·겹침 제어와 실제 결과 강조](카드_연출_후속_업데이트.md)를 적용했다. 정식 초상화·음성 제작은 별도 범위다.
