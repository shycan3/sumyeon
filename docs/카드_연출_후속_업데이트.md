# 반복 관전과 실제 결과 강조

적용일: 2026-10-06. [연출 등급 구현](카드_연출_등급_구현.md)에 이어 로드맵 4~5단계의 반복·겹침 제어, 결과 강조와 검증을 적용했다. 고정 4인 파티와 현재 카드·원정 범위를 유지한다.

## 연출 빈도와 저장

원정의 **설정·저장**, 체험의 **연출 설정**에서 다음을 선택한다.

| 설정 | 처리 |
|---|---|
| 매번 | 대표 기술을 사용할 때 초상화를 표시한다. 대사는 같은 기술 1.5초, 전체 0.8초의 최소 간격을 둔다. |
| 주요 장면 — 기본값 | 같은 캐릭터·기술의 초상화는 12초, 대사는 8초 간격으로 표시한다. 전체 대사 간격은 2초다. |
| 전투당 첫 사용 | 같은 캐릭터·기술의 초상화·대사는 전투당 처음 한 번만 표시한다. 새 전투에서 초기화한다. |

간격은 시뮬레이션 시간이다. 초상화나 대사를 생략해도 실제 준비·타격·차단·보호 정보와 사용 표시는 유지한다. 기존 **연출 전체/간소**도 함께 사용한다.

모드와 빈도는 별도 브라우저 키 `afterglow-presentation-v1`에 저장하고 원정과 체험에서 공유한다. 캐릭터 원정과 이전 게임 저장을 수정하지 않는다. 잘못된 연출 설정은 기본값으로 읽고, 저장 접근이 막히면 현재 세션에서 설정을 사용한다. 소리는 기존처럼 직접 켜며 자동 재생하지 않는다.

## 실제 결과 강조

- **처치:** 실제 전투불능 판정에서 생성한다. 반격의 처치도 실제 반격 시전자를 기록한다. 같은 순간 여러 적을 처치하면 한 알림으로 합친다.
- **추가 추격:** 유효한 대상에게 후속 타격이 성립한 경우에만 생성한다. 차단·대상 소실은 성공 알림이나 성공 횟수로 집계하지 않는다. 보호막에 흡수된 유효 타격은 성립한 공격으로 취급한다.
- **위기 회복:** 회복 직전 아군 HP가 최대 HP의 25% 이하이고 실제 회복량이 양수일 때 생성한다. 0 회복·사망한 대상은 강조하지 않는다. 사망을 막았다는 인과관계를 추정하지 않고 **위기 회복 +실제 회복량**으로 표시한다.
- **아군 전투불능:** 보호 중 쓰러진 경우도 실제 판정에 따라 표시한다.

알림은 기존 연출 영역 안에 표시한다. 대사·초상화가 전장과 손패를 가리지 않게 하며, 모바일에서도 차단·종료 원인은 텍스트로 유지한다.

## 겹침과 과거 연출 방지

대표 사용 연출은 낮은 등급 안내에 덮이지 않는다. 결과 알림의 우선순위는 아군 전투불능 → 위기 회복 → 추가 추격 → 처치다. 보조 대기는 최대 2개, 신선도는 1.4초로 제한하고 만료된 알림은 버린다. 같은 대상의 위기 회복 알림은 6초 간격을 둔다.

효과음은 한 번의 화면 갱신에서 최대 3개 사건만 선택하고, 같은 순간의 회복·보호 소리를 합친다. 실제 검무 타격·반격·위기 회복을 우선한다. 화면을 다시 그리거나 일시정지했다고 소리를 반복하지 않는다.

알림·대사 이력·재생 상태는 전투 저장에 넣지 않는다. 저장 복귀는 지나간 결과를 다시 강조하지 않으며 현재 실제 준비·공격은 이어간다. 표시 신호를 만드는 코드와 게임 판정의 상태를 분리했다.

## 검증

- `presentation-next-check.cjs`: 세 빈도 정책, 설정 복귀·저장 격리·접근 실패, 실제 처치/반격/위기 회복, 유효·차단·소실 추격, 알림 합치기·우선권·만료·소리 중복을 검사했다.
- 같은 세 체험 전투를 연출 신호 생성 켜기/끄기로 각각 진행해 최종 전투 스냅샷이 동일함을 확인했다.
- `presentation-next-browser-check.cjs`: 1280×720·390×844에서 공유 설정 저장·복귀, 실제 위기 회복 표시·원정 저장 보존·전장 범위를 확인했다. 오류 0건.
- 기존 카드 연출·관전·원정·다층 AI·전투 검사도 통과했다. 안전 경로 32회 완주와 강화·강적 경로 4/8 결과는 이전과 같다.

추가 추격 성공 횟수의 잘못된 집계만 수정했으며 피해·명령 회복·AI 선택·파티 편성은 바꾸지 않았다. 이전 저장의 과거 통계는 소급 변경하지 않는다.
