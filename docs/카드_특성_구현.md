# 카드 특성 첫 구현

2026-10-07. 대상: `prototype/character.html`, 오토 비교 체험. 모든 카드에 특성이 반드시 존재한다는 사용자 결정을 적용했다. 특성이 없는 중립 카드나 강화 예외는 없다.

## 집계와 카드 분류

현재 정의된 아군·기존 카드·적 기술 모두 정확히 한 특성을 갖는다. 데이터 생성, 카드 정의 조회와 덱 검증에서 특성 누락을 거부한다. 진화는 원본 특성을 유지한다.

특성 단계는 전투 편성 20장 안의 서로 다른 원본 카드 종류로 계산한다. 중복과 진화는 같은 1종, 대기·폐기 카드는 제외한다. 복제는 해당 카드의 등장 빈도를 바꾼다. 교전 중 캐릭터가 쓰러져 카드가 제외되어도 시작 시 특성 단계는 유지한다. 다음 전투의 단계는 변경된 편성에서 다시 계산한다.

| 특성 | 1/2단계 기준 | 현재 캐릭터 카드 |
|---|---|---|
| 호위 | 3 / 5종 | 차단 방패, 도발, 받아치기, 너의 곁으로, 위험 구역 구출 |
| 추격 | 3 / 4종 | 빛을 좇는 걸음, 간격 베기, 속사, 이어지는 섬광 |
| 공명 | 5 / 6종 | 방패 강타, 잔광 검무, 화살비, 집중 회복, 전체 회복, 긴급 재배치 |

기본 덱은 세 특성 모두 1단계다. 서로 다른 특성이 교차하도록 초기 배정을 좁게 유지했다. 기존 카드만으로 새 특성이 필요하지 않으며, 보상 카드 편성으로 2단계에 도달할 수 있다. 마지막 남은 기초 카드 종류를 빼면 다른 특성이 내려가는 대가가 있다. 수치와 기준은 첫 검증용이며 최종 밸런스 확정이 아니다.

## 실제 전투 규칙

- **호위:** 호위 카드가 보호한 아군의 피격·보호막 흡수 또는 차단 성공으로 8초 반격 준비를 얻는다. 다음 공격 카드가 실제 피해를 주면 준비를 소비하고 피해가 10% / 20% 강화된다. 준비 중 중첩·시간 재충전은 없다. 차단 카드를 준비만 했을 때 발생한 기본 공격은 보호 성공으로 세지 않는다. 일반 역할 AI의 피해 분담만으로 활성화되지 않는다.
- **추격:** 추격 카드의 실제 피해로 적에게 8초 표식을 남긴다. 다른 캐릭터의 단일 공격 카드가 표식을 우선하며, 같은 적에 실제 피해를 주면 10% / 20% 강화된다. 도발의 실제 대상 규칙을 따르고, 적 AI의 대상에는 아군 표식을 적용하지 않는다. 다른 적·같은 캐릭터·만료된 표식은 강화하지 않는다. 후속 카드도 추격이면 자신의 새 표식을 남길 수 있다.
- **공명:** 공명 카드가 성공했을 때 직전 성공 시전자와 다르면 축적된다. 1단계는 4회 후 다음 공명 공격·회복이 15% 강화된다. 2단계는 3회 후 25% 강화된다. 같은 시전자 반복, 체력이 가득 찬 대상의 무효 회복, 전투불능·취소·차단은 충전을 만들지 않는다. 재배치는 실제로 이동한 경우에만 축적한다. 충전 완료 후 재배치는 강화 충전을 소비하지 않는다.

강화는 동일 카드의 검무 후속 타격·처치 후 추가 추격까지 이어진다. 카드 종류에 따라 피해와 실제 회복량은 방어·보호막·남은 HP에 의해 제한된다. 여러 특성의 강화는 기본 효과에 가산하고, 새로운 명령·무료 카드·쿨타임 단축을 생성하지 않는다. 호위·추격의 계기는 서로 다른 특성 공격 카드에도 연결될 수 있다.

현재 시너지는 **아군 덱에 적용**한다. 적 기술도 특성을 보유하지만 적의 특성 단계와 추가 시너지는 아직 적용하지 않았다. 기존 적 패턴, 기본 AI 회피 정책, 수동 전환은 이번 작업에서 변경하지 않았다.

## 화면과 저장

기초 키트·덱·원정 보상·진화·발견 기록·손패에 특성 배지를 표시한다. 덱 편집은 종류 수와 단계, 구성 카드와 효과를 즉시 보여준다. 보상 교체 버튼은 실제 제거되는 카드 한 장을 기준으로 특성 종류 수와 단계 변화를 미리 표시한다. 전투에는 단계, 반격 준비, 추격 대상, 공명 충전과 실제 장면 기록을 표시한다. 추격 대상에는 전장 표식, 특성 발동에는 색상 텍스트를 표시한다. 결과 및 원정 보고에 특성 복기를 남긴다.

새 전투의 특성 상태·표식·충전·기록은 저장하며, 편성 카드 종류와 상태를 검증한다. 기록은 최근 40건, 시각 효과는 기존 한도를 유지한다. 재시작은 동일 결과를 재현한다. 업데이트 전 진행 중인 전투는 시너지 비활성 상태로 이관해 기존 전투 규칙을 보존하고 다음 교전부터 적용한다. 원정이 끝나면 특성 충전과 보상 카드가 함께 초기화된다.

오토 비교 체험에는 기존 편성 외에 추격·호위·공명 2단계 편성을 추가했다. 비교는 메인 원정 저장을 변경하지 않는다.

## 검증

- `card-traits-check.cjs`: 모든 카드 특성 필수, 중복·진화 집계, 두 단계 효과, 실제 보호와 추격 대상, 도발·진영 분리, 공명 검무 3타·회복, 무효·취소·차단·만료, 무료 명령 없음, 원정 초기화, 구 저장 이관, 손상된 상태 거부.
- 4전투 × 7편성 × 2방침 × 2시드 = **112쌍 / 224전투**. 특성 적용·미적용을 비교하고 적용 전투는 중간 저장 후 재생까지 일치하는지 확인했다. 시작 HP는 45%, 캐릭터 레벨은 1. 결과는 `prototype/card-traits-results.json`이다. 밸런스와 재미의 확정 근거로 사용하지 않는다.
- `card-traits-browser-check.cjs`: PC 1280×720 / 모바일 390×844의 모든 표시 카드, 편성 변경, 실제 보상 교체와 단계 전환, 전투 저장 복원, 결과 복기, 2단계 비교 체험. 오류·가로 넘침 0, 저장 격리 확인.
- 기존 `character-check`, `character-browser-check`, `effect-check`, `action-check`, `watch-frame-browser-check` 회귀 검사.

## 다음 판단

특성 단계 때문에 약한 카드를 넣기만 하는 편성이 우세한지, 세 특성 1단계가 너무 쉽게 동시에 활성화되는지, 특정 보상 카드를 무조건 골라야 하는지 실제 플레이로 확인해야 한다. 추가 특성·다중 특성 카드·연계 편집기를 늘리기 전에 이 세 특성의 행동 차이와 보상 선택을 다듬는다.
