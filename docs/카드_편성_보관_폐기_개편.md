# 카드 편성·보관·폐기 개편

20장 편성과 손패 5장, 현재 캐릭터·카드 종류·카드 수치는 유지했다. 앞선 레퍼런스 검토의 교체 중심 구조와 무료 대기 폐기를 적용했다. 보상 카드 종류 확장은 이번 개편에 포함하지 않는다.

## 실제 플레이 흐름

- 보상 후보를 선택하지 않고 넘길 수 있다.
- 획득한 새 카드를 기존 카드와 교체하면 다음 전투부터 등장한다. 빠진 기존 카드는 자동으로 대기 보관한다.
- 편성하지 않은 보상은 ‘편성하지 않고 대기 보관 · 다음 방으로’로 보관한다.
- 지도에는 편성 20장과 대기 장수를 따로 표시한다. 대기나 되돌릴 폐기가 있으면 ‘대기 카드 정리’로 관리 화면에 바로 이동한다.
- 대기 카드는 전투에 등장하지 않는다. 무료로 폐기할 수 있고 골드·강화 재료를 지급하지 않는다.
- 폐기는 이번 원정의 개별 복사본만 제거한다. 캐릭터·영구 기초 키트·발견 기록·레벨·경험치는 유지한다.
- 다음 전투가 시작되기 전까지 폐기를 되돌릴 수 있다. 중간 휴식·진화·정비 방이나 지도 이동, 저장 후 재개는 복원을 막지 않는다.
- 다음 전투 진입이 확정되면 복원 목록을 비운다. 전투 중에는 폐기·복원을 할 수 없다.

편성 중인 카드는 바로 폐기할 수 없다. 먼저 다른 카드로 교체하고 20장 편성을 확정한 뒤 대기 카드로 폐기한다. 편성 화면의 임시 변경을 취소해도, 별도로 실행한 폐기는 유지되고 폐기 되돌리기로 복구한다. 아직 교체·보관을 마치지 않은 최신 보상은 해당 보상 처리 화면에서 폐기하지 못하며, 보관 후 다음 방 지도부터 폐기할 수 있다. 이 안내를 화면에 표시했다.

## 중복 제한과 되돌리기

동일 계열의 편성+대기 합산 상한은 기존과 같다. 일반 카드 3장, 잔광 검무 1장이며 강화 전후를 합친다.

폐기된 카드는 현재 보유 수에서 빠져 같은 계열 보상 후보가 다시 열릴 수 있다. 그러나 이후 그 계열을 상한까지 다시 얻었다면 폐기를 되돌릴 수 없다. 이 경우 안내를 표시하고 현재 카드·편성·폐기 목록을 바꾸지 않는다. 다른 대기 복사본을 정리하면 다시 복원할 수 있다.

복원은 카드의 원래 ID, 기초/보상 출처, 소유 캐릭터, 진화 여부를 유지한다. 편성에 자동 삽입하지 않고 대기로 돌아온다.

## 최종 보스 보상

최종 보스 승리 후 ‘원정 완료 · 결과 보기’를 누르면 기존 경험치·발견 기록을 유지하고 원정 결과로 이동한다. 종료 직후 초기화될 카드를 새로 선택·교체하는 단계는 제거했다. 보스 처치 경험치는 기존 observe()에서 한 번만 지급하므로 완료를 눌러 추가 지급되지 않는다.

이전 저장이 최종 보스 보상·교체·진행 화면에 있던 경우에도 완료 버튼으로 결과를 볼 수 있다. 이미 획득했던 카드와 발견 기록은 완료까지 보존한다.

## 저장

기존 저장 키 afterglow-character-v2와 원정 규칙 버전 2를 유지했다. 원정의 선택적 disposals 필드에 복원할 복사본과 보관 순서를 저장한다. 이전 저장에서 해당 필드가 없으면 빈 목록으로 보충한다.

중복 카드 ID, 편성과 보관 목록에 동시에 존재하는 폐기 ID, 잘못된 소유 캐릭터·출처·진화 값·보관 위치와 전투 중 남아 있는 복원 목록은 저장 검사에서 거부한다. 기존 index.html의 저장과 규칙은 유지했다.
