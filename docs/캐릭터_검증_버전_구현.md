# 세린 캐릭터 검증 버전

적용일: 2026-10-06. 캐릭터 중심 설계를 비평한 뒤, 사용자가 제작 범위만 줄여 실제 구현하도록 요청했다.

[플레이하기](http://127.0.0.1:8765/character.html) · [설계](캐릭터와_원정_카드_설계.md)

## 제작한 범위

검사 원형 **세린** 한 명의 기초 카드 4종과 원정 보상 카드 2종, 임시 동료 세 명, 6개 방의 짧은 분기 원정을 구현했다. 기존 공용 덱 20장·손패 5장·명령 회복·수동·오토를 사용한다. 실시간 전투 엔진과 실제 카드 판정을 사용하며 미리 만든 승리 장면을 재생하는 방식이 아니다.

| 기초 카드 | 실제 행동 |
|---|---|
| 빛을 좇는 걸음 | 돌진 공격 후 2초 동안 지정한 적을 우선 추격 |
| 간격 베기 | 단일 공격 후 짧게 거리를 벌림 |
| 받아치기 | 자기 보호막과 4초 안의 반격 1회. 실제 공격한 적에게 반격 |
| 잔광 검무 | 한 명령으로 접근과 3타. 후속 타격은 추가 카드를 소비하지 않음 |

| 원정 보상 | 실제 변화 |
|---|---|
| 이어지는 섬광 | 부상 적 마무리. 처치하면 다른 적에게 추가 돌진 1회. 연쇄 무한 발동 없음 |
| 너의 곁으로 | 동료 곁으로 이동해 5초 엄호. 가까운 대상의 피해 25%를 대신 받고 반격 1회 |

기초 키트에는 대표 기술을 포함했다. 은빛 머리·붉은 스카프의 임시 벡터 일러스트와 전장 캐릭터 표현, 스카프·검 동작, 검무·반격 궤적, 엄호 연결과 대사를 표시한다. 최종 서브컬쳐 아트나 정식 3D 애니메이션의 완성을 뜻하지 않는다. 음성·효과음은 이번 범위에 포함하지 않았다.

세린의 캐릭터 ID에 기초·보상 카드와 태세를 연결한다. 호위 태세는 위험한 동료 주변의 적을, 추격 태세는 부상 적을 고려한다. 엄호 목적이 유지되는 동안 동료를 따라가며 일반 이동이 이를 즉시 되돌리지 않는다. 기간 종료·대상 전투불능 후 기존 태세로 복귀하고, 다른 이동 카드 사용은 목적을 대체할 수 있다.

오토는 반격의 위협, 엄호 대상·남은 목적, 마무리 후 추가 추격, 검무의 여러 타격을 평가한다. 수동과 같은 카드·대상·시간·효과를 사용하고 직접 개입을 지원한다. 캐릭터별 태세는 플레이어가 정한다.

## 원정과 카드 수명

`교전 → 휴식/진화 → 교전 → 정비 → 강적/휴식 → 보스`

정비는 보상 카드 선택 또는 생존자 HP 15% 회복이다. 휴식은 30% 회복과 전투불능 복귀를 제공한다. 기초 카드로 출발하고, 획득 카드는 다음 전투에 편성한다. 빠진 카드는 이번 원정의 대기 목록에서 다시 넣을 수 있다. 카드 한 장씩 원정 내 최대 한 번 진화하며, 빼고 넣어도 인스턴스의 진화 상태를 유지한다.

캐릭터와 기초 카드의 사용권은 유지한다. 기초 덱은 복사본을 영구 수집하지 않고 계열 상한 안에서 편성한다. 보상 후보는 세린의 두 보상 카드로 제한하며, 덱과 대기 목록을 합쳐 계열별 3장에 도달하면 후보에서 제외한다. 후보가 두 장보다 적으면 있는 만큼 보여주고, 모두 소진했거나 필요하지 않으면 넘길 수 있다.

성공·패배·중도 귀환 모두 보상 카드와 진화를 초기화한다. 완료한 전투의 경험치와 카드 발견 기록은 남는다. 레벨 변화의 성능은 다음 원정에서 반영한다. 발견 도감은 사용권이 아니며 보상 카드를 다음 판의 기초 덱에 넣을 수 없다. 이어하기에는 현재 원정의 카드·진화·HP·지도·전투·난수가 유지된다.

## 기존 버전과 저장

새 버전은 `character.html`과 `afterglow-character-v2` 저장을 사용한다. 기존 `index.html`의 원정과 `afterglow-expedition-v1` 저장은 계속 사용할 수 있다. 기존 화면 아래에 새 버전 링크를 추가했다. 서로 다른 저장을 덮어쓰지 않는다.

새 저장이 없고 유효한 기존 저장이 있으면 역할별 레벨을 해당 기본 캐릭터로 연결한다. 영구 카드·조각은 새 카드 사용권이나 재화로 환산하지 않는다. 기존 진행 중 원정은 이전 화면에서 그 규칙으로 이어갈 수 있다. 새 버전의 저장 다운로드·불러오기도 지원한다. 잘못된 저장은 조용히 초기화하지 않고 복구 필요 안내와 원본 다운로드를 제공한다.

보유 캐릭터는 기본 제공 4명으로 고정한 검증 범위다. 추가 캐릭터 구매·해금·판매 화면, 두 번째 고유 캐릭터, 새로운 보스 기믹은 이번 범위에 넣지 않았다.

## 검증과 한계

실제 엔진에서 시드 1~8, 레벨 1·동일 기초 덱으로 보상 두 운영 × 수동 검사 봇/오토 × 8회, 총 32회 안전 경로 원정을 진행했다. 모두 완주했다.

| 운영 | 모드 | 완주 | 추가 추격 | 엄호한 실제 피해 합 | 반격 | 검무 타격 |
|---|---|---:|---:|---:|---:|---:|
| 추격 | 오토 | 8/8 | 7 | 0 | 1 | 39 |
| 추격 | 수동 검사 봇 | 8/8 | 8 | 0 | 1 | 39 |
| 엄호 | 오토 | 8/8 | 0 | 127.8 | 19 | 40 |
| 엄호 | 수동 검사 봇 | 8/8 | 0 | 130.6 | 19 | 37 |

수동 검사 봇은 정지 상태에서 점수에 따라 카드를 선택하는 도구이며 인간 플레이가 아니다. 반격 집계에는 기초 받아치기도 포함한다. 안전 경로는 휴식 두 번과 정비 카드 선택을 사용한다. 카드 선택에 따라 추가 추격과 엄호·반격이라는 다른 실제 효과가 발생했음을 확인했다.

진화와 강적을 택한 추가 위험 경로 8회는 2/8 완주했다. 짧은 원정에서도 회복 대신 위험을 택하면 난도가 높다. 이 결과는 카드 운영 차이와 진행을 검증한 수치이며 최종 밸런스나 캐릭터의 매력을 입증하지 않는다.

규칙 검사에서 자기 대상·동료 대상 유효성, 반격 1회·정확한 공격자, 제한된 추가 추격, 엄호 이동 유지·복귀, 검무 3타·명령 한 번 소비·차단, 진화·보상·덱 상한, 성공·패배·귀환 초기화, 발견 기록과 소유 구분, 저장 후 동일 진행과 잘못된 저장 거부를 확인했다.

별도 브라우저에서 1280×720·390×844의 실제 카드 조작, 개입·복귀, 저장 후 이어하기, 보상 편성과 실제 사용, 정비·보스 완주·다음 원정 초기화·발견 기록을 확인했다. 전장·손패·개입 버튼이 화면에 들어오고 가로 넘침·브라우저 오류가 없다. 기존 저장 보존과 이전 게임의 수동·오토 규칙 검사도 통과했다.

```powershell
node prototype/character-check.cjs
node prototype/character-browser-check.cjs
node prototype/smoke.cjs
```

브라우저 검사는 정적 서버 `http://127.0.0.1:8765/`와 현재 PC의 Playwright 런타임을 사용한다. 다음으로 확인할 것은 실제 관전에서 세린의 개성과 대표 기술이 충분히 느껴지는지, 보상 카드 한 장의 변화가 눈에 들어오는지다.
