# 기존 캐릭터 빌드 분화 · v7 2단계 검증

적용일: 2026-10-09 · 플레이 버전: `noabuild1`

## 적용 범위

노아의 기존 기초 키트는 유지하고 원정 전용 보상 두 장으로 운용을 넓혔다. 새 성장 메뉴나 캐릭터별 전용 오토 엔진은 추가하지 않았다. 두 카드를 함께 편성할 수도 있지만, 각각 덱 한 자리와 명령 시간을 사용한다.

| 보상 | 행동 변화 | 비용 |
| --- | --- | --- |
| 네 곁의 피난처 · 호위 | 동료 곁으로 이동, 보호막 22, 4초간 보호막을 뚫은 피해 25% 분담, 반격 8 한 번 | 노아도 전열 위험에 노출, 다음 명령 5.5초. 기존 보호막은 24 / 4.5초 |
| 온기가 머무는 자리 · 공명 | 완료 시 노아 반경 170 안의 살아 있는 아군을 각각 26 회복 | 먼 동료 제외, 다음 명령 6.5초. 기존 전체 기도는 거리 제한 없이 18 / 7초 |

두 카드 모두 보상 전용, 사본 상한 1장이다. 노아 없이 출현하거나 다른 지원가가 사용하는 경우를 막았다. 새 일러스트, 특성, 대사, 중요도 연출, 보상 비교, 실제 효과 통계, 연습에 연결했다. 보상 선택 직후 접힌 상세를 열지 않아도 운용과 비용의 짧은 설명이 보인다. 출발 덱은 여전히 작은 봉합과 선제 보호로 작동한다.

공유 `coverWard`와 `circleHeal` 실행 및 현재 대상·현재 위치에 따른 오토 평가를 사용한다. 새 미래 예측이나 위험 구역 자동 회피는 넣지 않았다. 배치 비교의 주변 회복 집계도 의무관 한 카드에 한정되지 않도록 수정했다.

## 같은 조건 전투 비교

`prototype/noa-build-study.cjs` → `noa-build-results.json`.

- 새 보상을 무조건 기본 보호막보다 좋은 카드로 만들지는 않았다. 기존 보호막 유지가 이 표본에서는 가장 많이 이겼다.

이는 특정 만전 교전의 비교이며 실제 원정 완주율·낮은 레벨·최적 덱의 균형을 뜻하지 않는다. 비교 카드를 뽑지 못하거나 사용하지 않은 전투도 포함한다. 한 장 보상이 모든 교전에서 장면을 바꾼다고 주장하지 않는다.

## 기존 세린 운용 확인

같은 레벨 3 공명 출발 덱과 보스에서 일반/수호 검무를 시드 7/37/63으로 비교했다.

시드 37에서 일반 검무 실제 피해 63, 수호 검무 47.88과 보호막 20을 확인했다. 일반은 궁극기 준비 31.12초 / 사용 0회, 수호는 궁극기 1회였으며 종료 HP는 약 256.65 / 310.34였다. 나머지 두 시드는 검무 미사용으로 차이가 없었다. 유리한 장면이 나오지 않으면 분기 차이도 드러나지 않는다는 한계다.

기존 추격 릴레이 검사의 288교전에서 표식 전달 50회, 연계 8회를 확인했다. 전달과 명령 시간의 비용, 후속 타격 재귀 방지, 저장·연습을 유지했다. 호위·추격·공명 오토의 기존 240쌍 검사도 통과했다. 모든 준비를 한꺼번에 바꾼 승률로 특정 특성의 우열을 단정하지 않는다.

## 호환성과 검사

- 새 정상 원정에만 보상 규칙 `buildRulesVersion:1` 적용. 이전 진행 중 원정은 필드 없음/0을 유지하며 두 새 카드가 후보에 섞이지 않는다.
- 공개 도전과 격리 제작 체험은 기존 보상 규칙 유지. 보상은 원정 종료 후 초기화된다.
- 저장·전투 시작 기록·연습 기록·원정 보고서의 버전과 카드 소유·사본 상한을 검사한다. 버전 없는 기록에 새 카드를 끼워 넣으면 거절한다.
- 공유 기술 등록이 제작 원본 JSON을 변경하지 않도록 카드 정의를 복사한다.
- 효과 실행 중 저장·복원과 이후 전투 상태의 완전 일치, 범위 경계/범위 밖/전투불능 대상, 실제 이동·흡수 후 분담·반격을 검사했다.
- 기존 96개 전체 전투 기록 비교, 회복 판단, 성장 비용, 발견, 제작 정의 거절, 보상 교체 기능, 배치 비교, 궁극기 원정 검사를 통과했다.
- 1280/390 화면에서 실제 승리 보상으로 두 카드가 출현하는 시드 6/641439를 찾아 선택·그림·비용 표시·교체·새로고침을 검사했다. 가로 넘침과 브라우저 오류가 없고 화면을 직접 확인했다.
- release6 전체 진행 검사는 옛 보상 규칙을 명시한 고정 시나리오로 1280/390/320에서 통과했다. 새 보상으로 그 고정 선택을 반복했을 때의 완주 실패를 숨기거나 원정 성공을 보장하지 않는다. 새 보상 획득·교체·복원은 별도 새 규칙 검사다.
- 1단계 연구 스크립트는 당시 보상 규칙 0을 명시해 과거 측정의 재현 조건을 유지했다.

## 남은 확인과 다음 단계

로그 없이도 밀착 이동과 회복 범위 차이가 눈에 들어오는지, 보상을 포기하는 선택이 납득되는지는 실제 플레이 피드백이 필요하다. 낮은 레벨·노아+리아·원정 누적 소모에서의 조정도 이 비교만으로 완료했다고 보지 않는다.
