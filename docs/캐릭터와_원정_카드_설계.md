# 캐릭터와 원정 카드 설계 v1.0

작성일: 2026-10-06. 캐릭터 중심의 관전 전투와 원정 한정 카드 성장에 맞춘 최신 설계다. 기존 문서의 영구 보상 카드 수집·확보·조각 규칙을 대체한다. 비평 후 범위를 줄인 [세린 캐릭터 원정](../prototype/character.html)을 제작했으며, 실제 적용 범위는 [구현 기록](캐릭터_검증_버전_구현.md)을 따른다. 아래 전체 설계와 첫 검증 버전의 완성 범위를 구분한다.

## 1. 게임의 중심 경험

매력적인 캐릭터를 보유하고, 파티를 편성해 스스로 움직이며 고유한 카드 기술로 적을 처치하는 모습을 구경한다. 필요할 때 카드 한 장으로 전황을 바꾸고, 보상 선택으로 이번 원정의 전투 방식을 발전시킨다.

영구적으로 쌓이는 중심은 캐릭터와 그 캐릭터의 기초 키트다. 보상 카드는 원정 안에서 얻고 원정 안에서만 사용한다. 같은 캐릭터로 시작해도 획득 카드·진화·동료 조합에 따라 다른 장면과 운영을 만든다.

이 문서에서 **원정 한 번**이 한 판이다. 전투 한 번마다 보상 카드를 지우지 않는다. 여러 전투를 진행하거나 같은 원정을 저장 후 이어 할 때는 유지하고, 성공·실패·자발적 귀환으로 원정이 종료되면 초기화한다.

## 2. 결정의 지위

| 구분 | 내용 |
|---|---|
| 사용자 방향 | PvE, 기본 행동과 카드 행동, 캐릭터의 자동 이동, 공용 덱·명령, 카드 중심 개입 |
| 사용자 방향 | 캐릭터마다 고유 특성·기본 행동·전용 카드가 다르고, 매력적인 캐릭터 보유와 판매를 지향 |
| 사용자 방향 | 기초 카드와 플레이 보상 카드를 구분하고, 보상 카드는 매판 초기화하는 방향으로 고도화 |
| 사용자 방향 | 이동도 카드 행동으로 처리하고, 카드 사용 후 목적을 유지하다 기존 태세로 복귀 |
| 기존 방향 유지 | 후보 선택형 보상, 다음 전투부터 사용, 덱 장수 제한과 캐릭터별 자유 비율, 개별 카드의 원정 한정 1회 진화, HP·전투불능 유지 |
| 구현된 운영 | 선택형 오토·수동, 오토 중 일시 개입·복귀, 현재 손패·공개 전황으로 카드 판단, 플레이어 태세 유지 |
| 설계자가 채운 초안 | 한 판의 범위는 원정 1회, 캐릭터 획득 시 기초 키트 전체 사용, 파티 4명·덱 20장·손패 5장, 파티 고정, 보상 3장 중 1장 |
| 별도 중요 결정 | 캐릭터 획득·판매 방식, 영구 육성의 최종 범위, 첫 출시의 캐릭터 수·플랫폼·제작 규모와 시각적 분위기 |

새 방향은 이전의 ‘캐릭터 성장의 중심은 영구 카드 수집’이라는 규칙을 대체한다. 카드 진화가 출정 한정이라는 기존 합의는 그대로 유지한다. 캐릭터 레벨은 상한이 있고 비교적 쉽게 육성하는 방향을 유지하며, 정확한 상한 5는 기존 검증용 숫자다.

## 3. 캐릭터는 하나의 완성된 전투 경험

캐릭터 하나는 다음 요소를 함께 가진다.

| 구성 | 설계 내용 |
|---|---|
| 정체성 | 이름·외형·성격·동기와 짧은 개인 이야기 |
| 행동 | 기본 공격·이동·표적 우선순위·동료 보호 방식 |
| 태세 | 오래 유지하는 두 행동 방침. 캐릭터마다 판단 내용이 다름 |
| 기초 카드 | 획득 즉시 사용할 수 있는 대표 스킬·이동과 기본적인 전투 기능 |
| 원정 보상 풀 | 해당 캐릭터의 이번 판 운영을 발전시키는 전용 카드 |
| 표현 | 카드 그림·시작 자세·이동·타격·마무리·효과음·표정·대사 |
| 편성 가치 | 어떤 동료·카드·적 구성에서 특징이 잘 드러나는지 |

방패병·검사·사수·지원가 같은 직업은 역할을 설명하는 태그로 남긴다. 실제 행동·카드·스탯은 캐릭터 ID에 연결한다. 같은 근접 태그라도 부상자를 추격하는 검사와 동료 곁에서 반격하는 검객은 다른 행동과 전용 카드를 가진다. 복수 역할 태그도 허용한다.

캐릭터 획득 시 기초 카드 전체의 사용권을 제공하는 초안이다. 기본 카드 복사본을 별도로 수집하거나 동일 캐릭터를 여러 번 얻어 덱 수량을 확보하는 규칙은 두지 않는다. 출발부터 대표 스킬을 볼 수 있도록 하고, 보상은 이를 확장한다.

새 캐릭터의 차이는 행동·카드 조합·편성·연출에서 만든다. 기존 캐릭터의 카드와 AI에 피해 수치만 높인 캐릭터로 대체하는 방식은 첫 설계 목표에 맞지 않는다.

## 4. 기초 카드와 보상 카드

| 항목 | 기초 카드 | 보상 카드 |
|---|---|---|
| 권한 | 캐릭터 획득과 연결 | 현재 원정의 획득 기록과 연결 |
| 출발 시 편성 | 편성한 캐릭터의 기초 카드로 구성 | 불가 |
| 획득 경로 | 캐릭터 기초 키트 | 전투 승리 보상·보상 방 |
| 목적 | 그 캐릭터다운 기본 전투와 대표 장면 제공 | 운영의 분화·연계·강한 기술·새로운 장면 제공 |
| 전투 사이 | 출정 카드 인스턴스 유지 | 획득한 카드 인스턴스 유지 |
| 원정 종료 | 기본 정의와 편성 권한 유지 | 사용권·인스턴스 초기화 |
| 진화 | 개별 인스턴스마다 이번 원정 최대 1회 | 동일 |

비평 후 첫 제작 범위는 **캐릭터 한 명의 기초 카드 4종, 보상 카드 2종**으로 줄였다. 보상 한 장의 체감을 먼저 확인하고, 6종의 운영 분화는 이후 확대 예시로 둔다. 종류 수는 제작 범위를 조절할 수 있는 숫자다. 초기에 기본 카드만으로 캐릭터의 대표 액션과 역할이 성립해야 한다.

보상 카드는 다음을 섞는다.

- **운영을 여는 카드:** 추격·반격·보호 등 이번 원정의 다른 전투 방식을 시작한다.
- **조합을 잇는 카드:** 이미 선택한 운영이나 동료의 행동과 연결된다.
- **강한 기술:** 조건·준비·긴 명령 회복과 함께 큰 장면과 효과를 제공한다.

보상 카드가 항상 모든 기초 카드의 단순 상위 호환이면 선택과 캐릭터 개성이 약해진다. 기초 카드의 짧은 회복·안정적인 방어·대표 이동 등 유효한 쓰임을 유지한다. 발견한 보상 카드를 도감에서 볼 수 있어도 다음 출정의 시작 덱에 넣을 수는 없다.

## 5. 파티와 출발 덱

보유 캐릭터 중 4명을 선택하고 그 캐릭터들의 기초 카드로 20장 공용 덱을 만든다. 처음에는 기본 제공 캐릭터 4명으로 파티를 완성할 수 있도록 하는 초안이다. 출정 중 파티는 고정한다.

캐릭터별 카드 비율은 자유다. 추천 시작 구성은 캐릭터당 5장이지만 의무는 아니다. 0장 편성도 기존 초안을 유지하며, 해당 캐릭터는 기본 행동과 태세로 싸운다. 편성 화면에서 카드 기술이 손패에 등장하지 않는다는 사실을 보여준다.

기초 카드는 종류별 장수 제한 안에서 시작 덱의 복사본을 생성한다. 일반 계열 최대 3장, 강한 특수 계열 최대 1장을 기존 검증값으로 사용한다. 강화 전후는 같은 계열로 합산한다. 카드의 획득·진화는 별도 인스턴스로 식별하고 동일 인스턴스를 여러 슬롯에 넣지 않는다.

출정 후 편성 후보는 **시작 때 실제로 가져온 카드와 이번 원정에서 얻은 카드**다. 출발 덱에 없던 다른 기초 카드를 도중에 새로 생성하는 기능은 두지 않는다. 현재 덱에서 빠진 카드는 이번 원정의 대기 목록에 남아 전투 사이에 다시 넣을 수 있다. 진화한 카드를 빼고 다시 넣어도 그 인스턴스의 진화는 유지한다.

새 카드를 넣으면 기존 한 장을 빼 총 20장을 유지한다. 다른 캐릭터의 카드끼리 교체할 수 있다. 전투 중에는 손패 교체 기능만 사용하고, 출정 덱 재편성은 전투 사이에 한다. 손패 교체 2회는 오토와 플레이어가 공유한다.

## 6. 보상 후보와 선택

기본 보상은 서로 다른 후보 3장 중 1장이다. 후보는 현재 파티의 **원정 보상 카드**에서 뽑는다. 캐릭터를 보유하고 편성하면 그 캐릭터의 보상 풀이 열리지만, 개별 카드의 영구 소유권이 생기지는 않는다.

후보 생성은 다음 순서를 초안으로 둔다.

1. 현재 파티가 사용할 수 있는 카드만 포함한다.
2. 현재 덱과 대기 목록을 합쳐 같은 계열이 일반 3장·특수 1장에 도달한 카드는 제외한다. 진화 여부를 합산하며, 이번 원정의 카드 보유 상한과 덱 편성 상한에 같은 숫자를 사용하는 초안이다.
3. 생존 캐릭터의 유효 후보가 있으면 최소 한 장 포함한다. 전투불능 캐릭터의 카드는 복귀를 계획하는 선택으로 나올 수 있다.
4. 현재 조합과 연결되는 후보, 다른 운영을 여는 후보, 나머지 유효 후보를 섞는다. 전체 후보를 현재 덱의 정답으로만 채우지 않는다.
5. 아직 선택하지 않은 운영도 다시 등장할 수 있게 해 초반 한 번의 선택으로 이후 보상을 고정하지 않는다.

보상 획득 후에는 다음 전투부터 편성 가능하다. 즉시 기존 카드와 교체하거나 이번 원정의 대기 목록에 보관할 수 있다. 후보가 마음에 들지 않으면 보상을 넘길 수 있다. 유효 후보 수가 3장보다 적으면 있는 만큼만 제시하며, 중복 후보로 자리를 채우지 않는다. 모든 유효 후보를 소진했으면 카드 보상을 건너뛰고 다음 방으로 진행한다.

방문 ID·보상 ID·후보·선택 결과를 저장한다. 보상 화면 재진입이나 새로고침으로 다시 추첨하거나 두 번 받지 않는다. 기초 카드 복사본 생성, 보상 인스턴스 획득, 전투 드로우는 서로 다른 처리다.

보상 카드와 원정 진화는 플레이에서 얻는 규칙으로 둔다. 이 설계에는 보상 카드 판매·유료 보상 재추첨·유료 원정 진화가 포함되지 않는다. 캐릭터의 획득·판매 방식은 별도 결정 사항이다.

## 7. 원정의 흐름과 정산

`보유 캐릭터·기초 덱 편성 → 원정 → 전투 관전·필요 시 개입 → 보상 카드 선택·덱 교체 → 경로·회복·진화 → 보스 → 결과·캐릭터 기록 → 새 원정`

전투 사이 HP와 전투불능을 유지한다. 회복 방의 30% 회복·복귀, 카드별 명령 회복·대상·방어 규칙 등 기존 전투 베이스는 검증용 출발점으로 유지한다. 레벨은 출정 시작 시 상태를 사용하고, 완료한 전투의 캐릭터 경험치는 다음 출정의 육성에 반영한다.

| 상태 | 같은 원정의 다음 전투·이어하기 | 원정 종료 후 |
|---|---|---|
| 보유 캐릭터·기초 카드 권한 | 유지 | 유지 |
| 캐릭터 레벨·완료한 전투의 경험치 | 기록 유지 | 유지 |
| 기초 카드의 출정 인스턴스 | 유지 | 정리, 다음 출발 때 새로 생성 |
| 보상 카드·대기 목록 | 유지 | 모두 정리 |
| 카드 진화 | 유지 | 모두 초기화 |
| HP·전투불능 | 유지 | 다음 원정은 전원 최대 HP로 시작 |
| 손패·버림패·게이지·전투 상태 | 한 전투 안에서 유지 | 다음 전투 시작 시 초기화 |
| 지도·후보·선택·난수·전투 시각 | 이어하기에서 유지 | 새 원정에서 생성 |
| 카드 발견·교전·완주 기록 | 기록 | 유지, 카드 사용권은 제공하지 않음 |

성공·패배·자발적 귀환 모두 보상 카드와 진화를 정리한다. 성공했을 때도 보상 카드를 영구 반출하지 않는다. 게임을 종료하고 저장된 원정을 이어 하는 것은 귀환이 아니다.

승리한 전투의 경험치는 편성한 캐릭터 전원에게 지급하며, 전투불능 여부로 제외하지 않는 초안이다. 패배한 전투는 경험치를 지급하지 않는다. 승리 때 확정한 경험치와 기록은 나중에 원정에 실패해도 유지하고, 레벨 변화의 전투 성능은 다음 원정부터 적용한다. 보스 완주 보상은 완주 기록·캐릭터 경험치·이야기나 감상 콘텐츠 해금으로 설계하며, 정확한 콘텐츠 범위는 별도 결정한다. 반복 가능한 영구 전투력 강화층을 당장 추가하지 않는다.

## 8. 기존 확보 지점과 조각의 대체

새 규칙에서는 **영구 카드 확보·미확보 카드·초과 복사본 조각·조각 카드 교환·조각으로 첫 손패 예약**을 사용하지 않는다. 보상 카드를 잠시 영구 보존하거나 다음 판에 예약하는 예외도 두지 않는다.

기존 10개 방 구조는 검증 출발점으로 유지한다. 4·8번째 확보 지점은 중간 **정비 방**으로 바꾸는 초안이다. 원정 보상 카드 한 장 선택 또는 생존자 HP 15% 회복 중 하나를 제공한다. 정비 회복은 전투불능 복귀를 제공하지 않고, 복귀는 기존 회복 방이 맡는다. 실제 위치·방 수·회복량은 원정 난이도를 보며 조정한다.

전투·강적·보상·회복·진화·정비·보스를 지도에서 구분한다. 비전투 방만 이어서 보스를 만나는 경로는 만들지 않고, 피해를 입은 뒤 회복 기회를 고를 수 있는 경로를 보장하는 기존 원칙을 유지한다.

원정을 반복하는 목적은 캐릭터 경험, 새로운 동료 조합, 다른 보상 운영, 구역과 이야기 진행에 둔다. 카드 발견 도감과 스킬 연출 감상은 지난 플레이의 기록으로 남길 수 있지만 출발 덱의 소유권과 구분한다.

## 9. 오토·개입·이동·기믹

오토도 현재 손패·공개된 전황·캐릭터의 카드 연계로 판단한다. 적의 숨겨진 손패·다음 보상을 참고하지 않는다. 카드 소유와 비용·명령 회복·이동·피격 규칙은 수동과 같다. 플레이어가 정한 태세는 오토가 임의로 변경하지 않는다.

캐릭터별 고유 특성은 오토에서 실제 판단 차이를 만든다. 추격자는 지정한 적의 마무리를, 보호자는 부상자 엄호를, 반격자는 위험한 공격을 받아칠 기회를 고려한다. 기초 키트와 보상 운영을 자동 판단이 이해해야 관전에서도 선택한 캐릭터의 개성이 유지된다.

이동 카드는 대상과 목적을 선택한다. 돌진은 적에게 접근해 공격하고, 엄호는 동료 곁에서 보호하고, 후퇴는 위험과 거리를 벌린다. 카드 실행 중 이동 목적을 우선하고, 종료 후 짧은 목적 유지 시간을 거쳐 기존 태세로 복귀한다. AI가 즉시 원래 위치로 돌아가 효과를 없애지 않도록 목적 유지 조건과 종료 시점을 카드에 정의한다.

이동 목적의 처리는 다음 초안으로 통일한다.

- 시전자가 전투불능이면 이동과 목적을 종료한다. 소비한 명령은 반환하지 않는다.
- 목표가 전투불능이거나 무효해지면 그 목표에 대한 목적을 종료한다. 다른 대상으로 임의 변경하지 않는다. 처치 후 연계가 있는 카드는 명시된 추가 효과로 별도 처리한다.
- 목적지에 도착해도 엄호·후퇴의 유지 시간이 남으면 해당 위치의 행동 방침을 유지한다. 기간 또는 카드에 표시된 종료 조건을 충족하면 기존 태세로 복귀한다.
- 이동이 없는 새 카드는 현재 위치에서 목적을 유지하며 실행한다. 새로운 이동을 포함하는 카드는 기존 목적을 대체할 수 있다는 사실을 표시하고, 명령 확정 시 교체한다.
- 오토는 엄호의 효과와 남은 목적을 평가해 기본 이동이나 효과 없는 새 이동으로 즉시 취소하지 않는다. 이동을 포함한 새 카드를 선택할 때 현재 목적을 끝내는 손익까지 평가한다. 플레이어도 같은 대체 규칙을 사용한다.

보스 기믹의 첫 초안은 **큰 공격 예고 → 공격 실행 → 잠깐 노출**이다. 차단·지연·회복으로 대응하고, 노출 때 강한 카드를 맞출 수 있다. 오토도 기본 규칙을 읽고 대응하며, 플레이어는 다음 위험이나 노출을 예상해 명령을 남겨둘 수 있다. 필수 이동 입력을 요구하는 기믹은 첫 범위에 넣지 않는다.

오토의 목표는 편한 관전과 기본 대응이다. 숙련자의 개입 이득은 명령 보유·집중 대상·연계·다음 전투의 HP 보존에서 만들고, 적의 기믹을 일부러 무시하게 해 차이를 만들지 않는다.

## 10. 한 캐릭터의 검증 예시

아래는 최종 캐릭터 설정이나 출시 카드 목록이 아닌 **검사 원형 A**의 제작 예시다. 이름·외형·세계관은 별도 결정한다.

**개성:** 지정한 적을 놓치지 않는 추격자이며, 위험한 순간에는 동료 곁에서 공격을 받아친다. 추격 태세는 지정한 적 접근과 마무리를, 호위 태세는 가까운 부상자 주변의 적 견제를 우선한다.

| 기초 카드 | 행동과 관전 장면 |
|---|---|
| 돌진 | 지정한 적에게 접근하며 베기. 잠시 해당 적을 우선 추격 |
| 간격 베기 | 짧게 위치를 조정하며 안정적인 단일 공격 |
| 받아치기 | 잠시 피해를 줄이고 다음 유효 피격에 반격 1회 |
| 잔광 검무 | 캐릭터의 대표 연속 공격. 시작 자세·연속 타격·마무리를 연결 |

추천 출발 배분은 돌진 2장과 나머지 각 1장으로 총 5장이다. 대표 기술을 한 장 편성하는 제한은 검증 초안이다.

| 보상 운영 | 카드 예시 | 이번 판의 변화 |
|---|---|---|
| 추격·마무리 | 잇는 돌진 | 적 처치 시 가까운 적에게 추가 접근·약한 베기 1회 |
| 추격·마무리 | 노리는 칼끝 | 한 적에 표식을 남겨 자신과 동료의 집중 공격 연결 |
| 추격·마무리 | 도약 베기 | 접근 후 좁은 범위 공격으로 적 배치를 활용 |
| 엄호·반격 | 엄호 걸음 | 선택한 동료 곁으로 이동해 잠시 보호 |
| 엄호·반격 | 함께 받아치기 | 아군을 지정해 짧은 엄호 연결을 만들고, 대상이 공격받으면 검사도 반격 1회로 호응 |
| 엄호·반격 | 긴급 이탈 | 위험한 적과 거리를 벌리고 짧은 보호막 획득 |

이 운영들은 강제 분기가 아니다. 한 원정에서 양쪽 카드를 섞을 수 있다. 보상 카드 한 장은 기초 키트만으로도 쓸 수 있게 설계하고, 다른 보상과의 조합은 효과를 확대하는 선택으로 둔다. 추가 타격과 반격은 발동 횟수·대상·기간을 명시하고, 공용 명령을 무한 생성하거나 회복시간을 반복 초기화하지 않는다.

캐릭터별 스킬은 준비 자세·이동·타격·피격·마무리가 읽히게 만든다. 보호와 회복은 시전자와 대상의 관계를 보여주고, 대표 스킬은 짧은 강조 연출로 기억에 남게 한다. 전투 수치의 적용 시점과 연출의 타격 순간을 맞추며, 연출 길이만으로 카드의 실제 규칙을 변경하지 않는다.

기초 4종·보상 6종은 카드 콘텐츠 수이며 독립적인 고급 연출 10개를 뜻하지 않는다. 첫 제작은 대표 기술 한 종의 전용 연출을 완성하고, 나머지는 기본 동작과 이동·타격 효과의 변형을 공유한다. 공통 동작을 사용해도 카드의 목적과 결과는 구별되게 한다.

## 11. 데이터와 저장의 경계

구현 때 다음 데이터를 분리한다.

| 데이터 | 내용 |
|---|---|
| 캐릭터 정의 | 캐릭터 ID·역할 태그·고유 AI·태세·기초 카드·보상 풀·연출 |
| 영구 상태 | 보유 캐릭터·레벨·기초 덱 프리셋·발견 및 플레이 기록 |
| 원정 상태 | 편성 캐릭터·출발 레벨·HP·지도·출정 카드 인스턴스·대기 목록·진화·보상 |
| 전투 상태 | 시전자 인스턴스·현재 덱·손패·게이지·카드 명령·진행 시각·오토 상태 |

각 원정 카드에는 고유 ID·캐릭터 ID·카드 정의 ID·출처(기초/보상)·진화 0/1을 둔다. 영구 상태에 보상 카드의 사용권이나 진화 인스턴스를 저장하지 않는다. 캐릭터의 영구 ID와 전투 중 시전자 ID도 구분한다.

저장 파일을 불러와 같은 원정을 이어 하면 보상·진화·HP·전투와 난수를 그대로 복원한다. 원정 종료 처리는 한 번만 적용하고, 다음 원정의 카드 풀은 편성된 캐릭터의 기초 카드로 새로 만든다.

기존 저장의 전환은 구현 단계의 별도 작업이다. 현재 저장을 복사해 보존하고 원정마다 규칙 버전(`rulesVersion`)을 기록한다. 진행 중인 기존 규칙의 원정은 그 규칙으로 완료할 수 있게 하는 초안을 두고, 해당 카드·조각 정산도 이전 버전 기록에만 반영한다. 이후 새 원정부터 새 규칙을 적용한다.

기존 네 역할의 레벨·기본 파티는 기본 제공 네 캐릭터 ID로 연결하는 변환 초안을 둔다. 기존 영구 카드 기록은 이전 버전의 수집 기록으로 남기며, 새 규칙의 시작 덱 사용권이나 판매 재화로 자동 환산하지 않는다. 새 기초 덱은 해당 캐릭터의 사용권과 계열 상한을 검증해 만든다. 현재 저장을 이 문서 작업에서 삭제하거나 변환하지 않는다.

## 12. 제작 순서와 검증

1. **캐릭터·카드 수명 분리:** 역할 기반 정의를 캐릭터 ID와 기초/보상 구분으로 옮기고, 원정 종료 초기화와 저장 복원을 완성한다.
2. **검사 원형 하나의 완성:** 첫 제작은 기초 4종과 추격·엄호 보상 각 1종으로 줄여 이동·기본 공격·대표 기술 연출을 연결한다. 두 카드의 실제 변화를 확인한 뒤 보상 6종과 동작을 확대한다. 나머지 동료는 임시 표현으로 파티를 완성한다.
3. **짧은 원정:** 첫 승리부터 운영이 달라지는 보상과 회복·진화·보스 기믹을 연결한다.
4. **같은 역할의 두 번째 캐릭터:** 동일 근접 태그에서도 기본 행동·카드·편성·관전 장면이 달라지는지 확인한다.
5. **캐릭터 체험과 정식 콘텐츠:** 획득 전에 기초 키트와 대표 장면을 경험하는 체험 전투를 연결하고, 판매·획득 방식과 출시 범위를 결정한다.

규칙 검사는 다음을 완료 기준으로 둔다.

- 보상 카드는 성공·실패·귀환 모두 다음 원정에 남지 않고 기초 키트는 유지된다.
- 이어하기에는 보상과 진화가 남고, 보상 재추첨·중복 지급·종료 정산 중복이 없다.
- 덱 20장·카드 계열 상한·인스턴스 고유성·편성한 캐릭터의 시전자 연결을 지킨다.
- 전투불능의 카드 제외는 해당 전투에서만 처리하며 회복 방 복귀 후 다시 사용 가능하다.
- 같은 캐릭터의 서로 다른 보상 운영으로 자동 판단·대상·움직임·효과가 실제로 달라진다.
- 이동 목적이 유효한 동안 유지되고, 끝난 뒤 기존 태세로 복귀한다.
- 기본 덱·여러 보상 조합·수동·오토가 같은 판정 규칙으로 원정을 진행한다.

재미 검증은 ‘오토로도 캐릭터답게 싸우는가’, ‘대표 스킬을 다시 보고 싶은가’, ‘보상 선택 후 관전 장면이 달라지는가’, ‘그 캐릭터를 자신의 팀에 넣고 싶은가’를 확인한다. 카드 발견 수·승률만으로 캐릭터의 매력을 입증하지 않는다.

## 13. 아직 확정하지 않은 중요한 사항

- **캐릭터 획득과 판매:** 직접 구매·다른 획득 방식·게임 플레이 해금의 관계, 구매 상품에 포함되는 범위. 가격·확률·중복 구매 성장 규칙은 정하지 않았다.
- **영구 육성의 최종 범위:** 빠른 상한 레벨은 유지한다. 친밀도·이야기·외형 해금의 범위와 새로운 영구 전투력 성장층의 필요 여부는 미정이다.
- **정식 제작 범위:** 첫 출시 캐릭터 수, 대상 플랫폼·엔진, 아트와 세계관. 지금은 한 캐릭터의 실제 관전 경험으로 기준을 만든다.

기초/보상 종류 수, 덱 장수, 후보 수, 정비 회복량, AI 점수, 기술 시간과 피해 수치는 설계자가 검증하면서 조정한다. 구매 방식과 취향을 대신 확정하거나, 아직 구현되지 않은 기능을 완성으로 기록하지 않는다.
