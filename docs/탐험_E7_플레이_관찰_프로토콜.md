# 탐험 E7 직접 플레이 관찰

적용: `prototype/exploration.html`, Exploration GDD 0.1. 기능 구현 및 기술 검증과 사람의 재미 관문을 분리한다.

## 첫 관찰 (2~3명)

가능한 한 같은 기본 시험 설정으로 시작하되 서로 다른 시드를 사용한다. 관찰자는 연결구의 정답 경로나 특정 카드 조합을 미리 알려주지 않는다. 세계관·계열10종·아트 확대보다 기본 한 판의 선택을 먼저 확인한다.

원정 결과의 ‘플레이 관찰 기록’에 응답하고 ‘원정 로그 저장’으로 JSON을 함께 남긴다. 참가자별 기록과 시드를 구분하고, 브라우저 QA의 시험 응답을 실제 사용자 표본에 섞지 않는다.

확인할 장면:

1. 이동·조사·교전·하강 중 둘 이상의 선택지가 보일 때 스스로 대안을 비교하는가.
2. 무전이 불완전한 정보로 도움이 되는가, 지시에 따르는 반복이 되는가.
3. 시간이0이 된 순간 HP 비용을 이해하고 자발적으로 더 탐험하거나 귀환하는가.
4. 계열 임계점 때문에 카드의 직접 성능과 덱 일관성을 비교한 보상 선택이 있는가.
5. 선택 전투를 피하거나 필수 수문장을 준비할 때 위험·보상·현재 덱을 이유로 드는가.
6. 다음 원정을 원하는 이유가 새로운 전술·장소인지, 필수 해금 골드 파밍인지.

같은 전략을 반복해도 이유를 이해하고 비교했다면 실패로 보지 않는다. 많은 버튼 클릭이나 긴 플레이 시간 자체를 재미로 간주하지 않는다.

## 기록에서 계산할 지표

- 이동 수 대비 새로운 방문 노드와 재방문 비율. 회복을 위한 시간 소비 왕복과 의미 없는 길 찾기 왕복을 사람의 설명으로 구분한다.
- 심도별 진입·귀환·실패 위치, 시간0 이후 조사/이동/교전 횟수.
- 선택·필수 전투별 받은 피해, 보호로 흡수한 피해, 사용 카드·실행자·특성 발동.
- 카드 보상 전후 계열 장수와 단계 변화, 선택하지 않고 건너뛴 보상.
- 원정 골드 총획득/손실/실수령, 지상 해금 후 후보 등장, 해금 없이 진행 가능한지.

비교 실험은 한 번에 시간·회복·HP 단가·맵 밀도를 모두 바꾸지 않는다. 로그의 승리/실패만으로 참가자의 판단이나 감정을 추정하지 않는다.

## 수정 후 두 번째 관찰 (5~8명)

첫 관찰에서 가장 큰 문제 하나를 수정한 뒤 다시 같은 질문으로 관찰한다. 단계별 승률 수치를 유일한 통과 기준으로 삼지 않는다. E7의 통과 근거는 ‘카드 전투의 판단 재미를 유지하면서 탐험·무전·하강·덱 특성 선택이 재도전 동기를 늘렸다’는 구체적인 선택 장면과 참가자의 설명이다.

## 현재 상태

UI 응답 폼, 원정 기록 내보내기, 자동 기술 실험 도구는 구현되었다. 사람의 새 탐험 플레이 관찰 표본은 아직 없다. 이 문서는 테스트 준비물이며 관문 통과 보고서가 아니다.
