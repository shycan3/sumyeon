## P0 감사

- 새 명세의 후속 합의가 같은 주제의 기존 GDD보다 우선한다. 이전 E7 관찰 대기는 이번에 명시적으로 요청한 소규모 기능·비주얼 검증을 막지 않는다.
- 저장 키는 `sumyeon-exploration-session-1`. 방문 노드는 있지만 통과한 간선 기록과 무료 빠른 이동은 없다. 기존 이동 로그의 목적지·방향으로 실제 간선을 보수적으로 복원할 수 있다.
- 발견 지도는 방문 노드와 인접 미방문 노드를 표시한다. 전체 생성 맵을 클라이언트에 보관하더라도 UI의 비공개 정보는 별도로 제한해야 한다.
- 공간 징후, 선택 사건, 심층 법칙, 성격 중심 동료 대사, 자산 매니페스트는 미구현이다. 기존 오퍼레이터 무전과 조사 4종은 재사용한다.
- 기존 전투 엔진·10사본 시작 덱·카드 사본 특성·영구 후보 해금은 유지한다. 변경은 독립 탐험 모듈과 어댑터에 국한한다.
- 현 주경로의 북/동 편향은 별도 개선 후보로 기록한다. 이번에 맵 생성 알고리즘의 대규모 변경을 섞지 않는다.
- 공식 인물 외형·직군 매핑과 아트 앵커는 미결이다. 임시 콘텐츠를 공식 설정으로 선언하지 않는다.

## 검증 기준

화살표 이동은 재방문에도 유료이며 시간 사용분만 자연 회복한다. 지도 빠른 이동은 실제 통과 간선의 BFS로 검증하고 시간·HP·회복 버퍼·골드·덱·일반 이동 횟수·무전·대사를 바꾸지 않는다. 기술 검사와 사람의 재미·아트 승인·생산성 검증을 구분한다.

## P1 구현·검증

- 심도별 `traversedEdges`는 실제 화살표 이동으로만 추가한다. `staticMap()`에서 동적 필드를 제외하므로 기존 생성 맵 검증을 유지한다.
- `Session.travelPath()`는 현재 심도의 방문 노드와 실제 통과 간선으로 BFS를 수행한다. `fastTravel()`은 위치와 고유 로그만 갱신하고, 현재 위치 선택은 완전한 무변화다.
- 기존 저장은 목적지·이동 방향이 일치하는 이동 로그만 활용해 간선을 복원한다. 로그가 없는 방문 위치는 유지하되 무료 경로를 보수적으로 제한하고 안내한다. 은행·해금·원정 초기화는 하지 않는다.
- 지도에 현재 위치·방문·미방문 인접 방·조사/해결 상태를 표시한다. 확인한 경로는 실선, 미확인 통로는 점선이다. 클릭·터치·Enter/Space 이동을 지원하며 다른 심층은 읽기 전용이다.
- `node prototype/exploration-extension-check.cjs`: 신규 계약 7개 통과(유료 재방문, 무비용 반복 이동, 시간0, 미방문/다른 심도/미통과 경로/전투/보상 거부, 저장·구형 저장).
- `node prototype/exploration-extension-browser-check.cjs`: 1242/390/320px 실제 클릭·키보드·시간0·유료 재방문·저장 재로드·구형 저장 검사 통과. 390px 지도 캡처를 직접 확인했다.
- 기존 `exploration-check.cjs` 30개 및 `exploration-browser-check.cjs` PC/모바일·실패·다중 탭·구형 모드 보존 검사도 통과했다.
- 기술 검증은 사람의 길찾기 난도나 무료 이동으로 인한 시간 경제의 재미를 대신하지 않는다. P2~P5는 계속 구현 대상이다.

## P2 구현·검증

- `exploration-content.js`는 의미 6그룹과 감각 10종을 분리한 기본 문장 39개 및 테마별 소품 어휘를 관리한다. 내부 분류는 UI에 표시하지 않는다. 실제 출구의 적·조사물·시설·사건으로 징후를 고르고, 별도 해시를 사용하여 맵·보상 RNG를 바꾸지 않는다.
- 방향 버튼에 짧은 기척을 표시하고 무료 상세 열람을 제공한다. 방문 방향에는 확인한 장소·조사/위협/사건 상태가 우선한다. 미방문 연결구·적 이름·정확한 보상은 공개하지 않는다.
- 시험 사건 5종(수술대·기침·자판기·방송·그림자)을 테마별로 심층당 2개 배정한다. 회수·회복·카드 보상·선택 전투·무시 분기, 무료 선택 보류, EVENT 저장/복구를 지원한다. 정식 캐논·출시 수치는 아니다.
- 사건 배정은 기존 맵 형상과 별도의 동적 필드다. 기존 저장은 기하·경제·덱·보상 시드를 유지하며 사건 필드만 보충한다. 생성 맵 대조에서 동적 사건 상태를 분리하고 사건 자체의 배정/연결을 별도 검증한다.
- 선택형 사건 전투는 기존 어댑터를 호출한다. 사건 전투에서도 시간 정지·HP 동기화·보상·패배 정산을 유지하며 일반 조우와 구분한다. 해결은 한 번만 정산한다. 치명 조사 비용에는 기존 확인 절차를 적용한다.
- `node prototype/exploration-content-check.cjs`: 신규 7개 검사 통과. 100개 시드의 징후·모든 사건 선택 분기·전투 종료·복구·중복 차단·보류·치명 비용·구형 저장을 포함한다.
- 기존 도메인 30개 및 P1 계약 7개 검사 통과. 기본 브라우저 검사 통과. 확장 브라우저의 1242/390/320px 징후 열람·사건 선택/보류·EVENT 재로드·사건 전투 재로드 검사 통과. 320px 탐험 장면 캡처 직접 확인.
- P3 법칙, P4 동료 대사, P5 비주얼 파이프라인은 아직 구현 대상이다. 자동 검사로 사람의 이해·재도전 동기를 확정하지 않는다.

## P3 구현·검증

- `exploration-laws.js`는 시험 법칙 3종의 데이터·심도 배정·조사 비용·회복률·정확한 설명을 관리한다. 새 원정은 시드별 순서를 결정하고 심층당 하나만 적용하며, 같은 원정의 3개 심층은 서로 다른 법칙을 사용한다. 출시 분포가 아니다.
- 잔류: 라운드 종료 뒤 남은 아군·적 보호의 50%를 소수 버림으로 유지한다. 등대지기 이월과 더 큰 값만 적용한다. 적의 기존 보호를 적 행동 전 일괄 삭제하지 않고 종료 시 정산하므로 그 라운드의 반격도 남은 보호에 막힌다. 적의 새 보호와 아군의 피격 후 잔여 보호 모두 실제 남은 값으로 계산한다.
- 과잉: 아군 카드의 각 직접 타격과 적 공격의 각 피해에 +2. 노출·약화 계산 뒤 적용하며 기본 공격·반격은 제외한다. 적 예고/정책과 실제 피해가 같은 `intentDamage()`를 사용한다. X·연타도 직접 타격마다 고정 +2이며 기존 카드 계수는 바꾸지 않는다.
- 정체: 조사 및 비전투 사건 시간 −1(최소0), 시간에 따른 자연 회복 ×0.5. 이동·교전·하강 비용과 초과HP 단가는 유지한다. 직접 카드/시설 회복은 줄이지 않는다. 실제 조사 비용과 회복률을 UI에 명시한다.
- 진입 시 비차단 안내 패널이 이름·정확한 효과·수치를 보여준다. 확인 후 축약 상태는 저장되며 상시 법칙 버튼으로 탐험/사건/보상/전투 중 재열람한다. 최근 법칙 효과 로그에는 타깃·전후 수치 또는 실제 자연 회복률이 표시된다.
- 법칙 버전이 없는 진행 중 구형 저장은 새 법칙을 소급 적용하지 않는다. 계정·원정·활성 전투는 보존하고 다음 입수부터 적용한다. 새 저장에서는 맵·전투 법칙의 일치와 심층별 배정을 검증한다.
- `exploration-laws-check.cjs` 9개: 100개 시드 배정/복구, 양측 보호·피격 잔여·등대지기·적 지원·프리뷰·적 약화·정체 소수 누적·0비용·심층 전환·구형 저장 통과.
- `exploration-laws-browser-check.cjs`: 3법칙 ×1242/390/320px 총9개 UI 흐름 통과. 무료 재열람·안내 축약 저장·현재 조사 비용 포함. 320px 상세 패널을 직접 확인하고 작은 화면의 헤더 버튼을 3열로 정리했다.
- 기존 도메인30, P1 계약7, P2 콘텐츠7 및 기본/확장 브라우저 검사 통과. 기존 전투 규칙16·통합23도 통과했다. 기존 30라운드 무피해 시계 검사에는 피해를 바꾸지 않는 잔류 시드를 사용했다(과잉의 +2 피해는 별도 법칙 검사).
- 기존 공용 전투 엔진의 원본은 수정하지 않았다. P4 동료 반응과 P5 비주얼 제작 파이프라인은 계속 구현 대상이다.

- 법칙 적용 후 `node prototype/exploration-study.cjs 30`: 30시드×2정책=60개 기술 원정이 정상 귀환했다. 직접 하강 심도3 30개, 조사 우선 심도3 27개/심도2 3개. 정책이 전체 숨은 맵을 읽는 실험이며 사람의 길찾기·재미·밸런스를 입증하지 않는다. 생성 보고서는 저장소 제외 정책을 유지한다.
