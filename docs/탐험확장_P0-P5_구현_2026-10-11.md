## P0 감사

- 새 명세의 후속 합의가 같은 주제의 기존 GDD보다 우선한다. 이전 E7 관찰 대기는 이번에 명시적으로 요청한 소규모 기능·비주얼 검증을 막지 않는다.
- 저장 키는 `sumyeon-exploration-session-1`. 방문 노드는 있지만 통과한 간선 기록과 무료 빠른 이동은 없다. 기존 이동 로그의 목적지·방향으로 실제 간선을 보수적으로 복원할 수 있다.
- 발견 지도는 방문 노드와 인접 미방문 노드를 표시한다. 전체 생성 맵을 클라이언트에 보관하더라도 UI의 비공개 정보는 별도로 제한해야 한다.
- 공간 징후, 선택 사건, 심층 법칙, 성격 중심 동료 대사, 자산 매니페스트는 미구현이다. 기존 오퍼레이터 무전과 조사 4종은 재사용한다.
- 기존 전투 엔진·10사본 시작 덱·카드 사본 특성·영구 후보 해금은 유지한다. 변경은 독립 탐험 모듈과 어댑터에 국한한다.
- 현 주경로의 북/동 편향은 별도 개선 후보로 기록한다. 이번에 맵 생성 알고리즘의 대규모 변경을 섞지 않는다.
- 공식 인물 외형·직군 매핑과 아트 앵커는 미결이다. 임시 콘텐츠를 공식 설정으로 선언하지 않는다.

## 검증 기준

화살표 이동은 재방문에도 유료이며 시간 사용분만 자연 회복한다. 지도 빠른 이동은 실제 통과 간선의 BFS로 검증하고 시간·HP·회복 버퍼·골드·덱·일반 이동 횟수·무전·대사를 바꾸지 않는다. 기술 검사와 사람의 재미·아트 승인·생산성 검증을 구분한다.

## P1 구현·검증

- 심도별 `traversedEdges`는 실제 화살표 이동으로만 추가한다. `staticMap()`에서 동적 필드를 제외하므로 기존 생성 맵 검증을 유지한다.
- `Session.travelPath()`는 현재 심도의 방문 노드와 실제 통과 간선으로 BFS를 수행한다. `fastTravel()`은 위치와 고유 로그만 갱신하고, 현재 위치 선택은 완전한 무변화다.
- 기존 저장은 목적지·이동 방향이 일치하는 이동 로그만 활용해 간선을 복원한다. 로그가 없는 방문 위치는 유지하되 무료 경로를 보수적으로 제한하고 안내한다. 은행·해금·원정 초기화는 하지 않는다.
- 지도에 현재 위치·방문·미방문 인접 방·조사/해결 상태를 표시한다. 확인한 경로는 실선, 미확인 통로는 점선이다. 클릭·터치·Enter/Space 이동을 지원하며 다른 심층은 읽기 전용이다.
- `node prototype/exploration-extension-check.cjs`: 신규 계약 7개 통과(유료 재방문, 무비용 반복 이동, 시간0, 미방문/다른 심도/미통과 경로/전투/보상 거부, 저장·구형 저장).
- `node prototype/exploration-extension-browser-check.cjs`: 1242/390/320px 실제 클릭·키보드·시간0·유료 재방문·저장 재로드·구형 저장 검사 통과. 390px 지도 캡처를 직접 확인했다.
- 기존 `exploration-check.cjs` 30개 및 `exploration-browser-check.cjs` PC/모바일·실패·다중 탭·구형 모드 보존 검사도 통과했다.
- 기술 검증은 사람의 길찾기 난도나 무료 이동으로 인한 시간 경제의 재미를 대신하지 않는다. P2~P5는 계속 구현 대상이다.
