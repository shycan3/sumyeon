# 탐험 확장 직접 플레이 관찰 준비

대상: 새 명세 P0~P5 통합 버전. 자동 검사는 사람의 길찾기·읽기·재도전 의욕·아트 선호를 대신하지 않는다. 실제 관찰 표본은 아직 확보하지 않았다.

## 2~3회 비교 플레이

같은 시드·파티·선호·수치로 짧게 비교한다. 첫 원정은 장소 아트를 켜고, 다음 원정은 설정에서 임시 장소 아트를 끄거나 순서를 바꾼다. 다른 변수를 한꺼번에 바꾸지 않는다. 이미 알고 있는 경로의 학습 효과도 적는다. 원정 결과의 플레이 관찰 기록과 전체 로그를 저장한다.

| 관찰 축 | 실제로 기록할 장면 |
|---|---|
| 지도 | 돌아갈 길을 찾다 막힌 위치, 미방문/확인한 통로 구분 |
| 이동과 자원 | 무료 빠른 이동 또는 유료 왕복 회복을 고른 이유, 당시 시간/HP |
| 기척 | 읽은 문장과 선택 방향, 도착 뒤 납득한 근거, 읽지 않은 기척 |
| 법칙 | 정확한 효과를 다시 읽은 시점, 달라진 카드/실행자/탐험 판단 |
| 사건 | 보류·무시·위험한 교전 등 선택 이유, 위험 이해 여부 |
| 동료 | 기억에 남은 반응, 자연스럽거나 어색한 대사, 잦다고 느낀 순간 |
| 비주얼 | 이름 없이도 기억한 장소 소품, 이전 CSS와의 구분 차이 |
| 피로 | 반복 클릭, 스크롤·문장 읽기로 흐름이 끊긴 순간 |

결과 화면의 추가8항목은 yes/no/unknown와 메모로 저장한다. 메모에는 관찰 당시 남은 시간·체력과 구체적 행동을 적는다. `unknown`은 통과나 실패로 자동 변환하지 않는다. 버튼 클릭 로그만으로 실제로 문장을 읽었다고 추정하지 않는다.

## 아트 검토

`visual-review.html`의 배경/사물/UI 레이어를 확인하고 대표 장면 후보와 수정 의견을 기록한다. 후보 선택은 아트 승인이 아니다. 실제 승인 후에만 앵커 ID·파일 해시·승인 시점 및 소요 시간을 매니페스트에 남기고 파생 일러스트/공식 인물 초상을 제작한다.

현재 공식 외형·직군 매핑은 미결이며 승인된 최종 아트 앵커가 없다. 따라서 익명 직군 실루엣과 코드 벡터의 품질/재생산 검증을 실제 캐릭터 얼굴 또는 최종 일러스트의 승인으로 간주하지 않는다.
