# 배치 고도화 1단계 — 표적·보호 규칙

적용 버전: `character.html?v=targetrules1`. 12자리 격자나 적 배치를 보는 준비 상태는 아직 추가하지 않았다. 기존 6자리 배치를 유지하면서 다음 확장의 전투 규칙을 먼저 정리했다.

## 변경한 행동

새 일반 교전은 실제 거리를 기준으로 표적을 평가한다. 이전의 보호 태세 방패병 거리 비용 0.64배 우대를 제거하고, 같은 거리일 때 보호 태세 방패병을 우대한다. 방패병의 동료 주변 위협 견제, 세린의 태세와 부상 동료 보호, 부상자 사냥 적, 카드로 지정한 추격·엄호, 도발은 기존 역할 예외를 유지한다.

일반 역할도 표적을 잠시 유지한다. 판단 간격 0.2초, 일반 역할의 최소 유지 0.45초와 작은 점수 변화 허용을 사용한다. 세린의 기존 0.6초 유지 기준은 유지한다. 표적 사망·태세 변경은 재평가한다. 사수·지원가의 일반 공격에서 현재 표적이 사거리 밖이고 다른 적이 사거리 안에 있으면 유지 시간보다 사거리 안 대체 표적을 우선한다. 카드 추격·엄호·도발과 역할 예외를 이 기능으로 무시하지 않는다.

새 규칙의 기본 행동은 이번 tick의 준비 처리 후 모든 캐릭터의 의도를 먼저 평가하고 이동·공격을 실행한다. 먼저 순회한 캐릭터의 이동 좌표만 반영해 뒤 캐릭터의 첫 표적이 달라지는 문제를 줄인다. 피해·사망·실제 사거리 유효성은 실행 때 다시 확인한다. 피해 자체를 동시 처리하는 변경은 아니다.

기본 공격과 카드 사용 오토는 서로 다른 판단이다. 이번 변경은 기본 표적·이동에 적용했으며 카드 선택 점수와 카드 표적의 기존 판정은 유지한다.

## 보호 판정과 안내

`CharacterBattle.protectionFor()`와 읽기 전용 보호 상수를 사용해 실제 피해 분담과 전황 안내를 같은 기준으로 계산한다.

- 방패병 보호 태세: 실제 거리 110 미만, 보호막·방어 적용 후 남은 피해 20% 분담.
- 세린 카드 엄호: 실제 거리 115 미만, 남은 피해 25% 분담. 방패병 보호보다 우선하며 둘을 중복 적용하지 않는다.
- 살아 있는 보호자의 남은 HP까지만 분담한다. 엄호 종료 시점과 피해 발생 시점을 비교한다.
- 배치 화면의 ‘표적·보호 규칙’에서 조건을 읽을 수 있다. 전황 상세에는 보호 종류·분담 비율과 기본 판단 이유를 표시한다.

범위와 비율은 기존 수치다. 몸막음·투사체 차단을 새로 추가하지 않았으며 기존 회복·전체 지원 범위도 유지한다.

## 저장·연습 호환

기존 AI 구조 버전 2와 별도로 `targetingRulesVersion`을 사용한다. 새 교전은 1, 기존 교전과 이전 시작 기록은 0을 사용한다. 진행 중인 교전을 불러오면 현재 좌표·이벤트·난수·기억 상태를 유지한다. 과거 기록의 연습은 기록된 표적 규칙을 재현하고, 규칙이 없는 기록은 이전 규칙으로 실행한다.

잘못된 버전과 전투 시작 기록/현재 상태의 버전 불일치를 거부한다. 이후 새 교전에만 새 규칙을 적용한다. 안내도 이전 연습에서는 이전 규칙을 명시한다.

## 검증 결과와 한계

`target-rules-check.cjs` 통과: 최근접·동거리 탱커 우대, 작은 거리 변화의 표적 유지, 사거리 안 대체 표적, 사수 거리 유지, 지정 추격·도발·부상자 사냥, 배우 순서에 무관한 최초 판단, 보호 범위·만료 경계, 표시/실제 분담 일치, 읽기 전용 조회, 저장 재개와 이전 연습 재현, 잘못된 입력 거부.

`target-rules-browser-check.cjs` 통과: 1280×720·390×844에서 규칙 안내, 전황 판단 이유, 새로고침 복원, 이전 교전 안내·연습 버전 확인. 페이지 오류 없음.

기존 `layered-ai-check.cjs`, `effect-check.cjs`, `battle-insights-check.cjs`, `formation-check.cjs`, `character-check.cjs`, `formation-browser-check.cjs`, `character-browser-check.cjs`, `comfort-browser-check.cjs` 통과. 태세·카드 행동·효과·실제 보스·보상·저장·연습 격리와 6개 화면 크기 관전 안정성을 확인했다.

`target-rules-simulation-check.cjs`: 적 4종 × 시드 3개 × 방침 2종 × 체력 100/45/25% × 배치 2종 × 이전/새 규칙, 288회·144쌍 비교. 모든 교전이 제한 시간 내 종료하고 좌표가 전장 범위에 유지됐다. 결과는 `prototype/target-rules-simulation-results.json`에 보존한다.

| 조건 | 이전 승리 | 새 승리 |
|---|---:|---:|
| 최대 체력 48쌍 | 48 | 48 |
| 전체 144쌍 | 130 | 127 |

이전 승리 → 새 패배는 3쌍, 반대 전환은 0쌍이다. 모두 시작 체력 25% 조건이다. 방벽/시드 37/보호/추천 배치는 세린이 먼저 쓰러지고 남은 아군이 회복망을 돌파하지 못해 180초 제한에 도달했다. 돌격대/시드 19/방패병 후열·사수 전열은 공격·보호 방침 모두 패배했다. 표적·접근 변화가 생존과 카드 사용 흐름을 바꾸는 사례이며, 무효 표적이나 멈춘 AI로 확인되지는 않았다.

따라서 이번 업데이트를 승률 향상으로 소개하지 않는다. 명확한 규칙과 배치 의미를 위한 변경이다. 낮은 체력의 취약 조건은 후속 덱·배치·공간 카드 검증 대상으로 남긴다. 3개 시드·기초 덱·인위적인 체력 조건이 실제 원정 승률을 대표하지도 않는다.
