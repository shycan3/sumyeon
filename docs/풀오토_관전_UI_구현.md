# 풀오토 관전 UI 구현

2026-10-07 · `character.html?v=watchui1` · UI 로드맵 3단계.

## 변경

기본 전투 화면은 전장, 동료 HP/현재 태세, 적 위험 예고, 명령 회복, 최근 오토 판단을 표시한다. 기존 350px 수동 패널을 제거하고 전장을 전체 폭으로 확장했다. 관전 배속, 정지/재개, 소리, 연출 설정은 바로 접근한다.

손패는 `현재 손패 · 기술 정보 보기`에서 조회한다. 관전 정지 상태여도 카드 클릭은 기술 설명 조회만 하며 선택/확정으로 연결되지 않는다. 설명 조회 자체는 전투를 멈추지 않는다. Space는 관전 정지/재개다. 수동 조작 단축키는 실험 도구가 열린 상태에서만 동작한다.

`실험 도구 · 수동 조작`에서 기존 수동 전환/개입/카드 확정/교체/대기/태세 조작을 사용한다. 닫거나 Escape를 누르면 오토 관전으로 복귀하고 멈춘 전투를 재개한다. 도구 설명에 이 동작을 표시했다. 예전 수동 전투 저장을 재개하면 도구를 자동으로 열어 기존 상태를 보존한다. 공개 도전은 도구가 제공되지 않고 오토 한정을 유지한다. 도전에서도 손패 기술은 조회할 수 있다.

기본 화면의 태세 표시는 읽기 전용이며 전투 전 편성 화면에서 변경하도록 안내한다. 공개 도전의 기존 오토 제한도 그대로 적용된다. 적/아군 AI·명령 판정·덱 규칙·저장 형식은 변경하지 않았다.

짧은 화면은 보조 적 HP 목록/긴 기록과 특성 상세를 줄인다. 적 HP는 전장 캐릭터 표시로, 상세 정보는 손패와 기록에서 조회한다. 기술 연출 상태 영역의 높이를 제한하여 전장/동료 HP/핵심 조작을 밀어내지 않도록 했다. 카드 조회·실험 도구·기록은 펼침 패널이며 전체 접근성 적합성 감사는 아니다.

## 검증

- `watch-ui-browser-check.cjs`: 1280×720, 390×844, 320×568, 844×390, 768×1024, 360×640. 초기/6초 경과 전투 화면에서 전장 최소 100px, HP/정지/손패·도구 조회 버튼의 화면 경계, 가로 넘침 검사. 관전 정지 중 조회가 명령을 실행하지 않음, 기본 단축키로 수동 전환 불가, 도구 열기/닫기와 오토 복귀, 저장 재개, 실제 첫 전투 완료, 공개 도전 수동 제한, 브라우저 오류 없음.
- `watch-frame-browser-check.cjs`: 실제 requestAnimationFrame 1배/2배 고정 시간 단계의 동일 스냅샷, 정지·재개. UI 변경이 전투 난수/판정을 바꾸지 않음.
- `character-browser-check.cjs`: PC/모바일 수동 도구 사용, 보상 카드 실제 사용, 원정 완주, 저장 재개/다운로드/불러오기/손상 저장 복구.
- `compare-ui-browser-check.cjs`: 1·2단계 보상 비교/편성/되돌리기/6가지 화면 회귀 통과.

사용자 관전 만족도, 모든 조합의 긴 스킬/위험 예고 텍스트, 전체 보조 기술은 후속 실측 대상이다. 다음은 UI 4단계인 덱 변경 결과의 요약이다.
