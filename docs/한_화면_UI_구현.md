# 한 화면 작업 공간 — workspaceui1

전체 페이지를 늘어놓는 대신 높이가 제한된 작업 공간으로 변경했다. 전투 규칙/저장 스키마/수치는 그대로다.

PC는 왼쪽 현재 선택과 오른쪽 파티·특성·편성·다음 위협을 함께 표시한다. 모바일은 위 상태 요약과 아래 현재 선택으로 전환한다. 현재 방은 제목에 표시하고 전체 6방 경로는 팝업에서 확인한다. 보상 넘기기와 편성 확정은 작업 영역 하단에 유지한다. 문자를 무조건 작게 줄여 모든 상세 규칙을 동시에 끼워 넣지 않는다.

긴 적 구성·특성 효과·태세·규칙·기여도·카드 목록은 현재 화면 위의 native dialog로 열린다. 닫기/Escape/바깥 클릭, 포커스 복귀와 native modal 키보드 순환을 지원한다. 실제 DOM을 이동했다가 복원하여 기존 버튼/입력 동작을 유지한다. 팝업 안의 선택으로 원래 화면이 새로 그려지면 팝업을 닫고 새 상태를 표시한다. 화면 조회가 전투 상태나 난수를 변경하지 않는다.

모바일 보상/출발 컨셉/진화/편성 카드 목록은 좌우 스와이프 및 이전/다음 버튼을 제공한다. 여러 후보를 작은 글자로 한꺼번에 축소하지 않고 읽을 수 있는 카드 크기를 유지한다. 대량 카드나 긴 기록은 작업 영역/팝업 내부에서 스크롤한다. 따라서 '한 화면'은 페이지가 길게 늘어나지 않고 선택·핵심 요약·상세 조회를 같은 작업 공간에서 수행한다는 뜻이다. 모든 카드/규칙이 항상 동시에 노출된다는 뜻은 아니다.

파일: `prototype/workspace-ui.js`, `prototype/workspace-ui.css`. 기존 앱이 출력한 요소를 배치하는 UI 층으로 분리했다. 전투 화면은 기존 관전 레이아웃을 유지한다.

검증: `workspace-ui-browser-check.cjs`, 1280×720 및 390×844. 화면 높이/너비 넘침 없음, 카드/규칙 팝업 및 Escape, 팝업 태세 변경과 자동 닫기, 모바일 후보 이동, 실제 전투→보상→교체→편성 확정→재접속을 검사. 지도/보상 스크린샷도 확인했다. 기존 저장과 전투의 브라우저 회귀 검사를 함께 수행한다.
