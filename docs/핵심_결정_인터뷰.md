# 핵심 결정 인터뷰 기록

작성일: 2026-10-05

2026-10-06 최신 방향: 캐릭터마다 고유 행동·전용 카드·연출을 가지며, 보상 카드는 이번 원정에서만 사용한다. 영구 카드 수집·중간 확보·미확보 손실은 [캐릭터와 원정 카드 설계](캐릭터와_원정_카드_설계.md)로 대체했다. 레벨 상한·원정 한정 진화·HP와 전투불능 유지·다음 전투부터의 카드 사용·제한된 공용 덱과 자유 비율은 유지한다. 아래는 당시 답변과 선택 근거를 남긴 기록이며, ‘사용자 확인’이라는 표현은 이전 답변의 지위를 뜻한다.

## 후속 방향 변경 기록

- 사용자는 직업별 고정 역할을 넘어 캐릭터마다 특성과 사용하는 카드가 다르길 원하며, 매력적인 캐릭터를 보유하고 싶게 만드는 서브컬쳐 게임과 캐릭터 판매를 지향한다고 설명했다.
- 사용자는 캐릭터의 기초 카드와 전투 보상 카드를 구분하고, 보상 카드를 영구 획득하지 않고 매판 플레이해서 그 판에만 사용하는 방향을 제안한 뒤 관련 설정 고도화를 요청했다.
- 원정 한 번을 한 판으로 해석하고, 캐릭터 획득 시 기초 키트 전체 사용·대표 스킬 즉시 제공·성공도 보상 카드 초기화를 설계 초안으로 연결했다.
- 기존 확보 방의 정비 방 전환, 카드 조각 기능 제거, 후보·중복·저장 전환·캐릭터 데이터 구조는 새 방향에 맞춘 설계자 초안이다.
- 캐릭터의 획득·판매 방식과 최종 영구 성장 범위는 아직 묻거나 확정하지 않았다. 기초 4종·보상 6종, 4명·20장·손패 5장은 검증값이다.

최신 흐름은 [게임 기본 구조](게임_기본_구조.md), 다음 제작 범위는 [개발 로드맵](개발_로드맵.md)을 따른다. 새 규칙은 설계에 반영했으며 현재 브라우저의 카드 영구 수집 구현은 전환 전 상태다.

원칙은 한 번에 한 가지 중요한 선택을 묻는 것이다. 숫자나 작은 예외 처리는 베이스 설계의 초안을 사용한다. 필요하면 선택지 사이의 절충안을 사용자의 설명에 맞춰 설계한다.

## 1. 적 카드가 발생하는 시간 구조

**기록:** 사용자는 카드마다 파티 전체의 다음 카드 선택까지 걸리는 시간이 달라지는 구조를 확인했다. 이 구조를 넣으면 적이 독립적으로 행동하는 A가 자연스럽다고 설명했고, READY를 유지하며 상대 행동까지 기다리는 대기 기능을 제안했다.

이 조합에 맞춰 A 방향으로 베이스를 갱신한다. 기존 두 선택지는 배경 기록으로 남기고 지금 다시 묻지 않는다.

| 방향 | 경험 | 달라지는 규칙 |
|---|---|---|
| 독립적인 발동 — 현재 설계 방향 | 적의 위협이 실시간으로 발생하며 READY 대기로 대응 시점 선택 | 진영별 공용 게이지, 카드별 명령 회복 시간, 대기·예고 |
| 공통 명령 시점 | 정지할 때 적의 예정 기술을 보고 아군 카드로 대응한다. | 적의 명령을 정지 진입 전에 고정·공개하고 재개 후 양측 실행 |

세부 초안: 대기 중 READY를 보유하고, 수동 명령 재개 또는 새 적 카드 예고 시작에 다시 정지한다. 카드 확정 때만 READY를 소비한다. 대기로 무료 드로우·명령 축적을 하지 않는다. 기존 게이지를 소비하는 보류 초안은 대체한다.

적 예고 시작의 재정지는 대응 기회이며 결과 보장이 아니다. 이미 회복 중이면 카드를 추가로 쓸 수 없고, READY라도 카드 효과가 나오는 시간이 필요하다. 재정지 방법과 구체적인 예고 수준은 설계자가 채운 초안으로 검증한다.

상태: 카드별 다음 명령 시간은 사용자 확인. 대기는 사용자 제안으로 반영. A를 전제로 설계 진행.

## 2. 위치와 거리의 중요성

**기록:** 사용자는 자유로운 위치를 사용하는 A를 기본 방향으로 보고, 전투 중에는 캐릭터가 태세에 맞춰 움직이길 원한다고 확인했다. 한 명씩 세밀하게 위치를 지정하는 조작의 복잡성보다 카드 활용에 초점을 맞추길 원한다.

- 전투 중 평상시 이동은 태세 기반 AI에 맡긴다.
- 개별 캐릭터에게 목적지를 계속 지정하는 기능은 베이스에 넣지 않는다.
- 실제 위치·거리·범위는 카드 활용과 캐릭터 역할에 의미가 있도록 유지한다.
- 카드 자체에 포함된 이동은 기술의 실행 과정 또는 효과로 처리한다.
- 전투 시작 배치는 역할에 맞는 기본 프리셋을 사용하는 설계자 초안이다. 세부 배치와 간단한 프리셋 UI는 설계자가 채우고 플레이로 검증한다.

상태: 태세 기반 자동 이동과 카드 활용 중심 방향은 사용자 확인. 자유로운 전장 위치 방향 유지.

## 3. 카드의 대상 지정

**기록:** 사용자는 C, 자동 추천 후 필요할 때 변경하는 방식을 선택했다.

- 카드를 선택하면 시전자와 추천 대상 또는 범위를 표시한다.
- 플레이어는 그대로 확정하거나 대상·범위를 변경한다.
- 자신·전체 회복처럼 대상이 고정된 카드는 별도 대상 선택 없이 확정한다.
- 추천만으로 명령을 실행하지 않고, 플레이어의 변경을 자동으로 덮어쓰지 않는다.
- 캐릭터를 먼저 선택하는 추가 단계는 만들지 않는다.

상태: 자동 추천 후 변경 가능한 대상 지정은 사용자 확인. 추천 점수와 세부 UI는 설계자 초안으로 채운다.

## 4. 카드 실행의 확실성과 방해

**기록:** 사용자는 C, 안정적인 실행을 기본으로 일부 기술에 명시적인 위험을 두는 방향을 선택했다. 확정적으로 명중하는 공격도 상대가 카드를 사용해 방어할 수 있다고 강조했다.

- 일반적인 지정 공격은 안정적으로 추적하고, 일부 범위 기술은 위치로 회피할 수 있다.
- 준비가 긴 일부 기술은 표시된 조건과 단계에서 특정 방해로 중단할 수 있다.
- 명중과 방어·피해는 별도로 판정한다. 명중 보장도 카드 방어를 무시하지 않는다.
- 아군과 적군 모두 자신의 READY와 손패를 사용해 카드 방어를 수행한다.

세부 초안: 타격 시점까지 실제 발동한 방어 효과를 적용하고 선택만으로 소급 방어하지 않는다. 방어되거나 중단된 카드의 소비와 회복 시간은 반환하지 않는다. 같은 전투 시각의 방어 발동과 타격은 방어 활성화를 먼저 판정한다. 구체적인 차단 대상·유지 시간·횟수는 카드별 데이터로 채운다. 빠른 방어 기술은 양측 동일한 준비 시간을 사용한다.

상태: C 방향과 명중 보장 공격에 대한 카드 방어는 사용자 확인. 구체적인 판정·수치·소비 규칙은 설계자 초안.

## 5. 캐릭터 편성과 덱 구성의 관계

**기록:** 사용자는 B, 캐릭터별로 사용할 카드를 선택해 공용 덱을 구성하는 방식을 선택했다.

- 캐릭터마다 자신의 카드 목록에서 카드와 장수를 선택한다.
- 선택한 카드들은 하나의 파티 덱으로 합쳐지고 시전 캐릭터는 유지한다.
- 같은 파티도 빠른 카드·강한 카드·방어·회복의 구성 비율로 다르게 운용할 수 있다.

상태: 캐릭터별 카드 선택은 사용자 확인. 후속 답변에서 전체 덱 장수 안의 캐릭터별 비율을 자유롭게 정했다. 현재 총 20장과 카드별 최대 장수는 검증용 초안이며, 5장씩 편성하는 구성은 추천 예시다. 카드 획득·강화·재편성은 아래의 출정 진행 답변을 따른다.

## 6. 전투 밖의 진행과 성장

**기록:** 사용자는 캐릭터 레벨에 최대치가 있고, 몇 번 반복해서 플레이하면 각 캐릭터를 육성하기 어렵지 않다고 설명했다. 지속적인 캐릭터 성장은 그 캐릭터의 카드를 수집하는 것으로 만든다.

상태: 빠르고 유한한 레벨 성장과 카드 수집 중심의 장기 성장은 사용자 확인. 이것만으로 임무 진행형·반복 도전형을 확정하지 않는다.

### 카드 수집이 제공하는 성장

**기록:** 사용자는 새로운 기술과 조합이 늘어나는 A를 먼저 생각했으나 카드 성능이 강해지는 B도 존재하므로 C, 두 가지 모두를 선택했다.

- 새로운 기술·조합을 얻어 덱 구성의 선택 폭이 커진다.
- 사용할 카드의 성능이 강해지는 성장도 포함한다.
- 기술·조합 확대를 중심으로 성능 성장도 함께 설계한다. 후속 답변에서 강화 노드의 1회 진화는 출정 한정 성장으로 정리했다.

상태: C 방향은 사용자 확인. 영구 카드 수집과 출정 한정 강화를 구분한다. 강화 노드의 진화를 영구 성능 성장으로 취급하지 않는다.

### 반복 플레이의 단위

**기록:** 사용자는 B, 한 번 출정해서 여러 전투와 선택을 거친 뒤 귀환하는 흐름에 가깝다고 답했다.

상태: 여러 전투를 묶은 출정과 출정 종료 시 강화 초기화는 사용자 확인. 후속 답변에서 로그라이크 느낌을 게임 전체의 기본 구조로 원한다고 확인했다. 출정마다 지도·적 조합·보상 후보를 바꾸는 구체적인 처리와 최종 보스 목표는 설계자 초안이다.

### 새 카드의 확보와 실패 처리

**기록:** 사용자는 C, 중간 지점에서 일부 카드를 확보하는 정도면 실패의 불쾌함이 크지 않겠다고 답했다.

- 확보 지점까지 가져온 새 카드는 이후 실패해도 남는다.
- 마지막 확보 지점 이후의 미확보 카드만 실패 시 잃는다.
- 출정 전 보유한 캐릭터와 카드는 유지하는 기본 초안이다.

상태: 중간 확보 C 방향은 사용자 확인. 확보 지점에서 현재 미확보 카드를 자동 반영하고 성공 귀환 시 나머지를 확정하는 처리는 설계자 초안이다.

### 보상 카드의 선택

**기록:** 사용자는 B, 제시된 카드 후보 중 원하는 카드를 고르는 방식을 선택했다.

상태: 후보 선택형 보상은 사용자 확인. 후속 답변에서 획득 장소는 전투 종료 보상과 보상 방으로 정했다. 3장 중 1장을 선택하는 수량과 승리 전투의 보상으로 제공하는 처리는 설계자 초안이다. 선택한 카드는 미확보 보상 목록에 들어가며 중간 확보 지점과 귀환 규칙을 따른다.

### 카드 성능 증가의 방법

**기록:** 사용자는 기존 카드를 성능이 더 좋은 강화 카드로 진화시키며, 현재는 최대 한 번 강화하는 것으로 생각하고 있다고 답했다.

상태: 기본 카드에서 강화 카드로 진화하는 방식과 현재 최대 1회는 사용자 확인. 후속 답변에 따라 최대 1회는 카드 한 장의 출정 내 한도로 적용한다. 적용 단위와 진화 기회를 얻는 방법은 아래 답변을 따른다. 기술 정체성과 명령 회복 시간을 유지하고 주요 효과를 높이는 강화안은 설계자 초안이다.

### 진화 적용 단위

**질문:** 같은 캐릭터의 돌진 카드가 덱에 3장 있다면, 한 번 진화해 세 장 모두 강화할 것인가, 보유한 한 장씩 진화할 것인가?

| 방향 | 진화 후 구성 |
|---|---|
| 카드 종류의 진화 | 돌진 종류를 진화하면 사용하는 돌진 3장 모두 강화 |
| 개별 카드의 진화 | 선택한 한 장만 진화해 강화 돌진 1장과 기본 돌진 2장 |

**기록:** 사용자는 B, 보유한 카드 한 장씩 진화하는 방식을 선택했다. 돌진 카드 3장 중 한 장을 진화하면 강화 돌진 1장과 기본 돌진 2장이 된다.

상태: 개별 카드의 진화와 기본·강화 카드의 공존은 사용자 확인. 각 카드에 출정마다 최대 1회 규칙을 적용한다. 원본 보유 카드의 ID와 기본 정의를 유지하고, 출정 데이터에서 진화 단계를 관리하는 구조는 설계자 초안이다.

### 진화 기회를 얻는 방법

**기록:** 사용자는 재료를 요구하기보다 카드를 강화할 수 있는 노드 또는 방이 있으면 좋겠다고 답했다. 같은 카드 소비와 별도 재료 중 선택하는 기존 질문을 이 방향으로 대체한다.

상태: 강화 노드 또는 방에서 진화 기회를 얻는 방향은 사용자 확인. 출정 중 방문하고 현재 덱의 미진화 카드 한 장을 선택하며 별도 재료를 소비하지 않는 구체적인 처리는 설계자 초안이다. 강화 결과는 아래 답변에 따라 이번 출정에서만 유지한다.

### 강화 결과의 유지 범위

**기록:** 사용자는 강화 시스템이 남지 않으며 이 부분은 로그라이크와 비슷한 느낌이라고 정정했다. 강화의 영구 저장 시점을 고르는 이전 선택지는 이 답변으로 대체한다.

- 강화 노드에서 얻는 진화는 이번 출정의 전투 사이와 카드 순환에서 유지한다.
- 성공·실패로 출정이 끝나면 강화는 초기화한다.
- 중간 확보 지점에서는 카드 자체의 소유를 보존하며, 강화 결과를 영구 보존하지 않는다.
- 다음 출정에서는 기본 카드로 시작하고 카드 한 장마다 다시 최대 한 번 진화할 수 있다.

상태: 출정 한정 강화는 사용자 확인. 영구 카드 수집과 강화 상태를 별개 데이터로 관리하는 것은 설계자 초안이다. 게임 전체의 로그라이크 방향은 아래의 출정 경로 답변에서 추가로 확인했다.

### 전투 사이의 HP와 전투불능

**질문:** 출정 중 전투 하나가 끝나면 남은 HP와 전투불능 상태를 다음 전투로 이어갈 것인가, 다음 전투에서 전원 회복할 것인가?

| 방향 | 출정에서의 경험 |
|---|---|
| A. 남은 HP와 전투불능 유지 | 회복 카드와 회복 장소가 출정 전체의 생존에 영향을 준다. 다음 전투와 경로를 고려해 피해를 줄인다. |
| B. 다음 전투에서 전원 최대 HP로 복귀 | 매 전투는 건강한 파티로 시작한다. 전투 사이의 회복 관리보다 덱의 강화와 현재 전투의 승리에 집중한다. |

**기록:** 사용자는 A, 남은 HP와 전투불능 상태를 다음 전투로 이어가는 것이 맞다고 답했다.

상태: 출정 중 HP·전투불능 유지는 사용자 확인. 전투 사이 카드 사용과 기본 행동 회복을 중지하고, 회복 노드에서 회복·복귀를 제공하는 규칙은 설계자 초안이다. 아군 전원 전투불능이면 출정 실패로 처리하는 기본값은 유지한다. 다음 전투의 손패·게이지는 초기화하며 출정 한정 강화는 유지하는 초안이다.

### 카드의 획득과 다음 전투 활용

**기록:** 사용자는 사용 시점을 묻기 전에 카드의 획득 시점을 먼저 정해야 한다고 설명했다. 카드는 전투 종료 보상이나 보상 방에서 얻으며, 획득한 다음 전투부터 활용한다. 출정에 가져갈 카드 수에는 제한이 있어 덱 장수를 맞추는 것도 중요하다고 답했다.

상태: 두 획득 경로, 다음 전투부터의 사용, 출정 덱의 장수 제한은 사용자 확인. 영구 확보 전에도 다음 전투에 편성할 수 있다. 총 20장 유지와 한 장을 넣을 때 한 장을 빼는 교체 방식은 설계자 초안이다. 덱에서 뺀 카드의 영구 소유·미확보 보상 기록을 유지하는 규칙도 초안이며, 장수 제한을 전체 보상 반출 한도라고 추가로 확정하지 않는다.

### 캐릭터별 카드 배분

**질문:** 전체 덱의 장수를 맞춘 상태에서, 각 캐릭터가 넣는 카드 수를 동일하게 유지할 것인가, 캐릭터별 비율을 자유롭게 조절할 것인가?

| 방향 | 4명·20장일 때의 예시 |
|---|---|
| A. 캐릭터별 균등 배분 | 캐릭터마다 5장씩 편성한다. 새 검사의 카드는 기존 검사 카드와 교체한다. |
| B. 캐릭터별 비율 조절 | 8장·5장·5장·2장처럼 편성한다. 특정 캐릭터의 카드가 손패에 더 자주 나오도록 구성한다. |

**기록:** 사용자는 B, 전체 덱 장수 안에서 캐릭터별 비율을 자유롭게 조절하는 방향을 선택했다. 시전자가 다른 카드끼리 교체할 수 있다.

상태: 자유 비율은 사용자 확인. 20장이라는 정확한 수치와 캐릭터별 0장 허용은 설계자 초안이다. 실제 보유 수량과 카드 계열별 최대 장수 제한은 함께 적용한다. 위의 8장 배분 예시는 보유한 카드 종류와 장수 제한이 허용할 때 가능하다. 초기 역할별 3종 기술만으로는 일반 3장·3장, 특수 1장 제한에 따라 캐릭터당 최대 7장까지 구성할 수 있다.

### 출정 경로의 선택과 게임 전체의 방향

**질문:** 출정 중 다음 방으로 향하는 경로를 플레이어가 선택할 것인가, 정해진 방문 순서를 따를 것인가?

| 방향 | 출정에서의 선택 |
|---|---|
| A. 분기 경로 선택 | 갈림길에서 회복 방으로 갈지 강화 방으로 갈지 선택하는 식으로 다음 경로를 정한다. |
| B. 방문 순서 고정 | 정해진 순서로 방을 방문하며, 각 방에서 보상 카드와 강화 대상을 선택한다. |

**기록:** 사용자는 A, 분기 경로를 선택하는 방식을 택했다. 기본 게임 구조 자체가 로그라이크 느낌이길 원한다고 덧붙였다.

상태: 분기 경로와 게임 전체의 로그라이크 방향은 사용자 확인. 지도 표시 방식, 무작위 생성, 방의 수·배치·최종 보스 목표는 설계자가 채운 초안이다. 첫 출정 검증은 10개 방 방문, 두 차례의 확보 지점, 최종 보스 한 번으로 구성한다. 중도 포기는 미확보 보상을 잃는 기존 실패 규칙에 연결하는 초안이다.

### 전체 설계를 검토할 단계

기본 루프를 구성하는 큰 선택은 연결됐다. 추가적인 작은 숫자와 방 배치를 질문하기보다 [게임 기본 구조](게임_기본_구조.md)와 전투·출정 설계를 함께 검토한다. 검토에서 드러나는 중요한 방향 변경은 다시 한 번에 한 질문으로 정한다. 현재 답변을 기다리는 인터뷰 질문은 없다.

### 남은 결정의 위임

**기록:** 사용자는 지금 더 정해야 할 중요한 부분이 있는지 확인하고, 게임 자체에 큰 영향을 주지 않거나 쉽게 바꿀 수 있는 부분은 설계자가 판단하길 요청했다.

검토 결과 현재 전투·출정 프로토타입의 설계에 필수인 추가 질문은 없다. 출정 중 파티는 고정하고, 역할별 기본 배치와 중복 카드 처리·보상 후보 우선순위를 초안으로 채운다. 숫자·UI·방 배치와 추가 콘텐츠의 크기를 일일이 인터뷰하지 않는다.

전투 지연을 통한 반복 회복, 카드 활용 빈도, 경로 선택의 가치와 출정 길이는 플레이 검증으로 판단한다. 기존 재미를 크게 바꾸는 새 규칙이 필요한 경우에 다시 인터뷰한다. 실제 제작 단계의 대상 플랫폼·엔진·세계관 결정은 전투 시스템의 필수 미정 항목과 구분한다.

## 사용자에게 수치 결정을 맡기지 않는 항목

손패 크기, 초기 덱 장수, 충전 초 단위, 피해 계산식, 카드 준비 시간, 드로우·셔플, 같은 상태의 중복 방식, AI 판단 주기, 기본 UI 배치, 기본 승패 처리는 설계자가 초안으로 채우고 검증한다.

중요 결정의 답변으로 기존 기본값이 맞지 않게 되면 함께 조정한다. 큰 전투 방향을 정하기 위해 작은 숫자부터 인터뷰하지 않는다.

## 답변 반영 절차

1. 사용자가 설명한 원하는 경험을 한두 문장으로 확인한다.
2. 결정된 규칙과 영향을 받는 초안을 베이스 설계에 반영한다.
3. 아직 결정되지 않은 항목의 상태를 유지한다.
4. 다음 질문 하나로 넘어간다.
