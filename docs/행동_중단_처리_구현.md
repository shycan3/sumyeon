# 준비·이동·연속 타격의 수명 주기

현재 4인 파티의 세린 원정과 관전 체험에 적용했다. 카드 수치·파티 구성·저장 키는 유지하며, 이전 index.html은 기존 규칙으로 실행한다.

## 공통 처리

카드 사용마다 전투 안에서 고유한 actionId를 발급한다. 같은 카드 복사본을 나중에 다시 사용해도 다른 행동으로 구분한다. 시전자에 준비(preparation), 접근 이동(movement), 타격 판정(executing), 후속 타격(follow), 후딜레이(recovery)를 저장하고, 예약된 타격에도 같은 식별자를 붙인다.

정상 종료·차단·취소 결과는 최근 50개까지 actionResults에 기록한다. 실제 타격 횟수는 보호막에 모두 흡수되어도 적중한 경우를 포함하며, 차단·대상 소실로 실행되지 않은 타격은 포함하지 않는다. 전투 결과를 결정하는 별도 보상이나 재사용 이점은 제공하지 않는 진단 기록이다.

| 상황 | 처리 |
| --- | --- |
| 시전자 전투불능 | 같은 사용의 예약·접근·행동 잠금을 제거. 목적·반격도 정리 |
| 준비·접근 중 단일 대상 소실 | 남은 이벤트·접근·행동 잠금을 제거하고 취소 표시 |
| 살아 있는 도발 대상 존재 | 실제 도발 대상을 유효 대상으로 확인하고 공격 유지 |
| 전체 공격에서 선택했던 적 소실 | 남은 범위 대상이 있으면 발동. 범위가 비면 취소 |
| 검무 중간 차단 | 해당 사용의 남은 타격 모두 제거. 차단을 한 번 표시 |
| 검무가 직접 대상을 처치 | 남은 타격은 제거하고 처치에 따른 정상 종료로 기록 |
| 다른 공격이 검무 대상을 처치 | 다음 판단에서 남은 타격을 취소 |
| 추가 추격의 대상 소실 | 다른 적으로 무료 재지정하지 않고 추가 타격 취소 |
| 공격 도중 반격에 시전자 전투불능 | 이미 판정한 타격은 유지. 후속 이벤트를 새로 만들지 않음 |
| 구속 사격으로 준비 지연 | 같은 행동 식별자·명령 회복시간 유지. 기존 카드당 1회 지연 규칙 유지 |
| 전투 종료 | 남은 예약·접근·행동 상태를 정리하고 종료 결과 기록 |

취소·차단 시 해당 캐릭터의 행동 잠금은 즉시 해제한다. 이미 소모한 카드·명령 회복시간·통계는 돌려주지 않는다. 정상 사용은 기존 후딜레이까지 잠금을 유지한다. 기본 행동의 공격 쿨타임을 초기화하지 않는다.

한 번의 범위 타격은 같은 이벤트로 판정한다. 이번 변경은 범위 안의 개별 피격 순서를 새로운 중단 단위로 나누지 않으며, 예약된 후속 타격 단위로 중단한다. 자유 이동 명령이나 새 상태 이상은 추가하지 않았다.

## 연출·저장

준비 연출과 차단·취소 신호에도 actionId를 전달한다. 같은 카드 복사본의 오래된 신호가 새 사용을 중단시키지 않고, 중단 뒤에 도착한 타격 연출이 중단 문구를 덮어쓰지 않도록 했다. PC·모바일에서 ‘대상 소실 · 기술 종료’를 표시한다. 저장 재개 시 이전 초상화나 중단 신호를 다시 재생하지 않는다.

전투에 actionRulesVersion: 1, actionSerial, actionResults를 저장한다. 기존 저장의 예약된 카드에는 행동 상태와 식별자만 보충하며, 체력·남은 시간·접근 좌표·손패·난수는 유지한다. 과거 저장에서 시작 시각을 알 수 없는 예약은 관련 카드 사용 기록의 시각을 사용하고, 기록도 없으면 0으로 기록한다. 중복 식별자, 잘못된 상태·식별자 연결, 알 수 없는 버전은 불러오기를 거부한다.
