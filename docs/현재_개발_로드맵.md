> **첫 개발 묶음 구현:** 신규 일반 적 3종·정예 1종·보스 1종, 구역별 조우 후보군·공개 보스 선정, 문양의 실제 발동 기여를 원정에 적용했다. [구현·검증 기록](전술_다양화_첫_묶음_구현_2026-10-10.md). 과거 저장과 원본 명령 재생을 유지한다. 기술 구현을 사람의 재미 통과와 구분한다. 다음 제작 묶음은 카드 운용의 대체 경로와 대표 카드 6종의 두 갈래 강화다.

> **첫 플레이 이해 보강:** 발견형 적 도감, 첫 두 전투의 실제 예고·피해 힌트, 전투 로그 기반 패배 복기를 추가했다. [구현과 평가 범위](첫_플레이_이해와_패배_복기_구현_2026-10-10.md). 기능·저장 검사는 완료했으며, 새 플레이어의 이해도와 재도전 의향은 직접 평가 전이다.

현재부터의 개발 계획은 [다음 개발 로드맵](다음_개발_로드맵_2026-10-10.md)을 따른다. 이전 계획과 업데이트 기록은 [v3.1 기록](개발_로드맵_v3.1_기록.md)에 원문 그대로 보존했다. P0~P6의 정의는 [기준 개발 프로토콜](기준_개발_프로토콜_P0-P6.md)이 우선하며, 구현은 여러 기능을 묶은 전체 원정으로 진행한다.

## 현재 만드는 경험

전황을 읽고 공용 카드의 실행자·순서·대상을 정한다. 원정에서 얻은 카드와 강화로 운용을 발전시키고 후반 상대에게 시험한다. 패배하면 원인을 이해하고 다음 시도에서 바꿀 선택을 발견한다.

사용자는 상황 판단과 전체 원정의 재미를 긍정적으로 보고했다. 캐릭터 역할의 직관성과 자연스러운 카드 연계는 부족하게 느꼈다. 후속 구현과 최근 능력치 상향이 직접 플레이에서도 개선됐는지는 별도로 확인한다.

첫 묶음은 구현을 완료했고, 나머지 수량은 다음 제작 묶음의 제안 예산이다. 전체 게임의 확정 출시 수량은 아니다. 각 적은 특정 카드·문양이 유일한 답이 되지 않게 서로 다른 대응을 갖춘다. 원정 길이는 우선 현재 범위로 유지한다. 새 도전·심도는 기본 원정과 카드·편성 재미가 안정된 뒤에만 진행한다.

문양 목적 설명과 선택 미리보기는 이미 있다. 새 표현 작업은 인양한 사본·인계 할인·노출 환급·보호 이월처럼 시간차 효과의 원인을 이어 보여주는 데 집중한다. 설명을 늘리는 작업을 신규 전술로 보고하지 않는다.

## 병행하는 밸런스 조사

최신 신규 조우 표본은 120원정 116승·4패(96.7%), 848전투 844승·4패다. 시드 100~124의 대표 편성 3개와 시드 500~502의 전체 편성 15개를 balanced 정책으로 관찰했으며, 오류·중단·HP 검산 불일치가 없다. 패배 셋은 시드 502의 7구역 문지기+잠항 추적자, 하나는 동료 셋이 쓰러진 HP 11 보스 진입이었다. [최종 분석](../prototype/study-results/tactics-1-final-analysis/analysis.md).

기존 조우의 능력치 상향 기준선은 180원정 162승·18패(90.0%)로 보존한다. 이 표본은 시드 네 개·15편성·세 원정 정책이며 최신 표본과 조건이 다르다. 별도 동일 시작 75쌍의 기존 조우 73승·신규 조우 75승은 새 조우가 상대적으로 쉬워졌다는 조사 신호다. 조우·경로·성장이 함께 바뀌므로 패턴 하나의 인과 효과나 사람의 난이도로 단정하지 않는다.

규칙 2와 기존 정책을 기준선으로 보존한다. 기존 패배의 첫 6건은 같은 진입 상태에서 표적만 바꾸는 진단을 완료했다. 해당 사례의 6패→6승은 정책 조사 자료로 별도 보존하며 전체 승률과 합산하거나 생산 오토를 곧바로 바꾸지 않는다. 새 조우의 실패 표본을 다음 조사 대상으로 삼는다. 연구 도구는 기존 로그·검산·재생기를 재사용하고 콘텐츠 개발과 병행한다. 승률을 특정 퍼센트로 낮추는 것 자체를 목표로 삼지 않는다.

개발 묶음마다 새 시드 20~30개·대표 편성 3개·기본 정책 60~90회부터 확인하고, 편성이나 특정 상대 문제가 보이면 같은 조건 표본을 확대한다. 최종 덱 유사도와 준비→활용 관찰을 보강하되 카드 사용률을 강함이나 재미로 곧바로 해석하지 않는다.

## 평가 방식

P0 실행자·순서·조작, P1 전문성, P2 전술 발전, P3 브레이크 부담, P4 편성 가치, P5 성장과 활용, P6 전체 원정 재미를 계속 평가한다. 구현 완료·자동 검사·사람의 관찰을 구분한다. P3을 보류해도 다른 원정 개발은 이어갈 수 있다.

각 묶음의 실제 원정 구현과 기술 검사를 마친 뒤 전체 플레이로 평가한다. 사용자에게 매 기능의 비교 전투를 반복해 요구하지 않는다. 처음 하는 플레이어의 관찰을 확보하면 선택 이유·실패 원인·재도전 의향을 기록한다. 통과 조건이 실패하면 원인을 수정하거나 해당 기능을 줄인다.

진행 중 덱·지도·HP·공개 행동은 새 규칙으로 몰래 변경하지 않는다. 능력·카드·원정 규칙이 달라지면 새 버전과 재생 조건을 기록한다.
