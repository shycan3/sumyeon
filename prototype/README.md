## 실행

이 폴더에서 정적 HTTP 서버를 실행한 뒤 브라우저로 접속합니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

현재 프로젝트에서는 `http://127.0.0.1:8765/`에서 실행됩니다. `index.html`을 직접 열어도 플레이할 수 있지만, 저장은 같은 HTTP 주소와 브라우저를 사용하는 편이 안정적입니다.

## 플레이

1. 거점에서 필요하면 시작 덱을 편성하고 **새 출정 시작**을 누릅니다.
2. 지도에서 현재 줄의 방 하나를 선택합니다. 전투 방에서는 적 구성·전술을 확인하고 시작 태세와 덱을 준비한 뒤 전투를 시작합니다. 시작 전에는 다른 경로로 돌아갈 수 있습니다.
3. 수동은 명령이 준비되면 시간이 멈춥니다. **카드 선택 → 필요하면 대상 변경 → 카드 확정**으로 진행합니다. 준비 화면·설정의 **전투 운영** 또는 전투 상단의 **오토 시작**으로 AI에게 카드 운영을 맡길 수 있습니다. 오토에서는 준비 완료와 적 예고에도 전투가 계속됩니다.
4. 승리 보상은 후보 세 장 중 한 장입니다. 기존 복사본과 즉시 교체할 수 있으며 다음 방으로 넘어가기 전에는 되돌릴 수 있습니다.
5. 중간 확보 지점에서는 얻은 카드가 영구 수집에 남습니다. 최종 보스를 이기면 나머지 카드도 확보합니다.
6. 강적 승리 후에는 진화 카드 또는 생존자 HP 12% 회복 중 하나를 고릅니다. 특수 후보와 카드 보상은 양쪽 모두 제공합니다. 완주하면 추가 영구 카드 한 장을 얻습니다. 수집 상한을 넘긴 보상은 전술 조각으로 확보하고, 거점에서 조각 3개로 원하는 카드를 수집하거나 다음 출정의 첫 전투 손패에 시작 덱의 카드 한 장을 예약할 수 있습니다. 예약 취소·예약 카드의 덱 제외 시 조각을 돌려받습니다.

태세 변경은 다음 기본 행동 판단 시 적용되고 3초간 유지됩니다. 적용 전 다시 누르면 취소합니다. 카드 상세 아래에는 발동·현재 예고된 적 타격·다음 명령의 순서를 표시합니다.

대기는 명령과 손패를 보유하고 전투를 진행하며, 새 적 카드 예고에 다시 정지합니다. 선택 카드 교체는 전투당 2회입니다. 교체한 동일 카드가 곧바로 다시 나오지는 않지만 같은 기술의 다른 복사본은 나올 수 있습니다.

오토의 **직접 개입**은 시간을 멈춥니다. 명령이 준비돼 있으면 직접 카드·대상을 선택하고 확정한 뒤 오토로 복귀합니다. **오토로 돌아가기**로 취소하면 명령을 소비하지 않습니다. 충전 중에도 멈출 수 있지만, 카드 사용은 충전이 끝난 뒤 가능합니다. 오토를 재개하거나 수동으로 전환해 충전을 이어가세요. 오토와 플레이어가 손패 교체 2회를 함께 사용합니다. 지도·보상·진화·덱 편성은 직접 선택합니다.

키보드: **1~5** 카드 선택, **Enter** 확정, **W** 수동 대기, **R** 선택 카드 교체, **A** 오토/수동 전환, **Space** 오토 개입·재개 또는 수동 명령 재개·충전 중 정지, **Esc** 개입 취소 후 오토 복귀.

- 동료 네 역할, 역할별 두 태세, 공격·회복·차단·도발·보호막·피해 감소·표식·둔화 등 카드 20종.
- 전체 덱 20장·손패 5장, 자유로운 역할 비율, 개별 카드 수량·기술별 편성 제한, 빠른 편성 프리셋.
- 첫 명령 5초, 이후 카드별 명령 회복. 일반 카드 즉발과 강한 기술 준비시간을 기본으로 적용하며 설정에서 기존 준비시간 방식도 선택 가능.
- 적의 실제 덱·손패·버림패와 독립적인 명령 회복, 전장과 손패에 따른 카드·태세 AI. 공통 효과 판정으로 공격·방어·회복 처리.
- 선택형 전투 오토: 현재 아군 손패와 공개된 전황으로 카드·대상 선택, 긴급 회복·예고된 공격 차단·한 장 교체, 설정 태세 유지, 판단 이유 표시와 즉시 개입.
- 일반 교전 다섯 종류의 서로 다른 전술과 최종 보스의 단계 전환, 강적 변형. 적 공격 예고와 표적·차단·도발 상태 표시.
- 방패병 보호 태세의 어그로, 아군을 위협하는 적 우선, 가까운 아군의 최종 피해 20% 대신 부담. 압박의 공격·밀치기, 검사의 추격, 사수의 거리 유지, 지원가의 회복·둔화.
- 출정마다 달라지는 방 선택지와 적 조합·보상. 총 10개 방 방문, 4·8번째 방에서 카드 확보, 마지막 보스.
- HP·전투불능 유지, 회복 방에서 30% 회복과 복귀. 카드별 한 번의 출정 한정 진화.
- 새 카드 획득·출정 중 덱 교체·영구 확보·실패 손실·성공 정산, 캐릭터 레벨 상한 5.
- 자동 저장과 전투 중 이어하기, 저장 JSON 다운로드·불러오기, 출정 결과와 전투 통계, 플레이 안내, 1~2배속, 반응형 화면.

이전 전투 비교판은 `lab.html`에 보관했습니다. 이 버전과 저장을 공유하지 않습니다.

## 저장 규칙

보유 카드와 출정은 브라우저의 `afterglow-expedition-v1`에 저장합니다. 거점·설정·수집 화면에서는 진행 중 전투 시간이 흐르지 않습니다. 탭이 숨겨지면 전투를 일시 정지합니다. 이어하기에서 일시 정지 상태라면 **전투 계속**을 누르세요.

확보한 새 카드의 영구 ID와 출정 카드 ID를 연결해 중복 지급을 막습니다. 강화는 영구 수집에 복사되지 않습니다. 보상 후보·선택 결과·지도·전투 상태도 저장하므로 불러오기만으로 새 보상을 추첨하지 않습니다. 브라우저 데이터를 지우기 전에는 설정에서 저장 파일을 내려받으세요.

## 검증

```powershell
node smoke.cjs
node simulation.cjs
node browser-check.cjs
node layout-check.cjs
node auto-browser-check.cjs
node auto-layout-check.cjs
node auto-comparison.cjs
node legacy-smoke.cjs
```

`smoke.cjs`는 실제 전투·출정 규칙과 수정 결함, 새 시스템의 준비·교체·적 전술·단계 전환·복기를 검사합니다. `simulation.cjs`는 두 준비시간 설정·안전/위험 경로·다른 덱과 전략을 비교하며 새 보상 카드의 교체와 실제 사용, 대기·교체·태세 변경을 기록합니다. 각 기능을 하나씩 끈 비교도 실행하며 전투 직후 평균 HP·전투불능 집계·차단 횟수를 함께 출력합니다. 덱 비교 세 종류는 같은 전체 수집 목록과 레벨 1에서 시작하며, 기본 덱 비교는 초기 수집 상태를 사용합니다. `browser-check.cjs`는 실제 브라우저의 전체 흐름, `layout-check.cjs`는 1280×950·1280×720·390×844에서 전장·손패·예고·확정 버튼이 함께 보이는지 검사합니다. 두 화면 검사는 Playwright와 Chromium을 사용하며 현재 PC의 번들 런타임 경로가 포함되어 있습니다.

`smoke.cjs`에 포함된 `auto-check.cjs`는 실제 자동 전투, 회복·차단 판단, 숨겨진 적 손패와 판단의 독립성, 태세 보존, 수동 개입과 명령의 중복 소비 방지, 저장 호환·복원을 검사합니다. `auto-browser-check.cjs`는 실제 화면의 전환·개입·저장·다음 전투와 엔진의 자동 운영 완주를 검사합니다. `auto-layout-check.cjs`는 오토·충전 중 개입·준비 완료 개입의 화면과 키보드 복귀를 확인합니다. `auto-comparison.cjs`는 자동 운영 72개 전투와 비교 전략 72개 전투, 자동 운영 원정 72회를 실행합니다. 원정 경로·보상 선택은 검사 도구가 맡고, 카드 판단은 게임 엔진의 오토 기능이 수행합니다.

자동 검사와 시뮬레이션은 규칙·진행 가능성을 확인합니다. 최종 재미와 난이도는 사용자 플레이로 조정합니다. 제작 범위는 도형과 아이콘으로 표현하는 브라우저 한 구역이며, 정식 3D 그래픽·상용 배포·추가 캐릭터 제작은 포함하지 않습니다.
